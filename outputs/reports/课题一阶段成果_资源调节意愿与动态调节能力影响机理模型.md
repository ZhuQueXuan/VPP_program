# 阶段成果：虚拟电厂资源调节意愿与动态调节能力影响机理模型

## 1. 模型要解决的问题

虚拟电厂资源的实际响应行为不能仅由额定容量解释。实际响应不足可能来自两种不同原因：

1. 资源具备物理调节能力，但用户不愿意开放；
2. 用户愿意参与，但资源当前状态不具备足够调节能力。

因此，本研究将资源行为划分为“调节意愿形成”和“动态调节能力形成”两条作用通道，并通过场景匹配、安全校核和历史可靠度修正，得到实际可信可调用能力。

## 2. 模型总体结构

```text
市场信号、用户特征、业务约束、历史体验
                    |
                    v
          收益—成本—风险感知
                    |
                    v
             调节意愿 W(t,m)
                    \
                     \
                      > 可信可调用能力 A(t,m)
                     /                |
                    /                 v
          动态调节能力 C(t)      实际响应行为 Y(t,m)
                    ^                 |
                    |                 v
物理属性、实时状态、环境参数、运行约束
                              收益、偏差、损耗反馈
```

模型包含：

- 输入因素层；
- 中间作用机理层；
- 意愿与能力状态层；
- 场景校核层；
- 实际行为与反馈层。

## 3. 调节意愿形成机理

### 3.1 影响因素

| 因素类别 | 主要变量 |
| --- | --- |
| 市场收益 | 补偿价格、峰谷价差、容量收益、预计净收益 |
| 调节成本 | 生产损失、舒适度损失、出行影响、设备损耗 |
| 市场风险 | 收益波动、偏差考核、违约成本 |
| 任务属性 | 调节方向、目标功率、持续时间、调用频率、通知时间 |
| 用户属性 | 价格敏感性、风险偏好、绿色偏好、平台信任 |
| 历史反馈 | 历史净收益、履约结果、负面体验、调用疲劳 |

### 3.2 作用路径

```text
补偿价格、市场收益
        → 提高净收益感知
        → 增强调节意愿

生产、出行和舒适度影响
        → 提高不便及机会成本感知
        → 降低调节意愿

偏差考核和收益波动
        → 提高风险感知
        → 降低调节意愿或导致保守申报

历史收益及良好履约体验
        → 提高平台信任和收益确定性感知
        → 提高后续参与概率和能力开放比例
```

### 3.3 作用形式

- **阈值效应**：补偿需要先覆盖机会成本，达到最低接受阈值后，参与意愿才明显提高。
- **边际递减**：补偿继续增加时，对意愿的促进作用逐渐减弱。
- **疲劳效应**：调用频率或持续时间过高，会降低后续参与意愿。
- **滞后效应**：历史收益、考核和用户影响会作用于下一周期意愿。
- **资源异质性**：工业负荷更关注生产损失，充电桩更关注离站需求，空调更关注舒适度。

### 3.4 意愿状态表达

调节意愿不是单一变量，建议表示为：

```text
W_i(t,m) = [
  W_part,   参与当前任务的概率
  W_open,   愿意开放的能力比例
  W_keep    在任务持续期间保持响应的概率
]
```

概念模型：

```text
W_i(t,m)
= f(
  预计收益 - 调节成本,
  风险感知,
  调节任务属性,
  用户偏好,
  当前业务需求,
  历史参与反馈
)
```

## 4. 动态调节能力形成机理

### 4.1 影响因素

| 因素类别 | 主要变量 |
| --- | --- |
| 物理属性 | 额定功率、容量、响应速度、爬坡速率、调节精度 |
| 实时状态 | 当前功率、SOC、设备启停、在线车辆数、室内温度 |
| 环境参数 | 光照、云量、温度、湿度、季节、时段 |
| 业务状态 | 生产阶段、车辆离站时间、目标SOC、人员及营业状态 |
| 安全约束 | SOC上下限、温度边界、工艺安全、舒适度边界 |
| 历史状态 | 前次调用、恢复时间、反弹负荷、设备健康度 |

### 4.2 作用路径

```text
物理属性
  → 确定理论功率、能量和响应上限

实时运行状态
  → 确定当前剩余功率空间和剩余能量空间

环境参数
  → 修正资源可用出力、基础负荷和预测可信度

业务及安全约束
  → 限制可用时间窗口和最大持续时间

历史调用及恢复状态
  → 修正连续调节能力和当前可用概率
```

### 4.3 动态能力状态表达

```text
C_i(t) = [
  P_up,       向上调节功率
  P_down,     向下调节功率
  E_up,       向上可调电量
  E_down,     向下可调电量
  T_resp,     响应时间
  T_sustain,  最大持续时间
  T_recover,  恢复时间
  R_ramp,     爬坡速率
  Acc,        调节精度
  Avail       可用概率
]
```

概念模型：

```text
C_i(t)
= g_i(
  资源物理属性,
  实时运行状态,
  外部环境,
  基线用能需求,
  业务和安全约束,
  历史调用状态
)
```

其中，`g_i`随资源类型变化：

- 光伏：由光照、预测出力、当前出力及配储状态共同决定；
- 储能：由SOC、功率、容量、温度和后续SOC计划共同决定；
- 充电桩：由在线车辆数、当前/目标SOC和剩余停车时间共同决定；
- 工业负荷：由生产阶段、当前负荷率、工艺约束和库存共同决定；
- 空调负荷：由室内外温度、建筑热惯性和舒适度边界共同决定。

## 5. 意愿与能力的交互机理

调节意愿和动态能力不是简单并列关系，而是共同约束实际行为：

1. **能力是基础**：没有剩余客观能力时，提高补偿也不能产生响应。
2. **意愿是开放条件**：设备具备能力，但用户未授权时，能力不能被调用。
3. **业务状态同时影响两者**：生产任务既会降低参与意愿，也会压缩客观能力。
4. **市场任务形成匹配要求**：资源必须满足响应时间、持续时间和精度等要求。
5. **历史执行形成反馈**：收益、偏差和损耗会更新后续意愿、状态及可靠度。

## 6. 可信可调用能力模型

资源在时刻`t`面向调节场景`m`的可信可调用能力定义为：

```text
A_i(t,m)
= C_i(t)
× W_open,i(t,m)
× Q_match,i(t,m)
× R_history,i(t)
× S_safe,i(t)
```

其中：

| 变量 | 含义 |
| --- | --- |
| `C_i(t)` | 当前客观动态调节能力 |
| `W_open,i(t,m)` | 用户面向该场景愿意开放的能力比例 |
| `Q_match,i(t,m)` | 资源能力与任务方向、速度、持续时间和精度的匹配程度 |
| `R_history,i(t)` | 根据历史可用率、成功率和响应偏差形成的可靠度 |
| `S_safe,i(t)` | 设备、电网和业务安全约束校核结果 |

上述公式是阶段性机理表达，具体函数形式和参数需要利用实际数据进行验证。

## 7. 实际响应与反馈机制

```text
实际响应行为
= h(
  可信可调用能力,
  控制指令,
  通信和执行状态,
  随机扰动
)
```

实际响应产生四类反馈：

| 反馈 | 更新对象 |
| --- | --- |
| 实际净收益 | 用户收益体验和下一次参与意愿 |
| 响应偏差及考核 | 风险感知和历史可靠度 |
| 设备损耗及状态变化 | 后续动态调节能力 |
| 生产、出行或舒适度影响 | 后续授权范围和持续参与意愿 |

由此形成：

```text
影响因素 → 意愿与能力 → 可信能力 → 实际响应 → 结果反馈
                                      ↑              |
                                      +--------------+
```

## 8. 模型可验证变量

### 调节意愿观测

- 是否接受调节邀约；
- 申报能力占客观能力的比例；
- 可接受持续时间；
- 是否中途退出；
- 补偿变化前后的参与率。

### 动态能力观测

- 上下调功率及电量；
- 响应时间；
- 最大持续时间；
- 恢复时间；
- 调节精度；
- 当前可用率。

### 实际行为观测

- 实际调节量；
- 指令完成比例；
- 响应偏差；
- 任务成功率；
- 调节后反弹；
- 净收益。

## 9. 模型验证方法

| 研究内容 | 建议方法 |
| --- | --- |
| 是否参与 | Logit/Probit或广义线性混合模型 |
| 能力开放比例 | 分数响应模型或Beta回归 |
| 价格和持续时间阈值 | 分段回归 |
| 环境及状态对能力的影响 | 混合效应模型或广义加性模型 |
| 客观能力边界 | 物理约束模型加数据修正 |
| 因果作用路径 | 结构因果模型和因果图学习 |
| 影响因素敏感性 | 参数扰动和敏感性分析 |
| 反馈与滞后效应 | 面板数据或时序模型 |

## 10. 阶段性结论

本研究提出的影响机理模型可以概括为：

> 市场信号、用户偏好和业务约束通过改变收益、成本与风险感知形成资源调节意愿；物理属性、实时状态、环境参数和安全约束通过改变功率、能量与时间边界形成动态调节能力；调节意愿与动态能力经过场景匹配、历史可靠度修正和安全校核，共同决定资源的可信可调用能力及实际响应行为；响应结果进一步反馈至下一周期的意愿和能力。

该模型实现了：

1. 区分资源“愿不愿调”和“能不能调”；
2. 解释不同因素的作用对象和作用路径；
3. 体现阈值、交互、滞后及资源异质性；
4. 将理论机理映射为可观测变量和可验证模型；
5. 为多维行为特征库及后续资源智能分类提供基础。
