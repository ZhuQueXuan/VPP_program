## 4. 历史iFlex候选baseline与划分（非当前主动协议）

- 比较：B0合法历史/日历基线；B1既有价格与事前状态透明线性/Ridge基线。
- 预测：住户实际小时负荷；以冻结基线定义窗口变化，保留参照误差。
- 评价：MAE（kW）为主，按完整事件与独立日期汇总；窗口电量误差（kWh）、缺失、负变化与失败为辅助。
- 预处理、参数与阈值只在训练/验证内确定；测试不参与基线定义或选择。可合法使用留出住户在截点前已知的自身历史，但不使用其目标事件结果训练跨户模型。
- 当前v2 split_id：待准入后冻结。旧协议入口：`work/resource_regulation_behavior_causal_decomposition/stage1_20261012/behavior/frozen_protocol.json`。
- 原划分若变更，保留旧协议并生成新版本；新旧得分不混合比较。既往使用状态须随分区登记。
- 完整解析失败时，部分资料也必须重新准入，不能因旧样板曾运行就自动使用；少量独立日期即使通过核验，也不自动满足复杂模型准入。
