# 86条弱短时段漏检的原因核查

仅分析已保存的低幅压力测试，不改算法，不新拟合、不生成新数据、不调阈值。`known_response_duration`新版与`duration_fusion`旧版保留，原CPOP/LABS对照不动，第一部分之外和报告不处理。

## 结论

121条“真值超过0.15kW累计不超过60秒”的测试记录中：

| 环节 | 在真实过线位置漏检 |
|---|---:|
| 原CPOP输出按原阈值判断 | 82 |
| 旧状态/时长支持修正后 | 86 |
| 新整任务判断及直接时长校正后 | 86 |

集合逐一吻合：82条前级未命中+4条旧状态修正额外丢失，旧修正救回0条；新整任务证据在121条中全部通过，新增误拒0条。**主要应改局部信号检出和阈值附近的定位，而非再次单独调新整任务分类器或总时长回归。**

86条里38条整任务没有正时长，48条仍报正时长但报在真值过线位置之外。不能把86解释成86次整任务被拒，也不能把误报出的其他位置当真响应检出。该指标沿用旧“时长支持曲线”的位置掩码；新版直接时长模型本身不产生新起止位置，公共API的原CPOP结构曲线仍单独保留，不能把86解读成新时长模型输出了一条新的漏检曲线。

## 前级82条为什么没命中

- 33条在真位置的CPOP值不超过0.04kW，属于基本压平；另外49条还留有大于0.04kW的小幅值，但没有达到原0.15kW阈值。0.04仅为本次描述分组，并未改成新的判定阈值，也不证明对应小幅值已被可靠识别为动作。
- 59条在真位置至少有一个原始观测格超过0.15kW，CPOP后却没有过线；其余23条原始观测本身就全低于阈值。因此既有拟合压平/削峰，也有原始弱信号受噪声影响，不能统一归咎为CPOP求解错误。
- 82条中53条的真实峰值仅比阈值高0.005kW，26条高0.03kW，3条高0.10kW。声明噪声标准差为0.05kW，阈值附近极易翻转。
- 具体例 `cpop-short-7742300-one_bin_response-1-gaussian`：第1440—1500秒真实0.18kW、原始观测0.2410kW，CPOP仅0.006716kW且原生拐点数0，旧版随之为0。新整任务变化分数0.88545已通过0.025，但代码在旧时长为0时直接保留0，无法救回这次局部动作。这是现有结构的限制，不是新分类器把它拒掉。

## 后级额外4条为什么丢

均为振荡响应的真实短暂过线部分。旧状态模型在正确位置给出过低的状态分数，并把数值压到0.091—0.129kW，低于0.15；新整任务分数均大于0.99，没有拒绝。

四例的CPOP过线段宽分别120、70、80、120秒，因而不满足旧规则“拟合后的过线段≤60秒才保护”。真实过线只有30或60秒，CPOP把它拟宽后，短段保护就失效了。例 `fine-7742301-oscillatory-0-single_sample_spikes`：真值140—170秒过线，CPOP130—200秒共70秒；真位置CPOP最高0.17464，旧修正后最高0.10517，整段真位置被压低。`additional_retained_losses.json`和`independent_checks.json`保存四条逐点原值、模型分数和保护条件。

## 必须纠正的统计含义与覆盖缺口

这121条不是121个物理短动作：

- 54条是真正持续一分钟的矩形短动作，漏32条，全在CPOP前级已漏。
- 67条是持续较长的振荡响应，仅超过0.15kW的累计时间短，漏54条，其中50条前级漏、4条旧修正漏。

因此之前把86条统称“真实短响应漏检”不够准确，应拆成**真实一分钟短动作漏32条**与**长振荡响应短暂过线位置漏54条**。121条来自37条基础轨迹，86个失败变体来自31条基础轨迹，不是86个独立实车事件。

另核到测试覆盖缺口：该压力集按排序后的基础任务循环分配固定峰值，形状与幅度有关联；10秒采样的`one_finebin_response`和`one_minute_response`各18个基础任务，峰值全是0.08/0.13/0.145kW，均低于有效阈值，没有进入上述121条。所以不能用这组121条证明10秒采样下真正弱短动作的召回。上一轮另有连续幅度检查，但其结果不能填作本组原本没有的样本；本次不补生成数据或改写旧成绩。

## 下一步更合适的方向（未实施）

先分清“有没有发生物理变化”与“达到0.15kW多久”。前者不能被一个过线掩码替代；后者仍保持既定物理标准。

优先验证原始量测局部候选与CPOP候选并行：有局部变化证据的短动作即使CPOP拟平，也允许进入事件级复核，不能被“旧时长为0就永远为0”挡住。复核后再估起止/过线持续时间，让新时长估计对应具体位置。短段保护需依据局部事件证据，避免只看CPOP拟合宽度；不能简单加长保护窗、降低物理阈值或凡孤立点都保留/删除来求胜。

正式比较应把物理短动作、长响应短暂过线、短异常/持续异常分开，并让幅度与时长独立覆盖1分钟/10秒网格。在新数据上同时检查真位置召回、误报、累计/最长时长；不得只凭总时长变准或整任务判正就算救回漏检。新增局部候选是否真的可区分异常仍待验证，本次没有运行或采用候选。

完整逐条数据在`trace.json`，分组计数在`diagnosis.json`，形状/幅度覆盖在`shape_amplitude_coverage.json`。独立逐格计分与四条旧模型原生分数复放已核对；生产代码、所有模型和被核旧科学结果SHA保持一致。
