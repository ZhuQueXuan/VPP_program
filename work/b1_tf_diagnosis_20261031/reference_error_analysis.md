# 参考残差与时长特征错误：已见pilot全量诊断

2026-10-31。本件只分析已完成pilot的4个测试块，256个唯一基础任务、128原用户；强/弱/null为配对变体。重算旧参考、事实、评价真值和已保存拟合曲线，没有调用预测器、拟合器或优化器，没有选新参数。它不是新独立测试或正式报告。

**最直接的发现是：参考正偏尾部与两法共同误检相伴；GLS又保留了更多原始残差中的弱越阈片段。弱响应“很少整条漏掉”也没有保证时长准，GLS的大部分时长损失发生在已经测出响应、但累计时长被缩短的记录上。** 这些事实需要分别解决，不能统一归为求解失败或只调低检测门槛。

## 1. 参考平均不错，任务内尾部仍足以影响阈值

误差统一定义为“预测参考−模拟真实未调节参考”；正值会抬高观测减载。只取一次基础任务，不把强弱/null相同参考重复计数。

| 256个唯一任务的口径 | 结果 |
|---|---:|
| 前后观察全60格pooled RMS | 0.058615kW |
| 任务内30格pooled RMS | 0.061190kW |
| 任务内平均有符号误差 | −0.015161kW |
| 每任务均偏5%/95%分位 | −0.095698 / +0.095504kW |
| 均偏为正的任务 | 92/256 |
| 均偏≥0.05 / ≥0.10 / ≥0.15kW | 28 / 13 / 2个任务 |
| 任一任务格参考误差≥0.15kW | 4个任务，共50格 |
| 参考误差≥0.10 / ≥0.05kW | 390 / 955格，分母7680任务格 |
| 参考误差≤−0.15kW | 43格 |

每条任务内误差用30格时间作最小二乘线性斜率，仅作描述；平均−0.000420kW/分钟，5%/95%分位−0.002989/+0.002973，最小−0.004382、最大+0.004761。它不是本轮拟合新参考模型，也不是将整个误差认定为直线。误差既有正尾又有负尾，不能统一把预测参考减一个常数求误检下降。

逐格恒等式已核：`原始减载残差 = 真实减载 + 参考误差 − 计量噪声`。这说明参考误差确实进入过程观测，但单个误差与输出的关联还不足以分配它对MAE的因果份额。

## 2. null误检24对6：共同参考尾部与保留规则都有关

CP计量σ=.05的6条误检全部包含在GLS的24条之内；GLS独有18条，CP独有0条。共同/独有按唯一task_id配对，分母null256；强弱中相同无动作轨迹不加作独立样本。

|---|---:|---:|---:|
| 任务内平均参考偏差 | +0.132539kW | +0.085233kW | −0.026770kW |
| 原始残差已有任一格≥0.15kW | 6/6 | 17/18 | 2/232 |
| 原始残差连续≥2格越阈 | 6/6 | 9/18 | 0/232 |
| 原始残差连续≥5格越阈 | 1/6 | 0/18 | 0/232 |
| 原始越阈总格数 | 82 | 93 | 3 |
| GLS拟合越阈总格数 | 77 | 80 | 0 |
| CP计量σ拟合越阈总格数 | 49 | 0 | 0 |
| GLS均假时长 | 770秒 | 266.67秒 | 0 |
| CP计量σ均假时长 | 490秒 | 0 | 0 |

共同6条参考均偏全部≥0.10kW，范围+0.1074至+0.1644；GLS独有18条均偏也全为正，范围+0.0340至+0.1383。可观察到的机制是：背景预测正偏形成低水平正残差，计量噪声使部分格越过0.15，过程方法对这些片段保留程度不同。

**不能说GLS把24个原本干净任务全部拟合成响应。** 其中23条在拟合前已有越阈格，只有1条原始任务窗完全不越阈、拟合后首次越阈。全部null原始残差共25条任务/178格越阈；GLS输出24条/157格，它总体减少了越阈格，而没有达到CP的抑制程度。GLS误检组内存在局部扩张：19个GLS阳性格的原始同格低于阈值，同时有37个原始阳性格被拟合压下，净格数减少18。故需要区分“更容易保留短小片段”和“凭空创造整次响应”。

GLS误检24条中5条拟合任务峰值超过完整60格原始残差最大值；所有null中共12条出现此数值现象，其中7条仍未越阈。它值得结合GLS几何检查，但协方差加权平滑并非必是凸平均，这个现象本身不证明求解错误。本诊断没有改Σ/λ，也不能把标准TF与GLS差异全归于协方差，因为二者的λ同时不同。

这些分组支持“共同参考残差＋过程保留规则共同相关”的判断。哪一部分能由合法事前误差模型实际消除，仍需root正在安排的受控参考替换来判断；不能据本表报告参考贡献百分比。

## 3. 弱响应很少整漏，为什么MAE仍大

每个任务定义：FP格=真实低于阈值但拟合越阈；FN格=真实越阈但拟合低于阈值。严格有：

`时长偏差 = 60×(FP−FN)`；`时长绝对误差 = 60×|FP−FN|`。

逐格位置错配为`60×(FP+FN)`，它等于时长绝对误差再加`120×min(FP,FN)`。因此FP/FN会在总时长上抵消，时长恰好正确也不等于时段正确。这里是精确计数分解，不是参考/平滑/模型错设的因果分摊。

| 全部弱场景256条，含80条无动作 | GLS | CP计量σ=.05 |
|---|---:|---:|
| 真实阈上176条中整条漏成零 | 1 | 5 |
| FP格总数 | 170 | 87 |
| FN格总数 | 437 | 408 |
| 每任务平均FP时间 | 39.84秒 | 20.39秒 |
| 每任务平均FN时间 | 102.42秒 | 95.63秒 |
| 净时长偏差 | −62.58秒 | −75.23秒 |
| 时长MAE | 136.17秒 | 113.67秒 |
| 时段错配平均时间 | 142.27秒 | 116.02秒 |
| FP/FN抵消时间 | 6.09秒 | 2.34秒 |

GLS虽整条只漏1条，但176条真实阈上中，72条只缩短、40条只延长、12条同时有FP/FN错位、51条阈值位置完全一致。只缩短72条的绝对时长误差合计24720秒；全漏那1条仅120秒。已经测出响应的真实阳性合计仍有31140秒绝对误差。另有80条无动作中的8条GLS误检，增加3600秒。CP计量σ对应无动作误差480秒。

两法全弱MAE差22.5秒，可精确记账为：真实阈上组绝对误差和差2640秒/256，加无动作组差3120秒/256。这个加法只分人群来源，不能解释为两个模型机制的贡献比例。GLS比CP的整事件漏更少，FN格却更多：检测到一小段后漏掉其余十几分钟，不再算“整条漏检”，但累计时长照样很差。

位置错位也确实存在：GLS有7个真实阳性任务FP=FN>0，时长误差为零但时段不对；CP计量σ有3个。主误差仍是缩短，不宜只围绕起点/时段移动优化。

最突出的sustained0.14q组：GLS零整漏，却35条仅缩短、4条混合错位，合计FN322格，净偏差−368.75秒。峰值0.14q=0.21kW距离判据0.15只有0.06kW，且缓升/波动的部分格离阈值更近；参考负偏、噪声和拟合对形状的变化都可能影响越阈格数。该组平均参考偏差−0.02084kW，但不能只用这个组均值把每条错误归因给参考。

按真实阈上时长分层，GLS/CP计量σ的MAE分别：1—3分钟43条为60.0/61.40秒；>3—6分钟37条为69.73/66.49秒；>6—15分钟26条为168.46/175.38秒；>15分钟70条为310.29/270.86秒。长而低幅的部分时长损失，比“短弱响应全漏”更值得优先解释。

### 参考偏差与时长误差的描述关联

176真实弱阳性中，参考任务均偏与时长有符号偏差相关：GLS0.583、CP计量σ0.519；斜率对应仅0.162/0.165。按均偏分三组：

|---|---:|---:|---:|
| <−0.05kW | 47 | 326.81 / −324.26 | 302.55 / −302.55 |
| [−0.05,+0.05) | 110 | 106.91 / −77.45 | 104.73 / −74.18 |

这是已见数据的描述分层，组间形状、真实时长等也可能不同；不据它认定剂量/参考偏差造成了多少因果误差，更不按这些真值分组设部署阈值。它提供的方向是：统一抬/降阈值会同时改变不同尾部的取舍，单追平均参考RMSE或整条漏检率不足。

## 4. 对下一步方案的约束

1. 优先保留整段参考误差与实际残差结构的诊断；如果研究条件化参考均值/误差模型，只能用独立已完成non_event与合法通知前条件。不要使用本次响应后的任务均值作参考校正，否则会吸收真实持续减载。
2. 过程候选要同时抑制无动作的零散越阈，又保住低幅持续响应的阈上格。仅增加起点或降低检测门槛没有解释当前主要的FN格；简单提高驻留可能再损伤brief3。
3. GLS与CP设置的原始误检率不同，24对6不是匹配raw-FPR下的功效比较；共同rank证据也没有替代时长误检指标。后续若声称改进，应在新独立验证中事先声明取舍，不在这256任务上调参。
4. 协方差估计中心化不移除本次均偏；同时，真实持续响应与低频参考漂移可能重叠。若主张将二者分离，需说明可用信息与可识别条件，并做同参考/任务/预算的消融；不能宣称加一个漂移项就一定解决。

本件没有确定新方法，也没有开始实现。它把原因约束收窄为“参考尾部和误差结构＋过程对弱片段的保留/缩短”，保留求解受控核验和oracle诊断的独立作用，不把关联当最终因果结论。

产物为`reference_error_analysis.py/json`。JSON含全部256参考行、3072方法任务行、24个任一方法误检任务的完整任务窗曲线及分层；78个读取科学输入前后SHA相同、44冻结源码身份核同，15511项恒等式/身份/计数检查通过。代码不导入模型或过程求解器；检查数不作为性能样本数，全部材料均为已见4块数据的诊断。
