## 下一轮可以执行的工作

1. **先做 ACN 技术执行核查。** 从开发组按限额降到原电流之下、仍高于原电流两类预定规则取窗，分别报告可见跟随、延迟范围、限额释放后功率轨迹及缺测率，按会话或用户汇总。可检验“约束是否压到原充电电流”能否解释执行差异。若要主张限额调节的因果量，仍需外部下发时刻、控制分配依据及同窗车辆状态。Electric Nation 可作独立复核来源，先核交易键、时间和分组。
2. **按同场任务补受邀分母。** 优先落一套小批次的数据合同，逐条通过资格快照、报价版本、参与状态、控制回执和遥测的对齐，再决定能否验证“报价→参加”和“状态→执行/恢复”。缺现场来源时，Calgary 的公开复制包可作为离散随机奖励备选，实际取得主表后再核用户—阶段完整分母与用电口径。
3. **站点小时另开分析。** 超市表若继续使用，先按当地时段、工作日、折扣机制、相邻时段优惠及可用预测记录核查共同支持。只有补到预测生成时间、优惠发布时间及主要定价约束，才适合进一步评估定价依据和站点用电关系。结果单位保持站点平均 kW 或完整一小时积分的 kWh。

逐项字段、方向、证据等级和最小采集键见 [evidence.md](evidence.md)。[samples.json](samples.json) 保存原始行号、时间、数值、缺测统计和输入哈希。用 `python work/b1_ev_factor_evidence_20261104/audit.py` 重放。该脚本读取 ACN 训练清单和 9 场原始遥测、超市小时表、Harvard 会话表。首轮输出仅为核查与描述统计。
