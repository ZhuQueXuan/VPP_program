# B1与B2职责、输入输出及共用边界核验

2026-10-30。按用户要求回原任务书和现用需求框架核对，再审查当前代码；本轮仅分析，不修改算法、训练模型、原实验、正式依据或报告。

**核验结论：B1和B2有不同的研究任务，也有合理的重叠。当前未发现把同一个训练模型换名重复开发成两项主算法的证据；已发现公共计算分散、新旧入口并行和字段口径差异。近期模板修复属于B1，但继续只追过程拟合性能，会挤占因素、阈值、敏感性和时序研究主线。**

“B1研究过去、B2预测未来”或“B1只看群体、B2只看单车”均不能作为最终分界。两者都可以查询不同激励、研究条件差异，也都可能输出响应量；应按要回答的问题、保证的结果及评价依据来分工。

## 2. 两者各自要回答什么

| | B1：全过程特征驱动的行为因素分析 | B2：融合用户意愿的单体容量与响应评估 |
|---|---|---|
| 核心问题 | 在什么条件下，哪些因素改变参加、开放、执行或恢复，改变多少、为什么？ | 对当前资源和具体候选任务，物理上能调多少、用户可能开放多少、预计兑现多少？ |
| 必须覆盖 | 全过程特征；变量角色与结构/识别；非线性、阈值、敏感性、差异；与目标相符的时序表示研究 | 状态和业务约束；相容可行轨迹/边界；许可、行为经济/绿色选择与条件执行；功率、电量、速度、持续、恢复及可靠性 |
| 可以有的查询 | 某人群或条件组在不同补偿下的平均结果、作用差及敏感性 | 同一资源/任务在不同补偿、风险和需求下的可行性、接受及交付情景 |
| 主要评价 | 特征测量误差；因素估计及识别边界；曲线/阈值/敏感性稳定性；解释或表示的增量 | 容量边界高估及可行性；交付/轨迹预测误差；选择/任务概率校准；恢复与业务约束满足情况 |
| 不能互相替代 | 发生过的减载量、平均作用不是物理最大容量；预测准确不自动证明因素因果作用 | 平均预计量不是可承诺量；选择概率不生成控制许可；能力预测好不证明因素解耦已经完成 |

例：同一30分钟减载任务，B1问“补偿从0.8提高到1.2，排除原有需求等差异后，响应改变多少”；B2问“当前这辆车还需充多少电、多久离站、能否调节、是否可能参加以及预计交付多少”。B1同样可以条件化，B2同样可以比较补偿方案。其区别不靠金额输入或响应输出的有无。

B1可以把参加作为待解释结果；估计补偿对最终交付的总作用时，实际参加又可能是处理后中介。B2可以在已参加条件下建执行模型，再计算整个人群的预计交付。同一字段在不同研究问题中的角色可以不同，不能强迫使用同一个控制变量表。

## 3. 输入输出应如何明确

| 调用用途 | 必要输入 | 输出 | 时间边界 |
|---|---|---|---|
| B1已发生过程识别 | 事件/表计身份、任务、指令和完整功率、同格未调用参考及来源、计量/判据、质量信息 | 减载曲线、幅度/电量、累计与连续时长、延迟区间、退出/恢复/回补及不可识别状态 | 可以读取完整本次任务及后窗；它们是被测量结果 |
| B1因素研究 | 一组历史事件及结果、事前补偿和条件、目标人群、结果定义、结构/比较及识别条件 | 因素角色/结构证据、支持内平均结果和对比曲线、分组差异、阈值/敏感性与不确定性；识别不足则关联 | 本次处理后的参加、实际退出、实付金额等不能偷偷变成总作用的事前控制 |
| B2单体任务评估 | 当前资源状态/参数、剩余需求与期限、候选任务和参考、已有许可、激励/收益风险方案、用户信息、合法历史及外部预测 | 可行轨迹/功率边界、选择/开放、条件执行与预计kW/kWh、任务概率、恢复与约束余量；可靠性/承诺无证据时不可用 | 当前查询只能使用调用前可得信息，不读本次未来实际功率、选择或最终离站结果 |

这张表规定研究职责，不表示所有字段均已实现。特别要区分当前代码的两种接口：

- **新B1连续因素入口**当前要传事件结果集、事前因素、实际金额和查询grid，每次估计曲线；独立冻结连续因素模型后仅传新金额查询，仍属于已规划的后续步骤。B1参考模型已有save/load，不能因此泛称B1没有持久化或不能预测。
- **现用B2**查询固定的已训练模型，输入当前声明和方案即可输出预测；它只支持单EV指定任务族，不是任意设备/时长的通用已验证预测器。

所以目前“输入金额就返回响应”的直观说法，省略了B1的历史样本、目标人群、任务与识别条件，也省略了B2的状态、可行性和选择/执行条件。

## 4. 哪些部分应该共用

以下是核验后的实现建议，本轮未执行重构。

| 共用对象/组件 | 合理共享方式 | 保留的差别 |
|---|---|---|
| 资源/用户/事件身份，任务、方向、单位和时点 | 同一原始记录和来源登记；共享信息可得性及失败状态规则 | B1研究总体或条件组，B2保持所查资源与方案；不同支持域须显式说明 |
| 未调用参考和计量处理 | 相同用途下共用预测器、历史、来源及误差说明；不重复训练一套仅改名的参考模型 | B2当前给定平坦b与B1估计未知参考不同；规划参照策略和观测参照不能无说明硬拼 |
| 过程特征定义及提取 | 同一套电量、累计/连续时长、速度、恢复计算可供B1测量、B2训练标签/轨迹摘要和评价使用 | 阈值、驻留、单位和服务标准必须参数化；不能强制全部用10%或全部用90% |
| 物理机制与约束核心 | B2据其求边界，B1据其检查变量、声明或结果是否合理 | B1实测电量核算不变成最大容量优化；不同任务的可行域不能移植成同一承诺 |
| 用户行为原始记录及合法历史表示 | 共用事前方案、选择、授权、执行、历史缓存和编码候选 | B1识别作用，B2预测选择/执行；各自变量角色及用途验证不能省略 |
| 通用统计/学习内核 | 同一回归/选择模型可作为共同底层；同一训练成果若适用可直接复用 | 不把同一次选择拟合计成两项独立创新；因果效应、预测校准和容量验证分别验收 |

共享不等于B2必须消费B1每个结果。应优先共享事实、定义和基础计算；作用曲线、历史表示或模型参数是否进入B2，要先确认任务、单位、目标人群、条件含义与支持域，再做增量验证。

**尤其不能把B1已包含未参加者的总体平均响应，再乘一次B2的参加概率。** 这会重复计入参加机制。当前源码没有这样连接，此项是后续融合风险，不是已发生错误。

## 5. 当前是否重复开发：逐项裁决

| 核查项 | 实现事实 | 判断 |
|---|---|---|
| 两个主体算法 | B1连续DR的结果回归/金额密度模型与B2的参加标签、接受后五状态模型不同 | 未发现同一训练模型换名重复；不能仅因都用回归、都输出响应就合并两项职责 |
| F0及EV物理核 | 新B1包内F0与旧路径字节相同；B2/历史分支用旧路径。B1用EV核prepare校验声明，B2用evaluate校核可行 | 已有实质复用，不应重新发明同一物理模型。副本/版本需继续可追溯 |
| 阈值/电量小计算 | b123旧B1额外计算90%累计/连续；B2桥接fine_features也写90%判据和任务电量 | 确有可抽共用的基础逻辑；目前不同用途保留有依据，不等于两套主算法重复，更不应在本次直接删冻结代码 |
| 新旧入口 | 新B1库与根b123并行；b123的B1仍是旧F0和二元因素表 | 有版本与调用路径分裂，应明确“当前独立B1”和“冻结兼容联调”，不能宣称新全链已经自动接入 |
| B1→B2历史 | 已实际接通过去3次事件的F0统计/PCA/AE，可选入口保留；研究未显示稳定预测增益，默认未替换 | 不能写“完全没接过”；也不能为连接形式强推无增量分支或重跑到赢 |
| 新B1连续作用→现B2 | 默认B2调用链未导入新连续曲线 | 当前缺这条新连接；它不是自动错误，也不能写成已实现融合。需按用途决定是否值得接 |
| RIDE与B2五模板 | RIDE拟合已经给定的实测差值；B2预测未来属于哪种预定状态的概率 | 都叫模板但拟合对象不同。前者不能当B2预测器，后者不能当未知参考实测过程识别器 |

```text
                    → D124 b2_adapter → D122 guards → D118固定B2模型
可选历史：D123历史接口 → 旧F0历史特征 → 可选预测头（未替换默认）
```

## 7. 有没有偏离主线，下一步应如何收拢

1. **近期RIDE/CPOP过程修复没有偏题。** 它属于任务书要求的全过程时序特征，并且解决了已发现的问题。但其成绩只能支撑过程部分，不能代替因素作用、阈值/敏感性或整体B1完成。
2. **B1当前有重心过度偏向过程优化的风险。** 接下来不宜继续无限扩模板、搜参数或只追一项曲线指标。应回到已批准步骤4—6：连续敏感性/阈值与冻结查询、明确用途的B1时序表示、最终独立全链比较。声明图/辅助筛选已有基础，不能称完整图研究不存在，也不能把它写成全部真实机制已自动发现。
3. **既有B2/B3不是因为本轮聚焦B1就变成越界。** 它们在当时有授权，是整体项目的可复用成果；当前不应继续训练B2/B3来代替B1缺项。B2单EV原型也不能代替多机制、现实行为/绿色、可靠性、深度时序和正式90%证据。
4. **不能把金额曲线直接当定价算法。** 因素作用和候选方案评估属于本课题；最优套餐、交易申报与运营定价是另外的研究职责，不能顺手扩进去。
5. **共享不以强行串接口为目标。** 先明确字段、结果定义、信息时点和版本，再决定最小共用组件及是否需要新连接；不为画一条B1→B2箭头强制采用无增量模型。

本次建议的最小共用范围是**数据/任务与参考契约、过程特征定义、既有物理核及合法历史**。共享行为或结果模型有条件，不建议把B1/B2合成一个无差别“金额→响应”黑盒，也不建议现在新增一个大平台/第三套预测器。
