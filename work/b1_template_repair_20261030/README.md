# EV模板修复与新数据CPOP比较

2026-10-30。用户已批准修当前模板初始化、回补和求解，再与原CPOP公平比较。本轮已完成修复、新数据比较和核验；报告未改，没有转用CPOP冒充改进。

正式实现为根 [B1算法/process/_ride_revised.py](../../B1算法/b1_algorithm/process/_ride_revised.py)，统一入口使用 `process_method="ride_revised"`。旧模板的显式 `ride_template`、原CPOP、默认路由均保留。本轮将新版保留为可直接调用的实现，不把有限任务结果推广成所有计量间隔的新默认。

## 具体修了什么

- **初始化：**依据实际提供的任务功率差确定起点、终点、爬坡、内部间断及回补的初值；补零爬坡/零释放分支。回补允许在任务结束前或后开始，不使用真值参数给初值。
- **回补：**原正模板及区间平均保留，释放后增加独立等待时间，内部gap不再同时承担末端等待。回补幅界可明确选择设备声明余量或用户配置比例。
- **求解：**两个幅度的有界线性问题直接求解，时间参数作有限确定起点搜索；M1/M2仍按完整8/10参数计复杂度。记录每个起点的终止状态，失败或耗尽解不参与选择。没有调用CPOP生成结果，也没有承诺全局最优。

之前的“能精确表达却估长10分钟”的末端等待正控，以及内部间断加等待等控制例，修复版任务时长误差均为0。43项功能/数学检查通过，首次发现“只在W后找回补”的开发错误已修，原失败日志 `check.log` 保留，修正后日志及收据另存。首轮开发、修正后同数据复算 `development_fix1` 都保留，后者不计成额外独立数据。

## 开发与测试如何分开

[protocol.json](protocol.json)在主拟合前确定；同一独立四形状生成器使用全部新种子和新用户，未用推断模板生成主面板。开发2块128事实、验证2块256事实，最终测试8块2048事实变体，对应1024个基础事件及正/零作用配对。压力检查另有256事实，不能把方法行或配对变体当独立重复。

验证没有显示CPOP时长优势，未据此追调。验证完成后先保存 [候选冻结](final_candidate_freeze.json)，再生成和运行测试。冻结源码完整放在 `test/source/`；主测试只运行一次，无扩大样本追分。

三方法使用相同功率、所选历史参考、任务、名义计量噪声及设备声明。参考仍用既有冻结模型和过去片段选择，不重训、不做旧失败的偏移校正。原CPOP保持beta=2log(n)和原生精确剪枝，源码未改；旧模板也未修改。新方法使用任务结构和设备界，CPOP不使用其中部分结构信息，这属于方法差别，不能把共同修复收益单独归给某一个参数。

测试主任务30分钟、1.5kW、完整1分钟计量，前后各15分钟、计量噪声标准差0.05kW。真值仅评价器计分。零作用允许有真实响应，表示金额不改变响应；没有把零作用样本当全体无动作。

## 新测试结果

主结果以正/零作用等权合并，误差越低越好：

| 方法 | 累计时长MAE/秒 | 平均曲线RMSE/kW | 真无动作误检 | 真有响应漏检 |
|---|---:|---:|---:|---:|
| 旧模板 | 280.75 | 0.19352 | 91/866 | 1/1182 |
| 原CPOP | 119.56 | 0.15003 | 99/866 | 0/1182 |
| 修复模板 | 104.21 | 0.13998 | 88/866 | 0/1182 |

修复版时长MAE比CPOP低12.84%，8块中7块更低；配对块均值差为−15.35秒，t型蒙特卡洛95%区间[−25.23,−5.47]秒。曲线误差差为−0.01005kW，区间[−0.01758,−0.00251]。原先固定的10%幅度、均值差区间、曲线非劣、经验误检/漏检及全分母等六项门槛均通过。[主评价](test/assessment.json)

这些区间描述这8个独立模拟块，不是真实设备可靠性或完整因果/过程区间覆盖率。误检仍约10%，参考偏差问题未被本次求解修复消除。

## 审查后的接口修正与成绩身份

独立审查发现，隐式采用设备余量会覆盖显式的比例上界。冻结测试完成后作了契约修正：新增 `revised_rebound_bound_policy`，默认 `configured_ratio` 尊重原配置；本次试验对应显式 `declared_headroom`，未知最大功率时透明退回配置比例。零余量返回精确0。另将非有限失败诊断格式化为null，并将所有失败起点诊断传到公开回退结果。

这次契约修正没有改变测试候选的观测算子、初值、目标、求解参数、BIC或检出规则。原冻结源和成绩完整保留。[合同复放](contract_replay_receipt.json)检查全部2304事实上的幅界等价，48个实际公开入口重算的输入摘要、曲线数组、全部特征及η逐项精确相同。新默认比例模式是另一个合同选项，没有拿它的未测试结果替代已冻结成绩。

本次性能数字仅对应下面的明确调用；每条记录若自带非空 `ev_config`，需同步设置，单条优先级不变：

```python
events = analyze_events(
    records, process_method="ride_revised",
    ev_config={"max_charge_kw": 7.2,
               "revised_rebound_bound_policy": "declared_headroom"},
)
```

设备最大功率需要使用实际声明，不能把模拟的7.2kW硬套其他设备。该界只约束拟合回补幅度，不证明整个轨迹物理可行。新版只验证完整1分钟计量，10秒/15分钟显式调用会给出原始回退，其他方法原路由保持。
