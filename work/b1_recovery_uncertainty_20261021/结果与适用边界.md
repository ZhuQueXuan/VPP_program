# B1恢复观测不确定性：结果与适用边界

2026-10-21。按D106后续路线和用户“继续”授权完成一个冻结观察方法工作包。旧8条未确认结果、旧F0及旧DML结论全部保留；没有重算旧测试来追求“全部恢复”。

## 1. 改进了什么

新增recovery.assess函数，计算自请求开始的有符号相对参考欠量及其区间。固定截止点报告“欠量不超过声明界限／仍超过界限／无法确定”；沿路径给同时带及首个可能/有依据满足界限的网格端点。后两项都不是连续物理恢复时刻或持续恢复保证。无动作也可核欠量，但“界限内”不代表发生了恢复动作。

核心改变是给观测精度不足一个明确结果。真欠量为0、而判据也要求精确0时，正常结果经常是无法确定；这不代表物理模型失败。ε取0/.005/.01/.02kWh，仅为计算前固定的数值敏感性，不是现场用能服务标准。

方法、推导及假设见[冻结说明](方法与冻结说明.md)、[protocol.json](protocol.json)。固定点正态区间和有限时点同时界的依据分别核对了[NIST正态分位](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3671.htm)及[Bonferroni方法](https://www.itl.nist.gov/div898/handbook/prc/section4/prc463.htm)。保证只在声明的高斯差值误差协方差及偏差界成立时适用，当前不提供真实噪声自动识别或校准。

## 2. 新样本与冻结条件

新种子731021；4种机制为最终欠量0、+.03、−.03kWh及全程无动作；5个观测版本各1000重复，合计20000条观测变体、4000个机制/基础噪声抽样。变体共享外生标准噪声，不当独立样本扩大数目。全部600—1800s请求、3600s固定截止、10s网格；新样本未用于调ε、置信水平或噪声参数。生成与区间估计合计约3.72s，仅CPU。

已知参数分别为差值误差边际σ=.05kW、AR1ρ=.8、参考偏差绝对界.02kW。参考偏差从600积分到3600，累计最多.016667kWh。实际控制欠量属于物理真值，不从结果里扣除。区间保存后才用独立结构公式计算评价欠量；训练/参数估计均未开展。

## 3. 固定截止与路径覆盖

下表以真实欠量为0的restored机制为例，每格1000次。固定截止区间名义95%；路径对1810—3600的180个预定端点使用至少95%的Bonferroni同时界。其覆盖分别评价，不把路径各点的95%误称为整条路径95%。

| 观测/假设 | 固定截止覆盖 | 全路径覆盖 | 固定截止半宽kWh |
| --- | ---: | ---: | ---: |
| 独立噪声，模型正确 | 95.6% | 99.9% | .004715 |
| AR1相关噪声，协方差正确 | 95.5% | 99.9% | .014040 |
| AR1误当独立 | **48.3%** | **50.4%** | .004715 |
| 参考偏差界计入 | 97.9% | 99.9% | .021382 |
| 参考偏差遗漏 | **0%** | **0%** | .004715 |

正确模型的1000次覆盖率有Monte Carlo误差。独立噪声95.6%的精确二项区间为94.14%—96.79%，AR1正确95.5%为94.02%—96.70%；这些是覆盖频率的抽样误差区间，不是现场恢复概率。已知偏差界使区间更保守，不能要求其恰好95%。路径99.9%说明该有限面板下联合界较保守，不说明全部真实场景均可靠。

其他机制不全超过95%经验覆盖：过量回补组独立噪声为94.1%、AR1正确为94.4%，对应1000次精确二项区间分别92.46%—95.48%、92.79%—95.74%，均包含95%。不据这些波动重抽样、改α或宣布模型理论失效。

参考偏差遗漏导致覆盖为0，相关噪声误当独立使区间过窄，说明只增加一个“置信区间”字段仍不够。真实参考误差和差值协方差没有可信依据时，只能条件于假设报告，或返回不确定性不可算；不能把IID默认值当实测保证。

## 4. 三状态判断的实际意义

同一真实已恢复机制：

| 条件 | 声明ε(kWh) | 在界限内 | 仍超过界限 | 无法确定 |
| --- | ---: | ---: | ---: | ---: |
| 独立噪声正确 | 0 | 2.3% | 2.1% | **95.6%** |
| 独立噪声正确 | .01 | 98.8% | 0 | 1.2% |
| AR1正确 | 0 | 2.2% | 2.3% | **95.5%** |
| AR1正确 | .01 | 30.1% | .1% | **69.8%** |
| 参考偏差界计入 | .01 | 0 | 0 | **100%** |
| 参考偏差遗漏 | .01 | 0 | **79.9%** | 20.1% |

不能从“区间含0”得出完全恢复，也不能为让AR1或参考偏差场景全通过而事后增大ε。正确模型下仍可能有约定概率的错误确定判别；错误率的分母为全部1000次，不能把“只在已确定者中”的错误比例套同一保证。

这里的改进不是提高恢复确认率，而是让“欠量、误差假设、观测精度和判断条件”对应起来。未恢复+.03、过量回补−.03及无动作的全部指标保留在[逐机制评价](metrics.csv)、[逐界限判断](decisions.csv)，负欠量未裁0。

## 5. 缺失、截断与接口

接口为assess(time_edges,reference,power_obs,deadline,sigma_kw=...,rho=...,bias_bound_kw=...)。功率为n个左端分段保持值，边界n+1，秒/kW/kWh显式转换。参数是调用方明确声明的有效差值误差模型；AR相关按采样区间索引定义，不外推成任意物理时距相关。

请求后累计范围内缺测则后续欠量/区间不可算；不跨缺口。未观察到原截止点则deadline_available=false/right_censored，可另报观察终点欠量和区间，不能将该点改称原截止。噪声协方差未知则保留点值、区间unavailable。首次可能/支持时点只对预定网格同时带解释；响应触发的随机停止不在本轮保证内。

## 6. 收口与接续

12项主微型算术/状态检查先于数据通过；正式独立1006项全部通过，见[independent_verification.json](independent_verification.json)。独立密集协方差传播核对AR递推，全部积分/区间最大差6.94e−17kWh，指标差最大3.63e−13来自独立覆盖频率二项区间分位算法，80行状态频率差0。主科学实现、协议、区间身份见[source_freeze.json](source_freeze.json)和[run_receipt.json](run_receipt.json)。没有用此方法回写D106结果或修改七类现用核。

本工作包到此收口：三状态及条件区间可作为B1后续全过程接口的候选表达。它不自动辨识真实误差、不证明真实用能服务恢复；真实使用须补同步量测/参考误差及独立需求。接续受约束图学习小包与多档阈值研究，原DML候选降对照保持，图学习也不得把先验方向冒充数据学到的机制。
