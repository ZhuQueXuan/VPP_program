# 充电桩B1参数化与功能验收

用户已批准通用化框架，并进一步明确先做好充电桩，其他资源逐步开展。本轮只实现并核对单个单向交流充电资源的功能，报告继续后置。

## 已实现

- 任务时长15/30/60分钟、请求0.1—22kW、10秒/1分钟/15分钟完整对齐计量格；前后窗、通知提前量、阈值比例、驻留时间及模板参数界可配置。
- 默认过程方法按实际格宽选择。1分钟和15分钟沿用参数化的原RIDE求解方法，10秒保留guarded CPOP组合；显式CPOP继续作为通用主对照。旧域数值保持不等于整个修改后的源码与原源码AST相同。
- 参考预测支持上述EV任务时长，仍用原模型及完整1分钟历史；本轮没有训练新模型或自动细化计量曲线。新任务签名不继承旧误差半宽，匹配也仅标作混合样本经验校准。
- 增加独立的服务电量核对：通知前声明剩余网侧电量和期限，用实际功率积分核对，分别返回满足、未满足、观察不足、不可用或输入非法。缺声明不阻断合法功率分析。
- 复用原EV能力核的输入检查，未用优化生成的可行计划代替实际响应。设备最大功率未知仍可核电量；不可能需求和超名义功率保留诊断。
- 两条激励入口按同一W/q任务分组，拒绝混合任务误算及同一电表同一物理窗口改名重复计入。标准多档AIPW方法保持。
- 显式非EV资源声明拒绝；省略资源字段兼容旧调用。未实现空调、V2G或站级协同。

| 场景 | 需求 | 实际已充入 | 返回 |
