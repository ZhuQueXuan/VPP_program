# 同一原始轨迹的粗细对齐与指令证据核验

结论：**细采样与指令确实增加了可观察的时间和形态信息，但现有记录不足以验证“真实短响应／短毛刺／持续异常”的可靠三分类。现在没有依据据此删点、填gap或采用下一版算法。**

本轮只读原始数据，新增对齐记录、描述量与核验图；没有训练、运行CPOP/LABS、修改过程算法、注入噪声、改计量值或写报告。

## 本次实际核查了什么

1. 既有144个100毫秒事件，来自18个recording；从各自原始约21ms电流/指令NPZ重算100ms、1s、5s、10s。每个粗格与它包含的细格一一对应，均直接使用同一批原始样本，不用另一辆车或另一个事件代替。
2. 同时回查完整原始Parquet的指令上下文：既有候选账本共9547次指令变化，9529段相邻指令保持区间，其中823段不超过10秒。此前144样本要求新指令保持15秒，所以先天不能代表这些短时往返。
3. 按指令本身枚举“10秒内准确返回前值、幅度≥2A”的全部162次往返，来自10个recording，时长.016001—9.24秒，中位.567秒。初次沿用历史两端≥6A过滤得到17次；补充保留145次涉及0A启停，形成162次全量清单。初次清单/协议保留，补充原因在`protocol_addendum.json`；两次都不按电流效果选事件。
4. 直接从同一Parquet提取这162个原始20秒窗口，保留三相电流、有功功率、电压、原指令及原始行号。共154336个窗口内观测行（重叠窗口重复保留），没有合成轨迹或替换缺失点。162个事件×3相=486相行，加旧144相行，共630相行；不是630个独立样本，也不是独立新现场留出集。

## 对齐是否可信

- 全程用整数微秒和原始行顺序，半开区间分箱，以原始指令起变为0。微秒时间编码不代表硬件具有微秒精度。
- 100ms聚合与既有144事件的原均值、原计数、归一化进度全部一致。
- 原始点在每一个尺度都被恰好计入一个格。10s尺度的[-10,0)、[10,20)超出已提取窗口，显式标记为不完整，原有观测仍保留；完整比较使用[0,10)格，不补齐、不冒充完整30min。
- 粗格均值与按原始观测数量加权的细格均值相同，最大差约1.1e-14A。不能把每个细格等权平均，因为有些细格含4个、有些含5个原始点。
- `audit.py` 用独立bincount路径复核630相行、四种粒度、所有指令边沿及源文件，11970项通过，最大独立均值差8.9e-14A。核验项数不是性能样本量。

## 得到了哪些额外依据

**一，突跳快不等于毛刺。**既有144事件中，有7个原始10%→90%变化用时≤100ms，但100ms曲线随后达90%变化幅度连续至少5秒。第一个固定排序例子为VW记录`:4598:L1`：10%起变在.756s，90%在.777s，变化仅21ms，随后100ms达标段14.2s。若只因边沿很尖就抑制，会损害有持续支持的动作。

**二，单个粗格确实会丢失过程信息。**同例[0,10)粗格进度均值约.877，小于.9，而其100个100ms格中92个超过.9。144事件里有27个“10s均值未达.9，但至少一半100ms格达.9”的情况。这证明粗格均值不能替代格内达标时间。这里的90%是原电流指令跟踪描述阈值，不是EV净减载.15kW阈值，也不是预测准确率。

**三，可以观察短暂越阈和持续偏离，但不能自动贴故障标签。**144事件中19个存在≤200ms的短暂90%越阈片段；47个最后5秒归一化电流中位数未达到90%指令变化幅度。前者可能只是临界波动，后者可能与原需求、指令上限、动态过程或其他因素有关，均没有真实故障标签。不得改称19个毛刺、47个持续异常，也不能据此计算三分类准确率。

**四，指令确实提供了原先未使用的上下文，但短指令不等于真实短响应。**162次往返里，有70次在前后2秒内还存在其他指令变化，不能只解释成一个孤立动作。固定排序第一个例子是8A→0A→8A、持续7.122s，但L1原电流本来就为0，不能拿指令往返时长当成实际响应时长。其余所有相和原始指令也已保留，没有只选“看起来响应”的一相。

补充表中“活跃且前后2秒指令隔离”的L1有18个、所有相合计44相行，预先定义的“指令维持期间方向中位变化≥10%、连续原样本跨度≥100ms”描述量没有命中。**这不证明没有真实短响应**：它没有覆盖指令返回后的滞后动作，也不是经校准的响应判定；不能把这个零计数当成故障标签或新算法失败率。

## 能与不能确认的边界

| 问题 | 本轮证据 |
|---|---|
| 同一事件的粗细数据能否准确对应 | 能，按原始行和计数逐格核对 |
| 细采样是否比一个粗均值多信息 | 是，可看到格内持续、边沿、回撤与反复越阈 |
| 指令能否补充动作时序上下文 | 能，可区分单个保持指令、短往返和密集多次变化 |
| 能否把单个细点直接认定毛刺 | 不能，真实单格动作仍可能同形 |
| 能否把持续偏离直接认定故障 | 不能，指令并非实际用电/响应真值 |
| 能否验证三类真实区分率 | 不能，缺故障与实际短响应的可核实标签/独立证据 |
| 三相电流、功率、电压是否是独立故障真值 | 不是，同一记录仪的通道可能相关或由同源量计算 |
| 已提取20秒窗口能否证明30min全过程效果 | 不能；完整源文件还需按实际任务窗口另核 |

因此，上轮“10s采样下10s动作被抹掉”仍只说明v3回填规则错误，不能反推100ms没有用；本轮也没有反向证明100ms已经解决真假识别。

## 对下一版的约束

目前先不进入下一版改算法。下一步若继续，应围绕同一条细轨迹的可核实动作与故障证据，检查指令前后、允许滞后、持续和回撤，并结合实际执行/量测质量日志或可验证的独立观测建立标签。若只能做有真值模拟，应把真实动作、短毛刺、持续异常都放在同一细尺度，明确持续时间和可辨识假设，不用本批未标注曲线代替真值。

原CP/LABS继续作为后续同条件对照；本轮没有方法排名或新性能结论，也不把更细采样、更宽不确定区间本身算作算法收益。孤立、短暂、偏离指令均不构成修改原始点的充分理由。
