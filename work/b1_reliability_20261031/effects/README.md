# 连续作用配置选择与新测试

本阶段已在参考误差与整任务判断比较结束后执行。使用同一新冻结参考、原始 CPOP、全部已邀请事件的累计有效减载时长，只选择既有 Kennedy DR 估计器的有限配置，未提出新因果估计器，也未修改原估计器、原默认或物理阈值。

一次正作用验证为种子 7520200、256 用户、每人两次已完成事件，共 512 条测量。验证不读取模拟真值。先用同用户分折的实际结果预测 MSE，从 Ridge 强度 0.1/10 与样条结点 4/6 四组中选定 10/4；原代码的 GPS 正则强度随 Ridge 同时变化，因此不是只调整结果预测头。随后固定选定的交叉拟合伪结果，以整用户留一预测 MSE，在带宽倍数 0.75/1/1.5/2 中选定 2。每次同时排除该用户的全部事件，完整主查询点和参考点在全验证样本及每个留用户训练子样本中均须通过支持检查。本次四加四候选全部支持，完整风险和诊断见 `selection_description.json`。

`selection.json` 是不可变配置 artifact；校验和为完整性检查，不是来源认证。它冻结验证用户、输入摘要、完成时刻及截止、任务、单位、人群、X 列序、金额范围、参考金额、整组查询点与全部候选风险。验证完整后窗在 8330105 分钟前可得；测试最早通知为 10279985 分钟。测试用户与验证及其他测试块互不重叠。同一选择用于正作用和零作用测试。测试每块只按事前规定的块种子更换折分和抽样随机数，不搜索种子；带宽为选定倍数乘该测试人群的原规则带宽，没有搬用验证绝对带宽。

测试为八个新种子，每块 128 用户、每人两次事件，正作用与零作用配对，共 4096 测量变体，对应 2048 基础任务。这里零作用是激励改变不影响结果的原机制，仍含基础参加和真实动作。全部事件保留，没有按整任务证据结论筛选。原默认与选定配置共 32 个拟合输出均获得支持，先全部落盘冻结，再打开 evaluator 真值评分；16 个冻结模型查询与拟合曲线精确相同。

|---|---:|---:|---|---:|

合并先在每个独立种子内等权合并正零 MSE，再开方，最后报告八块均值和配对差。不能把配对机制当成 16 个独立块。正作用和合并区间仍包含零，本轮不足以认定总体稳定增量。选定配置保留为显式可选接口，不据此修改全局默认或继续调本测试。原有对照全部保留：选定配置下，正作用未调整曲线 RMSE 为 41.646 秒，低于 DR 的 49.381；零作用结果模型 plugin 为 23.163 秒，低于 DR 的 34.858。不能为了本面板较小误差删除合法混杂因素或将未调整结果当作新的因果估计器。

结果估计的是共同参考/CPOP 测得结果的作用；表中评价真值为模拟潜在真实时长作用，参考、过程和效应估计误差均参与最终差异。保留的条件抽样带没有传播配置选择、辅助模型、参考及过程误差；没有据此认证置信覆盖、现场可靠性或项目验收。
