# CPOP v3：细采样邻域证据试验（已完成，未采用）

结果：细采样使持续多格的真实动作与单格尖峰更容易分开，但“邻域平稳就回填单格”的规则仍然会吞掉真实单格动作、填平真实短缺口。总体时长更差，安全门失败。本版不替换现有算法或默认，不把胜过 LABS 或实测人工扰动稳定性提升当作整体改进成立。

## 实现和数据边界

- `candidate.py` 先检查观测网格；大于10秒的粗网格完全透传，不再把一分钟孤立点当异常。细网格上，左右各两个观测都局部平稳、两侧水平接近，且中间点偏离超过 κσ 时，回填两侧水平；指令变化前后一格保护。然后调用原生 CPOP，未改动态规划、beta、sigma、原始计量积分或物理阈值。这是工程候选，不是新的 CPOP 数学算法，也不是已经证明的异常分类器。
- 这仍是**同一通道上的邻域假设**，不是独立设备证据。真实短动作与故障占据同一个观测格时，可产生相同输入；指令没有说明动作一定立即发生，远离边沿也不能直接证明异常。`controls.py` 在正式比较前记录了该边界，采用门中保留了反例。
- 核实现有 KIT：18 个 recording、144 个已使用事件，原始相电流/指令有951—953点，采样间隔中位21ms、最大35ms；原始指令均与提取的前后指令相符。算法辅助试验使用已有100ms均值序列200格；原21ms仅作来源核验，没有伪称另一个独立量测通道。无故障标签、潜在干净电流或无调控反事实，不能直接验证真实误检/漏检。
- 新主比较保持30min、q1.5kW、物理阈值.15kW和既有30s驻留，累计时长仍计全部越阈格。由独立1s动力学生成10s表计均值，**不是把旧一分钟量测插值成细数据**。同一细数据给原 CP、候选和 LABS；两原方法不因候选加入指令利用就额外改造。当前10s成绩与旧1min成绩不可跨面板比较。
- 真实短响应与缺口含60s和10s两档；噪声含普通高斯、两个单格10s尖峰、两段连续40s异常。所有异常/真值位置只供评价，估计器不读取。

## 同条件结果

开发12基础×3条件=36输入、180输出；验证48基础×3=144输入、720输出，κ3/4/5内部选3并冻结；全新6seed测试144基础×3=432配对输入、1296输出，全部可用。配对变体不当作独立样本。没有测试后调参、改规则、筛样本或改变采用门。

| 指标 | 原 CPOP | v3 | LABS |
|---|---:|---:|---:|
| 累计/最长时长 MAE 均值 |17.975s|30.590s|45.255s|
| 累计时长 MAE |12.894s|13.148s|19.282s|
| 最长时长 MAE |23.056s|48.032s|71.227s|
| 无响应误检，36配对输入 |17|11|9|
| 60s真动作位置完全漏检，36配对输入 |0|0|2|
| 10s真动作位置完全漏检，36配对输入 |0|36|32|
| 10s真实缺口被完全填平，36配对输入 |0|30|36|

按干扰分组，主时长 MAE 原 CP/v3/LABS：普通5.486/22.917/37.604s、单格尖峰19.688/23.924/39.618s、连续异常28.750/44.931/58.542s。原 CP相对v3仅1/6seed主误差更差，其余5/6更好。

单格尖峰 null 12条：原 CP7误检，v3 1，LABS0；连续异常 null 12条：10/10/9，未解决持续异常。这表明收益只在部分孤立干扰，不是普遍异常识别成功。

**不能用“整任务任意位置还有正值”冒充找到了短响应。**原冻结指标的整任务漏检为0/25/30；带尖峰时，即使真正的10s动作被删，其他地方的假阳性仍可让任务看起来“没漏”。补充 `localized_audit.py` 按真动作位置复核后是0/36/32；它是事后描述性诊断，没有改原结果、选参或采用判定。60s真动作原 CP/v3均0漏；不能把10s失败扩大说成一分钟响应也全部丢失。

真10s gap组最长时长MAE原 CP0s、v3 390s。删除一个短缺口虽只改10s累计值，却能把两段相接，严重高估最长时长。正常高斯组也出现该问题，并非只在人工异常条件下发生。

## 现有细采样的实际帮助

144个既有100ms事件各三条件，共432输入/1296方法输出，全部可用；新增固定噪声、两个100ms尖峰，按同一方法比较加入尖峰前后：

| 特征变化（越小越稳定） | 原 CPOP | v3 | LABS |
|---|---:|---:|---:|
| 累计达标时长变化 |.1875s|.0556s|.1993s|
| 最长达标时长变化 |2.0389s|.1813s|.2465s|
| 达标有无翻转 |16|4|10|

这支持“100ms细采样对持续动作下的孤立尖峰稳定性有帮助”，但只是同一批旧观测的人工扰动，不能证明潜在干净时长更准，也不能证明现场短动作不漏。稳定性下降可以伴随真实短变化被抹掉，故不作为正式采用理由。

## 核验与结论

- 原 CP沿用锁定原生版本、β2log(n)、同sigma/原网格；LABS沿用作者MIT核心及原M5/R2/sSIC，未安装新库。参考了现有[原CPOP说明](https://www.jstatsoft.org/article/view/v109i07)、[异常分段论文](https://doi.org/10.1080/01621459.2017.1385466)及[SciPy现有滤波实现](https://github.com/scipy/scipy/blob/main/scipy/ndimage/_filters.py)，没有把中值滤波或调用现成方法称为创新。
- 原计量η在432输入×3法逐一相同，不用曲线处理改实际电量。
- `audit.py` 独立向量计数核37052项，包括全部开发/验证/测试特征、计分、身份、冻结、数据划分及真实描述量；检查数不是科学样本数。617项既有源码/数据/冻结文件SHA不变。
- `adoption_decision.json`：总体至少降10%、普通噪声非劣和真实单格动作/缺口安全门失败，**不采用**。不修改生产源码/API/默认、报告、第二部分或原实验。新增不确定区间没有被当作任何收益；本版也没有通过置零不显著事件求胜。
- 当前结论限定为：**用细采样是合理的，但只把孤立点识别规则搬到细网格，仍不够。**不能继续靠加保护窗、提高最短时长或在已见测试上调κ掩盖这一点。未来若继续研究，应让真实细采样在一个目标时长内部提供多次支持，或核实可独立验证的设备/量测质量信息；极短到只占单个有效观测的动作仍有不可辨识边界。本次未额外启动下一候选。
