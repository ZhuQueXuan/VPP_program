## 时钟依据与待审条件

当前公开电表列为 `LCLid`、`stdorToU`、`DateTime` 和半小时 kWh。原行的春季 01:00、01:30 标签实际存在，作为伦敦当地时刻则不存在。以 GMT 解释时对应当地 02:00、02:30 BST，支持原表走 GMT。项目作者的同源标准组重发布说明 `DateTime` 为 GMT，记录前一个半小时的用电。UKDS 另版对动态组也明确采用 GMT 期末。两条来源支持期末解释，仍未取得同版动态组的计量字段说明或实际半小时事件标签作直接双表校验。 [标准组时钟旁证](clock_key_checks.csv) · [作者同源数据说明](https://research.tudelft.nl/en/datasets/low-carbon-london-smart-meter-data-refactored/) · [UKDS 指南](https://doc.ukdataservice.ac.uk/doc/7857/mrdoc/pdf/7857_userguide.pdf)

实际例为 2013-06-13 高价首段。公开费率原行 7860 的当地 17:00，换算为 GMT 16:00 起点。两户均联到 GMT 16:30 的原电表标签。冬季 2013-02-11 的当地 17:00 对应 GMT 17:30 期末。连接使用原价档，未指定有争议的低价金额。 [计划窗口及 GMT 键](targeted_link/planned_windows.csv)
