# 第一部分：CPOP时长提取改进试验

用户所说“效率高”指推进研究的工作效率，算法运行速度不作为准入条件。

保留原版CPOP、作者版LABS同输入、同采样、同物理阈值比较。新候选由原版CPOP、常值/线性分段特征、已冻结的提升树中位数/状态模型组成，只处理持续时间相关的临界区间。既有算法组合与任务适配不能称为新动态规划或新提升树。

原始点与能量积分保持。原版识别出的≤60秒正响应段、预测≤0.10kW的点、大规模修改和整任务正响应状态都有保护。输入不删点，不把孤立点自动解释为故障。模型训练标签仅为可控模拟的潜在曲线，不是现场故障标签。

结果入口：`assessment.json`、`independent_checks.json`、`public_api_checks.json`、`test/metrics.json`。`selection_freeze.json`冻结了选型、模型与源代码；测试前没有使用本轮测试结果。测试以12个随机种子块作配对比较，含1分钟和10秒观测、普通噪声、尖峰及持续异常，另设低幅临界压力数据。

已通过预定准入条件并接入显式入口 `process_method="duration_fusion"`，没有更改旧默认策略。实际运行公共入口核对了两种采样共8个新版本事件和8个原CPOP事件，结果逐一与冻结输出一致；缺原CPOP或参数超范围返回不可用。所有原源码已保存在 `production_before/`。

| 等条件权重的MAE，秒 | 原版CPOP | 新版 | LABS |
|---|---:|---:|---:|
| 累计响应时长 | 19.7569 | 17.2230 | 45.5301 |
| 最长连续响应时长 | 43.2261 | 37.9120 | 103.4846 |
| 两项平均 | 31.4915 | 27.5675 | 74.5073 |

新版本综合误差降低12.46%，12个种子块中10个改善，块间配对差为−3.924秒，Monte Carlo t区间[−6.543,−1.305]秒；只描述本模拟生成机制的块间波动。短响应位置漏检原/新/LABS为1/1/171次，任务误检为79/79/34次，真实短gap被完全填平为6/6/191次。LABS低误检不能掩盖其短响应漏检。2016条输入来自792条基础轨迹的配对噪声变体，6048个方法输出均有效，并非2016个独立真实任务。

低幅压力集224条，等权综合MAE原/新为168.233/162.965秒，短漏同为3次，gap填平13→11。独立重算36,960个指标关系及24个分阶段推断重放通过，另有24个小规模穷举分段检查；检查数不是样本量。`assess.py`已完整写出 `assessment.json` 后在控制台打印numpy布尔值时失败；原结果与冻结代码保留，未重算或改评分。生产接口保留原结构曲线，只使用状态校正的两项时长，其余过程特征与原CPOP一致，原始能量积分一致。

此前失败轮次完整保留在：

- `../b1_fast_selection_20261101`：早期理解为运行速度，随后纠正；通用分段与简单树校正在独立验证中收益不足。
- `../b1_duration_selection_20261101`：面向时长的状态校正，普通场景改善，但低幅压力场景退步，未采用。
- `../b1_duration_adoption_20261101`：增加短响应保护；压力场景仍额外填平真实间断，未采用，未生成最终测试。
- `../b1_duration_final_20261101`：禁止任何负格转正，破坏正常持续响应的连续性；验证无收益，未采用，未生成最终测试。

本轮是有已知参照的30分钟受控模拟验证，不代表未知参照、真实100毫秒故障分类或现场5%误报已完成。整任务误检/漏检状态按设计与原版CPOP完全一致，不能宣称已经降低误检。第一部分以外的算法与报告不在本次改动范围。
