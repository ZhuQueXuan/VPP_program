# CPOP 突跳扩展无收益的原因核查（仅分析）

结论：这批已见试验不能支持“主要是原 CPOP 不会表示突跳”。更明确的瓶颈是：平方误差分段会把量测尖峰拟合成短变化，而后续逐格硬阈值没有真实性证据，也会放大临界点对最长时长的影响。分段误差与判定敏感性共同作用，不能硬分摊原因百分比。本轮参考已知，未使用预测器，不能归因于预测。

## 直接证据

- 复核 v2 冻结测试：240 个模拟基础任务、480 个配对输入，并非 480 个独立样本；原 CPOP、v2、LABS 共 1440 条已有结果。没有重新拟合、调参或新性能试验。
- 无响应组普通噪声 24 条，原 CP/v2 均 0 误报；同组加两个人工尖峰后均 17/24 误报。这 17 条完全相同，且两法逐分钟越阈掩码都与原始量测相同，恰好等于注入正向尖峰的位置。其余 7 条只有负向尖峰。是对人工干扰的识别失效，不是“多分一段就能去掉尖峰”；也不是现场误检率估计或整任务 5% 检验。
- 480 输入中，426 条（88.75%）原 CP/v2 的越阈掩码完全相同。460 条选了新突跳且惩罚目标更低，但任务真曲线 MSE 仅 134 条变好、234 条变差，其余在数值容差内不变；表示自由度及目标下降没有转成目标特征收益。
- 两法共翻转 80 个分钟格，其中 63 格的真实信号在物理阈值 .15kW 上下 .05kW 内；74 格至少一法拟合值距阈值不超过 .05kW。只是描述临界敏感性，不据此认定所有误差都是阈值原因。
- 明确反例 `command-sim-7641201-interrupted-1-gaussian`：第 13 分钟真值 .167542kW，原 CP .157031、新版 .129883；其余格越阈判定一样。原法累计/最长均 1680s，新版累计 1620s、最长 960s。因此一个 60s 的错误缺口使最长时长少了 720s。其带尖峰配对输入也有相同反例，不作为第二个独立任务计数。
- 总体累计时长 MAE 33.75→35.25s，最长 MAE 56.00→60.375s，主指标为二者平均 44.875→47.8125s。主指标总增量 1410s，间断组贡献 +930、弱持续 +810，其他组有抵消；这些是绝对误差代数变化，不是原因贡献率。
- 独立重新从保存曲线逐格计数，与全部 1440 行原累计/最长、真值、FP/FN 格、主指标一致（7200 条断言）。未发现这两项计数实现算错。固定 30s 驻留在 1min 格上折为 1 格，单格即 60s；该定义并不等于统计上已证明真实响应。

`diagnosis.json`、`null_cases.json`、`paired_cases.json`、`changed_cases.json` 保存明细；`supplement.json` 保存额外曲线及原 v2 完整清单核验。

## 论文给出的依据与适用边界

1. [Fearnhead & Grose，JSS 2024，CPOP](https://www.jstatsoft.org/article/view/v109i07)：优化加折点惩罚的加权残差平方和，目标不是响应时长准确或识别传感器故障。本实验新增重置仍保持平方误差，所以没有自动获得异常识别。
2. [Fearnhead & Rigaill，JASA 2019，Changepoint Detection in the Presence of Outliers](https://doi.org/10.1080/01621459.2017.1385466)：异常点可诱发额外分段；有界损失能抵抗极端异常，但论文也明确短真段可能被当异常、最短段长附近功效下降。因此不能重新简单套鲁棒降权或加最短时长，宣称能兼得短动作与低误检。其 R-FPOP 是分段常参数方法，不能当现有斜坡 CPOP 的直接替代。
3. [Fryzlewicz，JASA 2024，NSP](https://doi.org/10.1080/01621459.2023.2211733)：先通过多尺度检验定位有统计证据的变化区域，再进行位置估计，为“拟合变化”与“变化证据”分开提供依据；它不是响应阈上时长算法，也不自动区分一次传感器错误与真实单格动作。[RNSP，JBES 2024](https://doi.org/10.1080/07350015.2024.2316103) 针对中位数水平变化，允许重尾，但依赖真实残差符号独立、对称等条件，不能直接把其保证转给爬坡/相关量测/参考预测误差。
4. [Bolin & Lindgren，JSS 2018，excursions](https://www.jstatsoft.org/article/view/v086i05)：联合考虑曲线超过阈值的区域及不确定性，比仅对一条曲线硬切更贴近持续时间问题。它依赖潜在高斯模型，不能把选择后的 CPOP 曲线加普通高斯误差条，就冒称同时置信保证。

先查作者开源实现：[nsp](https://github.com/pfryz/nsp)、[excursions](https://github.com/davidbolin/excursions)。前者为作者研究复现仓库，本轮未核定包许可/当前发布维护状态，未复制或安装。后者有 CRAN/stable/devel 路径、文档、测试及 569 条提交；DESCRIPTION 声明 GPL≥3、GSL 与编译依赖。其工程资产较完整，但潜在高斯假设与现有 CP+尖峰模型不直接匹配，改造成本高；暂只借鉴越阈区域不确定性思路，不选择替换或安装。网页状态只代表此次浏览可见信息。

## 更合适的下一研究方向（尚未实施）

保留原 CPOP 为基础，优先研究“有观测证据约束的短响应确认与时长不确定性”，而不是继续添加突跳自由度。

1. **先补区分依据**：利用确实存在的更细采样、指令及独立设备/量测质量信息核实短动作和尖峰。指令附近可以有证据，但不把“远离指令边沿”当异常规则。现有 KIT 有 100ms 指令/电流，可用于辅助可辨识性研究；它没有本模拟任务的无调控反事实真值，也不是新的现场准确率证明。状态通道只有核实存在后才能使用。只有单分钟单通道且两种原因产生同样观测时，无法保证既保留真短响应又去掉所有尖峰，应明确不确定，不能硬压零。
2. **分开物理定义和统计证据**：物理 .15kW 阈值、累计/最长定义保持；多尺度任务证据用独立、与干扰条件匹配的未发任务样本做整任务校准。仓库已存在 `response_evidence.py`，仅重接它不算新算法，它的原校准条件也不能直接沿用到本尖峰试验。整任务校准可能改善“是否有充分响应证据”的可靠性，不自动降低累计/最长 MAE，不能把未显著的 Y 置零或剔除。
3. **针对临界缺口表达不确定性**：研究同时有效的曲线/越阈区域界，给累计及最长时长的范围，保留原点估计；不能直接填一格缺口，否则会吞掉真实短 gap。区间需要覆盖噪声、分段选择，未知参考时还要覆盖参考误差；不能用原版与新版曲线之间的距离冒充置信区间。
4. **下一轮是否值得采用另行验**：只能在新划分上检验，原 CP/LABS 仍同参考、任务、采样及输出口径。一起看真短响应漏检、真短 gap 保留、整任务误检、累计/最长 MAE，以及新增区间覆盖/宽度和不确定比例。只降低误报同时增加拒判、或仅把点估计改成宽区间，不算时长准确率改善。

本轮仅新增诊断脚本和分析记录，不改算法、阈值、默认、旧科学结果或报告；不启动下一候选，不按本已见测试挑选规则。
