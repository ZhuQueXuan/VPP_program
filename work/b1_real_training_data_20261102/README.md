# 真实训练数据查找与落地

正式入口为项目根目录下的`data/ACN_real_user_benchmark_v1_20261102/README.md`。已落地1,878条会话、195匿名用户，按用户固定训练/验证/测试，并留外站测试。原件逐个核对Git blob和SHA256；实际响应监督标签仍待核实，没有训练新模型或给真实准确率。

本目录保存检索、完整远端目录、官方元数据、原件下载及质量核对脚本。`sources_catalog.json`说明各来源能解决哪些问题；`canonical_dataset_pointer.json`指向正式数据目录。

采集经历两个阶段：先取得1,230条原件按充电桩作筛查，后从官方公开下载补充匿名用户关联，升级为正式按用户数据集。早期按桩的划分与质量结果保留，不能与正式用户划分混用。旧清单不是当前监督评测分组。

完整远端目录确有85,877个`.csv.gz`，不是声称全量已下载。部分官方早年份大范围查询返回了末尾截断的JSON（历史错误文件名为`*_failed.html`，实际内容是JSON前缀），没有修补后当完整结果使用；正式来源只纳入完整返回且可逐会话关联的元数据。

补下了Dortmund字段字典、索引和其他来源说明，没有扩大下载22GB KIT高频数据，也没有把电网扰动窗口或控制上限直接改名为响应/毛刺真值。原版CPOP、LABS及所有已采用模型未改，本轮不处理报告、参考预测或第二部分。
