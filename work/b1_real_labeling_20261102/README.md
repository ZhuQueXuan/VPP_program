# 首批真实片段核验与初审

本轮继续真实数据训练与泛化评测准备，只做第一部分的数据核验和初审；未改算法、未训练模型、未打开测试观测、未写研究报告。

正式数据源为 `data/ACN_real_user_benchmark_v1_20261102`。本轮新增标注见其 `ANNOTATION_STATUS.md` 和 `annotations/batch_20261102/`；原采集凭证与分组文件不覆盖。

## 发现与处理

收到的电流上限变化，既不等于实际功率必然跟随，也不等于实际响应起止。实际电流低于新旧上限时，经常看不到附近跟随；恒定上限的窗口也会发生停充。直接按指令造响应标签会把这两类都标错。

Case 32保留了一个特别短的明显下降：0秒上限32→8A，实际电流仍30.7A；4秒为6.7A、1.5kW；8秒已回升，13秒接近此前水平。最低点只有一格，不能按孤立点直接删除。这是时序一致的记录证据，不是独立电表确认的无故障物理真值。

Case 28收到上限增加但实际电流基本不变。Case 23上限没变却在末段停充。Case 63在锚点之前已开始下降，后续停到零，不能将整段自动归因当前指令。Case 18全窗口只有3个原始点，明确保留为未解决；Case 30/34上限、功率、电流的含义有待核实，不自动标故障或干净负例。

64个不同用户的初审均保留。窗口标签为40个可见变化、22个无清楚事件、2个未解决；这些是按指令分层抽取的开发窗口计数，**不是现场总体类比例、模型召回率或准确率**。锚点附近跟随决定另存，不能用整个窗口任意变化冒充当前指令响应。所有初审仍待独立复核。

28个锚点变化提供起变相邻采样范围，19个提供恢复完成范围。这些范围表达原始采样分辨率及人工解释，不是校准置信区间。恢复完成不等于有效时长终点；未见恢复的记录显式截尾，不填零、不补点。

## 执行与来源保护

1. `protocol.json`、`prepare.py`：只从正式训练/验证中选取，依据收到上限历史和用户哈希，不依据实际功率响应或算法结果。
2. `selection_freeze.json`：先冻结协议、选择与原始窗口，后查看图和给初审。
3. `plot_review.py`、`review_pages/page_01.png`至`page_16.png`：16页原始点图，本轮全部查看。连线只用于显示原始点，不插补输入。
4. `source_evidence.py`、`boundary_evidence.py`：回查关键边界原始观测。`review_rubric.json`在开发审阅中细化，未冒称看数据前预注册。
5. `build_annotations.py`：保存人工决定、原始坐标与未预填答案的复核包，不执行边沿模型、CPOP/LABS教师标注或拟合。
6. `verify.py`、`verification.json`：重新解析64份开发原件核对行号、时间、三路原始值和边界；同时对所有1878份原件只做字节哈希核验。检查不能代替第二位独立标注者。

核验通过：195用户跨分组为零；64片段均继承原组；11838个原始通道值及47个相邻采样边界与源文件一致；1878原件、13份旧采集文件、4份选择冻结文件及58份生产算法文件哈希不变。没有解析测试/外站测试观测值。

## 独立复核包

复用了维护中的开源项目[Label Studio](https://github.com/HumanSignal/label-studio)的[官方时序模板](https://labelstud.io/templates/time_series)格式，项目[许可为Apache 2.0](https://github.com/HumanSignal/label-studio/blob/develop/LICENSE)。此处仅生成原生JSON任务与XML配置，没有安装或启动服务。XML及任务结构已检查，尚未在实际Label Studio服务中导入验证。

复核时先使用 `second_review_unlabelled_tasks.json` 和 `label_studio_config.xml`，不先查看 `first_pass_annotations.json`。复核后比较起变、恢复、整窗变化和锚点跟随意见；分歧保留并查源，不用算法结果裁决。整个包仍是本地研究材料，未上传或对外发布。

## 后续边界

本批是标签定义与数据适用性试点，尚不是可直接重训现用整任务资格头的金标准。实际功率变化、超过有效阈值、物理原因和传感器故障是不同目标；不互相替代。没有无噪声曲线或故障标签就不报相应误差、故障精度。

下一阶段安排见 `next_stage_plan.json`。真实训练、原CPOP/LABS同条件比较和锁定终测均尚未执行，不能根据本轮给出现用算法真实准确率或宣称提升。
