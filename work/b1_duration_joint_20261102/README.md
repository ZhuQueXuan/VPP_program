# 连续段与停顿信息改进时长估计（已采用）

当前显式入口：`analyze_event(s)(..., process_method="gap_duration_refined")`。上一版 `known_local_response`、更早版本及原CPOP/LABS保留，兼容默认不改。只做第一部分已知参照的历史特征提取，参考预测、第二部分、报告保持。

## 查到的问题与实际改动

修改前诊断在 `../b1_duration_diagnosis_20261102`。旧约75秒误差中约68%来自已经有输出的长响应；间断及平滑弱响应最突出，最长连续时长比累计时长误差更大。不能继续仅靠补找短动作压低这个主误差。

本版给时长模型补充连续段与停顿的位置、长度、数量、多尺度观测信息，新增255个结构特征，加原171项共426项。旧模型会把少量正输出直接当短动作保护，本版用安静背景判据保护真实短动作，同时允许明显存在持续弱变化的长任务修正。累计与最长两个估计值再满足同一任务、采样格、驻留与相互大小约束。

模型家族比较了累计/最长比例和累计/最长绝对值；**最终选中31叶的两个绝对时长中位数模型**，不是比例模型，也不是联合优化求解器。标准HGB本身不算新发明，底层CPOP/LABS没有换名。实质改动是结构信息、适用规则和时长特征估计，收益由整套方法同条件比较。

现有任务判正/判负与定位掩码逐条保留，不把不确定任务置零；原始采样不删不填。新值仍是两个直接时长特征，**不宣称生成了新的物理功率曲线或精确起止位置**。原始电量与η、补检结果及其他过程特征不改。

## 新独立测试结果

两批新输入合计2808配对记录/792基础轨迹，普通936、连续弱幅度1872。各法相同参照、量测、任务、噪声、采样和判据。均为有真值模拟，不是现场N。主误差按原约75秒口径：累计MAE与最长连续MAE的平均，采样/条件等权，普通与弱面板以输入1:2合并。

| 方法 | 合并时长主误差/秒 | 累计MAE/秒 | 最长连续MAE/秒 |
|---|---:|---:|---:|
| 原CPOP | 101.94 | 80.40 | 123.47 |
| LABS | 157.82 | 141.06 | 174.58 |
| 上一采用版 | 71.54 | 57.97 | 85.11 |
| 本版 | 55.84 | 47.21 | 64.47 |

同批旧版到本版下降21.94%。之前75秒是上一批诊断数据的旧版值，不能拿它替代本表同批71.54秒算增益。

普通面板23.9974→20.8368秒，弱面板95.3108→73.3424秒；两个面板均4/4种子块改善。普通配对差值−3.1606秒的模拟重复95%区间[−6.5423,0.2212]含零，弱面板−21.9683秒区间[−29.1511,−14.7855]不含零，不称每类均稳定显著改善。

真正长响应主误差93.35→72.39秒，最长MAE119.81→88.95秒，预定长正响应10%收益门通过；不是仅把阈下/未达标样本的输出缩短取得平均改善。间断类主误差125.02→76.02，平滑弱形状79.50→50.00秒。单细格短动作时长10.62→10.73秒有微小退步，未删该类，整体短时长安全门仍通过。

**检测输出逐条相同**：两面板合并误报499、整任务漏39、局部漏101、真实短动作位置漏71/308均旧新一致；有效短时段位置漏88/333同。此处308真实短动作与333有效短时段分开，避免此前把长振荡短暂过线混称真实短动作。没有为了时长更准多漏响应或增加误报，但已有漏检/误报也没有被本版解决。

## 冻结与验证

以前所有已见测试明确作为新时长模型开发资料。共15244条已知开发任务，其中5827条进入适用时长校正范围；426维标准HGB中位数回归，31/63叶、绝对/比例时长、0.5/1混合在新7781xxx验证集比较。验证全部门通过后封存 `selected.json`/`freeze.json`，才生成7782xxx最终数据，未对最终追调。弱面板每个形状/种子都独立覆盖0.07—0.30kW六层连续幅度。

预定门包括整体和弱面板至少10%改善、真长响应至少10%、普通非劣、短时长非劣、间断最长时长非劣、判定及位置逐条相同，最终全部通过。累计/最长真值和误差在独立逐格计分中重算，未修改原计量定义。

公共/native新旧路径各12事件，含最大改善和退步例、普通短动作及无动作例；输出与冻结指标一致，全部2808个426维特征向量与发布实现精确一致。原版本由保留源码重放相同；定位、结构功率、电量、η和其余既有特征同。生产只新增 `_gap_duration.py` 与两模型/manifest并注册入口，原数学/旧权重/默认策略保留。

新输出 `duration_calibration` 及 `features.sources.duration`说明来源。`duration_estimates`与定位状态是不同量，不把改进值伪称为原定位曲线积分。范围继承已有模型：已知参照，30分钟、q1.5kW、sigma0.05kW、十秒/一分钟、前后15分钟及默认物理标准。

结果见 `assessment.json`、`public_checks.json`、`completion_receipt.json`；开发全部配置见 `validation_grid.json`。使用已安装sklearn1.7.2，[官方HGB实现](https://github.com/scikit-learn/scikit-learn/blob/main/doc/modules/ensemble.rst)支持所用标准回归工具；无新库安装、GPU、删除或外发。
