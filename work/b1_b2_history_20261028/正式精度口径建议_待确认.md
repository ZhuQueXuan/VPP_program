# 课题一正式精度评价口径建议（待确认）

本文件提出评价方法，不改写任务书，也不据本轮模拟结果宣告“准确率达到90%”。任务书的精度要求需要先明确评价对象、真值来源、允许误差、分母和独立测试集；这些内容目前尚未形成经确认的统一口径。

## 先固定一个能交付的任务

建议先以“具有既有控制许可、事前申报完整的单EV，在30分钟任务及声明期限内的减载和恢复”为首个评价任务。明确AC侧、kW/kWh、分钟平均值、任务开始与数据可得时点，保留未许可、物理不可行、缺数据和域外输入的状态。该任务是第一项可评价对象，不能代表全部源荷储组合或多市场场景。

同一对象的事前申报、实际是否接受、指令、同步计量及完整恢复窗才构成现实评价链。事后交付电量和离站时间不补作事前申报。现有模拟面板只能验证方法、接口及计算正确性。

## 不同输出分别评价

| 输出 | 建议主要评价 | 必须同时保留的信息 |
|---|---|---|
| B1全过程特征 | 时点/时长绝对误差，电量误差，缺测与删失识别 | 人工或独立参照、采样分辨率、不可判定比例；不把未达到编码当实测时延 |
| B1因素作用 | 有识别条件时报告效应误差和区间；现实数据先核识别假设 | 不能拿观测预测精度证明因果正确，也不能用模拟已知真值冒充现实真值 |
| B2预计交付 | 实际事件平均减载RMSE/MAE、轨迹误差；含拒绝及未发状态 | 分别给总体、可发任务、实际接受后条件结果；避免筛掉零交付后夸大效果 |
| B2参加/任务概率 | Brier、对数损失、校准图及分组覆盖 | 不把1−Brier写成准确率，不以某个概率阈值自动获得控制授权 |
| B3组合结果 | 服务任务达标和恢复分别记账；容量误差需独立可行上界或真实能力参照 | 所有共享约束及状态递推；未准入、退出、服务失败、恢复失败分列 |
| 对外能力承诺 | 另行确定可靠性目标、覆盖率和保守承诺规则，再用独立实证校准 | 本轮没有真实可靠性校准，承诺继续为null |

## 如何把“90%”变成可验收条款

连续量若采用“误差在允许范围内的样本比例”，可事先约定：

`合格 = |预测−独立参照| ≤ max(绝对容差, 相对容差×事先固定的尺度)`。

尺度可对应请求功率、任务电量或明确定义的时长；不能用接近零的实际交付作分母。绝对/相对容差、哪一项输出适用90%、是否需要置信区间下限达标，须由项目验收口径确定。本建议不先填一个有利于现有成绩的数值。分类任务如另用正确率，也须固定标签、阈值、类别占比及误判成本，并同时报告少数类和概率校准。

测试单位按独立用户/设备/站点或独立试验批次划分。相同用户事件、配对模拟机制和同一基础曲线的变体不当作独立样本扩大置信度。预处理、表示学习、选模和阈值均在训练/验证阶段冻结；测试集只用于最终评价。不可计算与拒答须列覆盖率；只报可计算子集的90%不足以说明整体可用性。
