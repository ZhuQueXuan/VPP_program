# 第4点下一步判断：只试正则连续R-learner

2026-11-05。**值得做一次有边界的新开发比较，暂不训练。** 这条路线直接学习随补偿变化的条件增量面，与此前“共享辅助后仍分组平滑”的失败候选不同。它能保持相同0.4参照、相同两组及事件等权目标，不必改成斜率、价格shift或二元补偿。现有证据只支持试验价值，未证明它更准。

## 给总管的短协议

- **唯一改动：** 全队列学条件增量，再按相同事前组平均；正式总体仍引用原DR，候选不提供绝对响应水平。
- **固定容量与预算：** 80列poly2状态×三次金额样条，固定rho=0.05。原DR、固定OR10、保留样条各1配置；本轮各法0次参数搜索，不做CV/GCV。rho来自作者示例，容量是与原OR相同函数空间的低维适配；不套作者全张量样条理论。
- **必须保留的数学：** 函数惩罚rho·E[h²]对应Q=Psi′Psi/n，不能换成系数I；最后是(1+rho)[h(x,a)−h(x,0.4)]。m必须是E[Y|X]；Gamma从同一整用户训练折的金额基条件回归求得，观察性情形不用模拟真GPS。
- **新数据及门：** 新925051101–106开发6块×4机制；确认另用925051201–220且单独放行，旧915…的24开发和20预留确认均不碰。R须在同批同时比DR与强简单OR降低至少5%，且同一至少4/6块胜两者、24/24完整输出；否则停止。确认需更强的20块门，不以多数队列代替独立块。
- **实现范围：** 核心[continuous_r.py](continuous_r.py)已写；只运行了[17项无拟合算子小核](operator_checks.json)。下一步按[机器协议](protocol.json)接原B0/OR/S的阶段执行与保存，不改旧代码。当前没有训练入口已跑通或新性能结果的声明。

## 为什么值得这一次，而非继续换参数

已有失败各有范围：连续DML/两部新确认没有胜过现DR；样条早期有益但后续复杂机制未稳定占优；平滑凸组合没有额外收益；全队列OR总体旧确认仅2/6块改善；共享条件辅助虽在新开发平均组差误差下降31.15%，但共同胜两对照仅3/6，已停止。OR在刚完成的开发中误差65.20秒，比原DR134.82秒低，说明简单对照很强；新候选不能只挑DR作唯一靶子。[最新总管裁定](../b1_point4_stability_design_20261105/ROOT_DEVELOPMENT_REVIEW.md)

R路线改变的是目标学习损失和条件增量表示。它先残差化Y和连续金额基，再以函数惩罚选定可识别中间函数，最后减0.4参照；不是再换最终平滑器，也不是原Ridge换名。这一机制与此前失败不同，但小样本下Gamma、曲面错设及求逆仍可使它更差。[原论文v3，§2.4、式17、S2.1](https://arxiv.org/html/2208.00872v3)

## 原论文和作者代码核查

论文首版2022、当前核到的修订版为2025-04-17 v3。原目标是条件潜在结果差；把零参照换成0.4后，再在同一事前X分布按组平均，保持本项目目标。相对增量不能独立恢复绝对功率/时长水平。原文假设无未测混杂、共同支持等，不是无GPS或无条件可比性的通行证；其iid理论不直接担保重复用户的性能或区间。[论文](https://arxiv.org/abs/2208.00872)

作者库只含README和两个R脚本，API许可为null、根目录未见LICENSE；不能因代码公开就按MIT复用。最新可见提交为2025-04-25的83cb60bd978a742b363896c05e1e387b574fe810。示例为5000个iid样本、单X、均匀随机金额；观察分配Gamma仅指向补充材料，默认16 worker和多项R依赖。本轮没有复制、安装或执行作者代码，按论文独立写现有Python依赖的小容量版本。[作者库](https://github.com/yichistat/Continuous-treatment-R-learner) · [版本及许可回执](author_repository.json)

无拟合小核用确定性矩阵而非研究队列，验证参照精确为零、函数Q惩罚及(1+rho)校正的联合恒等式、JSON加载和固定Q子空间。最大算子误差1.57e−16；把Q换成I的反例不能通过。这是数学实现检查，不能当开发拟合或性能提升。[小核代码](operator_checks.py)

## 能力缺口仍独立保留

原版能在声明条件与支持范围内直接查询连续补偿增量；条件差异及总体增量的跨块稳定性尚未达到研究收口，真实EV补偿作用也未验证。最低实测缺口仍为同场事前补偿、可信分配及全体对象覆盖、实测结果；单笔物理减载时长另需可信未调节参照。可信随机比较不要求SOC/离站齐全，缺这些主要影响分组和解释。

若本固定R候选再次失败，保留原版和负结果，暂停该相关模拟族的模型替换；后续须有新的数据条件、方法假设或明确能力容限才能重启。不无限换rho，不追加未审模型，也不把模拟结果写成现场补偿效果。
