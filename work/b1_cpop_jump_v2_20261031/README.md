# CPOP v2：突跳与爬坡共同建模，已比较，暂不采用

2026-10-31。用户批准保留真实短响应、同时识别突跳和缓慢爬坡，不再压低孤立点权重；完成一个有限结构版本、新模拟同条件比较及真实记录辅助。本目录是研究实现与实验记录，正式报告后置。

## 改了什么

[candidate.py](candidate.py)保留全部观测和原σ，在原连续CPOP之外允许少量候选边界发生水平/斜率重置：

1. 用宽度1/2/4的局部线性水平差生成6个观测边界候选，加上已知指令变化边界；仅作为候选，不强制该时刻响应。
2. 每个候选区间内部仍用未改的原生CPOP，允许平台和连续折线爬坡。所有区间统一全任务`β=2log(n)`，不随区间变短降低惩罚。
3. 外层无剪枝动态规划选择哪些边界确需自由重置；原版整窗CPOP作为零突跳候选完整保留。单点块取其常值、双点块取直线，仍付分段代价，不用最短段长删除真实短动作。

分块目标为`Σblock CPOP_cost + γ×重置数`。有效候选`γ/β=1或1.5`只在验证选择；冻结为1后新测试不改。`γ/β=2`是退化控制：原CPOP可用观察点之间的陡坡连接任一重置，代价至多每个边界多2个斜率折点，故γ≥2β时原版不劣。这意味着v2改变了结构组合和复杂度代价，不能说原CP在离散点上完全不能拟合突跳。

精确性仅针对固定候选边界字典、以原生CPOP区间最优为基础的外层分割，不是全部位置的GRACE全局递推，也不是跳变后强制保留旧斜率。点值/权重未改，未运行v1孤立点筛查；格内真实瞬跳还是陡坡仍不可由同一组均值观测认证。

复用依据：[CPOP/JSS2024](https://www.jstatsoft.org/article/view/v109i07)现有原生优化器和本地锁定1.0.10；[GRACE2026 v2](https://arxiv.org/html/2609.28831v2)提供允许不同转移的结构思路，本次不是其原样复现；[MOSUM作者仓库](https://github.com/Joonpyo-Kim/MovingSumLin)支持多尺度跳变/斜率方向，但许可未核、需Rcpp，本次局部OLS提案自行实现，不复制/安装其代码，也不声称其显著性保证。LABS沿用[作者固定版本](https://github.com/pfryz/LABS)，M5R2/sSIC不调参。

## 新模拟同条件比较

先80基础验证任务、常规/加尖峰共160配对输入，原CP、两个内部γ配置及LABS共640输出；按预定时长指标选γ/β=1并冻结后，再生成6新种子×40=240基础任务、两条件480配对输入，原CP/v2/LABS共1440输出，全部可用。没有在测试中扩候选数、改γ或路由赢家。

使用同一未改的独立一/二阶动态机制、新用户/新种子，保留真单格响应、真单格间断、低幅持续、短弱、间断、提前结束、振荡、延迟回补和null。两噪声条件是同基础任务的配对变体，不是480个独立用户。参照为明确已知的模拟未调用功率，无预测器，1min/30min/q1.5kW及判据相同。

主指标是**累计有效时长与最长连续有效时长两项MAE的平均**，越小越好；不是响应延迟：

| 方法 | 常规高斯噪声/s | 同高斯＋两尖峰/s | 两条件平均/s |
|---|---:|---:|---:|
| 原版CPOP | **25.875** | **63.875** | **44.875** |
| 本次v2 | 28.500 | 67.125 | 47.8125 |
| 原作者LABS | 81.750 | 128.750 | 105.250 |

**结论：短动作安全性保持，但没有总体时长收益，不采用为默认。** 新数据不同，不能直接拿本批分数与v1/更早不同种子批次比较。

| 重点检查 | 原CP | v2 | LABS |
|---|---:|---:|---:|
| 常规真单格响应漏检/24 | 0 | 0 | 24 |
| 加尖峰真单格响应漏检/24 | 1 | 1 | 23 |
| 常规短弱响应漏检/24 | 3 | 2 | 4 |
| 加尖峰短弱响应漏检/24 | 1 | 1 | 13 |
| 常规无动作正时长误检/24 | 0 | 0 | 0 |
| 加尖峰无动作正时长误检/24 | 17 | 17 | 2 |

常规短弱组时长综合误差60→48.75s，有局部收益；加尖峰同组53.75→61.25s退步，未隐去。总体常规累计时长22.5→23.25s、最长29.25→33.75s；加尖峰累计45→47.25s、最长82.75→87s。全部六块，常规主误差仅2块低，尖峰仅1块低、1块相同，不能称稳定增量。

所有预定安全、可用性、曲线非劣门通过，但“总体时长至少改善10%”失败（点估计反增约6.55%）。只胜LABS不足以采用，必须对原CP有收益。原始η在全部480输入、三方法间精确同；此次未做新整任务校准，24个null不能认证5%。

候选需计算整个有限区间字典，测试平均原生块成本及提案/DP计时约.257s/输入，对照原CP约.011s；4并发/非独占批运行，非独立现场单次延迟。计算负担明显增加，也不支持把此原型作为更快实现。

## 真实指令记录辅助

从已有冻结KIT144事件内，按每recording/方向的原时间顺序选首尾各1条，共72事件、18recordings；在拟合前写选择规则，不按误差选样。原观察、固定新Gaussian、同Gaussian加两尖峰共216输入、三方法648输出全可用；并非新真实现场留出。

同方法追加尖峰导致最长时长变化：原CP1.8639s、v2为1.8528s、LABS .4042s；累计目标时长变化.2153/.2000/.3181s，达90%状态翻转8/6/4条。v2相对原CP变化很小，不支持明显抗干扰增量。

这里是原100ms观察和外加扰动的描述/稳定性，不是潜在干净曲线准确率。秒、安培归一变化进度与主模拟分钟/kW分开；进度1不一定等于新绝对电流指令，不作真实净减载/现场时延或最终恢复认证。[选择](real_selection.json)、[真实摘要](real_summary.json)、[同方法配对](real_paired_stability.json)、[真实收据](real_receipt.json)。

5个开发控制，1536固定字典分割穷举，原CP与整窗缓存曲线差0，复算区间成本最大差约3.27e−12；退化γ=2β控制选择零jump、真单点保留和尺度变换检查通过。这些不是性能样本。

独立审计逐条核原生输入/输出、局部提案、区间成本、有限DP、统一特征/缺失分母、选择冻结和原始η，见[audit/independent_synthetic.md](audit/independent_synthetic.md)、[独立真实核验](audit/independent_real.md)。实现正确不代表性能胜出；本版不修改生产默认或伪称完整GRACE新算法。
