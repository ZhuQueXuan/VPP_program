# CPOP v2 跳变与斜坡候选：独立设计核查

2026-10-31。按用户已批准的v2方向，仅作技术核查，不拟合、不修改root实现或既有数据。下述结论针对给定候选字典，不预承诺性能增量。

## 数学目标

将候选边界作为观察点之间的切分，所有数据仅属于一个区间。对区间`[i,j)`，保持原观测值与声明σ，以全任务统一`β=2log(n)`运行原生CPOP，得到

`C(i,j)=min{Σblock (y−f)²/σ² + β×该block内部斜率变点数}`。

对候选分割`0=b0<…<bm=n`，外层目标是

`Σr C(b[r−1],b[r]) + γ×(m−1)`。在下述支配关系提出后、正式数据生成前，实施方已确定有效候选`γ/β∈{1.0,1.5}`，仅在验证选择；`γ/β=2.0`只作退化/等价控制，不参加验证选择。最初讨论的`{1.5,2,3}`已在试验前撤换，非看完数据换网格。

采用`F(0)=−γ`和`F(j)=min_i{F(i)+C(i,j)+γ}`可避免首段多付一次jump penalty；也可等价只给非首段加γ。内部原生成本已经含β斜率惩罚，不能二次加入；jump罚按外层边界数而非block数计。

原生R公开`cost()`定义为`sum(residuals²/sd²)+beta*(length(changepoints)−2)`。应直接保存该成本及真实内部变点计数，不能把两个自动端点当内部变化，也不能因为零长度端段被过滤就无说明重算惩罚。[官方文档](https://search.r-project.org/CRAN/refmans/cpop/html/cpop.html)、[CRAN源码](https://github.com/cran/cpop/blob/master/R/cpop.R)。

单点块取常数、双点块取直线都可精确拟合、残差0，仍须支付外层重置罚；它们不意味着有证据确认物理短动作。完整`[0,n)`块应与原版CPOP输出及成本一致，明确包含零jump方案。缺块或原生失败必须留记录，不静默改变候选类后声称原模型完整包含。

## 可以声称的精确性

每个区间沿用原生CPOP的连续折线优化；外层穷尽固定候选边界上的分割，可称相对于这一字典的最优组合。由于边界候选仅为观测分数top6与已知指令变化，不能称全位置跳变/斜率联合全局最优。

两个相邻块各有独立截距与斜率，故边界允许同时重置水平和斜率；它不是只允许跳变而强制保留传入斜率的模型，也不能把它等同某篇GRACE实现。区间均值仍按观察格分析，不认证格内物理变点时刻。

## 必须保留的风险与反例

- 不降权、不删点能避免v1的直接短动作压制，但增加自由跳变也可能更容易解释测量尖峰；改善与过拟合需要同场景评价。
- 观测top6可能被大尖峰或强任务边沿占满，遗漏真实单格动作的两侧边界。不能从真值补边界或按真实机制分流。
- 已知command edge只提供候选，不强制该时刻实际响应。无动作、延迟响应、未达标都保留。
- 一/二点块必须计入全部观测和外层罚，不能因最短段长删除真实短动作；同样不能以短块完美拟合证明其真实。
- γ只在独立验证选择，冻结后新test；不能依据已见test增加候选数、扩大γ网格或切换模型。
- 比较保留原CPOP/LABS及单格真实响应、单格真实间断、弱响应、null和尖峰配对条件；时长主指标、起变/达标缺失状态、曲线及失败/成本分别报告。
- 已知模拟参照不证明未知未调控参照可识别；原始电量积分不因拟合曲线改变。

目前设计未见原则性阻断。源码和保存输出就绪后，应独立穷举最多约`2^8`个候选分割核外层DP、核统一β及原版零jump包含，再重算指标与采用门槛。

## 试验前必须澄清：γ≥2β的支配关系

若所有原生观察位置都在原CPOP网格、允许零最短段长，则可将任一分块模型在相邻块之间的跳变，替换为最后一个左观察点到第一个右观察点之间的直线连接。所有观察位置的拟合值保持，至多每个边界新增两个斜率变点。因此原版全窗CPOP最优成本满足：

`C(0,n) ≤ Σblock C(i,j) + 2β×J`。

当`γ≥2β`时，原版零jump模型不劣于任何分块模型。`c=3`通常必退化为零jump，`c=2`至多形成等价tie；它们适合作为退化/等价控制，不能解释成和`c=1.5`同样有效的jump搜索。等价解应优先少jump，避免无必要切分。若保存输出在该条件下出现严格更低的c≥2有jump目标，应先查网格/内部成本/端点惩罚/优化器，而非宣布发现收益。

这一关系也意味着：新表示给跳变更低的复杂度代价和不同的格间形状，并不等于原连续CPOP在离散观察点上完全不能拟合阶跃。格内究竟瞬跳还是陡坡仍需独立信息，不可从同一格序列直接认证。
