# 未调节参考功率：有限比较与可复用入口

日期：2026-10-29。本模块为B1过程识别与激励主线提供共同的未知参考估计器，吸收RIDE的历史参考与条件GBDT思路。原RIDE源代码未改，真实数据适配器未使用。

## 1 本次实际改进

原自动选择采用平均有符号偏差，可能被正负误差抵消。本版按EV/空调分别选择，使用独立选择用户的伪事件窗口绝对误差，按事前请求量q归一。另保留固定GBDT与历史10日均值，检验选择器有无额外价值。

GBDT使用时段、星期、资源类别、通知提前量、通知前15/60分钟平均功率、历史日平均及模拟中声明为事前可得的温度。排除原实现中历史/伪事件终点导出的剩余能量、离站时间等特征，避免把仿真事后信息误当实际申报。这次实现没有证明该温度字段在任何真实数据源里均为事前可得；真实应用须另核数据时间戳。

训练、选择、校准、测试用户分别占50%、20%、15%、15%，互不重叠。校准以每用户全部伪事件窗口误差绝对值的最大值作为一个分数；不把同用户的各时点当成独立样本。选择与校准使用不同用户。输出为预测参考及经验校准窗口带，不能直接解释成已识别的单事件反事实轨迹。

## 2 冻结协议与实际规模

[protocol.json](protocol.json)先于主运行写入，检查与主运行收据中的协议SHA均为`db6eab89051cdcb61c3388706d29894eb1e8e507cb73ac878c8c02c25e34037d`。

- 开发检查仅用seed 905001；主运行用930100—930119，共20个独立种子块。
- 每块200用户×4事件，高温集中/普通两配对条件，合计32000模拟事件；两条件不是40个独立重复。测试用户每条件30人、120事件，三方法合计14400条测试误差记录。
- 1分钟计量，噪声0.15kW，无缺测；任务30/60分钟混合。保留原生成器的EV自然充电终点和提前离站机制。
- 实际模拟实现将后观察窗限定为90分钟、未使用的对照组数量限定为1，以减少资源占用。准确设置见run_reference.py的make；不复用作者自检seed。
- GBDT固定100棵树、15叶、最小叶35、学习率0.05，每历史窗口抽16个时段训练，单线程；无测试集调参。
- 主预算一次完成，耗时约62秒。没有因结果不理想而扩大样本或修改方法后重跑。

## 3 主要结果

下表为20次测试用户任务窗参考误差的平均RMSE，单位kW，越小越好。

| 条件 | 资源 | 历史10日均值 | 固定GBDT | 按资源选择后 |
| --- | --- | ---: | ---: | ---: |
| 普通 | 空调 | 1.2005 | 0.1575 | 0.1575 |
| 普通 | EV | 1.1351 | 0.3927 | 0.3927 |
| 高温集中 | 空调 | 2.1736 | 0.2395 | 0.2395 |
| 高温集中 | EV | 1.1351 | 0.3878 | 0.3878 |

按资源选择在四格均20/20选GBDT，因此本次结果**支持条件参考优于简单历史均值，未显示选择器比固定GBDT有额外增量**。按种子配对的RMSE差95%区间均低于0，见[paired_differences.csv](paired_differences.csv)。区间描述本模拟下种子间平均差，不代表真实设备性能。

GBDT仍有系统偏差：普通EV约−0.3112kW，高温EV约−0.2988kW，高温空调约−0.1485kW。因此不能把预测参考视为真实未调节功率，过程研究仍需评价其误差传播。

本次伪事件中，GBDT的`η̂>0.1`比例在普通空调上约35.7%，普通EV约0.71%。这个数值是原始参考残差积分的阈值频率，**不是经过程模型标定后的响应检测误报率**。即使参考RMSE降低，它仍可能不足以支持细小响应的判别。

用户最大窗口残差校准后，测试伪事件的整用户同时覆盖率在四格约89.99%—91.44%；潜在事件参考窗口经验覆盖约98.27%—99.40%，同时带较宽。名义90%的目标是伪事件用户块分数，不是单时点或潜在事件参考的精确90%覆盖。伪事件到实际事件的分布迁移条件未由公式保证；不能用潜在参考高覆盖单独宣称校准准确。

## 4 主线中的使用方式

共同未知参考建议首选固定`SafeGBDT`，因其更便于隔离过程方法的增益，本次选择器又未产生不同结果。所有过程对照必须使用同一预测参考，不给改进方法单独提供更准参考。

Python接口位于[reference_api.py](reference_api.py)：

```python
model = SafeGBDT(seed=...).fit(obs, train_users)
B_hat = model.predict(obs)

roles = split_users(obs.meta['user'], seed=...)
result = fit_references(obs, roles, seed=...)
B_event, B_pseudo = result.predictions['selected']
```

接口接受原RIDE的ObsData结构。`fit_references`返回三种参考、按资源选择结果、选择评分、每事件的归一窗口半宽及校准表。若某资源没有可用选择评分，该资源返回None选择与NaN参考；校准用户数量不足以取得有限90%分位时半宽为无限，不伪造有限区间。任务边界必须与完整计量格对齐；窗内缺测时窗口误差为不可用，不以缺测后的均值冒充完整积分。

`B_hat`仅是预测参考，接口不据此授权控制、不直接输出可信因果效应，也不替代后续过程可识别诊断。原B1现用接口未替换。

## 5 核验、复现与局限

七项必要检查通过：通知后功率改变不影响参考；事件离站/电量字段和历史/伪事件端点字段改变不影响预测和拟合；选择符合各资源MAE规则；用户角色重叠拒绝；窗内缺测保持不可用；宽度加权窗口均值正确。见[checks.json](checks.json)。

[audit_reference.py](audit_reference.py)独立读取落盘事件误差，重算240组RMSE与偏差，核对40组用户角色分离、选择方法一致，并核对原RIDE46个文件SHA不变，全部通过。见[audit_receipt.json](audit_receipt.json)。

运行命令使用项目内原RIDE复现虚拟环境Python，依次执行`run_reference.py --checks`、`run_reference.py`。主结果存在时拒绝覆盖。复核现有文件只执行`audit_reference.py`，不重跑实验。准确运行设置和数据/角色身份见[receipt.json](receipt.json)、[data_identity.json](data_identity.json)，原始误差见[test_events.csv](test_events.csv)。高体量时序不另重复保存，可由锁定源代码与新seed重生成。

这些结果只适用于原RIDE模拟器及本次范围。模拟的伪事件EV被构造成充电终点位于任务窗之后，真实事件允许自然结束，两者可能不具备完全可迁移性。温度集中造成的分布差异、原历史生成机制与GBDT匹配程度也会影响结果；未证明任何真实设备参考、跨资源泛化或B1总体完成。新增选择与校准属于通用方法的场景适配，不宣称独立创新。
