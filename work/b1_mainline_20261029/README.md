## 2 实际吸收了什么

参考侧吸收历史日与条件GBDT思路，排除实际离站、由未来终点反推电量等输入，分开训练、选择、校准和测试用户；选择按资源使用绝对误差，校准按原用户块计分。[参考模块](reference/README.md)

过程侧保留RIDE任务阶段模板和区间平均算子，并加入独立的有限网格连续折线适配，分别验证模板结构与观测解释。原F0/F1通过明确的任务窗适配参与比较。原生CPOP实际使用CRAN cpop1.0.10、R4.6.1；补充官方默认网格作为强对照，避免用4分钟粗候选网格弱化通用baseline。[过程模块](process/README.md)

因果侧落实离散七档、按用户交叉拟合的标准AIPW/APO、共同支持诊断、聚类同时带和非单调阈值集合。剔除自动单调收紧的保障主张，不启用有端点密度问题的连续剂量分支。与原生DoubleMLAPOS0.11.4在同一外部辅助预测下逐项核对一致；这是一项成熟方法适配，不是新的因果估计器。[因果模块](causal/README.md)

## 3 主要比较结果

过程主面板为20个独立种子块、8机制、3分辨率、2噪声，共960配对观测变体；不能当成960个独立事件。下表为请求窗曲线RMSE的均值，单位kW。

| 方法 | 10秒 | 1分钟 | 15分钟 |
| --- | ---: | ---: | ---: |
| 原生默认CPOP 直接格预测 | 0.02111 | 0.04893 | 0.09929 |
| RIDE式任务模板与平均观测 | 0.04664 | 0.04473 | 0.07255 |
| 同族通用平均适配 | 0.14358 | 0.13968 | 0.08503 |

10秒下CPOP更好；1分钟、15分钟下模板曲线误差较小，但不意味着所有过程指标改善。1分钟达标时点MAE，CPOP21.68秒、模板28.85秒，有效分母分别238、235。多平台机制下模板10秒、1分钟均20/20种子块未改善。匹配point/average消融在细分辨率无稳定收益，不能将模板收益全部归于平均算子。15分钟需要同时阅读连续曲线的平均投影和直接格预测，不能从少量粗记录宣称恢复了物理细时点。

因果面板20个独立种子块、600用户×6事件、5配对场景，共360000事件变体。非随机正作用下，六档相对作用曲线RMSE的20次均值：未调整0.06470、正确设定回归0.00697、标准AIPW0.00749。AIPW没有胜过匹配正确的回归；确定分配20/20拒绝报告因果曲线。仅20次重复不足以证明精确95%覆盖。

未知参考比较20新种子×2配对条件，共32000事件。固定SafeGBDT优于历史均值，四组选择器均选GBDT，没有额外选择收益；EV仍有约−0.30kW偏差。[参考到过程联调](reference/integration/README.md)使用另10新种子，按预设任务域实际取得52事件，参考误差明显大于1分钟两种观测算子之间的差异。

## 4 新研究入口与使用

[b1_research_api.py](b1_research_api.py)提供：

- `predict_reference`：从已完成历史和通知前信息拟合共同SafeGBDT参考。
- `identify_response`：显式选择`task_template`或`grid_average`，不按测试成绩自动切换方法。限定请求30分钟、1.5kW，观测窗−15至45分钟，10秒/1分钟/15分钟完整规则计量格。物理细时点和过程置信区间不输出已验证结论。
- `estimate_incentive_effects`：接收事前X、激励、合法事件结果y和原用户ID，诊断失败不输出因果曲线。聚类带的范围限于给定结果变量，不包含尚未验证的全链参考/过程不确定性。

使用原本地研究环境：`work/ride_b1_v02_reproduction_20261029/.venv/Scripts/python.exe`。运行本目录[run_demo.py](run_demo.py)可复核新入口和域外拒绝，输出[demo_output.json](demo_output.json)。这是过程与因果的独立入口演示，不冒充同一批数据的完整ABC主实验。SafeGBDT到过程模型的实际联调另见上文。
