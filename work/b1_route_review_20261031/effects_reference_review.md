# 参考、整任务证据与连续因素链的独立路线审查

2026-10-31。独立技术审查；只读实际源码、冻结协议与已有结果，没有运行新拟合、调整参数、生成新数据或修改旧记录。本文供路线决策，不是正式科研报告。根 AGENTS.md 最新纠偏优先；历史 `new_reference+original_CPOP` 决策只按已发生的实验处理。

## 一、我的推荐

**保留新参考作为双方共享、限定适用域的有效模块；保留任务证据作为独立状态；暂停把连续配置成绩解释为现有模板改进成果。下一次过程路线开发应先针对弱响应被压掉的具体机制立项，因素侧同时保持一条固定的合法估计链，分别评价测量和作用，避免再次以一个测量方法的排名替用户决定路线。**

现有证据支持“参考预测已实质改善”和“因果曲线仍有有限用户下的估计波动”。证据尚未支持“参考不确定性已进入过程估计”“弱响应测量已可靠”“新过程优于原CPOP”“提出新连续因果估计器”。继续模板或转向CPOP都应由过程侧的受控机制证据决定，不能由本次连续配置收益倒推。

本轮交叉审查新增的已见数据只读结果 `saved_process_diagnosis.json` 已进一步收窄下一步：151条模板漏中148条由幅度门置零，3条在检测后格均值低于时长阈值；这些漏并非BIC不过null。358条短矩形中，97条模板漏；其中55条存在合法M1精确形状见证，且见证BIC优于已选拟合并通过检测。该见证用了评价真值，不能用于初始化或当新算法成绩，但足以反驳“这些短响应全由模板结构不可能表达”。因此我赞成把下一步限定为**由可观测数据确定的短响应子族搜索，加到现有模板候选中，只改求解覆盖，先保持原惩罚/幅度门**。它比直接放宽阈值更能单独检验求解问题，也比立即转CP所需的新误差模型更接近已有证据。持续组漏的参考偏差均值约−.079kW仍是另一个问题；此修复不承诺解决全部151条或整任务60%不确定。

## 三、新参考：合法性已有基础，泛化仍须限制

### 已核的实现与实验事实

`reference/core.py:147–204` 禁止通知后功率进入prefix，核历史来源ID、非事件声明、所有输入可得不晚于通知；`reference/reliable.py:171–185` 进一步限30分钟/q1.5kW/提前15分钟/完整一分钟、任务相对[-15,45]的预测网格，实际特征prefix为任务相对[-75,-15]。`reliable.py:221–246` 只接受已完成的显式非事件观测作标签，训练目标为未来非事件实测功率减锚；没有接模拟true_reference。`reliable.py:266–291` 查询不重训，模型和输入必须已可得，负预测整条unavailable且不裁剪。

冻结协议 `work/b1_reliability_20261031/protocol.json` 列出train192用户、cal96新用户、validation/test新用户，整周时间平移保持日历。`study/continuous_inputs.py:25–64,96–127` 复用冻结参考，保留所有事实；连续正/零机制共享参考和事前条件，未按evidence筛选。接口本身允许训练用户后续查询并标为seen，因此研究中“用户隔离”是实验设计证据，不能泛说API对所有调用强制训练用户隔离。

同原CP、仅换参考，冻结测试的无动作正时长169/1024→15/1024，弱真实阈上漏185/690→38/690，参考唯一基础任务pooled RMS .17464→.06217kW。这个比较控制了过程算法，因此可以归为参考模块收益。该收益不自动支持“模板胜CP”。原始积分η也会随参考变化，过程拟合本身不进入η，必须分别归因。

### 尚未确定的部分

新参考在单一平滑自然负荷机制族、固定任务/采样下验证；整周平移保证时点合法，不提供新日历/新设备/结构改变的外推证据。源记录的真实性、非事件定义和可得时间仍需调用者保存原件，JSON和checksum仅作合同/完整性验证。

模型是一个点预测，没有预期误差均值、相关性或条件误差尾部分布输出。现有误差约.062kW已显著减少，但弱响应幅度约.21/.30kW、阈值.15kW，少量持续负参考误差仍可能决定格是否越阈；“点预测平均更准”与“阈值附近可靠区分”是两个验证目标。此句是机制推断，需过程侧事件级分层和受控替换进一步证实，不能给各原因分配百分比。

## 四、整任务校准：测量值和证据仍须并列

秩是 `(1 + #校准用户最大分数≥当前分数)/(96+1)`；在同分布、独立用户块、同两事件结构等可交换条件下解释。通过事件级查询的方式对未来同一两事件块取最大可对应用户块控制；随意扩大每用户事件数、改变任务或过程/参考路径，都不能继承原控制结论。校准signature绑定过程方法、策略、参考模型、W/q/采样/噪声比例、通知和分析profile，路径变化应重新校准，双方同信息并分别校准。

还有一个现场边界：明确未发任务的non_event与“已发通知但真实无动作”的null，在当前生成器中共享可比较自然负荷机制；现实中通知本身可能改变行为或背景，二者的可交换性不能只靠非事件声明保证。这是现场外推限制，当前模拟计分没有因此自动失效。

上尾比较使用的是各路径自己的**拟合**曲线，所以模板若先压掉弱信号，后置扫描无法恢复它；单独降低证据阈值也未必恢复物理时长。另一方面，原CP正时长漏仅38/690时，弱证据仍不足414/690（60%），说明“可以量出正时长”与“相对自然残差有足够证据”相距很大。3分钟的短弱响应尤其需要单列。

最终输出应继续保留数值Y、证据/不确定状态、参考/过程来源与可用性。不得用“不确定→0”或只筛有证据者估总平均作用；后者按处理后的响应选择样本，会改变目标人群并可能引入选择偏差。校准的non_event必须是明确未发任务记录，不能从已邀请未响应者中挑“干净”组。

## 五、连续作用：收益是真实的配置收益，但路线证据不足

冻结成绩 `effects/assessment.json`：正作用原默认73.597秒→所选49.381，5/8块更低，配对差−24.216、MC95[-61.290,12.858]；零作用59.657→34.858，8/8更低，差−24.799、MC95[-42.787,−6.810]；每块正零等权合并68.919→43.422，配对区间含0。八个独立种子是推断单位；正零配对机制不能算16个独立块。

这里两配置共享同一新参考+原CP测得Y。它直接检验“在该测量链上的有限配置选择”，没有检验现有模板的端到端改善。zero指激励不改变响应分布，仍有参加和动作，不能当物理无动作。

`protocol.json` 的 `continuous_after_reliability.process` 已写入新参考+原CP；`validation_decision.json` 也记after-validation选择和“as predeclared”的连续阶段。仅凭现存文件内容，不能独立恢复每个决定的生成时刻。能确定的是协议与验证决策均写入该路径，`study/continuous_inputs.py:60` 的实际调用随后使用 `'cpop'`。无论该选择写入早晚，兼容默认/原CP源码未改都不能说明研究路线未换；现有记录不提供用户批准替换正式主线的依据。

`tuning.py:169–185` 的Ridge alpha同时影响结果回归和GPS，选择风险却是Y预测风险；不能据此判定密度最优。`tuning.py:107–139,193–245` 的整用户留一平滑确实排除该用户全部事件，但伪结果先整体crossfit固定，各人的伪结果可能经辅助训练彼此依赖，所以它不是重跑全辅助模型的嵌套全链验证。这是已明确披露的局限，并不使已有测试成绩无效。

已有 `b1_effect_detection_diagnosis_20261031/effects/mechanism_notes.md` 还提供重要反证：真Y下后段正作用RMSE仍75.449秒、零47.517；伪结果校正存在明显有限样本波动。新过程与CP的零作用总MSE差同时伴随更负交叉项，测量分量A²并未更低，故总分改善可能含误差抵消。不能用过程MAE下降宣称曲线因果改善，不能直接把旧面板分解搬成新参考面板的原因占比。

未调整在当前面板胜出（所选正作用41.646<DR49.381）是必须保留的反证。L/U在设计中共同影响金额，且对Y方向相反，混杂可部分抵消；删除合法L/U只为求RMSE好看没有识别依据。plugin、未调整、同伪结果直线都应留作诊断对照，而不能轮流挑赢家当新估计器。

### 旧selection的复用边界

`tuning.py:215–245,388–416` 绑定task/units/population/domain/grid/X列/assumptions等，保留验证数据digest。但固定合同没有单独强制“参考模型ID+过程方法版本+结果测量policy”字段。实测Y换了，原超参数可能仍能运行，这只表示合同允许，**不表示它已经在新测量链上验证过**。后续协议/元数据至少应绑定测量来源；若要为新过程形成部署配置，须新验证用户选择或明确按旧配方作未重新优化的迁移评价。本轮只记审查项，不改合同或旧artifact。

## 六、推荐的最小后续工作与停止条件

1. **把本轮只读弱响应机制判别作为开发依据，不再泛说BIC压制全部弱响应。** 按短/持续、.14q/.20q、真实阈上分钟数、参考有符号偏差/尾部、拟合模型/BIC/求解状态并列；用上文55个精确合法好解见证支持一次有限求解覆盖修复。151条漏不能全归为模板表达或全归为参考。已见测试只用作诊断，不得让oracle产生部署参数。

2. **过程候选只增加一种可解释机制。** 首选上文有限短响应子族搜索，保持原惩罚和幅度门，避免同时改变求解与统计判定。参考相关残差作为后续独立问题，可研究由独立non_event估计的误差模型及其对拟合/判定的明确作用。参考协方差/误差模型需要避免把真实长响应当漂移吸走，须用同信息CP及原模板做消融。当前后置秩校准不等于已经实现这项机制。若转基于CP，应以这一真正改变目标/模型/估计的部分为研究对象，同时对比同新参考的原CP；原CP直接接入仍是baseline。

3. **先固定因素估计，评价测量是否带来作用增益。** 首个矩阵至少为共享新参考×[原CP、现有修复模板、一个新候选]，下游共享一个预先固定Kennedy配置和合法L/U。Y必须保留全体已邀请者。分别比较个体时长、真实阈上漏/无动作误、证据不足、作用差曲线和η；这能判断改进在哪里进入链。

4. **连续配置优化在测量路线明确后再单独评价。** 如保留有限选参配方，使用新验证用户/新测试并固定预算，不追当前8块。若需要改模型，应先检验OOF残差与校正项的哪项不足；直接增加网络、随意截权或抹除合法混杂无证据。可把参加/正时长两部分作为结果回归的内部nuisance候选，其最终结果仍对全体求均值，不能把参加当调整变量；这是待论证选项，非当前推荐立刻开发。

5. **比较与停止标准须同时限制收益和代价。** 开发前声明可接受的弱漏/强响应退化、误检、时长误差、运行预算、作用差曲线误差等实用幅度，以用户/种子块配对区间判定；不以“所有指标都显著赢”作不可能承诺，也不以平均总分遮盖短弱反例。若新增机制只在已见数据奏效、优势来自筛样本/换目标、过程收益无法在匹配下游体现，或代价超过事前预算，则停止该候选并保留负结果。若只证明参考收益，就按参考收益收口，再与用户决定是否继续过程路线。

6. **阈值/敏感性先维护现有功能与限制。** `frozen.py:90,168,194–216,250` 已明确条件抽样带不传播全链误差；本轮不应借路线审查扩成完整覆盖理论项目。所选测量/因素链稳定后，用同协议检查支持、导数和达标候选是否改变；无稳定支持或阈值跨越不确定时保留不确定/未达。

## 七、保留、暂停、需重做

| 处理 | 内容 | 理由 |
|---|---|---|
| 保留 | 新参考代码、冻结模型和同CP参考消融成绩；旧选择器及负结果 | 有明确可复核的模块收益；域外和历史反例有研究价值 |
| 保留 | 独立任务校准与全部数值Y；原CP独立主对照 | 证据状态有用；需要防止弱响应筛选改变估计目标 |
| 保留 | 现有连续DR、plugin/未调整/直线、冻结查询、现有selected配置与原成绩 | 是成熟方法适配与有限配置实验，实测收益和反例都应保留 |
| 暂停 | 沿用“newref+原CP已正式选为主线”、宣称模板改好/全B1完成 | 授权不足且证据不支持 |
| 暂停 | 在已见8块继续调带宽/阈值/权重、因naive好而删L/U、按evidence删样本 | 会破坏比较/估计目标，并掩盖关键风险 |

本审查没有新增性能样本，也没有证明当前模板一定可救或CP增量必胜。最值得保住的是已经得到的参考收益、合法因素链和负结果；最值得花下一小步成本的是查明短弱响应在过程估计哪一步消失，以及一种针对性机制能否在公平新比较中改善它。
