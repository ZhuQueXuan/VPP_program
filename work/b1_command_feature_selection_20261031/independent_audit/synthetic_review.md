# 同条件过程特征比较：独立只读审计

2026-10-31。审计对象为新协议下的已知参考、一分钟格过程特征比较。仅核验保存结果与来源，不调用估计器、不重跑R、不改冻结脚本或旧文件。

**结论：全部计分与冻结选择一致；LABS是验证候选中的最小主误差者，但新测试没有通过预定改进门槛。原CPOP控制的主指标更好，应完整保留这个反证。本轮不足以正式采用LABS或将原CPOP重新命名为我们的新算法。**

## 1. 设计、输入和来源

- 64个验证任务、192个测试任务，每任务7种方法，共448+1344=1792方法输出，全部ok，无不可用/删行；验证/测试各一个新用户一事件，用户和种子不重叠。8种机制分别为验证每种8条、测试每种24条；测试6种子，每块32任务。
- 方法均收到相同已知自然基线B、实际功率、任务W/q、minute格和测量尺度。拟合器不读取command_kw或生成参数；LABS仅接同一残差y。这里的B是显式已知模拟背景，不是任务指令，也不是事后训练的预测参考。本比较不能认证未知参考部署。
- 独立动态生成代码是细格一阶/二阶控制响应、延迟/间断/回补，再聚合60×60的一分钟均值。没有以RIDE/TF/CP/LABS输出生成干净标签。它保证检查到的功率范围，但未构造完整充电需求、期限、SOC或任务减载与回补能量债务守恒；early_exit表示响应提前结束，不是实际拔枪离站。
- 全方法曲线先保存，再打开evaluator计算分数。LABS选择仅用验证集，冻源、模型与旧运行源码SHA一致，冻结记录test_not_generated_yet=true，文件时刻支持随后才生成test。哈希/mtime是本地记录一致性证据，不能代替外部可信时间戳。
- 作者LABS commit为`0bb0524dec39336a2e0d032287ce092e2968145a`，与协议/下载收据一致。作者R源码、MIT许可、引用文件、README的SHA都核同；全部256个LABS原生输入case与返回60点从CSV复放一致。没有把作者2026方法记为本项目创新，也没有执行整套作者benchmark或安装依赖。

## 2. 全量计分复核

独立按格重算累计、最长阈上时长、首次onset/target区间、恢复首次入带、幅度/功率曲线及回补积分；逐条核真值状态、不可达类别、条件时点误差及全分母。所有1792行与126个“方法×全部/各机制”汇总一致。全部7法raw_eta均与共同原始残差积分相同，未将拟合电量替代原始η。512条TF曲线也用旧对偶变量核固定Σ/λ的原始重建式，无求解重跑。

测试主指标是`0.5×(累计时长绝对误差＋最长连续时长绝对误差)`，不是单一累计时长，不能把同名“秒”混用。

## 3. 验证选择和预定门槛

验证主指标候选：原RIDE44.5313、修复RIDE33.2813、标准TF42.1875、GLS52.0313、LABS24.8438秒。因此选LABS与冻结一致；raw和CP仅作正式控制没有进入候选选择。候选间没有1e−9附近tie，本轮代码直接min的差异不影响真实选择；本审计没有修改冻结脚本。

LABS测试相对修复RIDE的主指标仅改善1.1628%，不足预定10%；全60格曲线RMSE .070388也高于.060116。全可用和null误检限制通过，另外两项不通过，所以综合gate不通过。不能在test看到原CP较好后改选它作为新候选，或改用TF最低累计误差重新定义原主指标。

## 4. 原RIDE回补上界的影响：单列，不归咎全部求解

原RIDE保留历史默认回补幅度1q=1.5kW；修复RIDE在声明的7.2kW设备/基线下使用headroom。二者输入资源资料相同，但约束表达不同，不能说形状/幅度可行域完全相同。

对干净**一分钟格**曲线，验证3/64、测试10/192的后窗负回补峰超过1.5kW；测试为delayed_rebound7条和oscillatory3条。对完整60格的上界分类恰相同。完整细格最小值虽已保存，也不能把其位置一律当“后窗细格峰”；本文子集明确按干净minute曲线分类。

## 5. 本轮GLS与标准TF的解释边界

新噪声开发128×60残差是已知参考域中的独立高斯计量噪声，不含旧预测参考误差。LedoitWolf的**shrinkage=1.0**，完整协方差完全缩到标量单位阵。本轮没有实证学出有用的相关协方差结构；GLS/标准TF的差别主要是固定λ2/4及中心化方差尺度。不能将本轮GLS成绩称作“参考相关误差处理增量”，也不能用新域成绩覆盖旧未知参考pilot。
