# 指令与实测曲线的全过程特征：近期方法比较

2026-10-31。已完成文献核验、原生作者复现、共同条件验证/新模拟测试和真实记录辅助检查。第一部分限定研究，不训练参考预测、不动第二部分或正式报告。原算法源码、全局默认与旧冻结记录保持。

## 结论与使用建议

**本轮新增的2026年LABS没有达到整套替换条件。CPOP在本轮已知参照模拟的持续时间和曲线指标上综合最好，但时点/恢复与各机制并非全面最好。当前不存在证据支持把某个候选称为全特征通用最优。**

实用建议分清用途：

- 对已有指令和实测的速度、跟踪、稳定执行等特征，继续使用直接定义和提取，保留原始观察值、采样限制与未达状态；预测不作前置条件。
- 对参照已经给定的完整减载过程，CPOP目前是最强的现成测量基准，仍作为独立主对照。若只问这次相同条件下哪个表现最好，答案是CPOP；其成绩不算项目创新，也不据本实验擅自替换正式研发主线。
- 原RIDE/修复RIDE作为已有方案保留；本轮不整体采用LABS或TF替换。LABS在固定尖峰扰动下有局部抗干扰收益，可保留作候选，不按已见测试继续调参。
- 未知未调控参考仍单列为条件受限问题；本次已知模拟参照的成绩不证明未知参考或真实净减载已解决。

## 最近论文与候选选择

核验截至2026-10-31。新增唯一方法候选为Fryzlewicz于2026-08-21发布的[LABS预印本](https://arxiv.org/abs/2608.21122)：识别连续分段线性曲线的斜率变化。直接使用[作者GitHub](https://github.com/pfryz/LABS)固定提交`0bb0524dec39336a2e0d032287ce092e2968145a`，MIT许可；仅核到一次提交，不称长期成熟维护或已验证EV算法。

原生R核心仅用已有stats/splines，显式M5/retest_M2及作者sSIC；无重写核心、无额外安装、无运行全仓库安装/下载脚本。作者文章里的长序列速度优势不能直接外推到60个分钟格。LABS是成熟统计构件的新近候选，不作为本项目新算法。

另核MOSUM_linear（2024，同时跳变/斜率，额外Rcpp与许可核验成本）和skchange（2026，算法框架仍需选具体检测器）；本次不扩张安装与选参。领域论文采用[Esser等2025充电动态数据论文](https://doi.org/10.1038/s41597-025-05524-5)及2026 KIT发布核对输入和技术响应用途。项目10%/90%为既有定义，不能冒充其他论文5%/95%或正式90%模型精度。详见[简明文献选择](literature/literature_selection.md)、[公式和来源核验](literature/selection_review.md)、[作者下载版本与许可](vendor/LABS/download_receipt.json)。

## 同条件主比较：192个新模拟任务

先128个独立非事件估计计量误差，再64验证任务；按预定规则冻结候选，然后才生成6个新种子块、每块32任务，共192任务/192用户，不复用前轮test选参。每任务同时比较7法，无按真实强弱切换。模拟是独立一阶/二阶动态控制响应，含低幅持续、短弱、间断、提前结束、振荡、延迟回补和无动作，非RIDE/TF/CP/LABS反向生成。

所有法使用同一明确已知的模拟未调控功率、同一实际功率/噪声、任务30分钟/q1.5kW、1分钟完整前后窗和特征判据；不把指令冒充反事实。原生产过程函数与特征函数未改。TF使用原实现、固定既有λ4/2，在新非事件重标计量误差；这是不同于旧未知参考冻结配置的新实验。此处LedoitWolf最终shrinkage=1，完整Σ已缩至标量I，不能据两TF差异声称相关权重改善或恶化。

主指标是**累计有效时长误差与最长连续有效时长误差的平均**，有效仍为≥.1q；不是响应延迟。所有主输出可用，未删行：

|---|---:|---:|---:|---:|
| 直接原曲线特征 | 36.56 | 110.94 | 73.75 | .05025 |
| 原RIDE | 27.81 | 52.81 | 40.31 | .07191 |
| 修复RIDE | 25.31 | 55.31 | 40.31 | .06012 |
| 标准TF | 23.75 | 65.63 | 44.69 | .03938 |
| 加权TF配置 | 26.88 | 82.19 | 54.53 | .04353 |

完整数值与各机制结果见[比较表](comparison.csv)、[全部机制结果](outputs/test_summary.json)。

验证前已定按时长两项平均选择非对照候选；验证选LABS24.84s，冻结后测试39.84s，仅比修复版改善1.16%，6块仅2块较低，曲线误差反增，未达到预定≥10%时长改善且曲线不退步的门槛。CPOP相对修复版6/6块主指标更低，但不能据此改用其名称当作项目贡献。[冻结选择](validation_freeze.json)、[采用判定](selection_decision.json)。

其余特征保留负面结果：

- CPOP并非时点最优。共同可用时点的起变MAE13.65s、达90%MAE38.42s；修复RIDE为9.75/24.86s，但起变状态错8条、CP1条，不能只看条件时点均值；全部分母/未达状态均报告。
- 低幅持续组24条，原RIDE主误差42.5s、修复70s、CP75s；间断组标准TF23.75s、CP52.5s、LABS98.75s。不据真实机制事后路由或拼赢家。
- 本次无动作仅24条；CP/TF/LABS/两RIDE原始正时长误检0，不能称已认证5%。此次未运行新整任务秩校准。
- 原始电量积分/η在全部192任务、7方法间逐项相同；拟合曲线收益不冒充计量电量收益。
- 原RIDE保留历史1q回补上限，修复版利用声明headroom：10/192任务干净后窗超原1q界。共同界内182条旧/修主误差均41.87s，LABS40.71s、CP25.71s；不是删掉这些任务重做主成绩。该界差主要影响后窗，不能将其全算作新求解思想。见[独立核验](independent_audit/synthetic_review.md)。

ODE仅保证本次功率形状处于单向充电范围，未标定真实用户需求、期限或能量债务守恒；early_exit表示响应提前结束，不等于观测到了实际离站。六种子小比较不证明跨资源、市场或现场能力。

## 真实记录辅助：144个指令事件

KIT原件18套记录，每套固定4上调/4下调，按原候选时间均匀抽取，先写选择再读原Parquet，不按误差/速度选样。每命令只取一个优先L1的可用相，共144事件。用100ms格内原观测均值聚合，原点4—6个/格，无插值、无补挑、无删除。秒和安培/归一化进度保持，不塞入分钟/kW RIDE生产入口；RIDE本域明确N/A。

原记录没有独立干净曲线或未调控参照，所以本域只比较**同一观察记录的特征变化与外加噪声后的保持能力**。原始观察算自身差0不等于真实准确率100%。先固定增加σ=.03进度高斯噪声，再用同噪声加两个±.30尖峰；432输入不是432个独立真实事件。

真实进度定义为`sign(Δ指令)×(实测电流−事前实测中位数)/|Δ指令|`，90%是请求变化幅度的90%，不是新绝对指令电流的90%。只有事前实测恰等旧指令时，进度1才对应新绝对指令；本表稳态进度偏差不可与原CSV的安培绝对指令误差直接混用。

| 外加条件 | 方法 | 保持原观察累计达90%时长的差/s | 最长连续时长的差/s |
|---|---|---:|---:|
| 高斯噪声 | 直接特征 | .742 | 1.892 |
| 高斯噪声 | 标准TF | .636 | 1.219 |
| 高斯噪声 | CPOP | .377 | .474 |
| 高斯噪声 | LABS | .412 | .531 |
| 高斯＋两个尖峰 | 直接特征 | .793 | 3.017 |
| 高斯＋两个尖峰 | 标准TF | .692 | 2.531 |
| 高斯＋两个尖峰 | CPOP | .392 | 2.044 |
| 高斯＋两个尖峰 | LABS | .388 | **.567** |

这支持保留LABS作为特定尖峰扰动下的候选，不代表其真实时长更准。原未加噪输入，LABS改变了8/144条“是否10秒内达90%”状态，CP2条；差异不等于与独立物理真值相比的错误。

上述表统一以原始观察特征为参照，混合了拟合偏移与扰动影响。更严格比较相同高斯噪声/相同σ下追加两尖峰前后，同方法最长时长变化LABS .305s、CP1.846s，达90%状态翻转5/19条；但累计时长变化LABS .227s反大于CP .185s，局部优势不能称全部特征更稳。[独立真实核验](design_review/independent_real/real_audit.json)

可用性必须同时看：原条件标准TF只有115/144通过，29条求解虽有限且SciPy终止成功，但凸最优性gap/KKT证书未通过，明确拒选、无raw回退；其115条均值不能拿来与其他全144条宣布胜出。这是当前实现转入低噪声秒级域的数值可靠性限制，不等于趋势滤波数学模型天然无效。两加噪条件TF各144可用，其余三方法三条件均144可用；总1699/1728有效。失败完整保留。[真实摘要](real_summary.json)、[准备协议](real_preparation_protocol.json)、[扰动协议](real_comparison_protocol.json)、[原件及选择保护](real_preparation_receipt.json)。
