# 指令与实测场景：同条件特征提取比较设计审查

2026-10-31。独立技术审查，仅新目录材料；不改旧源/原始数据/冻结结果。本设计区分可识别的模拟误差评价与真实记录的描述/扰动稳定性，避免将任一去噪结果当成干净真值。

## 可执行的主比较

**同意在生产共同合法1分钟域做小规模独立非模板模拟主比较，并以真实KIT命令记录做有限适配辅助。** 主比较固定W=30min、q=1.5kW、[-15,45)完整60格；原RIDE、修复RIDE、TF标准/GLS、原CPOP、作者LABS接同一事实残差、任务、参考与共有测量口径。TF标准可作主要TF结果；GLS保留同样本内部复现列，避免抹掉用户关心的已有版本，也不再发展成每个模块一套baseline。

模拟B是生成机制声明的未调节功率，不是指令本身，也不是从响应后的实测反推。若共同输入真实B，结论应限定为过程恢复能力筛选；不能由此宣称未知参考问题已经解决。未知参考/实际观测功率变化需要另列证据。本次不重训参考预测器来改变比赛条件。

建议接受主审提出的规模：独立dev64个非事件供误差尺度/协方差；validation约64个跨8机制事实用于有限配置冻结；test6独立seed块×32=192事实、每机制各4/块。生成机制、seed用途及选择规则均在test前冻结。不同方法同样本、全失败分母保留，旧源码及旧结果SHA保持。少量seed只支持有限机制下的研究取舍，不构成真实精度或总体优越保证。

## 2. 主指标及防止任务偷换

**主结果保持原物理计量阈值0.1q=.15kW的累计秒数。** 最长连续段另列，驻留按原30秒定义映射为1分钟完整格，不能为不同方法改阈值。全部方法都从输出格曲线用同一冻结提取器计算。

同时报告：任务与后窗曲线pooled RMSE；幅度/平均/峰值；累计与最长时长MAE/偏差；原始正时长误检与弱阈上漏检；onset、target、恢复和右删失状态；任务/回补电量与剩余债务；失败/降级/不可用及CPU/批处理计时。所有结果按机制分层，不用null平均掩盖强/弱或间断失败。

onset=.1q，target=.9q，必须保持相对同一请求q；弱响应未达.9q是合法结果，不能换成自身平台90%制造t90。时点误差只在双方定义时给条件值，另报真实未达、误报达标、漏达及不可用全分母。模型θ的“爬坡时长”不等于统一格曲线10/90时间，不能把RIDE参数与CP折点或TF曲线斜率直接当同一真值比较。

当前`_frozen_f0.extract`的power recovery为W后首次连续入±恢复带，不要求其后永远不再回补。延迟回补前等待可能已经入带；需写“首次入带”，不能称最终物理回补完成。能量恢复/剩余债务及观察结束右删失另评。原始η继续直接积分共同原始残差，不因拟合器不同变化；拟合能量仅可单列为曲线特征。

独立非模板生成可用一阶/二阶动态、衰减/疲劳、多次中断、早退、延迟回补及未完成回补等控制，不调用RIDE/TF/CP输出生成真值。先在更细独立生成网格产生轨迹，再按精确时间积分形成1分钟真格均值；所有方法评价同一可观测格尺度。允许用该独立干净真格曲线经统一规则得到“格尺度特征真值”，但不能用候选去噪自身的曲线当truth。物理约束超界应明示生成失败，不隐式截幅。

TF若在新dev重估Σ和λ，要保留新协议/新产物身份，不冒称旧pilot冻结配置；λ/Σ与CP的σ都在test前确定。标准TF与GLS若协方差尺度、λ同时不同，只能称整套配置比较，纯相关结构收益须限定内部消融。所有方法获得相同合法数据，原算法无法使用完整Σ时应说明其模型限制，不声称信息差为算法原创收益。

## 3. 原始真实来源核查

**KIT**原件为`work/ev_charging_research_20261016/downloads/KIT_LF_SOURCE_01/ev-charging_lf.parquet`；旧协议SHA绑定此原件，字段名timestamp_ns实际由TIMESTAMP_MICROS解码，原观测约20/21ms。既有PREP保留全部28641分相候选，admitted4928条，其中L1共1875个不同命令变化、18recordings；单方向每recording至少8条，足以固定4up+4down。旧源摘要为18recordings/24474687行，不能把各相当独立车辆样本。

原KIT记录特征以指令前5秒电流中位I0，定义`progress=sign(ΔI)*(I−I0)/|Δcommand|`，相电流A、时间秒；t10/t90按原采样持续100ms，搜索起点至10秒、确认可至10.1秒。真实raw特征已有4263达90%、665未达记录，未达必须保留空值/删失。它们是描述性观测特征，不是独立潜在干净电流truth，也不是端到端派单时延。

**Dortmund**原`data/public_datasets/德国_多特蒙德_电动汽车充电实验/dataset_merged.zip`已直接只读查看其中动态V1G AC CSV。原CSV第一行为分号字段名，第二行为单位行，随后数据；`P_kocos_200`是网侧kW，`AC_Power_set_ID2/3/4`是指令kW，epoch为毫秒量级，不可当秒。同期三接口指令相等是旧静态映射协议的取样条件，不证明这些指令就是未调控功率。不得猜STATE/接口枚举，不能混输出侧DC功率与网侧P。历史分钟汇总表已损失原秒级阶跃信息，不适合拿来认证秒级动态。没有相同独立未调控对照，仍不能直接计净减载truth。

Dortmund可后续按原动态V1G原序窗口作命令跟踪辅助，但本次最小真实比较用KIT即可，避免把两个独立场站/车辆拼成同一资源或多加一条数据处理主线。旧冻结任务仅会议/原真实结论不改。

## 4. KIT本轮最小真实辅助设计

**建议值得做，限定144单相事件，不让RIDE硬入域。** 每个recording在旧admitted命令里每指令只保留一个相，优先L1，再L2/L3；各方向按原时间顺序，用预先固定均匀索引取4个。窗口/分箱失败保留N/A，不换下一个好事件。当前每方向均足4，但协议仍保留不足时不回填的分母记录。

输入统一为[-5,15)秒的200个100ms原观测均值，按原微秒时间戳半开分箱，不插值/补点；每bin至少2个原观测、首末距边界不超50ms，全窗口原相邻gap≤50ms。这里是“记录点均值”，并非校准过的连续电流积分。保存原relative_us/phase_current_A及每bin计数供重放；不用其他相补缺口。

事前I0仍取原[-5,0)样本中位，q=|Δcommand|、方向符号固定，不能用未来末窗实际幅度归一。前噪声仅由前窗格均值差分MAD估计，退化时差分SD，再用预定1e−3 progress数值floor；记录所有估计和所用方法，floor不是传感器精度证据。TF/CP/LABS收到同一归一progress数组和真实秒坐标。原RIDE/修复RIDE在此正式域标N/A，不喂虚假未调控reference，不伸长20秒成20分钟。

真实评价报告：提取是否可用、t10/t90达阈状态与区间、原/聚合/各去噪曲线的观察差异、末窗电流/跟踪误差及过冲、按recording/direction分层。原50Hz与100ms均值的采样尺度不同，原raw特征仅作描述参照，不计算“哪法更准确”。不将末窗贴近新指令当去噪器预测准确率。

可以加一次预定、同seed、同幅度、独立加性小噪声扰动到各方法共同输入，评价输出特征相对本方法原记录输出的变化，名称限“扰动稳定性”；原记录已含未知噪声，不能据此称真值恢复。没有独立重复测量/注入前干净信号时，噪声扰动不识别原始测量误差。不要用某法去噪输出生成干净信号再证明该法胜。

## 5. 本轮可下结论及停止边界

模拟主比较可回答指定非模板机制下哪种方法更适于共同格尺度特征；真实KIT辅助可回答数据域接入、可用状态、方法差异与小扰动稳定性。两者均不自动回答未知反事实净响应、真实因果激励曲线或B2单体承诺能力。

若某方法只在曲线RMSE好但累计时长/删失恶化，必须分别结论，不用总分强定赢家。验证不适用/数值失败需留分母，既不重复调test到赢，也不因LABS较新预承诺胜出。原源码保持；所有新work适配都明确版本、单位和范围，不覆盖旧记录。
