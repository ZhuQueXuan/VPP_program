# 近期方法选择核验

核验日：2026-10-31。只核论文与作者代码，没有执行算法或安装库。详见本目录`selection_review.md`及`sources.json`。

本轮只新增**LABS**作为文献候选。Fryzlewicz的[2026-08-21预印本](https://arxiv.org/abs/2608.21122)研究连续分段线性信号的斜率变化，用子递归结果限定父节点复检区间。作者[原生R源码](https://github.com/pfryz/LABS/blob/0bb0524dec39336a2e0d032287ce092e2968145a/code/LABS_functions.R)可独立调用基础R、stats、splines；无需为核心算法新装比较库。固定作者配置`labs_sic_fast(x, initial_test=TRUE, M=5L, retest_M=2L, multipliers=seq(.50,1.50,by=.05), alpha=1.01)`。函数默认M=2，故必须显式固定M5R2。

作者代码选择准则为`n*log(RSS/n)+(2*K+3)*log(n)^1.01`，噪声以`mad(diff(x,differences=2)/sqrt(6))`估计，固定阈值倍率网格。这里alpha是信息准则指数；“SIC配置”不等于用户任务层面的5%误报认证。该方法输出斜率断点及拟合曲线，四阶段、累计/最长时长仍由所有方法共享的项目规则提取。

固定提交为`0bb0524dec39336a2e0d032287ce092e2968145a`（2026-08-21T13:33:27Z），仅核到1次提交。[MIT许可](https://github.com/pfryz/LABS/blob/0bb0524dec39336a2e0d032287ce092e2968145a/LICENSE)只覆盖作者原创代码。它适合作为可复现的新候选，尚不能称长期成熟、已同行评审或经过EV现场验证。原CPOP是成熟强对照；[2024 JSS软件论文](https://doi.org/10.18637/jss.v109.i07)已有加权残差、非等距、异方差与CROPS，保留这些已有能力的准确归属。

本轮不新增以下安装与移植：

| 选项 | 证据与取舍 |

| skchange | [2026-08-20论文](https://arxiv.org/abs/2608.19767)描述算法框架；[作者仓库](https://github.com/NorskRegnesentral/skchange)BSD-3，2052提交并有CI/文档。新增该库仍要确定检测器、代价、重建与参数，不能把框架名称当完整新提取法；本轮无需扩安装范围 |

已知指令与实测功率可以直接评估操作响应，不要求先预测未调用功率。指令前局部水平支持这次操作幅度定义；未知未调节参考及净减载是单列问题。LABS采用连续线性结构，真实阶跃/短中断仍可能不占优；MAD估噪不等于异常点稳健回归。它没有原生不等距时间接口、缺失处理或精确区间平均算子，15min少格数据不支持唯一分钟级阶段识别。提前离站、恢复未完成与缺测须保留删失/不可用状态。

领域语义参考[Imanaka与Baba2025在线/2026正式论文](https://doi.org/10.1002/tee.70176)：其起变/全激活阈值为5%/95%，ICT回执与功率响应分开；本项目10%/90%若继续使用，须标项目定义。[Esser等2025数据论文](https://doi.org/10.1038/s41597-025-05524-5)包含动态setpoint及同步grid active power，可支持命令响应核验；不同设备命令有kW与A两种单位，不能互换。公开数据无完整人工阶段真值时，不得把算法边沿当标签或声称阶段准确率。

本件推荐的仅是新增候选和复现边界。具体验证/测试、候选冻结与最终是否采用，应引用主实验原始记录；文学新颖性和验证表现都不支持提前承诺全面胜CPOP。
