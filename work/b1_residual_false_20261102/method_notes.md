# 方法依据与备选（2026-11-02）

本轮实际实现的是量测证据增强后的整任务达标核验：保留既有426维描述，增加101维多窗口均值分位数、临界功率占比、连续段和超阈面积描述；标准HGB分类器判断是否达到原0.15kW标准。观察窗口包括单个采样格，不设置最短真实动作，不修改测量点。该分类器不是新发明的提升树，也没有修改CPOP动态规划。分数不是校准概率。

先查官方 [scikit-learn ensemble源码](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/ensemble/__init__.py) 与 [HGB源码](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/ensemble/_hist_gradient_boosting/gradient_boosting.py)：仍维护、BSD-3-Clause，已有1.7.2可用，原生JSON导出成本低，故复用，不增加依赖。

初次冻结测试414→373误报，减少9.90338%，未达到预设10%门，原assessment明确不采用。不能改为9%后宣称通过，也不能追该批分数。保持模型与配置不动，只做预先留件的一次更大独立确认；确认单独与合并均须达到原10%及全部安全门，否则保留现用版。

另外核了近期原始来源，作为收益不足时的备选：

- [skchange（2026-08-20预印本）](https://arxiv.org/abs/2608.19767) 及其 [作者仓库](https://github.com/NorskRegnesentral/skchange)：有变点、短区间偏离及惩罚标定工具；BSD3，仓库有持续开发和迁移说明。可借鉴区间候选与惩罚标定，但CAPA的统计异常段不等于传感器故障，真实短动作也可能被检出为异常段，不能拿它直接删点。本轮未安装、未实现或借用其精度保证。
- [ART（2025-01-08）](https://arxiv.org/abs/2501.04475)：对独立观测构造对称分数，再作多尺度秩聚合。其可交换条件与变化检测目标不直接等于受污染充电量测的有效功率判定；不能套名义I类错误保证。本轮未实现。

这次改进只估计已知参照的历史任务是否达标。物理变化证据、原CPOP曲线、原电量/η仍保留；负资格样本完整计入误判，不作为“不确定”排除。未获得设备故障真值，不声称能从相同的单路波形普遍分清真短动作与故障。
