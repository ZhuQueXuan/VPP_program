## 原因
上批2808任务剩444误报：123真实无动作、321有弱物理变化但未达0.15kW。405来自带注入干扰条件，其中314在同一基础轨迹的纯高斯配对中判对。443条原CPOP已经给出正时长，主要不是后续时长校正把负任务变正。安静背景区有283误报，也包含全部300真实短动作，不能统一压孤立点。详见diagnosis/paired_diagnosis/evidence_audit。

## 实际改动
