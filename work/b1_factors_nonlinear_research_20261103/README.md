# 因素作用与非线性、阈值、敏感性：本轮研究结论

用户要求按课题一第一个研究点研究“分清因素作用”和“非线性、阈值及敏感性”，先查近期论文和成熟开源方法，再决定实施。本轮已完成主源调研、作者源码核对、数据可行性核查和直接导数公式的数值微复现。

**结论：现有方法能够支持这两块研究。主线采用“低维结构分析＋连续作用与事前人群差异＋直接边际作用＋目标阈值区间”。现有连续DR继续承担均值曲线，优先补结构证据与边际作用，不重开上一轮失败候选。**

## 已落实成哪些输入和输出

输入为同一任务下的连续事前补偿、形成前用户/物理条件、全体受邀事件的同口径时长和用户身份。输出按问题组织：

1. **因素结构**：哪些连接有数据支持，哪些与潜混杂相容，哪些仍不能确定。
2. **连续总作用**：同一固定人群下，金额a相对参考金额的平均响应增量。
3. **人群差异**：在事前期限、需求等预定条件下，补偿作用怎样不同；金额变化时保持同一组人群。
4. **边际作用**：每增加一个金额单位带来的平均时长变化，报告为秒/金额单位；允许趋缓、零作用和下降。
5. **目标交点与区间**：给定业务响应目标后，在哪些金额达到、是否存在多个上穿、是否未达。曲线目标交点与用户选择的机制阈值分别研究。

当前DR、DML与两部模型上一轮取舍保持。现有高层因素接口与直接校正时长的衔接问题已登记，具体见上轮独立审查；它属于后续完整接入前的必要工作，本轮未改正式接口。

## 数学微复现已经执行

`method_microcheck.py`独立实现Zhang–Chen Eq8，采用论文A5相符的Epanechnikov紧支撑核及二阶矩1/5，输入给定辅助均值、解析导数与正密度。结果在`method_microcheck.json`：

- 97个新构造数值、5个直接查询，向量公式与逐项标量复算完全相同，插入查询点不改变原结果。
- 在二次条件均值和非均匀分配密度下，独立数值积分与解析导数误差小于2×10^-12；结果均值故意设为常数、密度保持正确时，积分仍恢复该例导数。
- 构造两个在已观测人群金额范围内完全相同的机制，其人口曲线仍可不同：本例最大相差135.08秒，达到650秒的交点分别为2.000和1.781。这落实了新论文对强分层支持的辨识问题，后续实验须有跨条件可比金额或明确额外结构。

这些是公式与识别可行性核验，没有拟合估计器、生成主评测队列或得到新精度排名。作者代码只静态读取，未执行其训练路径。静态发现的差分/折索引问题详见`derivative_sources.json`；公平比较应按正确论文方法共同实现，不靠源码错误制造增益。

## 数据路线已经核清

**方法验证可以立刻使用新明确SCM开展。** 旧模拟用户项只影响结果，不影响补偿，因此尚未测试真正的处理—结果潜混杂。新机制要分别包含随机补偿、可观测混杂、零作用与未观测H同时影响补偿和结果。图学习先按用户取一个预定事件；曲线仍保留所有响应者和未响应者，重复用户同折。图以正确CPDAG/PAG等价类评价，导数和目标交点用独立已知真值评价。

**真实扩展优先iFlex。** [作者数据论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC10539631/)与[Zenodo官方归档](https://zenodo.org/records/8248802)支持价格行为研究；本地40,332,391字节RData的MD5本轮与官方精确匹配。已有较新通知前历史样板，早期同日状态问题已修正。当前分析只是13组日/11独立日期的预定24小时价格路径，不能将23,832小时当独立随机连续补偿。下一先用现有R运行时核全量对象/阶段/分组/日期，再规划未见整期/组日的价格路径与异质性研究。

其他来源也有用途：EPFL适合技术设定跟随因素，澳大利亚适合真实削减差异，ETH/EKZ适合多设备电价/控制研究；它们不作为同一个EV补偿试验横向拼接。详见`data_feasibility.json`，没有新读外站或已消耗测试值。
