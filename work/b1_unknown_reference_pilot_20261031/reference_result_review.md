# 参考预测小规模实际复现：只读复核意见

2026-10-31。只复核新pilot参考预测环节。本次不调用fit、不生成数据、不调参数，也不读取evaluator真值文件。正式对照仍在特征提取/响应分析两个板块；以下树与GP是辅助预测模块的内部选型，不另立正式预测算法主对照，不表示已选正式B1算法。

**结论：本次有限选型过程和冻结结果相符，LightGBM leaves7确为四个候选中非事件验证MSE最小者。训练/验证标签、用户、时点、公共特征和原生保存载入均核过，没有发现测试结果进入参考选型的证据。这个结论只支持当前小pilot的内部选择，不支持树普遍优于GP或提出新预测算法。**

## 1. 实际样本、输入和时点

- 训练：seed7610000，64用户各2个明确未发任务、未宣布激励的non_event，共128记录。训练目标是这些记录的实测功率减通知前60分钟均值，不读取模拟自然功率或响应真值。
- 同一128记录、同一8个索引 `[0,8,16,25,34,43,51,59]` 用于四候选，共1024训练行。每行是原一分钟观测；没有把稀疏标签插值成额外训练数据。预测每条仍直接计算原60个一分钟格。
- 参考验证：seed7610100，32个新用户各2个non_event，64条；按全60格实测功率MSE选择，非过程真值或弱漏检标签。四配置均未在验证标签上重训。
- 11个公共特征为4个15分钟去中心前缀均值、horizon位置的历史去中心形状、horizon比例、时钟sin/cos、星期sin/cos、温度；前缀60分钟均值只作offset。相同StandardScaler仅用1024训练行估计，四模型训练摘要digest相同。
- 查询函数只读`reference_window`。当前金额、参加/弱强类型、当前实测功率、潜变量不进入查询特征。训练/验证才读明确non_event实测标签。历史来源按原用户/表计与事前完成时间逐条核对，历史平均也从声明的原历史记录独立重算。

训练最后标签完成为231545分钟，早于参考验证最早通知2215985；参考验证最后标签2241785早于过程开发4231985；随后过程开发/校准/响应验证/测试依次隔离。全部阶段原用户集合互不交叉，各测试种子也互不重叠。每阶段沿用整周平移，日历字段与绝对任务时钟一致。窗口只含通知前前缀：任务相对[-75,-15]，不能把通知后[-15,0]解释为合法输入。

1024训练行和3840验证格具有同用户、同任务内相关，不能当1024/3840个独立样本；独立用户只有64/32。两事件结构使事件等权与用户等权在本次恰好一致，不推广至事件数不平衡的人群。

## 3. RMSE与GP结果应该怎样解释

**表中目标含未来实测计量噪声。** 它衡量可观察非事件负荷预测风险，符合不用oracle选模型的要求；不是模型相对潜在无噪自然功率的RMSE，更不是时长/误检或最终因果曲线的误差。不能把它与另一数据面板的true-reference RMS直接相减当新模块收益，也不能任意减掉0.05²就声称得到精确去噪误差。测试记录里的参考真值诊断由独立evaluator承担，与本次选型目标分开。

这次GP只是两个固定核的有限复现：ConstantKernel(.04)×RBF(.7或1.5)＋WhiteKernel(.0025)，optimizer=None、alpha=0、normalize_y=False，同1024训练行、11维训练内标准化特征。它没有搜索核族、学习长度尺度、加入用户层次/开停状态，也没有输出或检验概率区间。零均值GP在特征域外趋向prefix offset；树模型可以学不同非线性交互，二者归纳假设不同。当前结果说明这两个GP点预测没有胜出，不能说概率预测失败、GP不适合EV或提升树普遍更优。两候选预算相同也不等于所有模型容量和先验完全等价。

1024行的精确GP在本次运行约0.22秒，树约0.13—0.16秒，是一次本机小cohort计时；不能从小矩阵开销推断扩大数据后的复杂度或现场延迟。尚未做硬件独占、重复基准或真实时延验证。

## 4. 未发现泄漏的证据和其界限

`run.py`的 `select_reference()` 实际只取train和reference_validation事实，标签使用`power_kw`，没有evaluator读取或test分支；模型artifact、选择和源身份随后封存。`evaluate_phase()`先校验freeze、响应验证完成后才生成测试，所选参考固定。源审查、训练摘要、用户/时间和冻结SHA彼此相容。

这比单靠`selection_truth_read=false`标志充分，但仍属于本地可复核科学记录；checksum和文件时刻不提供外部可信时间戳，也不能独立认证未记录的执行历史。该限制不意味着发现了真值拟合。

## 5. 还缺什么，当前可以停在哪里

当前正常背景仍是同一平滑自然充电机制族。没有自然充满停机、真实提前离站、缺测或会话状态数据验证；旧调研建议的会话条件化没有因这次11特征小pilot而全部实现。预测器不返回逐条参考误差分布/置信带，后续过程的协方差加权也不能倒推为GP概率输出已校准。

保留所选树作为**本次各过程共同的内部预测器**足够，不应在本批测试再调GP核或换树深度追分。若后续要研究预测模块新机制，应先提出它解决自然退出、相关误差或域外失败中的哪一项，用新验证协议检查输入增益与模型增益；正式特征提取/响应分析比较仍按用户确认的板块口径组织。当前没有理由仅因GP负结果自动扩为大型网络搜索，亦不能因树胜就停止检验参考误差怎样影响全过程特征。
