## 这轮改动与最终取舍

此前恢复判断只看“回去了原变化幅度的多少”。最后一个候选增加“功率、电流离原状态还有多远”两个输入，仍用标准小型正则逻辑回归，固定原0.7阈值，训练位置与用户分组不变；没有添加短段删除、驻留限制或抹点规则。所用标准实现来自[scikit-learn开源项目](https://github.com/scikit-learn/scikit-learn)，BSD-3-Clause许可，使用原有1.7.2环境，无安装。这是已有学习校正结构的一个候选调整，不是新发明的分类算法。

只在原96个训练片段中评估，恢复头分用户四折误差23.09→17.00秒，故按预定规则进入一次最终验收。前级事件核验器固定在原训练数据上，以上是条件恢复头交叉验证，不能宣称全链条无偏交叉验证。

随后冻结模型、样本规则和评分规则，首次打开原封存主测试角色：48个真实窗口，22个与训练/验证隔离的匿名用户；短上限、小阶跃、普通阶跃、恒定上限各12个，每个源会话只取一个窗口。选样仅用时间、上限及哈希，不按功率、当前输出或模型表现筛样。扫描中32份不足预定60分钟的源记录列明保留；这不是按响应大小剔除。先看12页原始图和关键行作暂定标注、冻结，再生成模型输出。

新旧适配版的7个恢复参照误差**完全持平**，并未在这批新用户上复现训练收益。两者的33个已确定变化标签均有2次误报、0次漏检；7个未恢复/被后续变化打断的正例中仍有1次报了恢复。候选只改变了两个误报事件的恢复位置，没有改善上述指标。因此最终结论为**保留 `state_v2`，拒绝最后候选**。

原计分脚本的比例门写成 `new <= .95 * old`，当新旧误差均为0时会错误通过。独立核验纠正为“必须实际减少误差且达到5%”；未重跑推断或改变结果。原错误决策文件保留，**当前唯一生效取舍为根目录 `acceptance_decision.json`，它明确覆盖 `real_test/decision.json`**。持平不能当作有收益。
