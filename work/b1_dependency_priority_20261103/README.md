# 第二至第六部分的联系与完善顺序

本轮结论：先核第二部分的变量角色与调整依据，再把第三部分连续补偿—响应曲线作为下一轮唯一主要改进对象。此优先级是根据当前实现和误差传递作出的研究判断，不是已经比较过所有改进路线的实验结论。

## 当前实际联系

| 部分 | 当前用途 | 与其他部分的联系 |
|---|---|---|
| 第二：因素关系 | 区分事前状态、补偿、参与过程与响应结果；学习关系图作为诊断 | 声明的关系决定调整变量；自动学习的图目前不反馈调整集。变量角色错了会影响第三、第四及下游；提高学图分数本身不会改变第三 |
| 第三：连续补偿作用 | 估计补偿连续变化时，全体用户平均响应如何变化 | 默认第五是这条曲线的导数；默认第六在这条曲线上找目标交点 |
| 第四：人群差异 | 看不同事前状态的人群，补偿作用是否不同 | 目前每组独立重新拟合；改总体曲线不会自动改组曲线。若改共同估计方法并重新训练组模型，才可能获得收益；组间共享信息须另作研究 |
| 第五：敏感性 | 看某个补偿附近，多给一点补偿能增加多少响应 | 默认依赖第三；直接导数候选另行拟合，不参与默认第六。曲线误差下降不保证导数误差下降 |
| 第六：阈值 | 找达到目标响应所需的补偿，并判断能否达到 | 默认直接依赖第三，不必等待直接导数候选。目标附近曲线很平时，微小曲线误差也可能造成明显交点偏移 |

第二和第四之间也有研究上的反馈：第四发现差异，可提示第二需要重新检查哪些事前因素重要；这种线索需要另行验证，不能把分组差异当成因果连边证据。第五可提示第六哪些交点不稳定；当前没有自动反馈计算。

## 核验依据

- `code_dependency.json`：源码调用关系与行号。
- `dependency_probe.json`：只读已有开发模型的数值探针。去掉图输出、去掉组输出，默认总体曲线、导数、阈值均不变；对内存中的曲线构造量作人工线性扰动，默认导数与阈值随之变化，独立组模型不变。该探针不评估方法优劣。
- `literature.json`：论文主源、开源实现、许可、适用条件与最小比较建议。

## 第二部分的前置核查

已核 `factors.py`：参与是补偿后的中间变量，不进入事前调整集；因素应在补偿形成前测得且可获得；结果是全体受邀事件的累计响应时长，包含未响应者；观测分配下使用声明关系所要求的事前因素。源码中的时间与角色约束已存在。

这些约束只核实实现与研究定义一致，不能证明现场没有遗漏共同影响补偿和响应的因素。现有模拟基准与现场数据分开；ACN没有事前补偿，不能用于验证现场补偿因果作用。自动学图尚不能替代以上识别依据。

## 下一轮单模块研究

第一部分保持冻结；第二部分先完成上述识别核查。下一轮只比较第三部分最后的曲线生成方法：

1. 保留现有 Kennedy 连续双重稳健估计、相同事前因素、辅助模型、用户分折与连续金额。
2. 基线为当前局部线性平滑；首候选为带曲率惩罚的三次平滑样条。它改变最终曲线平滑层，不是辅助结果模型内部原有的样条，也不重试已失败的 DML／软两部候选。
3. 依据 Bonvini–Kennedy《Fast convergence rates for dose-response estimation》2026 修订版算法1的通用两阶段路线，使用 SciPy 成熟 BSD 实现；属于按论文比较任务适配，不称新因果估计器或完整复现其高阶方法。
4. 用新的开发样本选择一次平滑强度；先写清具体样本量、机制、主指标、采用门槛和停止条件，再生成新终验。旧终验不用于调平滑强度。
5. 主看曲线误差与完整输出；同步记录导数误差、达标误判和交点误差。曲线变准但其他部分变差时分别报告，不概括成整链提升。

第三部分稳定后，第四研究分组支持与共享信息；第五专门完善导数；第六完善达标判断、交点与区间。第二的完整图学习另立候选、继续完善，不以追整图分数阻塞当前曲线研究。

本轮完成依赖核验、前置定义检查和候选调研，未拟合新模型、未进行性能比较、未修改正式算法、未重开终验。下一轮实验设计尚未冻结。
