# 证据主线、阶段门与下一主动问题审查

日期：2026-10-17。角色：academic consistency / technical reviewer。只读审查既有研究与执行记录，本文件为唯一新增审查产物；不修改现用阶段、台账、实验或正式文件，不宣布P2开放。

结论：已有工作建立了可信度较高、可复算的六类**有限组件基础**；负结果和用途边界保留得较完整。下一项的主要风险已转为“研究出口不够明确”：组件G1与六类基础包陆续收口后，持续写全体P1未过，却没有列出一份有终点的剩余判据；新增来源和描述若继续仅横向铺开，将难以形成核心文件要求的因素作用结果、全周期响应或条件化能力输出。建议先整理阶段门的逐输出裁决，再选择一个能连接指令、状态和执行的单体问题。不能据此把六类组件改称完整资源能力或103通过。

## 1. 审查范围及证据强度

实际读取：两份现用核心文档的任务映射、模型输出、验证与实施段；ROADMAP v2及第一阶段计划；决定D069—D071、现用数据卡04和实验台账对应记录；六类四层矩阵与六类最终README；五份现有`basic_research_acceptance*.json`（储能以README/发布收据及历史G1说明衔接）；D069入口/过程结果；水箱新准入裁决。沿用本轮已实核的104个发布条目身份和水箱独立复算结果，未为本次审查重复跑模型。

本分项检查两核心文件所列正式任务/成果与实际证据的衔接；103原PDF逐页任务审查由主审汇总，本分项不替代它。未以网页候选、同名字段或未取得的文件推定实际能力。

必须区分三种“独立”：

## 2. 五项优先发现

### 发现一：整体P1剩余判据需要收敛，不能用P2缺口循环阻止P1结项

**优先级：高。** [ROADMAP阶段表](D:/myDocu/project_postg/VPP_program/outputs/ROADMAP_v2.md:107)将P1出口写成“声明输出范围内G1六项＋单类基础包”，并把深入因素/单体能力列为P2；112行明确不是前阶段所有子问题全完成才准备下一项，139行又明确完整SOC/容量不再阻塞所有资源基础包。这些条款是合理的按输出管理。

但D071及[计划当前下一项](D:/myDocu/project_postg/VPP_program/outputs/第一阶段两周执行计划_v2_20261013.md:155)继续只写“P1未过”和“后续先补真实控制/单位/完整恢复/独立容量参照”，未明确全体P1究竟还缺哪一项本阶段必需输出。六类有限收口后，缺口清单几乎覆盖正式任务全部困难，容易形成“P2才能研究的完整能力未成，所以永远留在P1”的循环。

**建议裁决方式：**在下一实验前，给现有输出逐项记录“六项G1已通过的范围—仍缺的本输出必要条件—属于后续专项的条件—下一分支能否准入”。先裁决现有证据，不能先预设全体P1已经通过，也不应把P1未过等同于任何P2子问题一概不准准备。若全体P1另需“行为时序样板＋设备能力样板”，应明确这两个最小产物及验收证据；这是[技术方案7.2](D:/myDocu/project_postg/VPP_program/01_项目依据/课题一技术路线与模型设计方案_v1_20261011.md:629)已有的输出依赖，不能无声改成六类每类都需最大容量/问卷/全链路。

### 发现二：六类覆盖达成了基础广度，尚未形成从正式输出倒推的主实验

**优先级：高。** 当前强证据集中在转换、同记录映射及条件下一标签预测。它们对模型依据、状态观察和透明baseline有价值，但回答的多为“已知原行输入，原行/下一标签是多少”，与“调用前能提供多少、因素影响哪个决策与执行环节”尚有间隔。

| 当前已有组件或结果 | 对正式任务的实际贡献 | 尚未完成的关键衔接 |
|---|---|---|
| 储能同站转换MAE 8.397877→1.422310kW；给定初SOC电压模型 | 物理计算/参照及参数适用边界 | 不是未知SOC/可用容量；三组件不同对象，不能组成同一设备闭环 |
| PV组件DC及另一站下一标签；风电同期风速—功率曲线 | 环境/出力关系和可复用简单参照 | 不等于健康可用AC出力、限发跟随或上下调余量 |
| EV共同指令同期P与独立KIT记录阶跃 | 指令—执行的局部技术描述，比一般功率曲线更接近响应研究 | 无完整需求/授权及物理送达时钟；记录级越限尚非完整全周期响应能力 |
| 空调/水箱条件温度标签及分层观察 | 热状态、透明预测baseline和失败边界 | 不等于功率调节因果作用、舒适授权、持续/恢复或储热容量 |
| 新水箱两放水文件 | 真实补进用水/电能字段语义和不准入裁决 | 968行不是968次干预；阀/计数/单位冲突、恢复后窗不足，尚不能补热平衡/控制输出 |

依据：六类最终README；[六类矩阵](D:/myDocu/project_postg/VPP_program/work/process_notes/2026-10-17_六类资源四层证据矩阵.md)、[水箱用途裁决](D:/myDocu/project_postg/VPP_program/work/electric_water_heating_research_20261016/draw_admission_v1.json)。

需求框架148行要求“因素—作用对象—方向/效应—条件—证据”；技术方案204/634/635行进一步要求因素作用表、全周期特征、条件能力曲线及限制/恢复记录。现有证据不宜停留在“又增加一类/又增加若干QA行”。近期优先选能向这些输出前进一步的问题，而不是继续以类别数量或累计复算数量作为主要接续依据。项目16类为后续示范覆盖支撑，不要求本阶段16个独立算法，见[需求框架4.4](D:/myDocu/project_postg/VPP_program/01_项目依据/课题一需求分析与研究框架_整合修订版_v1_20261011.md:96)。

### 发现三：必须补的缺口应随下一输出变化，四层不能彼此替代，也不必同时齐全

**优先级：高。** 四层矩阵已经纠正“无功率变化就是不愿参加”的风险，但当前下一步描述仍容易把所有缺口合并成一项前置条件。应明确哪些证据是此输出的必要条件：

| 下一输出 | 真正必需的新增证据 | 不应先强加的条件 |
|---|---|---|
| 记录级指令跟随/状态关联 | 同实体与信号层级、原指令/设定语义、对应测量、时间分辨率、状态和完整评价窗口；缺物理送达时点只能称日志记录关联 | 最大容量真值、问卷、真实合同，不是限定技术描述一概必需 |
| 端到端控制时延 | 请求发送/接收/生效与量测时钟、同步/精度及失败确认 | 秒级行间隔不能替代这些条件；更多采样行不能补证 |
| 最大可调容量/持续与恢复 | 状态、功率/能量/需求边界、有效调用、完整恢复及独立边界参照 | 一次执行量不作最大值；公开温度标签误差不替代边界 |
| 经济激励对行为的作用 | 实际报价/补偿及合同传导、公布/送达/决策时点、分配机制与可比较变化、主要共同原因 | 技术设定、调频功率、是否收费不代替实际经济处理；识别不足时只报条件关联 |
| 参加/开放选择 | 邀请母体、接受/拒绝/撤回/覆盖、授权范围和需求版本；运营方/人/EMS角色分别定义 | 不强求风机/自动EMS做人类偏好问卷；无邀请母体不能推总体参加概率 |

依据：[技术方案129/160/190/192行](D:/myDocu/project_postg/VPP_program/01_项目依据/课题一技术路线与模型设计方案_v1_20261011.md:129)、[最大容量参照要求](D:/myDocu/project_postg/VPP_program/01_项目依据/课题一技术路线与模型设计方案_v1_20261011.md:574)。

例如新水箱No单位行把累计水量写mL，XLSX/论文写L，With无单位行；累计列全0，不能从数值判真实单位。No最后正水后仅40秒、With末行仍放水/后窗0。因此可以验收此次来源审查和发布观察描述，也必须停止从它推容量、恢复时间或控制失败。继续在这两文件追加归一化/模型不会补齐独立物理参照，宜将该对象对应能力用途保留为阻塞，而不阻塞其他资源已满足条件的技术问题。

### 发现四：DML已完成方法接入，负控未通过，不能用总体接近继续拉动资源调研

**优先级：高。** [D069](D:/myDocu/project_postg/VPP_program/docs/DECISION_LOG.md:769)和[实验记录](D:/myDocu/project_postg/VPP_program/docs/EXPERIMENT_LOG.md:14)均完整披露：高档总体真值11.1702个百分点，线性DML/森林估12.3038/12.3131个百分点；但16类均值绝对偏差OLS4.5823、线性DML5.2123、森林7.4083个百分点。森林对预设零效应PV/储能估9.7682/15.5005个百分点；高档负控144任务中，线性81.94%/森林100%超过事前5个百分点绝对阈值（描述比例，不是统计显著性）。OLS也有假效应，不能据比较直接推荐为合格因果方法。

这一结果支持暂停当前配置采用，不支持继续在已见测试调到好看。资源调研应该按真实问题补时点、状态、选择与独立参照，不能迎合同事包的问卷/绿色/七天历史默认列。后续若重开DML，应先明确待识别作用和零作用条件，以训练/验证确定方案并另有未用检验；原测试保留为开发已见证据。技术方案6.2要求零作用/异质性和因果质量分别检验，现有失败不是研究无进展，而是已经淘汰一条尚不适合直接采用的候选。

### 发现五：90%正式验证口径可留待确认，但首个拟交付能力输出的评价合同不能一直空置

**优先级：中。** 两核心文件正确保留“模型精度不低于90%”，同时未擅定具体指标。现有MAE改善、90%阶跃幅度、覆盖率或复跑相同均不能折算该要求。问题在于：如果一直等到P4才确定评价对象、分母、参照与状态覆盖，前面可能积累很多与正式能力输出不匹配的标签预测成绩。

建议在选定第一个拟交付容量/响应输出时同步起草“验证口径候选”：对象和物理单位、独立参照/误差、评价窗、不可计算与失败处理、按状态/实体的汇总和业务可接受误差依据，并标明待正式确认的内容。先冻结研究评价，不自行把候选指标定义成103官方口径；更不能看过结果再选最有利的90%算法。[需求框架12.3](D:/myDocu/project_postg/VPP_program/01_项目依据/课题一需求分析与研究框架_整合修订版_v1_20261011.md:343)和[ROADMAP G4](D:/myDocu/project_postg/VPP_program/outputs/ROADMAP_v2.md:110)已提供这一边界。

## 3. 建议的一条下一主动问题

建议对象：**原M5BAT同站系统级请求/执行与LMO1单元设定/实测的证据连接**。这是六类既有资源的一个控制层缺口；不启动另一对话待选的蓄冰/循环泵、工作场所EV或两级AC，不做跨类型整合，也不要求立即采用DML。

研究问题写为：“在原记录能够可靠关联的同站时段，系统请求、单元设定和单元实测分别发生了什么变化，哪些变化只能解释为记录关联，哪些具有可核执行证据？”先核层级映射，**不能要求单个LMO1承担全系统请求，也不能把二者不相等自动诊断为失败**。若能够明确单元分配请求及时间条件，再形成单体执行误差/条件响应样板。只有系统请求而没有分配关系时，限定输出为链条可观测性与不可归因原因，停止该单体跟随目标，不补算法绕过。

选择依据：[储能分项已核线索](D:/myDocu/project_postg/VPP_program/work/process_notes/2026-10-17_储能光伏风电四层证据核对_分项.md:66)和[原储能过程入口](D:/myDocu/project_postg/VPP_program/work/resource_sample_selection_20261013/README.md:3)说明原ZIP/Batt5在本地，官方同月报告区分系统FCR/SPA请求执行与单元P_AC_Set/P_AC、模式/插值。BESS其他成员尚未准入，本建议不将其存在推成可用；原LMO1研究本就有设定值优于混合模型的透明参照，可减少新模型需求。

**可验收的最小产物：**一份“同站对象/信号层级—时点—字段单位—允许输出”裁决，加一份可复算事件表或明确不准入结论。具体验收条件：

1. 在查新输出前冻结来源成员范围、目标输出和准入检查；重核原ZIP/成员身份、许可、全部拟用字段、UTC/倍率、重复/缺口/插值与模式。先确定系统到单元的合法映射，不能按功率相关性猜映射。
2. 表内列出系统请求/执行、已核单元设定/实测及状态，区分发送/接收/生效/测量的已知和未知；保留未发、零值、未知、失效、截断及异常，不能只保留跟随好的时段。
3. 若准入完整事件：预先固定事件边界、前史、执行及后窗、误差口径与同信息透明对照；若没有发送/送达真值，只评价日志标签与条件响应，不报现场时延。若拟预测，另冻结完整日期/事件外层留出；旧April已用于诊断，不能重称新盲测。
4. 分模式/方向/零请求/有效支持范围报告误差、覆盖、最差与恢复截断；未知拒绝原因保持未知。限定技术输出不强加合同/问卷/最大容量真值；真正升级容量/经济/选择层时再增加各自证据。
5. 数据无法满足对象映射或时点要求时，以明确不准入及可复查缺口结项，不继续靠插值/猜状态/新增参数补分。若满足，再由阶段门审查确定该技术子问题的合法位置；本报告不自动执行实验或宣布P2开放。

该建议的终点是形成一项比同期映射更接近正式任务一“指令—状态—执行”与任务二“响应误差”的可核输出。后续最大容量、真实激励和授权依然保留各自准入，不因技术样板完成而被替代。
