# B1充电桩主线：步骤4—6

本目录接续已批准的研究点一最终规划。正式源码继续位于根 `B1算法/`，没有生成报告、压缩包、启动器，也没有继续开发B2/B3或其他资源。

## 已接通的调用

`参考选择 → 同一任务过程分析 → 合法事前因素与声明图 → 连续作用模型 → 保存/加载 → 任意支持金额查询、曲线图、敏感性与目标阈值`。

事件测量仍以累计阈上时长为主、原始η并行为辅。新版过程使用显式 `ride_revised` 与设备已声明充电上限；CPOP保留为强主对照，旧模板保留复现。新过程只在完整1分钟计量下完成研究；不能把更细/更粗计量的原始曲线回退称为新版成功拟合。

## 步骤4：冻结查询

- 新增 `effects/frozen.py` 及公开接口：`fit_continuous_model / fit_ev_factor_model / save_continuous_model / load_continuous_model / query_continuous_model / find_incentive_threshold`。
- 训练只做一次，固定同一人群/任务、伪结果与带宽，查询不调用训练。金额直接求值，支持内也可能因缺乏可比数据拒答。
- 敏感性是冻结平滑均值的真正导数；阈值是声明目标与搜索网格下的首达判断，不与几何拐点或最优价格混同。
- 33项初始数学/合同核验通过；新增16组标量模拟，12组可比较结果与原连续DR均值/增量逐项差0，4组确定分配均拒答。16组由四个独立块的配对机制产生，不是16次独立试验。
- 饱和/零作用曲线可用；非单调机制平滑偏差较大，保留原始误差。候选阈值允许“可能仍未达到”，不把阴影冒称连续因果覆盖。

原始标量诊断事实在 `data/B1_finish_queries_v1_20261030`，协议、模型、查询和完整成绩在 [step4](step4/protocol.json)。这些标量例仅检验查询/平滑行为，不是物理充电全过程仿真。

## 步骤5：直接服务B1的历史表示

[历史研究入口](history/README.md)保存六个新独立块、9000事实事件、固定三历史与训练/验证/测试用户隔离，以及stats/PCA/AE的冻结比较。主结果是本任务因素作用曲线，未转成B2单车预测。

验证先冻结选择C0，再测试；没有历史表示的稳定增量，不强行纳入主流程。C0测试可用4/6块、统计5/6、PCA/AE各6/6，所有拒答保留，不能用不同分母的均值直接比胜负。四法共同三测试块的误差为72.018/177.886/287.839/207.716秒。旧负结果与本轮结果均未改写。

53功能小控和实现者18227项只读审计通过；另由root从原始事实重新生成参考/历史，对18用户36目标及完整分割作4045项独立核验，见 [独立历史收据](independent_history_receipt.json)。核验项数不作为独立实验样本数。

## 步骤6：新的独立完整链

固定八个新独立种子、每块128用户、每人5事件；前三事件为历史，后两次为评价目标；正/零作用配对。主任务30分钟、1.5kW、完整1分钟计量。选型规则和输入在运行前冻结，主面板不用于调参或改选。

全链证据位于 [assessment.json](final_chain/assessment.json) 与 [最终收据](final_chain/final_receipt.json)。八块均自然完成，10240五事件事实变体中有4096目标变体，三过程共12288条输出全部成功，无降级或批次失败。独立随机单位仍是八个种子块，正/零作用及各方法均为配对。

### 本阶段取舍

- 参考继续复用冻结预测与合法历史选择；不通过本次结果重新训练或调整参考。
- 修复版RIDE保留为显式EV过程候选，CPOP继续作为强对照和可选过程方法。完整1分钟、30分钟/1.5kW的本轮结论不能推给所有时长与采样；此前37分钟高噪声不如CPOP的结果仍有效。通用兼容默认未静默切换；使用本候选需显式传 `process_method="ride_revised"` 与真实设备上限。
- 因素作用使用声明图要求的合法事前调整与共享连续DR；不将复用通用DR称为新估计器。C0进入本阶段因素主线，历史表示作为可选研究模块。
- 保存查询、图、敏感性和网格阈值已贯通。当前完成的是EV限定模拟研究流程，真实部署、完整因果覆盖或普遍优越性均未通过验证。

### 收尾核验

实现者142529项只读数值/合同复核通过。初审把规范化task省略resource_type及用户ID类型前缀误当不一致，已保留原件并单独纠正；未更改主科学输出。639项原科学文件SHA一致，最后封存645项，见 `final_chain/` 两份清单。

已从事前指定的首个新独立块7240200保存模型直接生成连续查询与敏感性两图，并逐图查看，见 `figures/`；没有为选好看的曲线更换样例。

## 边界

本轮目标是EV限定机制的算法贯通与独立比较。多元资源/市场、真实行为证据、完整图的自动学习、全链因果不确定性与任务书正式精度验收仍不能由本轮模拟代替。原生CPOP与通用Kennedy DR分别承担过程和作用主对照；B1复用同一连续DR不构成新的效应估计器。
