## 固定设计

- 六块种子7130000—7130005；每块300用户、每人5事件。用户按生成序号100/100/100分别训练、验证、测试，没有按字典序混排。
- 各目标事件3、4均仅使用固定历史事件0、1、2。目标3不会成为目标4的额外控制。历史包括完整任务及后窗，全部观察端点/可得时点须不晚于当前通知。
- 共9000事实事件；3600目标行中训练/验证/测试各1200行。每人两目标行相关，六块是独立随机重复单位。
- 同一既有冻结GBDT/prev10模型和合法非事件历史选择供全部方法共用；没有参考重训、真值参考或当前响应选参考。
- 输入raw90为三次30分钟任务的逐分钟`(预测参考-实测功率)/请求功率`，不拟合CPOP/RIDE。统计六维为平均η、最近η、平均累计时长比例、平均最长连续时长比例、平均后窗回补电量比、η沿三事件的趋势。
- PCA6与90→24→6→24→90 tanh小型AE仅在训练用户历史上拟合；AE固定60轮、4752参数。后两类编码器的均值和标准差也仅用训练历史。模型在 `models/{seed}_{method}.json`，可供新用户只编码。
- 所有效应方法均保留必需事前混杂L/U，并加六列表示。C0六列为零。八列输入维数相同，不表示有效容量或参数估计复杂度相同。
- 结果统一为预测参考下原始累计阈上秒数，主对比0.8金额、查询0.4—2.0的九点。连续DR保持原支持规则、用户crossfit、99次条件聚类抽样；编码器不接触验证/测试结果。效应辅助模型在各评估cohort中crossfit，不声称冻结预测头跨人群迁移。

## 核验和使用

`check.py` 的53项小控覆盖时点/绑定/非法输入、raw90独立算术、固定AE预算和编码器往返。`verify.py` 只读审计共18227项，核训练隔离、所有3600行历史时点/身份、raw90到五个可重算摘要、模型训练均值/尺度、参数预算、选择规则及逐块RMSE；它不是另一组性能试验，也不冒称独立人员复核。

调用顺序为：`prepare_ev_history` → 对训练用户调用 `fit_ev_history_encoder` → `save_ev_history_encoder`；以后 `load_ev_history_encoder` → `encode_ev_history`。编码输出含模型ID、当前任务和历史可得时点。模型里的`trained_on_outcomes=False`指未使用当前目标事件结果训练编码器；原始历史本身是过去响应结果，AE重建这些历史。因果调整是否充分仍由B1研究的声明图、事前变量和识别条件负责，编码器不作因果保证。

本步依据有限负结果收口，C0供后续独立全链使用。统计/PCA/AE作为可用候选保留，不继续搜网络、扩历史或改支持门槛追分。
