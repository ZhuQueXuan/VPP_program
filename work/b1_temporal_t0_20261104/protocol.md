# 第3点 T0 首轮协议

范围为 ACN Caltech 的原训练及开发验证会话。先清点可以研究的观察过程，冻结小份原点审阅材料。热泵是同一 T0 的独立补充。此阶段不产生模型、形态标签或验收分数。

1. 每会话只取一个观察对象。候选是原始相邻有限限额点下降至少 2 A、间隔大于零且至多 12 秒，锚点至少晚于记录首时点 60 秒并早于交易断开。只用限额、时间及会话边界挑第一个候选。12秒是约4秒主尺度的开发质量筛查值，既不代表仪表精度，也不作为真实响应时延标准。
2. 保留前60秒与锚点后30分钟。若其中出现一次向上至少2 A并回到锚点前限额±0.25 A的原相邻边沿，保留该边沿及随后5分钟，最晚至锚点后35分钟。这是回限代理。后窗再有0.25 A以上变动、超12秒断档、缺测或提前终止时单列。所有原始时刻与行号保持，缺口和重复时点均不修补。
3. 共同观察范围初筛采用原时刻区间、核心通道非空、无重复和最长12秒间隔，边界允许最近样点相差12秒，同时检查原记录和交易实际覆盖端点。数据范围、长断档、重复与缺值分开记录。无锚点及所有原会话都进台账。该初筛仅给后续可编码分母的上限，矩阵单元覆盖规则由T1另定。
4. 按原训练/开发验证角色，分别在完整回限、完整多次控制、完整单次控制、不完整四层中固定哈希抽取每层最多3条，每个匿名用户在首包最多1条。抽样不看响应形态或幅度。审阅包只提供原始时刻、限额、电流、功率和源行号。首包上限24条，未满如实记。可行性参照要求另行盲核。
5. 统计会话、匿名用户和观察覆盖数。截尾记录仍在原分母。既有测试和外站波形保持封存。本包是开发资料，后续确认须另核新对象和新记录。
