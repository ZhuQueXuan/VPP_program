# 第三点真实辅助验证：iFlex 峰窗电量预测

在真实留出日期，**峰窗历史特征＋梯度提升树**将现有样条结果模型基线的日期等权RMSE从 **2.012149降到1.809376 kWh（10.0774%）**，五个测试日期均改善，2,419条全部输出。通过本轮预定采用门，保留为真实居民辅助结果模型。原EV连续补偿曲线、已有改善样条和其他部分不替换。

## 目标与对照

用[公开iFlex试验](https://zenodo.org/records/8248802)的实际报价预测同一P价形下的实测峰窗（原Hour17、18）电量。718户、14,213住户日、59组日/30日期。它是四个实际路径报价的事实预测，原连续DR的条件密度和连续因果曲线不在此数据上训练；因果作用、EV时长和未见家庭泛化不是本轮指标。全天电量原列保留，本轮集中训练峰2h。

既有基线沿用项目原辅助结果模型的结构：事前协变量二阶特征、固定六结点三次价格B样条、价格×协变量交互及Ridge。把金额范围适配实际2–15 NOK/kWh。另比较数值价格线性Ridge和无价Ridge；候选使用现有 [scikit-learn HGB](https://scikit-learn.org/1.7/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html)，与样条Ridge使用逐值相同的特征矩阵；另有同类型去价对照。原辅助B样条特征不等同于上一轮用来估计连续因果曲线的最终平滑样条。

全部方法使用相同组/地区、星期、通知前24/168h总用电和历史气温。每方法4个预先固定的配置；预处理只用训练数据。HGB显式关闭自动early stopping，训练行数变化不导致额外随机切分。第一次验证中，现有样条2.094014 kWh、同输入有价树2.068115 kWh，日期组均值指标也未随换模型一同改善。

## 有针对性的改动

过去一天或一周总电量无法区分用电集中在哪个时段。追加一个特征：通知前168小时内完整配对的原Hour17+18电量的平均值。每条事件有6对真实历史，最近一对结束在通知前23小时；不用当前事件结果，不把之前历史当认证无激励反事实。原档固定3训练+2验证事件复算一致。

追加特征后，五个模型族的验证误差分别降低6.74%–7.44%。最优有价树由2.068115降至1.914329 kWh，按预定1%规则选追加历史的树。现有基线也只由验证集选择，为不加同峰历史的样条Ridge。所有方法选择冻结后同用25个训练/验证日期11,794条重拟合，再对5个未来日期一次评分。

## 同批测试

| 方法 | 日期等权RMSE kWh↓ | MAE kWh↓ | 组日均值RMSE kWh↓ |
|---|---:|---:|---:|
| 现有样条Ridge | 2.012149 | 1.424720 | 0.448330 |
| 同输入换有价树 | 1.947425 | 1.358404 | 0.463790 |
| 现有样条Ridge＋同峰历史 | 1.907342 | 1.321344 | 0.430258 |
| 有价树＋同峰历史 | **1.809376** | **1.238301** | **0.390704** |
| 去价树＋同峰历史 | 1.827797 | 1.240996 | 0.415485 |

主指标是各日期分别算户日RMSE后等权平均；组日均值误差另计。只换树结构降低约3.22%，树模型族再加同峰历史降低7.09%，合计10.08%；同峰历史对样条Ridge也改善5.21%，说明主要收益不是单一学习器偶然获益。去价对照相比有价候选差约1.01%，且验证时有价模型未胜去价：此证据仅是价格字段的预测增量较弱，不能解释为补偿无作用。

测试只覆盖2、10、15三档，5档无测试日期，15档仅1日期。都是已见家庭的未来日期。2档在本测试平均高估0.430 kWh，10、15档分别高估0.061、0.069 kWh，可作为后续新数据上的校准问题，不用这批测试继续调。未报告缺失报价上的真实误差或连续金额外推。

按训练期同峰历史四分位做描述性诊断，四组误差均比原样条低；历史高用电一组仍最难，RMSE为2.722 kWh。切点只取训练期分布，未改变模型或采用判定，见 `history_bias_diagnostic.json`。
