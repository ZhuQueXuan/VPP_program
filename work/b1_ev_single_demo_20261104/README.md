# 研究点一充电桩单资源演示

[打开演示](index.html) · [研究点一总框架](../../B1算法/RESEARCH_FRAMEWORK.md) · [公开充电曲线](../b1_temporal_ev_demo_20261104/index.html)

演示把同一批模拟任务的事前补偿和车辆状态接到原始参考功率、实际功率及有效减载时长，再从保存的模型直接查询补偿增量。示例为半小时、请求少充1.5 kW、已知3 kW参照和10秒观测。补偿从0.40升到1.20元/千瓦时，平均累计有效时长的点估计增加302.5秒，同批模拟真值增加331.8秒。图中条件采样带只反映固定辅助模型后的抽样波动。原始功率队列的总体曲线可用，两个分组未能在所报全范围内同时给出可比较曲线。分组改进另用足量的新模拟队列评估。

| 分点 | 本轮交付和结果 |
| --- | --- |
| 1 量响应 | 240笔新功率任务全部有时长输出。同一批数据上，现用提取器的累计、最长连续时长MAE为15.38和35.33秒。原 CPOP 在该组信号清晰、参照已知的10秒模拟中，两项误差均接近零。现用方法对这批双段轨迹存在退步。 |
| 2 核比较 | 核对原始任务、计量和事前因素同事件绑定，车辆条件先于报价，报价先于通知。原始功率队列中，FCI 与 PC 各找到已知5条相邻关系中的2条，均未额外连边。图诊断保留，主比较使用事先声明的离站余量和需求等条件。 |
| 3 补过程 | 任务需要考核连续性或恢复时，可查三例真实充电曲线。另在240笔模拟里做探索诊断。以累计减最长达到20秒为分段提示，原 CPOP 在47笔真分段中未漏，193笔其余任务未误报。现用提取器漏12笔、误报4笔。此规则与这批固定50秒间隔模拟绑定，属于开发诊断。 |
| 4 算补偿增量 | 先用3个新种子块开发，冻结一个合并样本拟合的候选。再用6个新种子块、4种机制、共24组、11,520个模拟事件做配对比较。总体曲线平均RMSE由50.18降至45.33秒，组间作用差异由116.20降至82.88秒，均24组可评。总体曲线仅2/6种子块改善，未达4/6稳定性门槛，候选留作研究对照。 |
| 5 判断目标 | 同批曲线每单位补偿的响应变化误差由146.02降至119.24秒，随该候选一同保留作对照。另用48组新模拟检查达标报告。只看点估计给出48个判断，错3个。用现有采样带设“证据不足”后给出32个判断，这32个均正确，其余16个留待判断。该方法用于演示的有限金额网格，现场误差和区间覆盖仍待验证。 |

在原始功率队列中，用两种提取时长分别重跑同一连续估计器。现用提取器和原 CPOP 对应的曲线 RMSE 分别为46.79秒和58.96秒。原 CPOP 量单笔时长更准，但在这一批有限样本上，换成原 CPOP 的时长后曲线误差反而增加。此对照只用于说明前级误差和下游估计应分别验收。

另用新种子复查96笔功率轨迹，两种提取器共用同一次原生分段。48笔已知参照且信号清楚的模拟中，现用提取器的累计和最长连续时长误差分别为81.25和62.92秒，原 CPOP 两项均接近零，分段误判由8笔降为0。把原 CPOP 列为这一限定场景的提取候选。另48笔同时接近判定线且计量噪声较大，现用方法超出适用范围，原 CPOP 的两项误差为17.71和39.17秒，分段误判4笔。高信号下的结果只用于所测场景，真实任务需另验。[独立波形复查](process_confirmation.json)

## 真实充电资料的可比性

| 来源 | 能核什么 | 与首演示有关的缺口 |
| --- | --- | --- |
| ACN | 桩端限额、实测电流与功率过程，支持技术执行和三例过程复查 | 现有任务记录无法接到同一次任务的事前报价及完整分配名单。限额本身是技术指令。 [ACN 数据字典](https://ev.caltech.edu/dataset.html) |
| Calgary 实验 | 论文与复制目录列出真实充电和奖励方案 | 原始工作簿下载入口此次返回超时，未取得原表。即使取得，也先按固定奖励方案比较，连续金额和30分钟有效减载参照需另核。 [正式论文](https://pubs.aeaweb.org/doi/10.1257/pol.20230653) · [原表目录](https://www.openicpsr.org/openicpsr/project/202941/version/V1/view?path=%2Fopenicpsr%2F202941%2Ffcr%3Aversions%2FV1%2FReplication-File%2FData%2F20220314---charge-data.xlsx&type=file) |

首轮真实效果所需的数据是同类任务的事前补偿、分配规则和完整对象范围、报价前车辆条件、实际结果，以及有效减载所需的未调节参照。已确认零响应与缺测分别记账。真实报价效果暂缺这一连接。

开发初次调用遗漏连续分配声明，保留了未完成的结果文件。修正后在原定开发种子上重新运行，冻结后才首次生成确认结果。原始功率初次尝试发现脚本使用了错误的最长时长字段名，修正后以同一份原始输入重跑。波形复查修正了任务相对时间入口，并将超出现用噪声适用范围的轨迹明确记为不可用。下游真实准确率仍需新数据。
