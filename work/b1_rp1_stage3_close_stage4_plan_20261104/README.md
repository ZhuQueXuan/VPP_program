## 第4点 非线性作用与条件差异

首个演示按[总框架第6节](../../B1算法/RESEARCH_FRAMEWORK.md#6-首个充电桩演示)执行。第1点交付实测结果，第2点交付比较依据，第4点估计提高补偿后的调节增量。任务考核连续性或恢复时再接第3点。

核心问题是改变充电补偿后，充电桩实际调节差多少，以及同一笔补偿在不同充电需求和离站余量下效果差多少。首轮优先核充电桩同一任务的事前补偿、可比较分配、受邀范围、需求和离站等事前条件、实际功率与减载参照能否接起来。正式充电连续补偿以同一任务内累计有效响应时长为主结果，保留现有连续DR及样条研究对照。公开ACN缺配对事前补偿。模拟曲线与居民用电各自保留原口径。先前提出的 iFlex 逐档比较改列辅助备选。[既有真实预测](../b1_iflex_real_training_20261103/README.md) · [连续方法对照](../b1_curve_stability_20261103/README.md)

### 辅助备选 核 iFlex 实际报价和同日对照

固定使用本地官方 iFlex Phase 2 的纯 P 价形。P_2、P_5、P_10、P_15 的区别集中在源 Hour17/18，其他22小时报价相同。只读复算排期得到59个组日、30个日期，其中原开发角色49个组日、25个日期。全排期只有5日同时出现两种不同 P 报价，任意一对报价的直接同日重复最多1日。作者说明试验日偏向冷日，报价随机初选后可为平衡次数改派。两种报价在不同日期的均值差可能反映天气、日期和构成差别。若缺实际改派规则和足够重叠，逐档比较仍可针对各自日期估计相对于无试验报价的差值，档间差只标为描述，精确随机化推断和连续外推不放行。[作者数据说明 §4.5](https://pmc.ncbi.nlm.nih.gov/articles/PMC10539631/) · [组日与区域对照研究 §6](https://arxiv.org/html/2609.25924v1)

1. **对齐名册、日历和实测字段。** H2 按 Oslo、Stavanger、Bergen 分层，匹配同招募机构的 `Control`，Os_2 对 `Os_Control`，Trom_2 对 `Trom_Control`。从公开参与表核到处理侧718条和对应对照侧802条名册记录，电表可用数待核。H2 地域细分仍属同一报价组日。用组日表、参与表及小时原档核 Phase 2、无报价对照、UTC、重复和缺失。按档×报价组×地区列处理和对照家庭数、实测完整数及日期数。保留零值、缺测及原分母。核旧数据使用清单，旧预测测试日期的结果不再打开。先固定字段与比较规则，仅在原开发角色抽最小切片回源。
2. **锁定比较条件和停止线。** 主结果是报价峰窗2小时的每户电量差，同时给窗外22小时和全天电量差。窗外可按源小时分开检查峰前与峰后。全天、峰窗和窗外用同一完整分母，账面相加须一致。对照优先同地区、同招募渠道、同日期的未报价家庭。先用原始均值差做基线，复核试验前同窗平衡，预定一个用试验前差异调整的简单对照。处理与对照均按固定名册保留，前后相邻干预按实际排期登记，通知后的用电不用作事前调整；检查前期无干预日期上的安慰剂。按日期聚合并报告实际组日、日期和重复家庭，做留一日期与留一组敏感性检查，区分组日水平和跨日期假设。下一轮开结果前先冻结最小有意义电量差、精度门和共同支持，范围过宽则写明判断不了少用或移时。
3. **通过后只做一次真实开发比较。** 四个档位分别对各自同日无报价参照，给可比日期、覆盖与峰窗、窗外和全天差。用量移时须同时看到峰窗下降和窗外增加，并交代全天净差及其不确定性。用共同地区与条件的支持来判断能否比较档间增量。第二层只留一个事前条件，先试试验前同峰用电水平，按地区和招募渠道用预先固定的试验前规则分组，在相同档位和日期估高低组差。覆盖不足则暂不估分组，停止本数据线的加模型。独立确认另用可说明的新数据。

**若启动辅助线，先交付**一张逐档同日可比表、一份字段和源行核验、一份放行或停止决定。原作者同期对照及固定效应分析作方法基线，2026年预印本用于核实组日和对照的构造。先用现有工具做表与均值计算，暂不接复杂反事实模型。[原研究](https://doi.org/10.1016/j.enpol.2023.113821) · [iFlex 原档及冻结口径](../b1_real_response_data_20261103/README.md)
