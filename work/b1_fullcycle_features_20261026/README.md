# B1全周期曲线特征比较 v1

2026-10-26｜接续D110，实际执行规则F0与常均值变点F1的冻结比较，未开展表示学习或B2模型训练。

## 研究结论

**变点平滑对较强噪声有增量，但不能统一替代原规则。** 对缓慢爬升，阶梯近似仍有定位偏差；采样间隔与驻留判据的统计特性也会影响误检。保留两法及失败，不按事后已知真实机制给算法切换答案。

完整观测，原生噪声标准差0.15kW、10秒采样：

| 指标 | F0原始曲线规则 | F1变点平滑后同规则 |
| --- | ---: | ---: |
| 无动作却检出响应，25次配对重复 | 8/25 | 0/25 |
| 有真实响应的起点MAE，125个机制变体 | 11.68秒 | 8.00秒 |
| 最长连续阈上时长MAE，150个机制变体 | 17.40秒 | 6.67秒 |
| 功率恢复时点MAE，125个机制变体 | 38.16秒 | 1.68秒 |

完整观测的0.15kW/30秒版本，无动作误检21/25→0/25；30秒数据由三格10秒观测平均，噪声会降低，但30秒驻留从3格变1格，误检并不必然降低。这不是比较真实设备通信延迟，也不是证明采样越细/越粗越好。

失败没有隐藏：

- 低噪声0.05kW/10秒的缓慢爬升，达90%目标时点MAE **13.6→27.2秒**；30秒版本 **7.2→25.2秒**。F1在四个噪声/采样组合下的缓慢爬升起点MAE均比F0大。强噪声30秒的该机制，达标MAE20.4→36秒，30秒内定位正确23/25→19/25。常均值拟合不能自动解释物理阶段。
- 低噪声总体最长阈上时长MAE，10秒3.13→3.27秒、30秒0.80→2.80秒，F1并非全面改善。完整观测F1阶段标签各150/150相符只是这6类声明情景的观测判据分类，不是B1准确率或正式90%考核。
- 原始电量积分始终共同使用，两法结果相同，不用平滑曲线“改善”交付电量。请求缺测600条都不输出完整电量/起点/时长；恢复期缺测600条仍保留可算请求电量，但恢复与累计欠量不可用；后窗不足600条的能量恢复为右删失。缺测/删失正确标记不当作识别成功率。
- 完整截止能量区间覆盖552/600变体，实际对应同一批噪声中的23/25，二项MC区间73.97%—99.02%；不能将600当独立样本。能量状态336个within_margin、264个unresolved，没有错误确定above_margin。数值容差0.01kWh非业务标准，未知噪声/参考误差下不保证覆盖。

## 数据、方法与边界

25新种子261026501—261026525；每次6个配对机制：无动作、阶跃、部分、缓慢爬升、提前退出、中途掉落再响应。每机制派生4观测条件×2噪声×2采样，共2400观测变体/4800方法输出；独立基础抽样25次，不是2400独立事件。原件[data独立版本](../../data/驱动因素解耦模拟数据集_B1_fullcycle_features_v1_20261026/README.md)。

声明单向EV参考3kW、请求1.5kW，600—1800秒请求，后续1.5kW回补并在最后一格作平均能量补齐；0—3600秒潜在功率1.5—4.5kW，总净量最大数值差1.42e−13kW·s。完整后窗本轮有保存，但参考、功率/期限、执行与回补皆为模拟假设，不补齐真实EV证据或真实用户意愿。

F0原样调用D106 `features.extract`，共同扩展最长连续阈上时长与明确缺测策略。起点0.15kW、目标0.9×请求、恢复带±0.15kW，驻留30秒，10/30秒对应3/1格。时长是事后阈值判据，不是可承诺容量持续时间。

F1用与D106开发相同的**精确未剪枝常均值DP**，向量化候选起点计算；分段残差SSE加每内切点惩罚，最短段30秒，惩罚`3*sigma_eff²*log(block_n)`，未调参。按已知指令分成前/请求/后窗，缺测处分开有限块、不插值；切点只是曲线近似，不是阶段真值。O(n²)，不称PELT或线性复杂度。

原始积分和固定观测截止能量区间两法共同使用；已知iid高斯误差声明下传播方差，短窗只描述已观测截止、未来3600秒结论删失。没有重用旧精确零判据宣布完全恢复。

本轮目标是相应采样分辨率的**无噪区间平均曲线阈值/驻留特征**，评价器独立从隐藏曲线计算。缓慢爬升物理动作起点与达到0.15kW判据的起点不同，元数据分别保留。10/30秒目标随区间平均变化，不声称恢复了连续物理时刻。阈值提取为事后分析；当前事件的后续曲线不可直接作为调用前预测输入。
