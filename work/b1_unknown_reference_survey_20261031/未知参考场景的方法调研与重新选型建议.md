# 未知参考场景的方法调研与重新选型建议

2026-10-31。B1第一部分的研究笔记与选型建议，非正式项目报告。本轮重新查找论文和作者开源，找回用户旧截图；没有训练、实现新路线或运行新实验。

## 1. 场景找回来了：任务已知，正常功率未知

旧截图已找回并实际查看，关键行是：

> 未调节参考功率：原B1主要在参考已给定条件下分析；老师RIDE增加模块A，从历史平均、回归等方法中选择参考。

见[截图副本](prior_scenario_screenshot.png)与[来源对话/场景回查](scenario_recovery.md)。老师原稿也明确“如果没发请求，本来会充多少电看不到，只能估计”。

本轮研究目标是：**任务时间、要求与通知已知；用通知前合法资料预测没有本次调节时的正常功率，再用任务实际计量识别减载、持续、退出、恢复和反弹，并说明可信程度。** 不是在任务尚未提出时预测用户执行多少，也不是从没有任务记录的电表自动猜任务。

预测器从通知时出发，一次预测任务与规定后窗；过程提取则可事后读取实际完整观测。预测参考所用资料与提取过程所用资料分开，不能把通知后、尤其回补期的目标车功率偷偷送回参考模型。

先维持EV实例与既有结果口径：累计阈上时长为贯通主结果，最长连续时长分列，原始参考差积分η并行。单EV与站级聚合分开；1分钟、15分钟均为区间平均。会话字段缺失就明确限制，不补造SOC或实际未来离站信息。

## 2. 重新调研后的推荐

**推荐将下一研究底座改为“条件化的概率参考预测＋较自由的分段趋势恢复＋可靠性和删失标记”，不再默认继续加补丁修RIDE。** 这是用户本轮开放算法选择后形成的新建议，尚未替换运行代码或正式选型。

最小优先顺序如下：

1. **参考预测：先比较一个提升树模型与一个概率GP模型。** 提升树优先复用已锁定的LightGBM；GP使用已有scikit-learn作有限对照。两者使用同一合法信息、相同用户/时间划分，均评价整段预测误差。保留简单历史/正则回归参照；不预定谁获胜。
2. **过程恢复：优先复现L1趋势滤波及其加权广义lasso版本。** 它允许数据决定在哪里改变斜率，不要求每条曲线符合完整四阶段硬模板。把计量尺度的曲线与特征先做可信；阶段名称、缺失阶段及中断另按任务定义解释。
3. **真正待研究的增量：参考误差如何传入特征判断。** 用独立未发任务的整段误差资料，研究在相同误警/可用率条件下，能否更可靠地保留短弱响应，并输出时长、恢复和删失的不确定状态。若只是复现成熟加权趋势滤波，就按成熟方法的领域适配评价，不称新过程算法。

相比立即另建联合HMM/HSMM，这条路线较容易隔离“预测错了”还是“提取错了”，也能复用现有CPU工具。风险同样明确：树模型的逐格分位数不等于联合路径分布；GP核/高斯假设可能不适合单车开停；L1平滑可能压低弱响应；参考残差有偏时，加权不能消除偏差。**文献只支持将它们列为值得优先验证的方法，不支持现在宣布优于现有算法。**

Chronos-2作为现代预训练预测模型保留一个有预算的探索位置；暂不为了“用深度学习”重训大型Transformer。双向补洞、合成控制、HSMM留有条件的备选，不在首轮同时展开。

## 4. 基线怎样重新定

**可以重新定，但CPOP的问题是覆盖范围不完整，不是“太强所以换掉”。** 它是过程分段器，既不替代参考预测，也不完整解决误差传递和删失。因此新方案应有完整管线与过程模块两层比较。

| 层次 | 本轮建议的基线安排 | 为什么这样定 |
|---|---|---|
| 参考预测 | 简单历史/正则回归作透明参照；**条件化提升树与GP概率参考为主要有限组** | 至少有领域机器学习强参照和概率强参照，不只赢简单均值法。首轮不必安装所有树库或联合模型 |
| 过程主比较 | **同一冻结参考、同一平均观测、同一误差信息下的标准/加权广义趋势滤波** | 目标是恢复曲线与计量格特征，匹配新路线；完整协方差版必须进入强基线，不能把误差信息独占给“新方法” |
| 强补充比较 | 同参考的原CPOP；必要的阶跃PELT/多尺度对照 | 保留自由斜率强结果，避免为赢只选常均值对手；阶跃对照只承担匹配的用途 |
| 旧版/老师版 | 保留为历史参考，不强制继续作为研发主线 | 既有得失真实保留，不重写历史；新用户已允许开放选择 |
| 完整第一部分 | 使用合法参考预测＋共同特征定义＋相同可靠性输出的组合管线 | 先分别评预测和提取，再看全过程；组合是本项目配装，不能伪称来自某一篇同题算法或新通用算法 |

其中最容易误记贡献的三步，必须分开：

- TF0：标准L1趋势滤波，用作基础参照。
- TF1：加入相同平均算子和对角误差尺度。
- TF2：加入相同完整残差协方差，构成广义最小二乘/广义lasso强基线。

**如果拟采用方法恰好就是TF2，就应把它称为成熟底座的领域适配，不能再把TF2换一个名字当“新算法优于基线”。** 后续若研究特征不确定性、任务证据或删失处理，必须在TF2之上清楚定义新增输出/机制，并与同信息版本比较。若没有新增机制，也可先完成强方法复现和问题诊断，但不能宣告研究创新已完成。

## 5. 研究增量应落在哪儿

建议将具体问题定为：**参考预测误差传入过程特征后，能否在相同误警与可用率要求下，提高短弱响应和删失任务的可信测量。**

这比“再换一个预测模型”“让拟合曲线更光滑”更接近现有瓶颈。可按顺序检验：

1. **整段参考误差，是否比单点噪声尺度有实际价值。** 未发任务的预测残差要保留时间相关、正负尾和用户重复结构；分位数每格独立拼接会丢失持续偏差。协方差只表达相关波动，不修均值偏差，仍需单独评估偏差及模型错设。
2. **不确定性是否真正进入了特征。** 在固定模型下对合法参考路径/残差路径重复提取，可先给特征敏感性；频率或模型后验不能直接称有保证的置信区间，需要在独立数据上检验覆盖、宽度及拒答。任务证据不足不置零、不删样本。
3. **提前离站、缺观测和恢复未完成是否被正确区分。** 不用实际未来离站回填自然参考；缺失恢复不等于没有回补，已充满停机不自动等于指令减载。完整任务结果与截至观察截止的结果分列。

以上均是待验证机制。没有针对性证据前，不同时把会话条件、新网络、平均算子、误差协方差和阶段图全部叠加。只有参考模型更好，就按参考收益评价；只有更准确的区间/拒答，就按可靠性收益评价，不强称点时长全面提升。

### 最小数学底座及两条限制

令y为预测参考减实测的格残差，r为候选过程参数，H为所声明的区间平均算子。一种成熟底座为：

\[
\min_r\;\frac12(y-Hr)^\top\widehat\Sigma^{-1}(y-Hr)
             +\lambda\lVert D^2r\rVert_1.
\]

这是广义lasso/加权趋势滤波形式，非本项目新求解器。协方差须来自独立非事件预测残差并适当收缩，不能从本次响应轨迹自由估计；完整预测残差通常已经含计量噪声，不再机械重复加入同一噪声方差。

H也不能为了“有创新”凭空复杂化：若每格内只有一条直线，区间平均就等于中点值。只有跨格内折点/跳变才可能不同；增加格内自由度会带来不可识别性。15分钟只有少数格时，正则化挑出一条曲线不等于唯一恢复物理四阶段，主评价仍应在Hr的计量尺度。

只凭一条受任务影响的功率轨迹，若没有合法历史、可信对照或明确结构约束，参考与响应一般无法唯一分开。换GP、Transformer或HSMM都不能绕过这一信息限制。

## 6. 开源复用和实施成本

先查过GitHub与官方实现，优先复用，不另造求解器：

- **现有LightGBM/scikit-learn**：项目`B1算法/requirements.txt`已锁LightGBM4.6.0、scikit-learn1.7.2。可先做提升树、正则回归和有限GP，不需因某论文用了CatBoost就立即换依赖。LightGBM是MIT、scikit-learn为BSD3；不是CatBoost作者研究的逐项复现。[LightGBM](https://github.com/lightgbm-org/LightGBM)、[scikit-learn](https://github.com/scikit-learn/scikit-learn)
- **趋势滤波**：作者`genlasso`/`glmgen`提供方法参考，但有R/C依赖和GPL许可；老作者软件不等于当前高频维护。可优先用维护中的CVXPY作凸模型核对，官方已有[标准趋势滤波例子](https://www.cvxpy.org/examples/applications/l1_trend_filter.html)；它不是专用快速求解器，不能承诺运行速度。CVXPY当前仓库Apache2，实际求解器与固定版本还须单独核。[genlasso](https://github.com/ryantibs/genlasso)、[glmgen](https://github.com/glmgen/glmgen)、[CVXPY](https://github.com/cvxpy/cvxpy)
- **Chronos-2**：代码和模型卡列Apache2，有官方示例/维护；需额外权重与PyTorch相关环境。zero-shot免任务训练，不免下载、内存和推理成本。本轮未下载/安装，也不使用云服务。[官方库](https://github.com/amazon-science/chronos-forecasting)、[模型卡](https://huggingface.co/amazon/chronos-2)
- **其他路线**：CausalImpact依赖R/bsts且需有效控制序列；gfpop需Rcpp并需斜率/平均观测改造；pyhsmm作者明确停维护。部分新论文作者库可读却未核见许可或训练数据，不直接复制。不用stars或发表年份替代场景匹配。

## 7. 下一步怎样最小推进

以下是调研后的实施建议，本轮没有执行：

1. 固定单EV计量边界与“通知时冻结参考、事后提取过程”的输入表；审核现数据是否含正常充满/停机/离站、合法历史和非事件。当前数据缺哪项就先限制结论，不额外生成假字段。
2. 参考侧只做有限提升树与GP对照，另保留已有简单参考；按用户/时间留出，预先固定训练规模和计算预算。GP不能对大规模逐分钟样本无预算直接全核拟合。Chronos仅在明确环境/权重预算后安排一个探索对照。
3. 固定共同参考，先复现标准/加权趋势滤波与原CP，验证数值求解及共同特征口径；不把库调用或更低观测损失当性能胜出。
4. 在标准强底座之外，只选一项可信特征增量，例如整段参考误差传播＋相应任务/特征校准；与同信息GLS-TF比较。若只是同一个目标/输出，则回到“成熟方法适配”定位，不创造名义新方法。
5. 开发和选参使用合法已见开发/验证资料，真值仅评价；不能按测试真实动作给模型调参或路由。一次冻结后，用新独立用户/种子评价全链；既有test可作反例，不能重称新测试。

比较时共同报告参考偏差/尾部与概率分数，过程曲线/时长误差、短弱漏检、无动作误检、恢复/删失正确性、不可用率、区间宽度/覆盖与成本。固定物理阈值，另比较同误警水平的检测能力，不能靠多拒答/少报响应“改善”误检。

采用标准是预定主要输出存在实用增量、关键弱响应/误检/可用性无不可接受退化且预算合理；若只有平均RMSE改善、概率带不校准、自然停机误当响应或只在模板生成数据上奏效，就不升级。只完成可靠性收益也可形成明确结果，但不能冒称所有点特征更准或B1整体完成。

这轮结论允许重新起一个方法底座，**既不要求保住RIDE，也不以移除CPOP换取胜出**。下一步应验证新底座与明确增量，不先改全局默认、连续因素模块、B2/B3/B4、其他资源或正式报告。
