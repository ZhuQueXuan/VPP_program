# 第一部分：真实数据定位试跑

这轮已经实际运行原版CPOP、原版LABS和一个CPOP后接原始电流/功率定位补检的试验版。结果是：**补检没有改善验证集起变或恢复定位，还多出一个与初审标签不一致的正判断，未采用。** 现用 `effective_response_refined` 和全部旧模型保持不变。

本轮是128个已整理真实开发窗口的可行性实验，标签仍是单助手初审；没有独立物理真值，不能把下面的吻合数称为经过认证的真实准确率。封存测试与外站测试观测未读取。

## 实际比较的对象

三者使用相同原始功率点，不重采样、不删点、不填缺口。CPOP用现有CRAN1.0.10原生求解器，`beta=2log(n)`、`minseglen=0`、精确剪枝。LABS用已有固定提交的原作者代码、SIC、M5/retest2/alpha1.01。两者在此次主比较都用观测序号建模，再把定位结果映回原始秒数，避免只给一方使用非等间隔时间能力；不把这些序号冒称等间隔物理采样。

原生实现按现有适配器通过R子进程复用。已核[CRAN代码镜像](https://github.com/cran/cpop)和[LABS作者仓库](https://github.com/pfryz/LABS)，沿用本地冻结源，分别遵守GPL>=2和原作者MIT范围；未安装或下载新的实现。CPOP支持非等间隔时间，但本轮没有另行调这个分支；LABS沿用其原序号假设。

试验版保留CPOP曲线，用原始电流和功率的同向局部变化补检、修正起变及恢复点。没有改CPOP数学求解器，也没有发明新的树或新分段算法。两路来自同一桩，只是同时核对观测，不是两个独立故障仪表。

此前采用的整套 `effective_response_refined` 要求30分钟任务、已给定参照和特定采样，本批是4分钟非等间隔窗口，且没有请求减载kW/未调节参照的真值。因此本轮不强行编造q和参照去跑整套模型，更不把本试验版说成正式版已经适配真实场景。

## 训练与验证如何使用

训练96窗，验证32窗，用户不跨组。训练集仅搜索补检强度k=2/3/4三个配置，选k=3；没有训练监督分类器或改原模型权重。训练阶段该配置未增加相对CPOP的误检/漏检，但联合定位误差14.51秒略高于CPOP14.39秒，已经没有显示收益。

`selection_freeze.json`在验证原生输出生成前锁定配置和代码；随后只跑一次验证，不看验证结果再调k。验证标签此前已在标注时查看，故不宣称独立盲审；验证是开发用途，正式测试仍封存。

所有128窗保留。Case98有重复原始时间或不满足严格时序条件，保留为不可用，不删除或去重；它原先就是无锚点的上限不变窗口。其余127窗完成原版CPOP、LABS共254条原生拟合。各方法的不可用与不适用状态都在输出中，不能当负样本。

## 验证结果的正确读法

32窗中，只有18窗有明确的锚点跟随正/负初审标签，另14窗未解决或没有上限边沿，不计成负例。18窗的标签吻合为CPOP18、LABS15、试验版17；LABS漏掉3个初审正例，试验版新增1个正判断但没有多补回真阳性。这是初审标签吻合，**不是CPOP现场准确率100%**。

11个有起变位置参考的窗口，CPOP和试验版都落在参考的原始采样范围。这个起变集合很小、又围绕指令抽样：单报指令0秒也全部落在范围内。因此不能据此宣称起变提取已经解决或有新算法收益。对首个可见点的误差和仅指令的检查一并保留。

7个有恢复参考的窗口，CPOP与试验版平均超出参考范围6.29秒，试验版没有改善。其余6窗都命中，全部误差来自Case41：初审恢复在4至8秒间，而两者报52秒。LABS有5个窗口未给出恢复估计；所有缺失定位均按预定180秒失败代价计入，未只挑成功定位报低误差。

这些范围是原始采样与初审解释的表达，不是物理置信区间。本轮恢复是回到此前附近水平，不是过去模拟中的累计/最长有效时长，不能把这轮6.29秒和过去几十秒的模拟有效时长误差相减算改进。

## 为什么没有收益

Case73新增正判断来自原始记录很小的电流/功率波动，CPOP已将这段拟合为平缓变化。补检把这段波动重新报成锚点跟随；两路一致也不能自动证明真实控制响应，按冻结初审标签计为新增误报。没有把这条改标或移出计分。

Case41的CPOP曲线已跟上真实记录的下降和回升，8秒原始电流已回31.7A、功率6.759kW。本次试验恢复判据围绕此前中位6.713kW只允许约±0.03kW，因此8秒被挡住，直到52秒一次波动落入窄带才判恢复。**直接拿原始曲线套相同判据也报52秒，说明这条主要是试验恢复判据的问题，不能归咎CPOP没分出来。** 这只解释当前7条恢复参考，不外推为所有真实/生产时长误差的原因。

`source_diagnosis.json`保存原始行数值，`diagnosis_examples.png`已查看核对。原始证据单用与试验版在全部32个验证窗口的存在/起点/恢复输出相同，因此没有把任何差异归功于CPOP求解器。
