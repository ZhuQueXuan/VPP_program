# 有效响应核验降误报（已接入）

当前入口 `analyze_event(s)(..., process_method="effective_response_refined")`。上一版 `gap_duration_refined` 及更早版本、原CPOP/LABS对照和兼容默认保留。只处理第一部分已知参照历史特征，未展开参考预测、第二部分或报告。

## 原因与改动

先核上一轮2808条：499次有效响应误报里，120次没有物理动作，379次确有弱变化但没有达到原定0.15kW有效标准。观察到的持续弱背景范围（任务中位数0.075—0.20kW）包含其中248次误报，且该批真实短脉冲不在此范围。没有把全部误报归咎为故障/尖峰，也没有把低于有效标准的真实物理变化称为“没有响应”。详见 `diagnosis.json`。

本版在已有时长校正之后，增加整任务有效性核验：观察到持续弱背景、当前正时长不超过180秒时，结合整段原始量测/结构特征给出有效性分类。分清物理变化与达到有效标准。原始点、结构曲线、物理变化证据、电量与η全部保留，负判定只将有效时长/有效定位状态改为零；每条负判定按实际分类结果计分，未当不确定或删除样本。

采用标准7叶HGB、220轮，426维完整轨迹描述，训练代价有效正任务5、有效短时段正任务50、负任务1。标准分类器不是新发明；改动是有效性目标、任务适用范围、保留物理证据及与既有特征融合。分类分数阈值0.05是验证选择的未校准模型分数，**不是5%误报率、95%置信或现场零漏检保证**。物理有效阈值0.15kW及原判据未改。

## 训练、冻结与实现核对

19456条旧已知任务明确作为开发，4223条进入适用核验范围，其中2675真实有效；当前7791/7792完全排除。7/15/31叶及分类分数/当前时长范围只在新验证集选择，预定“误报至少减10%、不增加任何真实任务拒绝/整漏/局部漏/短漏、时长非劣”全部在最终通过。每条真值时长、预测误差和分类在独立逐格审计重算，所有负判定均留件，没有滤除反例。

公共/native新旧入口各12事件，包含4个分数接近阈值的负资格例、保留的真响应、真短脉冲及未解决的安静背景无动作误报。输出和冻结结果一致；全部2808个426维特征向量与生产构造相同；旧接口从保留源码重放相同。物理变化分数/接受状态、原结构曲线和支持曲线、原始量测特征、电量、η及其他既有特征同。

新输出 `effective_verification` 标注有效性资格，不表示物理参与/执行或故障真值。`duration_estimates`和有效定位状态是最终资格结果，原 `duration_calibration`明确为资格核验前的时长提案；被判不达有效标准的记录仍返回`ok`及原始事实，不能据此过滤后续因素分析样本。

范围继承现有版本：已知参照、30分钟/q1.5kW/sigma0.05kW、十秒/一分钟、前后15分钟及默认物理标准。强背景/安静短动作等范围保留旧结果，未解决的误报也没有被隐去。生产新增 `_effective_response.py`、模型与manifest，注册单条/批量入口，旧权重/数学/默认保持。

结果与冻结见 `assessment.json`、`public_checks.json`、`completion_receipt.json`、`freeze.json`；所有开发配置见 `validation_grid.json`。已核2026 NP分类与NeurIPS2025 Conformal Risk Training备选原始来源，见 `method_notes.md`；当前实测已有收益，未实现或借用论文风险保证，也未更换为未经比较的论文算法。无新库安装、GPU、删除或外发。
