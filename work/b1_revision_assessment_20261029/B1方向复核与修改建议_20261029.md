## 一 总体判断

**B1可以继续沿着“识别已发生的响应过程，估计激励对响应的因果作用”推进。报告需要重构，方法还需要补未知基线、观测分辨率及非随机多档估计的证据。**

老师修订稿保留了原来的两个核心问题，进一步要求它们在更接近实际的观测条件下成立。这支持保留研究方向，但还不能说明现有研究已经足够完整。会议最集中地暴露了表达和研究组织问题；书面意见又提出了几项实质的方法问题。

已有模拟研究具备可保留的代码和结果。原先在“参考功率已知”的假设下做实验是合法的条件研究；它所证明的范围应写清楚。向真实计量数据推广时，参考从哪里来、误差有多大，必须进入研究。

老师稿提供了有用的研究框架，其中部分现状判断和公式还需核准。建议把它作为修订依据，先落实核心问题，分阶段选择方法，避免一次性展开其中全部E1—E10。

## 三 报告怎样重写

### 1 开头先说清一件事

建议用下面这段作为重写的起点，再由本人按实际方法确认：

> B1研究已经结束的虚拟电厂调节事件，回答资源实际怎样响应，以及提高激励使响应改变了多少。它先根据任务记录、参考功率和实际计量，计算减载时长、电量及恢复情况，再结合任务发出前的用户条件，区分激励作用与用户原有差异。当前以单向充电资源的模拟数据检验这条分析链，真实应用还需解决未调节参考的估计及粗采样下的识别问题。下一次事件的预测由B2承担，任务控制与多资源组合由B3承担。

可采用“响应过程识别与激励因果效应估计”作为B1的说明性名称，保留与正式任务“行为影响因素与全过程特征分析”的对应关系。老师稿提出的RIDE暂作候选名称，待具体方法和实验确定后再决定是否使用。

### 2 采用一条连续的叙述主线

建议B1独立说明，按以下顺序组织：

1. 研究问题、使用场景和输出用途。
2. 一类可调功率资源的上层描述，以及充电桩实例。
3. 两个子问题：从曲线取得事件结果；从多事件记录估计激励作用。
4. 方法依据、关键计算和同类比较方法。
5. 实验：过程提取、平均作用、多档关系和交点不确定性。
6. 已支持的结论、适用条件及尚待验证的部分。

历史表示对B2的预测增量试验放在末尾或附录，避免抢占B1自身问题的主线。主结果至少分别回答“过程提得准不准”“平均作用估得准不准”“激励关系及首次达标位置能确定到什么程度”。

算法类别需要准确：B1总体做事后估计；内部可以包含基线预测和数值拟合优化。“属于估计问题”不意味着内部不能使用预测器或优化求解。已知算法的组合也不自动构成创新，需要通过具体难点、方法处理和实验说明贡献。

## 四 算法和实验需要补什么

### 1 统一结果定义及参考的身份

明确区分三种参考：模拟评价器保存的真反事实轨迹、业务约定的参考计划，以及由历史数据预测的未调节功率。它们分别支持不同结论，不能统一称为已经知道的真实基线。

建议新研究以请求窗净交付比例为主要结果候选，同时保留净交付电量、累计时长、最长连续时长和恢复状态。净交付比例以实际有符号净交付电量除以请求电量；不强制截成0至1。对请求幅度大于0、窗口明确的事件计算，在不同任务条件间比较时明确标准化对象。

从“秒”改为净交付比例会改变估计目标，需要新评价，旧表不能直接换单位或换标题。群体平均作用也不能直接换算成单个资源的可承诺容量。

### 2 增加未知基线的有限验证

在新模拟样本中保留真基线供独立评价，但不向估计器提供。先选一个透明历史/条件回归基线与一个合理对照，比较已知基线和估计基线下的电量、误检及平均作用变化。需要覆盖事件条件与普通时段不同的情景，不能只在容易预测的平稳数据上验证。

伪事件有助于发现无调节时的误报，但伪事件通过不证明实际事件中的基线无偏。事件前后有系统差异时，重抽样也不会自动消除偏差。

### 3 增加分辨率和缓慢响应的检验

在同一组潜在曲线上生成10秒、1分钟和15分钟区间平均观测，区分采样损失和方法误差。实际平台采用何种分辨率仍需核实；这里的三档首先是研究条件。

含斜率的分段模型值得作为候选，与F0和F1比较。候选模型需处理无响应、缓慢爬升、提前退出、掉落再响应及观测中断。恢复约束按资源机制定义，四阶段模板不能自动代表所有资源。

例如，一个15分钟区间内，前10分钟减载与后10分钟减载可以产生相同平均值。仅凭这个平均值无法判断开始时间。增加区间平均算子能正确描述观测，却不能补回已经丢失的信息。阶段参数应允许输出范围或“无法区分”；在请求窗完整且边界可处理时，电量等积分结果可能比细分时点更容易估计。

### 4 将非随机多档与有效推断接成主链

保留原随机剂量实验作为参照，另设连续事前条件影响激励分配的新场景。先比较透明调整、加权及一个交叉拟合双重稳健候选，不同时扩大到多种森林和网络。输出平均曲线、两档差、区间、重叠情况和无法估计的状态。

旧AIPW负结果必须保留。只有新问题带来的困难和新验证证据，才能支持改变默认方法。[DML原论文](https://academic.oup.com/ectj/article/21/1/C1/5056401)与[连续剂量双重稳健原论文](https://doi.org/10.1111/rssb.12212)提供方法依据，不保证在本项目全部场景胜出。

先评价新结果变量和平均作用区间，再评价整个基线—过程—效应链的不确定性。重叠诊断通过不能证明没有遗漏混杂；重叠不足时需要限制目标范围或报告不可估计，不能仅裁剪权重后沿用原目标声称有效。

### 5 明确本轮完成标准

完成标准应是：输出定义一致、方法有依据、与可比方法在同一信息条件下评价、关键误差和不可识别情况被报告。无需预设新方法所有场景获胜，也不以B1特征必须改善B2为通过条件。

新协议、新样本与独立评价应先于主计算冻结，保留旧数据、原模型和负结果。重复次数根据区间精度和计算量确定；不能仅因老师稿写了100次，就把100次经验覆盖率落入93%至97%当作无随机误差的硬门槛。

## 五 老师修订稿采用前需要核准的内容

| 内容 | 需修正或限定之处 |
| --- | --- |
| 单调投影 | 只在有依据的单调情景使用；保留真实非单调和负作用情景。共享随机数本身不能保证激励上升使参加不下降 |
| 参加的定义 | 平台接受/授权记录与“检测到幅度超过阈值”分别命名；不能由功率反推出授权 |
| Lee界 | 针对满足相应假设的始终参与者效应，不能直接当全样本总效应的精确可加分解；非随机分配需作条件处理，不能直接套未调整截尾公式。依据见[Lee原论文](https://www.princeton.edu/~davidlee/wp/resrevision8.pdf) |
| 预响应与阶段公式 | 文中要求计入通知后、请求开始前的动作，公式却限制延迟非负且请求前无动作；须统一时间原点及适用阶段 |
| 超窗与零爬坡 | 释放时点取最小值可能早于爬坡结束，需增加顺序/超窗定义；爬坡或释放时长为0时明确瞬时切换规则 |
| 时间与电量单位 | 以分钟积分功率得到kWh需除以60；净交付比例的分子分母使用一致时间单位 |
| 恢复与资源推广 | EV相对参考的电量恢复、储能SOC恢复、空调热状态恢复分别建约束，不能统一套相同电量守恒 |
| 基线区间及整体自助 | 预测区间、参数区间、效应区间、整条曲线同时带分别定义；自助法不能修复系统偏差或结构不识别。[分裂保形原论文](https://jmlr.org/beta/papers/v25/23-1553.html)也要求处理可交换性或相应依赖条件 |
| 站内干扰 | 改为站×时段并不自动消除干扰，需定义站级处理、结果、跨时段联系及独立抽样层级 |
| 参数作为下游真值 | B1估计出的参数是带误差特征或标签，不能自动作为B2精度的独立真值 |
| 创新与实验门槛 | “所有形状不劣于最佳方法”等是研究期望，不能预先承诺；IMSE、PEHE、覆盖率和排序指标不能混作同一种显著性检验 |

## 六 推进顺序与暂时后置的工作

按用户后续确认，先明确通用研究问题、查文献并选定同类baseline，再确定具体改进点、开展公平比较和阶段验证，最后修改报告。未知基线、分辨率、非随机多档作为待评估缺口，其实施次序由文献依据和估计目标决定。

连续剂量、细粒度CATE、Lee界、多种市场信号、第二资源、站级干扰以及下游再次训练，应在核心链明确后逐项确定目的。先做哪些由研究问题和数据决定，不同时展开老师稿中的全部方法。

其中差异化市场、多机制、时序及深度表示、真实证据仍是完整课题需要持续处理的方向，不能因近期后置而永久取消。四阶段拟合本身不等于完成深度时序表示；既有历史表示负结果也不等于整个方向结束。真实数据的字段和可得条件可先明确，未获得证据前继续保持原有真实验证边界。正式90%精度的评价对象和口径仍以任务依据确定，不能由本稿自行改定。

开源实现已先查看官方GitHub： [ruptures](https://github.com/deepcharles/ruptures)用于离线变点，BSD-2-Clause；[DoubleML](https://github.com/DoubleML/doubleml-for-py)用于DML，BSD-3-Clause。两者有公开源码、文档和开发记录，可作为实现复用或独立对照候选。现有NumPy/SciPy及冻结代码可复用；未知基线、区间平均和项目特定推断仍需适配。本轮没有安装新库；正式选用前需锁定版本、核验该版本维护状态和目标估计量支持范围。
