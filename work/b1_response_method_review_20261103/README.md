# 第二部分方法调研：连续补偿—响应曲线

结论：优先复现 **Colangelo–Lee 连续处理DML**，以正确实现的论文原方法作为主基线候选，保留现有Kennedy连续DR作参照。正式采用以同条件复现结果为准。目前没有本任务上“新方法已经更好”的成绩。

补偿金额始终按连续数值输入，同一曲线固定任务时长、请求功率和目标人群。主结果是全体用户的平均累计有效响应时长，电量辅助；包括未响应者，允许曲线趋缓、下降，不预设直线。现有代码已支持这些连续功能，不能重新算作创新。

## 先把基线复现正确

静态阅读[原核心代码](https://raw.githubusercontent.com/KColangelo/Double-ML-Continuous-Treatment/master/Supplement/estimation.py)发现，普通DDMLCT路径把同一个可变模型放进多折缓存，后续查询可能复用最后一折模型。`cache_audit.py` 的小型对象行为复核确认共享引用现象；这不是整仓库运行或性能实验。

正确基线要按论文保留每折独立模型，并与改进版共用用户分组及重复用户推断口径。作者缓存修复、运行兼容、用户分组和聚类标准误均为复现所需，不能当作我们的创新，也不能靠有缺陷的作者输出制造优势。

## 先试一个贴合任务的改进

本任务的累计时长有两个特点：不少任务没有有效响应，已经响应的任务也不会超过给定任务长度。首试在连续DML内部，分别估计“出现正响应的概率”和“正响应的平均时长”，相乘后继续进入同一连续校正，所有用户仍参与总体估计。

这个软两部结果模型只改变辅助结果学习，不按概率门槛把任务置零，不筛掉未响应者，不再修改第一部分。正时长辅助均值有任务上界，最终校正曲线保留原始估计，不事后裁剪制造收益。净电量可为负，不能直接照套正时长结构；`Y>0`也不等于已识别的参与意愿。

两部建模有[Yu等的作者论文依据](https://shuyang.wordpress.ncsu.edu/files/2022/09/Yu-Lu-Yang-Ghosh-2022-MMSM-for-zero-inflated-outcomes.pdf)，正式发表为Biometrika2023；其纵向结构模型并非本项目连续曲线基线，只借结果均值分解。**连续DML、两部模型都是成熟方法；当前是任务适配假设，收益和进一步研究贡献尚待验证。**

备用为[ICML2024的连续处理与代理结果方法](https://proceedings.mlr.press/v235/zeng24a.html)：有一小部分可信结果时，可结合大量代理结果。这需要真实校准标签及可核实的标注机制；当前首审起止标注不是有效时长gold，不自动满足条件。主线先不加这一层。

## 同条件比较与收尾

下一步先复现现有DR与正确连续DML；开发数据选定基线后，只试上述一个结果结构改进。同一数据、用户划分、补偿范围、分配模型、带宽和调参预算，控制基础学习器容量。观察整条曲线误差、零作用时乱报情况、输出覆盖及第一部分误差怎样传到曲线。

把干净参照特征与已冻结第一部分实际提取结果分别送入第二部分，以真作用曲线评价，不能拿第一部分输出作真值。按用户、基础事件和整类机制隔离，只做一次终验；没有收益就保留基线。详细计划见 `reproduction_plan.json`。

真实因果分析需要事先告知的补偿与事前因素；ACN本身缺这些记录，不能从电流上限造标签。已有第一部分112条模拟也没有激励分配，不能直接补一列金额冒充有作用真值。可先复核既有连续激励模拟开发资料，再规划独立的端到端验证；真实有激励记录的数据另核。

本轮只调研、核源码和小型对象问题，未拟合研究模型、未安装新库、未修改正式算法、未重开第一部分测试，未宣称性能提升。第一部分保持阶段冻结。
