# 过程失效诊断：独立静态技术审查

2026-10-30。范围为只读现用代码、旧实验和诊断方案。本文不提出正式替换决定，不改报告或算法源码，不运行主拟合。依据academic技能C3核对模板公式与代码，对因果归因和公平比较作限定。

## 已确定的代码事实

1. **M1的恢复/回补时序约束。** `_ride_template._unpack`以 `r0=tx+Tdn` 规定负回补块紧接连续正减载释放结束。M1没有独立的恢复后等待参数。提前退出后等待至任务结束再回补，通常不属于M1精确可表达的过程。
2. **M2能够借末端掉落表达一段等待。** 不能把上述M1限制扩成“全部RIDE无法表示等待”。取 `tx=W,Tdn=0,g0=E,g1=W`，M2可在保持段末尾扣去[E,W]，形成响应结束E后至W的空档，再从W回补。无内部间断的矩形响应在回补幅度合法时可精确表达。已有一个内部间断再加末端等待时，一个掉落参数对通常不够；非线性爬升、疲劳和波动还包含额外形状错设。
3. **本次回补幅度超出默认模板上界。** 默认 `template_rebound_max_ratio=1`，主任务q=1.5kW，负回补最多1.5kW。独立模拟用1.8kW回补，许多完整后窗计量格因此不在当前模板范围内。这个问题来自现用边界与研究情景不匹配，不能一概归于参数化模板思想无效。
4. **参考不确定性未进入现用检测。** 适配器传 `sB=0,lr_crit=None,ci_method='none'`。`sB`只改变LR和参数区间，当前BIC判别不读它。因此单把sB换成非零、继续lr_crit=None，不会改变这条流程的点曲线/检测。参考误差若需影响检测，应有真正接入的目标、误差模型或独立伪事件标定。
5. **优化器成功未认证。** n_starts=3是下限；常见情况下已有启发式、穿越、两抖动和DP五个初值。局部最小二乘每起点最多300次函数评估， `_fit_one`只保留最低cost而未检查 `res.success`，公开status=ok表示数值可输出，不证明找到本模板的最好解或优化充分终止。
6. **任务内阈值时长与全窗平方误差目标不同。** 两法拟合均以全窗曲线误差/惩罚为基础，评价主结果是任务内0.15kW阈上格数。贴阈值的小偏移可使时长跳一整格，后窗拟合优先级也能改变任务内曲线。单一时长指标不能独自区分表达不足、数值优化、BIC结构选择和评价函数不匹配。

## 现有比较公平性

RIDE/CPOP使用同一所选参考、功率、计量间隔、名义sigma和观察窗；原生CPOP调用保持beta=2log(n)、精确剪枝设置，未给其真实响应作为拟合输入。按同一阈值提取时长。这个比较对当前固定实现是公平的。

它仍是一个限定情景。独立生成器没有直接调用RIDE模板，包含提前退出、间断和非线性形状；CPOP灵活折线在此可能有结构优势。原研究没有系统覆盖模板匹配正控、不同回补时序、不同参考误差机制，因而不能推广为RIDE在一切EV环境均无效。所谓“未知参考”只是参考不可观测，不自动验证所选历史参考模型适合当前生成分布。

## 对根诊断方案的意见

固定8块、每块前16用户两事件、正/零配对，共512事实作已见诊断数据，预算足以回答局部机制问题。复用原预测参考结果，新增真实参考+有噪、真实参考+无噪、清洁输入移除回补、清洁输入放松回补界，比较的是相同事件上单项条件变化。每次两方法输入应相同；仅改模板边界的版本应标为诊断变体。保持原sigma而移除噪声，避免同时变更模型选择惩罚尺度。

需要以下解释保护：

- 真实参考是评价器才能提供的oracle，不是部署方案。换oracle后的改善是误差敏感性证据，不能算实际参考预测已提高。
- 去掉后窗回补同时去掉幅度越界和时序约束压力，若误差下降，只能先说明后窗回补建模影响；需与单独放宽边界、M1/M2结构及正控共同解释。
- MAE差的变化不构成可加分解比例。参考误差、模板结构与噪声存在交互，不宜写“参考占X%、模板占Y%”。
- 无噪声时仍有误差，不足以单独证明模板表达能力不足，局部求解与结构选择也可导致。建议小型模板匹配正控以及固定少量多起点敏感性，避免把优化器失败误判成模板无效。
- 这批旧留出已被看过且用于机制诊断，后续候选选择可在此开发，正式优势必须用独立的新评价数据检验。

## 待结果后的路线判断

若放松合法幅度/修正时序后，模板在匹配场景与多数目标形状均恢复竞争力，可继续采用结构模板并补显式适用诊断。若模板仍在间断/未知形状中稳定失效，可将原生CPOP作为通用核心，围绕参考误差传播、任务条件约束、误检校准或稳定阈值结果作实质改进。改进必须明确新增机制、预定主要指标、代价和失效条件，并与原CPOP用同信息、合理调参预算和新测试公平比较。

若改进仅相当于采用CPOP、调一个已见测试上的beta或扩大模板界，宜分别称复用、调参或边界修正；目前不足以称新通用方法。原始η与过程拟合无关，不能把过程曲线改善记作η效应改善。
