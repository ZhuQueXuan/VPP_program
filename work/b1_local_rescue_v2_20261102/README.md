# 已知条件下的独立弱短动作补检（已接入）

新增入口 `analyze_event(s)(..., process_method="known_local_response")`。当前 `known_response_duration` 和更早 `duration_fusion` 均保留，兼容默认不变。只做第一部分，不展开参考预测、第二部分或报告。

本版在原来完全没报出有效响应的任务中，直接扫描原始量测的局部正向脉冲，使用独立的原始量测提升树证据确认，输出补回动作的计量格位置与时长。**原来已报正的任务保持上一版结果。**因此能绕开“前级没有正时长，后级永远保留零”的限制，又不改已经提取好的短动作。没有删除或回填原始点，也没有把所有孤立点都当异常。

|---|---:|---:|---:|---:|

时长主误差为累计及最长连续MAE的平均，按采样与扰动条件等权。漏检比上一版少8/67=11.94%。补回8条测试记录来自6条基础轨迹，四个种子块均有补回；3条一分钟量测、5条十秒量测，其中十秒样本是实际持续十秒的动作。8条新增位置格全部与真值对应，未靠拉宽不确定区间或在别处报响应取得收益。

完整连续弱幅度面板1872条输入中，误报482→482，假阳性占用时长66.21094→66.21094秒，原有误报没有被掩盖；整任务漏43→35，局部漏105→97，总体时长主误差99.48438→99.34852秒。总体变化很小，配对种子块误差差值−0.13585秒的模拟重复95%区间[−0.37680,0.10510]包含零，**不能说整体时长显著改善**。收益集中在原来完全漏掉的少数弱短动作，剩余59/165仍未找回，也没有解决长振荡短暂过线定位。

另一批普通面板936条输入，本版与上一采用版结果保持：时长主误差25.48090秒，误报40条，真正短动作0/132位置漏检。原CPOP为39.02517秒/误报45，LABS82.89236秒/误报19及短漏75/132。不能只按LABS较少误报而忽略其漏检。

两最终面板合计2808配对输入、792条基础轨迹、四法11232行结果；均为有真值模拟，非实车N/现场故障准确率。

## 做法与范围

独立补检分支使用50个原始观测特征，含局部均值、波动、相邻变化和全任务分位数；不输入CPOP曲线、kind/seed/异常条件名或真值。冻结的标准HGB树作局部证据，配合1格至60秒的双侧窗口扫描，没有最短段长。候选要求前后背景较静、核心均值有足够正变化和噪声裕量；仍使用原0.15kW真值判据及30秒最长时长驻留，未改物理达标标准。

只补旧有效时长为零且整任务物理变化证据通过的记录，安静任务背景中确认0.15—0.35kW弱短脉冲。旧正任务原数值保持，不声称这是所有波形和异常的通用解法。支持范围继承上一版：已知参照、30分钟、q1.5kW、sigma0.05kW、十秒/一分钟、前后15分钟及默认物理设置。

`localized_response_intervals_seconds`、`rescued_response_intervals_seconds` 和 `features.localized_response` 给出计量格上的估计位置；不是物理精确转移时刻或置信区间。对补回的零任务，累计/最长时长由新状态格实际计数；其余任务继续使用既有直接时长特征。`localized_threshold_state`为状态量，不能当新物理功率。原CPOP结构功率及其余过程特征保留，电量与η仍是同一原始量测积分。

## 开发与失败记录

上一轮查出的测试覆盖缺口已纠正：开发面板每个形状×种子都交叉六个幅度；最终弱面板对每个形状×种子分别在0.07—0.30kW的六个等宽层内抽连续幅度，再打乱分配。既有一分钟与十秒真实短动作都覆盖阈上/阈下，幅度不再和形状绑定。普通面板保留原独立ODE生成方式，各法同参照、量测、采样和判据。

完整失败版在 `../b1_local_rescue_20261101`：复用旧状态树没能救短动作；新原始量测树加逐点补检、双侧脉冲补检也有失败配置。首个冻结版新测试虽将弱短漏71/132降到53/132，却误报664→666且新增格精度不足，明确未采用。没有改写这次失败成绩。

本版以其已见结果作开发资料，树权重不重训，新增7762xxx独立确认。更保守的开发筛选只安全救回6/108，没通过自定10%收益门；这个失败也保留。随后单独封存 `confirmation_plan.json`、`selected.json`、`freeze.json`，在新数据产生前声明仍以原安全/收益门独立确认，未冒称开发筛选全通过。新连续幅度确认全部预定门通过后才接入；没有按本次最终测试追调阈值。

HGB训练资料9628条已知开发任务，817046行、50维；已见旧测试明确转为开发，新增最终7762xxx完全排除。对真短正位置加权20、困难负点5、弱正点3，标准模型不是新发明。GitHub方案核查：[scikit-learn官方实现及许可](https://github.com/scikit-learn/scikit-learn)、[skchange官方实现](https://github.com/NorskRegnesentral/skchange)。沿用已安装sklearn1.7.2训练，原生树导出独立核同；skchange窗口思想相关，但其完整变点包不能直接解决本任务真假短动作证据，未额外安装。实质改动在任务级独立补检、确认和与已有特征融合，不是把已有方法换名。
