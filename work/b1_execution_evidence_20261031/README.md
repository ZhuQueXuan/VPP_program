# 执行、故障与交叉量测证据核查（第一部分，不改算法）

结论：**现有数据里找到两次可核实的设备上报故障，以及可做交叉核对的交流量测，但仍不足以建立100毫秒尺度的“真实短响应／毛刺／持续异常”完整真值集。已补充同一100毫秒尺度的受控真值样本，验证信息边界；没有运行或改进CPOP/LABS。**

## 两次故障样本已经整理

[官方参数字典](https://zenodo.org/records/14065331/files/parameters.csv?download=1)明确：`STATE_ID2/3/4=9`为故障，`ChargeState_ID2/3/4=7`为出错结束。暂停状态6/7不能当故障，未知其他代码不扩展解读。上轮未取得该字典的历史缺口，本轮通过官方网页文本核实了这两个码的含义。

实际命中：

- Fiat 500e，DC/CCS，实验`DC_kW_3_202308171457`：ID2故障与出错结束同一时刻首次出现，记录内持续约592.5s。
- Tesla Model Y，DC/CCS，实验`DC_kW_1_202309200805`：同样两码同时出现，记录内持续约689.1s。

两者一直持续到各自记录结束，属于右截尾，不含恢复证据；日志首次出现时间不是经过独立校准的物理故障起点。4个状态段是每次事件的两个字段，**不是4个独立故障**。

`real_evidence_samples.json`及`reported_device_faults/`保留原行号、原epoch、两状态码、指令、桩输出和外部功率上下文。可称“设备上报故障状态样本”，不能称“电流单点确实是传感器毛刺”，也不能混入交流100ms真值评测或把DC输出与网侧AC功率直接当同量相减。

命令行下载77KB字典受本机网络权限限制，失败记录保留在`dictionary_fetch.json`；官方网页已成功读取。不声称已下载完整本地字典或核过该本地文件MD5，也没有为此请求新数据访问权限。

## 双量测能做什么

[作者论文的数据说明](https://doi.org/10.1038/s41597-025-05524-5)区分外部电能质量分析仪G数据与充电桩C数据；[发布者记录](https://zenodo.org/records/14065331)说明本地merged包由这些原始记录合并。25份交流文件中，`P_kocos_200`与`Output_Power_ID4`均为kW，两者变化相关系数约.984—.999，说明确有不同来源的量测可用于核对。

但这不是每个短点都正确的证明：合并时间不等于两个仪表的物理采样同步，慢速刷新/保持值、损耗与量测边界仍需考虑。本次没有排序修复、插值、重新对时、拟合阈值或按效果挑选文件。25份中没有满足预先声明短往返条件的候选，不能把长保持指令下很快完成的一次阶跃，改称“短持续响应”。

KIT的功率字段由发布者标为[计算量](https://zenodo.org/records/17866847)，因此不能把“电流和功率同时变化”自动当成两个独立仪表都验证了真实动作。

## 同一100ms尺度的补充真值核验

真实100ms三类标签不足，已制作一个小型**受控信息核验集**，不是训练新算法或现场真实性能比较：

- 20秒窗口[-5,+15]，统一100ms观测，与既有局部记录尺度一致；1ms潜在波形积分成100ms均值，不从粗实测插值。
- 4个预设种子×6种形状（100ms、500ms、2s、5s脉冲、爬坡保持、慢漂移）=24个基础波形。
- 每个波形分别生成真实物理动作、主仪表故障、两仪表共因故障，共72个配对变体。各自保留干净物理轨迹、故障项、噪声和真时长。
- **同一对中的主电流、主功率、指令刻意完全相同，但物理真值不同。**这是不可辨识反例，不是估计的错误率。它说明仅凭这三列观测，即使采样为100ms，也不能保证给不同原因正确分类。
- 另提供一个**假设存在的独立仪表**。主仪表单独损坏时，第二仪表产生不同观察，说明独立证据可能有帮助；若两仪表遭同形共因干扰，两路仍可完全一样。此通道是模拟假设，不是暗中拿到的KIT新传感器，也不证明未来算法或实际设备具备这种独立性。
- 源文件`simulation/*.npz`、清单`simulation_samples.json`、配对关系`simulation_pairs.json`。真值列只供评价，不得在后续识别输入中使用。

这些仅是有明确生成假设的正功率单相受控波形，不是经过独立验证的充电桩高保真动力学模型，不代表30分钟全过程、真实异常分布或现场误检率。没有运行CPOP、LABS、分类器、滤波或任何新选参。

## 当前可以下的结论

1. 真实故障证据并非完全没有：已整理2次DC设备上报故障，但它们不能补交流100ms电流毛刺真值。
2. 真实交叉量测存在：Dortmund可用于原生约半秒尺度的核对，不应伪升采样成100ms独立观测。
3. 本轮尚未形成可供正式三类识别验收的真实短响应和传感器异常样本集。
4. 同100ms尺度的有真值模拟可以补信息条件与安全边界验证。要证明新算法有用，仍需在明确假设、未见数据、相同信息与判据下比较实际漏检/误检/时长；不能把这些构造反例或额外模拟通道本身叫算法收益。

本轮结论支持继续保全真实观测与按证据分层，**不支持恢复孤立点压制或自动填gap**。下一版具体方法仍未实施，原CPOP/LABS对照和原生产算法保持，第一部分之外与报告不动。

## 保全和核验

`verify.py`独立用Decimal复核两事件的状态段与原行，逐项核对真值模拟的同观测/异真值关系，29447项核过。检查项不是科学样本数。1546项原始来源、前轮对齐结果、正式算法、task/01等SHA不变，原v3清单773项不变。未删除、覆盖、修复原始观测，未改报告、默认、API或第二部分，未安装新库、上传或提交。
