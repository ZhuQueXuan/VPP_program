每次240/80/80用户训练/验证/测试完全分开；训练目标事件3—6（960行）、验证7—8（160行）、测试9—11（240行）。每事件一天，调用+600秒，观测至+3600秒；每次只用j−3至j−1的完整历史。测试第10/11次允许读取先前已完成的第9/10次曲线，属于冻结模型的逐次预测；不更新权重/编码器/缩放、不用后来标签选模。不是一次性同时预测全部未来，也不是零历史冷启动。

当前只给已知激励d/2.4、x、w；历史给当时条件和观测功率。不给本次功率、接受A、Y、用户ID、真实偏好/状态、场景标签或未来曲线。所有拒绝保留。Y直接从保存的float32请求功率转float64积分，固定1.5kW×1200秒分母、有符号不截断。

稳定场景用用户固定隐藏幅度/速度/偏好；无信息场景每事件独立重抽；变化场景第9次起三个隐藏特征反号。它们只是声明模拟反例，不是观测到真实用户行为翻转或真实因果结构。

## 四组实现及隔离

C0为当前3条件；C1另加过去条件均值3项，以及平均交付/最近交付/检出比例/条件起点均值/最长阈上时长均值/回补量均值6项，共12维。C2在C1上加早晚请求均值、早晚斜率、历史交付趋势及起点趋势6项，共18维。C3在C1上加6个线性PCA分量，共18维；输入为最近3条归一化全周期曲线的顺序拼接360维。

PCA只拟合训练目标行的历史曲线，固定randomized6/iterated_power3/seed18、不白化。各组均StandardScaler→二次PolynomialFeatures→Ridge(alpha10)，缩放与回归只拟合训练；没有用验证/测试调整正则、维数、特征或选择最好种子。完整历史必需，缺测拒绝、不补值。历史阈值检出不等于真实参加。

这是B1表示用途的下游预测小试，不是完整B2、B4自监督或深度网络实现。没有因本机未装torch就否定深度方法；先做安装库可完成的线性表示基线。后续若需较大训练，仍按服务器约定先准备具体任务/小检查，再申请连接。
