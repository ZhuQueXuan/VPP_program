# 方法复用与范围

复核开源仓库：[scikit-learn](https://github.com/scikit-learn/scikit-learn)（BSD-3-Clause）、[MAPIE](https://github.com/scikit-learn-contrib/MAPIE)（BSD-3-Clause）。两者有持续维护的仓库与文档。沿用现有scikit-learn1.7.2的HistGradientBoostingClassifier训练，导出原生数值树并重放核对，不安装或升级库。MAPIE提供预测集合/风险控制，不能补出现场短响应与同形故障的真值；本轮不额外引入或宣称其误报保证。

原版CPOP仍是原生R包原求解与参数；LABS仍是原作者MIT许可锁定版本。辅助分类与时长校正使用标准提升树，不作为新树算法或故障物理识别方法。

上一版duration_fusion的代码、模型与已完成试验保持原样。V1整任务分类在常规独立测试降低误检，但新增未知参考60秒短响应试验漏检31/64，对原/保留版1/64，故拒绝采用；最终拒绝见 `../b1_false_unknown_20261101/combined_adoption_decision.json`，不能只引用其主测试的adopt字段。

V2增加独立用户的未知参考60秒真动作/无动作配对训练，保留全部原量测。普通验证沿用已见V1数据作为开发，另有新短响应验证；最初不带保护和全短段保护的验证方案均未通过，原结果留存。最后选取15叶模型、分数阈值0.05，并对预测参照下原CPOP≤60秒且峰值≤0.45kW的短弱响应保留证据。分数阈值0.05不是5%误报率或校准概率。

未知参照预测复用既有冻结EV参考模型，只读取通知前窗口和历史。所有原版CPOP、LABS、保留版和新候选使用完全同一预测参照、实测与判据。未将真参照或当前响应量送入预测器；已知参照与未知参照分开报告。未知参照保持原生1分钟尺度，没有伪造10秒/100毫秒轨迹。

60秒短响应补测是明确声明的可控物理干预：同一自然充电轨迹与计量格上，真动作相对无动作在一个完整分钟减载0.45—1.5kW，噪声与测量故障配对；不是现场采集的执行真值。预测时不读取动作/故障标签或样本类型。模型只输出“任务内是否有阈上响应”的二分类，不把未达阈理解为设备从未动作。

不得隐去被拒绝任务：指标始终包含全部真响应、无响应、异常、短动作；同时评价误检、漏检和时长。原曲线与原始能量积分保留。本轮没有真实现场故障分类或5%可靠性认证，没有报告或第二部分改动。
