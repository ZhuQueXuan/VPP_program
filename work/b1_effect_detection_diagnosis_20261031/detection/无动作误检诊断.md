# 现用 EV 面板无动作误检诊断

本项全量核验只读取已见的 8 块面板，未重拟合过程或参考，也未修改源码、阈值、默认和正式报告；另一路固定子样本 oracle 探针见下。主要证据指向共同参考的持续偏高部分；过程之间的误检差异相对较小。不能把关联数字分摊成原因百分比。

当前“误检”指真无动作时，30 个任务分钟格中至少一格的拟合减载量达到 0.1q＝0.15 kW，即累计时长大于 0。它没有被标定成 5% 的事件检验，也不是 η＞0.1 或因果零效应检验。“零作用”场景仍有 927/2048 个实际响应；真无动作分母同时包括正作用场景的 657 条和零作用场景的 1121 条。

新 RIDE 与 CPOP 共同误检 246 条，并集 291 条，Jaccard＝0.845；三法共同误检 244 条。1778 是配对变体数，其中 657 条正零场景为完全相同的无动作轨迹，因此只有 1121 个不同任务 ID，且仍共享用户和种子块，不能当作独立试验数。

无动作时，原始残差严格满足 `raw = Bhat − P = (Bhat − Btrue) − meter_noise`。完整无动作面板的参考误差逐格 RMS 为 0.17219 kW，噪声 RMS 为 0.05014 kW。共同误检 246 条的任务平均参考偏差均值为 +0.21421 kW、中位数 +0.19748 kW；190 条任务的平均参考偏差已经达到 0.15 kW，三法全部误检。共同误检中 241/246 条仅参考偏差本身就至少有一格超过阈值。总体参考偏差均值为负（−0.05693 kW），因此这里的问题集中在正偏差尾部，不能笼统写成“所有参考都偏高”。

原始残差有 438 条无动作事件越阈，过程后新 RIDE 保留 261 条并增加 2 个变体，CPOP 保留 274 条且未增加。新 RIDE 增加的 2 个变体实际是同一任务的正零重复：原始最大 0.14026 kW，拟合最大 0.15974 kW，误检 60 s。共同误检 246 条的原始残差全部有至少 2 个连续阈上格，其中 193 条至少连续 5 格，原始阈上格中位数为 23/30。主要共同误检已有持续残差，不符合“主要由拟合把孤立噪点放大”的解释；这一核对仍没有量化两种因素各自的因果贡献。

模拟噪声为有界均匀分布，标准差 0.05 kW、绝对上界 0.08660 kW，小于 0.15 kW。在真参考且真无动作时，原始噪声本身不可能越过此阈值。此结论只针对原始阈上量。

另一路固定 512 变体 oracle 探针覆盖各块前 16 用户、目标事件 3/4、正零配对。其 244 条无动作中，新 RIDE 与 CPOP 均由 33 条误检降至真参考保留噪声时的 0 条。新 RIDE 正/零场景时长 MAE 从 116.25/130.078 s 降至 6.094/1.875 s，再去噪为 0.703/0 s。这与全量共同偏差证据一致，但仅是该固定子样本的诊断，不能称全量或现场保证。声明 headroom 规则保持，数字回补上限随输入参考改变，因此 oracle 比较也包含既有参考派生规则的变化，不能写成所有数值参数固定下的纯误差扣除。

共同误检组的任务前、任务中、任务后参考平均偏差分别为 +0.21875、+0.21421、+0.20962 kW，呈持续同向偏移。全体无动作样本中，任务中偏差与前窗、后窗偏差相关系数为 0.896、0.934。这里前窗是通知后的 [−15,0) 分钟，不可称为激励形成前已经全部可用的观测。真正事前输入是 [−75,−15) 分钟；这段历史均值相对当前观测的可观测偏移，与任务参考误差相关系数为 0.594，共同误检组均值 +0.21058 kW。它提示值得研究参考误差的识别与不确定性，但不构成本面板上选校正量的依据。

参考选择分组差异很大：新 RIDE 在选 GBDT 的无动作子集为 61/1257＝4.853%，选 prev10 为 202/521＝38.772%；对应平均参考偏差 −0.08693 与 +0.01544 kW。两组对象和选中条件不同，GBDT 的负偏差也可能压低真实响应，不能据此取消选择器或认定方法因果优劣。剂量分组新 RIDE 误检率为 16.47%、15.90%、11.68%，L/U 四组为 11.11%—16.95%；这些均为描述性结果。无动作样本的物理真曲线全部为零，潜在 shape 标签不是此时真实出现的形状，不能将其分组差异解释为形状错设造成的误检。

诊断优先级是先厘清共同参考水平偏移及其可识别程度，再分别评估持续弱响应与参考误差的区分，以及事件层面的可靠性标定。现有证据不支持立即提高阈值以降低此面板误检数，也不支持继续只修模板就能消除主要共同误检。任何后续优化均需用户决定后另定协议和新数据，保留弱响应漏检代价。

复核入口为同目录 `recompute.py`、全量逐事件 `event_join.csv`、分组 CSV、`summary.json` 与 `receipt.json`。独立 `verify_join.py` 对原 `process.json` 核对 36864 个数值并通过；129 个读取输入前后 SHA 一致，122 个与原科学清单相同，35 个中央源码冻结项相同。原始 η 逐事件差为 0，正零恢复 Bhat 差为 0，逐格观测恒等式最大差为 8.88×10⁻¹⁶。
