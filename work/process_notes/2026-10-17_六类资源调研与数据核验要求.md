# 六类资源调研与数据核验要求

日期：2026-10-17；本对话 `01a148f8-f7dc-7ab0-86a7-a118640b615f`。与[四层证据矩阵](2026-10-17_六类资源四层证据矩阵.md)配套使用。新增要求服务103任务一的因素与全周期特征及任务二的后续能力研究；当前仍为P1证据补强。原曲线、公式、参数、约束、baseline及冻结失败均保留。

## 1. 每次调研先固定一个可以核验的问题

问题应写为“对哪个对象，在何种信息与约束下，以什么观测核验什么输出”。例如：同一水箱的原放水文件是否同时提供可解释的用水、电能和物理时钟。找到字段后先裁决其含义与质量，之后才讨论模型。

| 证据层 | 可以提出的输出 | 最低依据 | 缺少依据时的处理 |
|---|---|---|---|
| 物理能力 | 给定状态下的功率、能量、持续与恢复；或更窄的电压/温度/同期功率组件 | 对象身份、量测边界、公式/参数/约束、适合该输出的独立参照 | 容量无参照时保留局部预测/描述，不用执行量冒充最大容量 |
| 指令执行 | 指令跟随、失败、时延区间、任务后恢复 | 指令含义、发送/接收/生效、量测窗口、模式、完整前后过程 | 只有共同发布行时限同期映射；只有功率突变时限观察变化 |
| 经济激励 | 实际报价对参加、开放或功率的条件作用 | 接收主体、合同传导、报价版本与可得时间、分配机制、可比较变化/共同原因 | 无真实价格时裁剪激励项；保留技术研究，不填默认模拟价格 |
| 选择授权 | 邀约后的接受、拒绝、退出、开放范围及手动覆盖 | 完整邀请母体、结果、事前需求、控制权、有效授权范围与版本 | 仅有参加者时只研究参加者；未记录拒绝保持未知 |

设备输出和主体选择分别定义。人的参加意愿、运营方经济选择、自动EMS策略、设备保护限功率分别登记；调查问卷只在研究人的偏好且有相应授权/设计时需要。

## 2. 信号—合同—决策—执行链

一个处理变量必须能回答“谁在何时知道什么，以及它改变了谁的决策”。市场出清价、用户报价、最终结算、电流设定和功率限制分别保存。

| 记录组 | 必查内容 | 会直接影响的研究判断 |
|---|---|---|
| 实际激励 | 原币种与单位、税费/固定费/分档、奖励或罚则、适用对象和窗口、价格版本、报价与结算差别 | 不能把是否收费、市场价格或事后返还直接作为用户事前报价 |
| 合同传导 | 合同/规则版本与有效期、签约主体、固定/浮动/封顶/分成方式、传导系数的来源、结算边界 | 没有依据时不估或不填传导比例；合同相同并不意味着逐时激励相同 |
| 分配机制 | 随机分组/邀请规则、调度排序、运营选择、时段规律、共同信号事件ID | 样本量按独立主体/事件说明；固定时段电价与时段需求可能混杂 |
| 控制策略 | 人工/温控/本地EMS/聚合EMS、策略版本、目标、优先级、保护/闭锁、手动覆盖 | 策略响应不能直接解释成人的风险偏好 |
| 使用需求 | EV到离站与目标电量版本；空调占用和舒适范围；水箱用水/供水要求；工业生产期限/质量；储能保底/备用；发电并网/运维约束 | 事后实现的离站或用水可以作结果，不自动是事前已知输入 |
| 授权 | 发出者、受权者、设备/方向/功率或电量/时窗、撤回/到期、未授权原因、是否允许自动调整 | 不能把设备接入、用户填需求或实验员切换开关自动当市场调节授权 |

经济激励研究先确定结果：邀请后的参加、已参加者开放量、授权后技术执行，或含这些路径的最终交付。研究总作用时，处理后的接受/授权/控制动作通常是中间路径，不随意放入共同原因控制表。研究参加者条件执行时则明确选择范围。

## 3. 六种时间和量测窗口必须分开

| 时点/窗口 | 建议登记名称 | 需核验的含义 |
|---|---|---|
| 公布 | `published_at`, `signal_version` | 哪一版价格/任务何时公开；修订前后分别保留 |
| 送达/可得 | `received_at`, `available_at` | 特定主体/控制器何时收到；只有平台发布协议时标记“协议推定” |
| 决策 | `decision_at`, `decision_actor` | 用户或EMS何时接受、修改需求、选定控制；不能用最终版本倒填历史 |
| 生效 | `effective_from`, `effective_to`, `actuation_at` | 合同/指令适用窗与实际动作；设定发布时间不等于执行时点 |
| 测量 | `measurement_start`, `measurement_end`, `timestamp` | 瞬时/均值/区间增量/累计量、标签在区间左/右端、时区和时钟误差 |
| 上传 | `uploaded_at`, `ingested_at` | 文件或平台何时能读到本条；原量测时刻不保证当时在线可得 |

这些是研究字段要求，不创建六类统一运行接口。源没有的字段填“未提供/待核”，不能制造默认时间。未来价格仅在 `available_at <= decision_at` 且版本可核时作为提前信号。状态应按研究起点取值；提前价格公布后的SOC/室温可能已受处理影响，不能一律称处理前状态。

时间只到分钟时不补秒；无日期时不跨午夜补日期；未核时区不加UTC；采样平均区间不明时不将每个标签直接换算电量。累计量与区间量的差分/求和选择必须引用字典并检查复位、负值、初末边界和缺测。

## 4. 最小可审阅资料包

不要求六类都有全部表。按当前问题保留所需原生记录，缺少的信息列在用途裁决中。

1. 对象与来源：发布者、DOI/版本、URL、许可、取得日期、文件名/大小/哈希、设备/测点/主体对应；不同来源使用不同实体ID。
2. 机理卡：曲线和公式、变量单位/方向、参数来源与识别范围、约束、近似、原baseline及失败入口。
3. 字段时点卡：原字段、原定义、原单位、测量/估算/设定属性、时间含义、可得时点、缺测码；推断与字典明示分开。
4. 事件/选择卡：实体、主体、邀约/会话/任务、信号版本、需求版本、前—中—后窗口、被邀请但未参加/控制失败/退出；没有完整母体时明确条件样本。
5. 裁决与收据：网页发现、文件取得、身份通过、字段/质量通过、某输出准入、实际运行、算术复核、真实有效性分别记录。通过一项不自动带过下一项。

## 6. 准入与检验顺序

先裁决来源、身份、字段和时点，再建立样本。任何新模型实验均需在运行前冻结：对象/结果、参照来源、输入截点、独立主体/事件/完整未来时段划分、旧留出已见状态、透明对照、主要模型与参数、指标/分母/单位、失败处理及复现容差。源审查与描述不冒称新模型实验。

评价同时覆盖总体、对象/类型、状态、处理强度/零作用、拒绝或失败、域外、最差及结束后恢复。空组保持空，失败与未知不能合并为0。连续片段先按完整事件/主体划分再切窗；测试侧不能用于选阈值、平滑、挑状态路由或删瞬态补分。若只有两次不同日期实验，不能按几百测量行计算几百次独立干预，也不能直接把二者差值称处理效应。

物理/控制数据可先形成限定组件；经济激励和人的意愿仍按相应证据准入。DML为可选工具，同特征OLS与负控保留；D069零效应失败不因新文献或新字段存在而改写。
