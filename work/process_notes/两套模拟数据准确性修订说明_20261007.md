# 两套模拟数据准确性修订说明

日期：2026-10-07。本轮实际修改了两套模拟数据的生成规则，并重新生成数据与受影响标签。数据仍按评分、解耦分别使用，原两个数据目录名保留。

## 已完成的修正

| 数据内容 | 修正前 | 当前 |
| --- | --- | --- |
| 评分数据的功率、电量或指令时序不一致 | 涉及22个任务 | 本轮核验为0 |
| 某储能案例的最终电量 | 达到96.4%，自身上限90% | 充到90.0%后停止 |
| 量测调节峰值超出仿真能力上限 | 涉及304个任务 | 本轮核验为0 |
| 解耦数据无授权仍标为接受 | 59个任务 | 区分意愿、授权和执行，矛盾为0 |
| 有效调节窗口之后仍有EV响应 | 评分3例、解耦11例 | 本轮核验为0 |
| 缺测点对应标签的依据 | 仅有标签，不能从现有观测完整重算 | 新增明确隔离的模拟真值，可重算全部标签 |

修正不仅改了表中的数值，也修改了生成程序。之后重新生成时，仍执行这些约束；验证脚本也已加入相应检查。评分931个任务的交付电量及18个成败标签改变；解耦15个交付电量及63个接受标签改变。变化表示依据修正后的模拟机制重算，不表示模型准确率提高。

## 数据放在哪里

- 评分：`data/资源市场适配评分模拟数据集_v1/`，内部修订版本1.1，仍为96个实体、1,728个任务。
- 解耦：`data/驱动因素解耦模拟数据集_v2/`，内部修订版本2.1，仍为96个实体、3,456次实验。
- 两套修正前的完整副本分别保存于各方法 `work/data_accuracy_revision_20261007/before/`，没有删除。

评分的实体、状态、任务、全部事前输入与样本划分保持原样；解耦的实验条件保持原样，已有授权不再被误写成行为接受，历史按修正后的事实更新。没有修改评分或解耦预测算法。

## 已验证的程度

两套数据的结构、逐区间功率与储能电量、响应时间、标签电量重算和固定种子复现均已检查通过。共完成2,174项逐案例数值/语义核对；它们不是2,174个独立现实实验，也不能折算为拟真百分比。

这轮提高的是**模拟数据内部的正确性和可核验性**。响应速度、持续时间、用户行为和扰动分布多数仍是假设，未新增实测资料校准。因此尚不能说数据已达到某个真实准确率。

接下来完善数据本身，需要把这些假设参数逐项与同类实测记录比较，再修正采样范围和条件关系；泵的具体启停及完整恢复曲线仍未完成。这些都是数据生成内容，不是算法性能或项目路线调整。
