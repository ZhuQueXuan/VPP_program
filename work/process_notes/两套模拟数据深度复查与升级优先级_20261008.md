# 课题一两套模拟数据深度复查与升级优先级

本报告描述优化前历史版本1.2/2.2；现用数据已更新为1.3/2.3，已落实的修正及仍有缺口见 [本轮优化说明](两套模拟数据过程一致性优化说明_20261008.md)。


2026-10-08。检查对象：评分1.2、驱动因素解耦2.2。此次没有重新生成、替换或删除两套数据；逐文件核对了当前文件与上次发布指纹，并重新运行现有校验，再增加过程一致性和公开证据覆盖检查。

## 结论

没有达到最完善的程度。当前两套数据适合继续进行接口联调、已声明设备边界检查和已知模拟机制下的流程实验；还不能称为完整、充分拟真的资源运行数据集。

上轮“核验通过”只覆盖已实现的检查：主键关联、档案功率上限、方向、指令接收时序、储能SOC、电量积分、授权含义、标签一致性及部分公开字段的分布。此次增加检查后，发现光伏的来源曲线与上网功率关系、充电全周期电量、热负荷时间片覆盖等仍需修正。基础检查通过与这些新发现不矛盾，但不能把前者扩大解释为全套数据已经拟真合格。

## 新增检查发现

下表每行是一个不同检查，样本可能重叠，不能把各行数量相加作为“不合格总数”。“条件核验”用于检查明确的模拟假设，不是在判断国外真实客户发生了这些问题。

分母为相应资源的全部构造案例，包括可能不适用或不执行的市场任务。热负荷覆盖检查针对设定的任务时窗；没有宣称不适用案例也产生了执行量测。EV的最早离开时间在现版只被用作保守调节窗口；目标交付检查是在“把它同时作为目标交付期限”的条件下进行，提示应补齐目标交付时间及车辆进出记录，不等于该时刻必然实际离站。

| 检查项 | 评分1.2 | 解耦2.2 | 判断与影响 |
| --- | ---: | ---: | --- |
| 公开光伏15分钟时段内的位置没有计入后续曲线偏移 | 108/108个光伏任务 | 216/216个光伏任务 | 生成器只加“任务开始减观察时间”，遗漏观察时刻距该来源15分钟时段起点的分钟数。是代码时间映射缺口；应统一原始区间含义后修正，不能把15分钟均值当作秒级实测 |
| 上网功率超过生成器自身引用的可用光伏曲线 | 15/108个光伏任务 | 79/216个光伏任务 | 已有校验只比较设备额定功率。基线固定，而公开发电形态会变化，因此“基线＋调节量”与所引用的可用功率不一致。这属于模拟内部关系问题，需动态基线和联合功率约束 |
| 90%目标电量即使从观察时刻满功率充电也赶不上设定期限 | 24/108个充电任务 | 50/216个充电任务 | 按模拟容量、90%目标、设定期限及100%能量转换的乐观上界判断。说明统一90%目标和历史停留时间不能独立拼接成保证可行的计划；真实来源未声明所有用户都有90%目标 |
| 任务开始时调节窗口已经关闭 | 22/108个充电任务 | 14/216个充电任务 | 可以作为不可执行邀约或陈旧信息压力案例保留，但应单独标明。不能混进正常可执行案例后宣称代表自然运营比例 |
| 全任务充电电量与固定等效车辆容量不一致 | 18/108个充电任务 | 149/216个充电任务 | 条件：不引入未记录的新车辆，按85%充电效率积分整个执行期净充电功率，会推得SOC超过100%。此处不是发布数据中实测SOC越界，而是缺少完整车辆进出/电量演化账造成的条件不一致 |
| 上述容量问题在调节窗口结束之前仍出现 | 2/108个充电任务 | 35/216个充电任务 | 限制积分到调节期限后仍触发，表明不能仅靠到期停止调节修复电量闭合。还应核查公开估计容量、功率和SOC的用途与误差 |
| 引用的热负荷公开片段在任务结束前耗尽 | 381/432个有公开代理的任务 | 864/864个有公开代理的任务 | 当前片段耗尽后保持最后值。这个延伸是假设；不能把延伸段称为公开实测支持的运行变化 |
| 热负荷公开片段在任务开始前就已耗尽 | 206/432个有公开代理的任务 | 221/864个有公开代理的任务 | 部分任务整个执行期引用的是片段最后状态，进一步削弱了时间变化的拟真依据 |

### 一个具体的充电计划例子

评分任务 `SYN-ENT-01-ev_charging_station-01-2`：在模拟观察时刻，距离设定期限剩11分钟，距离90%目标还需要0.413116MWh。即使从这一刻开始使用设备全部额定功率，最多也只能补0.221375MWh，尚未扣充电损耗。因此不能把它作为“正常且可完成目标的充电计划”。可以保留为显式不可行案例，或在正常数据中重新联合生成目标、停留时间、容量和功率。

同一例子不用于判断原始EPFL用户充电失败。90%目标由本项目模拟生成器指定，公开容量字段也只是近似估计。来源明确区分了车辆请求、站端设定、实际功率和近似容量。[EPFL官方说明](https://github.com/DESL-EPFL/Level-3-EV-charging-dataset)

## 公开字段更接近，仍有哪些核验缺口

### 光伏预测下界还没有充分校准

本次对公开留出的285个日期、25,080条有效记录重新检查了“P10下界被实际下一小时发电量覆盖”的比例。结果如下；这是预测下界覆盖率，不是评分模型准确率或项目90%验收精度。

| 公开留出子集 | 行数 | 实际下一小时发电不低于生成下界的比例 |
| --- | ---: | ---: |
| 全部有效记录 | 25,080 | 88.78% |
| 预测发电大于额定功率5%的时段 | 11,046 | 84.17% |
| 来源钟点9:00至15:59 | 7,980 | 86.47% |

全部记录中51.34%的下界为零，夜间/弱光容易满足零下界，不能用全时段比例掩盖有发电时的偏差。不能把“训练残差的10%分位”直接解释为已经保证实际业务中90%覆盖的预测。下一轮应分场景校准下界、按日期留出新核验批次，并展示有发电时的覆盖率及区间宽度。

来源本身是归一化、原生15分钟记录的一条光伏曲线；其预测与已发生区间含义不同，多个工业站的PV来自该曲线缩放。当前仍未核验来源时区与山东日照钟点迁移，更不能据此验证秒级调节。[EMSx官方说明](https://zenodo.org/records/5510400)

### 多变量关系和不同设备覆盖还不充分

上轮主要展示单字段分布距离变小。此次按完整充电会话进行了200次重抽样，保留会话内相关性，检查公开参考中SOC、实际功率、请求功率关系的变化范围。

公开留出中SOC与实际功率的等级相关约为-0.310；评分模拟约-0.145，解耦约-0.344。评分分布虽然变近，这个关系仍有明显差别。公开参考重抽样范围不是较小模拟样本的正式通过阈值，本次没有据此宣布统计不合格。下一轮应增加联合变量、分SOC条件和同一会话时间变化的检查，不能只比中位数和直方图。

当前16类参数来源分为：3类有充电/光伏/储能组件的实测迁移参考，4类有住宅实验向目标资源迁移的代理，9类仍主要是假设。实测迁移也不是整个资源类型已全面校准。家庭冷凝器、冰箱、烘干机的一段实验无法证明工业冷水机、冷库、热泵烘干机的温度边界与调节能力；公开实验本身时间较短。[NLR设备实验说明](https://data.nlr.gov/submissions/48)

### 连续性、极端状态与共同因素缺少覆盖

- 两套数据仍按任务独立抽取状态，缺少同设备多天连续的温度、库存、车辆和SOC过程。解耦储能210次相邻任务转换的SOC差值绝对值中位数为4.875个百分点、最大17个百分点；任务之间相隔多天，所以不能称为物理跳跃违规，但数据没有提供中间运行记录来解释变化。
- 校准后评分储能起始SOC为62.25%至80%，解耦为62.5%至80%。没有接近各自声明上下限5个百分点内的起始样本。单次实测阶梯试验让局部统计更像参考，却不等于覆盖了真实运行人口，也削弱了低电量/近满电压力覆盖。
- 非变频泵仍使用连续功率近似，生产机械工序和算力任务也缺少匹配实测执行链。这些数据不能仅靠增加随机波动变得合理。
- 同一气温、日历、天气或生产班次应同时作用于相关资源，当前没有经核验的共同驱动过程。多车/多站的叠加也没有独立验证。
- 解耦路线14类资源仍共用一套假设意愿公式，储能/光伏零价格作用则是实验对照。它适合检查能否恢复设定机制，不能证明真实工业资源受哪些因素影响。平衡随机实验应保留，并另设较自然的运营场景，不能把实验比例冒充市场自然频率。

## 升级顺序与数据验收方式

| 优先级 | 要改进的数据内容 | 完成后应怎样核验 |
| --- | --- | --- |
| 第一批 | 光伏原生区间和时间偏移、动态基线、实际可用发电/上网功率/调节量的一致关系 | 每个区间同时核对额定上限与天气可用功率；功率与电量闭合；源时间区间一致；有发电时单独核对预测覆盖 |
| 第一批 | 车辆到达/离开、SOC、容量、充电功率、目标、剩余时间、调节后的补充充电 | 车辆逐区间电量账；有界SOC；可行目标能按约定交付；不可行目标/陈旧信息单独标记；整站功率等于在站车辆功率和 |
| 第二批 | 热负荷更长的公开片段/可解释动态模型、温度与恢复、泵的离散启停 | 原生样本覆盖整个引用窗口；模型延伸明确标记；温度/库存/液位约束与功率共同变化；验证最短启停时间和恢复能量 |
| 第二批 | 同一资源跨任务的连续运行状态、日历与共同天气/班次 | 上一次末状态与下一次初状态由中间运行解释；相关资源在同一时间受共同因素影响；区分各类真实参考与假设 |
| 第三批 | 正常运营与不可行/故障压力样本分开，并补低SOC、近满电、夜间、季节和长任务 | 明确每类用途、数量和抽样依据；不会为了贴近一条参考分布而丢掉必要的边界覆盖 |
| 持续核验 | 联合变量、时间变化、极端值、来源外设备/日期与参数不确定性 | 按会话、日期或设备成组留出；展示来源间差异；已用于诊断和调参的数据不再冒充新的最终独立核验 |

以上升级均针对模拟数据内容、构造规律和核验，不是修改评分或因素预测模型的优化方案。部分内部关系可以用现有资料修复；没有工业实测的参数，应给范围/情景及证据状态，不能为了“像真实”补一个无法核实的精确值。
