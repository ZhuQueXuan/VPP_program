# 单类资源验收边界与储能论文复现

日期：2026-10-15。用户要求直接分析、过程记录照常保存；现有教师汇报已完善，本轮不修改汇报、不新建outputs交付文档、不更新handoff。

## 1. 问题与依据

用户要求回到研发，明确一种资源研究做到什么程度可结束，避免储能单类无限延伸；后续还拟研究约三四类。另要求寻找有论文、数据和实现依据的较快复现路径，覆盖特性与后续预测。最新继续研发授权替代D039当时的实验停止安排；D039科学裁决和失败证据保持。

核对103下达稿（现有抽取文本物理页5—6）、需求框架及技术方案。103规定课题一容量/响应特征模型精度不小于90%及论文、专利、报告等正式成果，没有规定每一资源的P1必须先解决完整SOC、真实时延、意愿和所有容量问题。资源不少于16类是课题四示范范围，不直接改成课题一每类相同深度门槛。技术方案§1.7、§6.3已允许缺容量参照时先验证响应组件。执行路线P1表却把“最大容量参照”写成所有闭环的条件，应修正为“与声明输出相符的参照”；容量声明仍须容量边界参照，不降低其证据要求。

## 2. 本轮采用的单类资源基础包完成标准

这是一轮基础研究的管理与证据标准，不替代103正式验收，也不代表此类资源所有问题研究终结。

| 检查 | 可审阅的完成证据 |
|---|---|
| 问题与范围 | 具体对象、输入、输出、时域和应用条件固定；每个缺口归为本轮必需、后续专项或不适用 |
| 特性与模型 | 典型资源曲线、主物理关系、参数来源、方向和运行约束有依据；实际观测、估计与假设分开 |
| 数据与参照 | 实际读取文件、字段、时间、质量、许可和版本；参照适合声明输出，缺失/不可用有明确状态 |
| 实际组件 | 至少一个可验证且有正向证据的简单组件；能说明有效条件与输出范围，不能只以排除候选充当资源模型 |
| 对照与边界 | 同信息/同样本对照、事先固定划分与指标；误差、覆盖、最差情况和失败都保留，未胜过对照不继续无界调参 |
| 复现与接续 | 固定数据/代码/配置可重跑，重要量可复算；后续接口仅传有证据结果，尚缺SOC/容量等不能自动补齐 |

运行闭环、组件有效、单类基础包、全课题正式验收分开。复杂模型不必胜过简单模型才能结束合格baseline；但失败的容量估计不能写成容量功能通过。绝对误差门槛应由输出用途、量测精度和承诺风险确定，不能从103的90%直接推成任意连续变量MAPE≤10%，也不能将1−MAPE直接命名正式精度。

本轮主动试验只保留一个：固定公开参数的2RC电压轨迹受限比较。一次准入、一次冻结评价；仅为复现做必要复跑，不据评价误差改参数/初值/窗口/对齐。若缺必要数据、越域或效果不成立，以相应用途不通过收口，不默认再找第三种复杂方法。这个工作量限制是本轮实施选择，不是任务书规定。

## 4. 论文与实现选择

文献专项核查见[候选核查](2026-10-15_储能论文代码复现路线候选核查.md)。主要来源：

1. [Figgener等2024](https://doi.org/10.1038/s41560-024-01620-9)：现场储能容量研究依据，与现有家庭系统最贴近；现读公开包16个MATLAB主要是加载/图/统计，不声称完整容量识别代码已公开取得。
2. [Blyth等2026](https://doi.org/10.1016/j.mex.2026.103865)，[作者仓库](https://github.com/MarkBlyth/parameterisation_methodsx)：原始脉冲和WLTP试验、参数、OCV与真实模型公开，优先做小规模条件电压模型。不是未知SOC观测器、未知未来负荷预测或容量识别。
3. [Braun等2022代码数据](https://zenodo.org/records/6985321)：确有SOC/SOH实现，作者声明CC BY-NC与专利，参照也有限定，暂作备选。
4. [Knox等2024](https://www.nature.com/articles/s41598-024-61596-0)：状态估计方法参考，代码数据需向作者请求，不作为当前快速执行入口。

## 6. 冻结试验

[协议](../resource_sample_selection_20261013/blyth_voltage_protocol_v1.json)在模型误差计算前保存，SHA256 `a7406f173cd0539f8f0875526c899c303427e72722445eadae7c34573837646f`。采用论文验证的SOC初值1、2.132Ah、25℃、原整窗；不混用demo的.99与截尾100秒。

电流输入按原始有重复时间序列调用np.interp；不能先去重而声称插值不变。评价在每整数秒，电压取该秒最后一条原始记录，明确不同于论文在自适应求解点上评价的口径。没有原始亚秒时刻，不造亚秒精度。2RC为作者代码；R0-only共享SOC/OCV/Q/I和欧姆项，仅去掉极化动态。实测电压不作输入，不重拟合参数。给定初值的SOC递推不作独立SOC准确率。

主指标MAE/RMSE（mV），另报bias、95分位、最差误差/时刻及有效覆盖。完整有限覆盖且两主指标优于R0，才支持本试验中极化动态有增益；绝对业务误差门槛尚未确立，不据此判现场可部署或90%通过。越域、求解失败或不足整窗原样保留，不裁剪/外推。一次评价后收口，不按分数调参。

执行结果及复算状态以本节后续补记、机器收据和EXPERIMENT_LOG为准；协议里的not_executed是冻结时快照，不回写成已运行。

## 8. 基础包验收裁决与下一项入口

六项基础包检查按当前声明范围完成：

1. 对象/输出：锂离子储能基础特性、稳态AC/DC转换、受限日志AC预测、给定电流的实验室电压轨迹；三来源分别成立，未拼成同一设备模型。
2. 曲线/物理/参数/约束：现用研究样板已有来源、典型曲线、功率/能量状态关系和参数边界，本轮补作者等效电路与初值/参数域。未知SOC/真实边界不补造。
3. 数据/参照：既有组件的原始来源与划分收据保持，新增原始电压试验实际读出并按用途限定准入；样本数、事件数与同一试验时间点明确区分。
4. 正向组件：已有M5BAT转换组件独立试验比较为正向证据；新增2RC参考试验有平均增益。容量失败不是通过证据，不把几个受限组件合称完整容量模型。
5. 比较/边界：既有独立试验/时间划分与本次明确参考再现分别记录；覆盖、最差和容量失败均保留，无为了达标删除尾部。
6. 复现/接续：既有收据及本次同版本复跑/独立指标核验完整，后续仅调用相应有效条件下的组件，未知能力输出不可用而不补零或冒充容量。
