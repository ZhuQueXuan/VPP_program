# 课题一·两套模拟数据过程一致性优化说明

本报告为历史1.3/2.3。当前已升级1.4/2.4，工业机制、连续状态、车辆聚合等进展见 [最新说明](两套模拟数据机制与连续运行优化说明_20261008.md)。


日期：2026-10-08。评分数据由1.2升级为1.3，驱动因素解耦数据由2.2升级为2.3；两套目录仍独立，16类、96实体和1,728/3,456任务规模保持。升级对象是模拟数据及其生成、核验程序，预测模型未优化。

## 本轮实际改变

| 项目 | 之前的问题 | 已落实的变化 |
| --- | --- | --- |
| 光伏时间 | 15分钟原生相位遗漏；过去时段均值被当作当时点值 | 补相位；明确actual(t)对应前15分钟，未来物理过程从下一原生区间起；较短输出按交叠时长加权 |
| 光伏功率 | 基线固定后，在可发功率下降时净上网可能超过可发功率 | 基线随可发功率变化，并同时限制基线、调节和实际净上网 |
| 充电全过程 | 只限制调节，不更新基线充电后的SOC；充满/离站后可能继续记电量 | 所有实际充电计入SOC；记录观测至任务、执行、恢复/后续充电和计划离站；达到目标或离站即停止 |
| 充电计划 | 任意90%目标与容量、停留时间可能不相容 | 正常目标由同一公开训练会话的状态与电量预算联合构造；部分90%请求保留为明确的压力目标，不伪装成正常计划 |
| 充电恢复 | 调节后目标是否兑现不可核查 | 任务后用当前剩余电量/剩余时间安排补充充电，受当时充电接受上限约束；目标缺口与评价时间单列，不承诺全部成功 |
| 热负荷长任务 | 短实测片段结束后长期保持最后一个数值 | 训练片段之后用运行/停机时长及同状态功率抽样构造6小时延伸；保留实测前缀长度并逐时段标记模拟延伸 |
| 储能压力覆盖 | 实测SOC集中在约62%～80%，缺少接近边界状态 | 正常SOC仍参考实测，另以20%设计概率抽取上下界附近压力状态，标明来源是假设覆盖 |

没有将互不关联的公开来源拼成真实甲方事件。充电表示一个缩放后的固定等效车群；并未实现多辆车的独立到离站聚合，也不暗中插入新车维持基线。

评分光伏共有108个任务记录，其中18个市场不适用，没有执行轨迹；上表90个是实际可进行轨迹检查的案例。不能把正常计划当成调节后必定完成的保证：目标未完成表可用于检验后续方法是否保护用户的用电需求。任务履约标签只评价该任务，充电目标结果是更晚的独立评价，不混作一张事前输入表。

核验程序独立于物理生成器，重新按公开原生区间及能量方程计算；同时检查完整缺测真值、实际服务与标签、解耦激励反事实一致及零作用对照。额外核对跨15分钟边界、接近充满和跨离站边界的手算案例。公开光伏延伸全部在原训练日期内，EV仅补同一训练会话的全部分钟，不读取留出会话拟合。

## 来源与拟真的具体边界

- [EMSx官方发布页](https://zenodo.org/records/5510400)明确区分过去15分钟实际值和未来15分钟预测；独立归一化PV文件是多个场景共享的一个历史曲线。现在的秒级字段来自原生均值分配，不是新增秒级实测；地域和时区迁移依然是假设。P10仍是训练误差构造，既有留出诊断未达到可宣称的统一90%覆盖，本轮没有以该指标调参。
- [EPFL官方数据仓库](https://github.com/DESL-EPFL/Level-3-EV-charging-dataset)提供功率、需求、SOC、会话及近似容量。模拟效率0.9、正常目标的90%预算留量和压力请求比例是设计参数；计划离站不是甲方真实离站。公开数据不会替我们证明这些场景在山东的真实频率。
- [NLR住宅实验来源](https://data.nlr.gov/submissions/48)只有约5.4小时住宅实验记录，不能证明工业冷水机组、冷库和烘干设备的长期过程。训练片段的运行时长受分块截断，延伸后的时长和功率分布是模型结果，不能当作工业热惯性或工艺验证。
- 储能的边界压力来自主动覆盖设计，充放电效率、健康度等仍有假设；不同任务之间的SOC仍是独立快照，不能把它们当作一条连续运营日志。

既有公开留出样本此前已被用于诊断，不能称为本轮全新盲测。本轮证明的是新的过程关系闭合、训练来源隔离和可复现性，未证明16类资源全面达到真实分布，更不代表正式模型90%精度。

## 当前明确保留的缺口

1. 冷水机组仍只有住宅冷凝机迁移代理。新的动态基线下，评分90个适用任务暂时全部失败；其余15类仍有成功与失败样本。验证改为如实报告类别覆盖，不强制凑成功标签。这一类型目前不适合单独训练成败分类器，需要更贴近工业连续过程的长曲线。
2. 固定转速泵仍缺少离散启停/流量过程，生产资源仍有连续响应代理，算力资源缺少真实队列和SLA轨迹。这些类型的工业响应尚未被公开实测全面校准。
3. 解耦的价格意愿系数、长期状态衔接、共同天气/生产冲击和整个资源组合的同时运行关系仍是假设或未实现。即时价格反事实只针对任务交付，不对车辆目标兑现或长期政策作用给出已验证的因果结论。

接下来提高数据拟真度最有价值的工作，是补工业热过程的长时段参考、离散设备过程和跨任务状态关系；这些仍是数据的改进方向。
