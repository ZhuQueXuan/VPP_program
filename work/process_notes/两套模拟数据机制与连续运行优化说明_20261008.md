# 课题一·两套模拟数据机制与连续运行优化说明

日期：2026-10-08。评分数据 **1.3→1.4**，解耦数据 **2.3→2.4**；目录仍各自独立。修改对象是模拟数据和生成/核验程序，预测算法没有优化。现在可用作流程开发、机制检验和压力测试的数据基线；尚不能称为与山东真实数据充分一致的最终数据。

## 本次实际改善

| 数据问题 | 已落实到数据中的变化 |
| --- | --- |
| 工业负荷原先主要按能力限值缩放 | 热负荷温度、泵液位、生产库存和算力待处理工作有逐时段收支，实际功率会改变后续调节余量 |
| 固定转速设备曾出现连续小幅调节 | 固定泵和生产机组按整数台数启停；加入最短运行/停机时间；变频泵低负荷时允许正常停泵与重启 |
| 调节后的状态被立即当作新基线 | 实际设备和“没有参加任务”的设备独立演化；恢复和反向影响相对同一未控制对照记录 |
| 标签忽略真实跟踪和反向影响 | 评分跟踪误差从完整功率轨迹重算；交付电量按请求方向计净值，反向响应扣减；保留失败原因 |
| 各任务快照之间没有连续关系 | 保留原条件实验，另增独立四天运行场景，96实体状态跨任务、跨天持续，天气和生产工况在聚合内共用 |
| 充电群没有可核查车辆进出 | 连续场景逐车记录到站/计划离站、SOC、目标、电量；两接口共享站点容量，实际和未控制车群分别更新SOC |
| 数据过于整齐 | 独立量测流加入明确假设的持续误差、资产偏差、量化、迟报和成段缺测；保留完整物理真值用于复算 |
| 随机价格实验不能反映观察混杂 | 连续补充价格随事前状态与生产负荷变化，保存模拟分配概率；原解耦随机全因子主实验继续保留 |

## 改进—复查—修正的结果

设备机制第一轮复查发现“状态条件基线漏记停止后的影响”，已换为独立对照；跨天复查发现变频泵低需求下液位累积越界，已改为受约束的启停；车辆聚合复查将五分钟平均分配改为分钟级积分，避免遗漏同时充电的共享容量问题。最终查看连续曲线又发现部分设备任务结束后未按自身状态恢复，已改为实际设备自己的反馈策略，未控制对照仅用于对账，并加入手算的恢复收敛检查。新增核验独立从导出记录复算，不调用评分模型，也不直接复用生成器的状态更新函数。

## 公开依据支持到了哪一层

[EPFL原站点说明](https://github.com/DESL-EPFL/Level-3-EV-charging-dataset)给出172.5kW、同时服务两辆车及余量再分配机制；本轮使用其训练会话的功率/SOC/容量/停留形态与共享结构。合成车流到站率、目标与效率不是原站实测分布。连续补充逐车建模，原主实验等效车群用途保持。

[LBNL公开冷水机模型](https://simulationresearch.lbl.gov/modelica/releases/v12.1.0/help/Buildings_Fluid_Chillers.html)用于理解能量、温度及部分负荷联系；本次只实现电当量缓冲简化模型，没有使用公开机组性能参数识别本项目设备。[DOE变频泵指南](https://www1.eere.energy.gov/buildings/publications/pdfs/building_america/measure_guide_pool_pump.pdf)用于立方相似律结构参考；工业系统曲线和效率尚未识别。生产库存模型为明确假设；[Google集群资料](https://github.com/google/cluster-data)仅支持任务/队列结构的理解，未读取其原始轨迹做数字校准。

光伏继续使用EMSx公开训练日期的原生曲线和已知预测语义，连续场景使用完整四天训练片段。储能SOC/残差参考仍来自单设备阶梯试验。此前的公开留出数据已经多次用于核验，不能再称为从未看过的盲测。住宅NLR实验仍保留作历史辅助，当前工业温度变化由显式过程机制生成，不能再写成住宅曲线证明了工业温度拟真。

**本轮更强的是数据内部的因果过程和工程一致性；没有因此获得新的真实工业或价格行为证据。** 外国数据尺度、行业迁移、跨来源共同天气、生产需求、经济系数和量测误差都有假设标注。评分四个离散工业类别仍缺成功标签；炉窑的升温启动、产品质量曲线、工业泵扬程和真实计算SLA仍未识别。用这套数据检验程序和假设是合适的，用它证明真实项目规律、市场收益或90%精度是不合适的。

评分主实验继续读 `data/资源市场适配评分模拟数据集_v1/model_inputs.jsonl`；解耦主实验继续读自己目录的 `01_predecision_inputs.csv`。研究连续状态、车辆聚合或观察混杂时，再用该目录 `continuous_predecision_inputs.csv` 及对应标签，按 `scenario_id` 隔离。做量测特征时必须遵守接收时间，未来区间平均值、独立对照、潜在结果和评价专用来源信息不能提前进入特征。

两套连续场景各自生成、各自引用本地实体和校准文件；共同脚本只承担数据工程。两套数据均附新的README、证据表、场景说明和核验收据。旧 **1.3/2.3全包及程序**分别保留在两个方法的 `work/mechanistic_dataset_revision_20261008/before/`；更早备份也保留，本次没有删除文件。当前阶段停在规定工程核验、来源隔离和可复现检查通过的版本；进一步提高真实拟合程度需要匹配行业的新增独立实测证据，不能通过反复调同一批模拟数值来证明。
