主交点是“相对零激励提高10个百分点净交付”的首个相邻剂量区间，另报5个百分点；这是预定结果界限的交点，不是价格建议、连续精确根、置信区间或机制硬阈值。敏感性为相邻档位平均结果的有限差分除激励步长，不叫价格弹性。

- 平滑机制总体主区间为[.8,1.2]：M0正确19/20，M1为0/20，M2为18/20；M1虽每次都给区间，区间均不对。
- 分段机制总体主区间为[1.6,2.0]：M0/M2各2/20正确、18/20按事前规则返回非单调歧义，不能用2/2报100%。真实前段平台的观测噪声触发严格单调闸门，并不说明真实响应非单调。
- 线性机制总体主区间[2,2.4]、末端真增量.11154接近.10：M1正确14/20，3/20估计未达到；低余量组真最大增量.09295，在支持内未达到，高组则主区间[1.6,2.0]。

## 实验身份与复算

7档激励0/.4/.8/1.2/1.6/2/2.4元每kWh，全部为声明模拟水平；600用户×14事件，用户360/120/120训练/验证/测试；20种子×4机制共672000事实场景变体，对应168000基础事件/12000次用户抽样。无用户内配额，剂量独立随机；机制变体共享外生条件且不跨用户划分。A为观测接受记录单独建模，Y始终由带噪公共请求功率积分，保留拒绝及有符号结果，不用A作Y的调整量。

M0组/档位均值，M1[1,d]OLS，M2[1,d,(d−.8)+,(d−1.6)+]OLS；M2结点不是生成机制1.2处拐点。三方法同一训练信息，无后验调参、概率裁剪、单调修补或测试重拟合。验证/测试事实预测MSE另列losses.json，与总体作用曲线误差不同。预测保存后评价器才积分隐藏U/V及过程噪声；32/64点真值差2.22e−16。

主入口：`python work/b1_multidose_20261026/run.py micro`，已完成generate→fit→evaluate；现存原件/预测后主脚本拒绝覆盖。独立复核用`python work/b1_multidose_20261026/verify.py`。models.py提供fit/predict/crossing；只在声明支持内输出，M0只接受已观察档位。models.joblib保留240组模型包并核重载一致。

证据：metrics.csv（1440行）、crossings.csv（1440行）、evaluation.json、losses.json、fit_diagnostics.json、generation_receipt.json、fit_receipt.json、source_freeze.json。30项微型检查通过；独立29914项全过，正规方程重算OLS预测差4.76e−14，84公共曲线积分差1.11e−16；详见independent_verification.json。生成约1.35s、拟合约2.64s为本机实测，仅CPU。主观察保存请求窗而非全部后窗，高频全周期恢复本轮仅解析条件检查，不能冒称重新验证全部恢复轨迹。
