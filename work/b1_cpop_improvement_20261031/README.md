# CPOP第一版改进：已比较，暂不采用

2026-10-31。用户授权针对第一部分特征提取开发CPOP改进版，并与原版CPOP、LABS同条件比较；另由一个子agent核实四法介绍。本目录是研究代码/数据/记录，非正式报告。

## 改了什么

新增[candidate.py](candidate.py)：在原生CPOP之前，根据左右邻近观测筛查孤立的大幅偏离点，降低这些点在拟合中的权重；指令切换附近保护原始边沿。原观测不替换、不删除、不裁剪，原始电量积分不改；所有标记均保留“可能测量尖峰，也可能真实短动作”的歧义。

具体为左右各2格的局部中位/MAD筛查，两边须接近、各自稳定；超过阈值κ时，令有效拟合标准差增至`max(原σ,|局部残差|/κ)`，即降低该点平方误差权重。κ仅在预定3/4/5中按验证选择，选5后冻结，新测试不改。

CPOP本身早已支持异方差权重，不能把这一接口、局部异常筛查或算法接通当成新通用方法。本次新增的是项目特定权重生成、指令边沿保护及歧义记录，并未改写CPOP动态规划，也不等价全局Huber/有界损失估计器。有效σ是数据依赖拟合权重，不是传感器方差估计或置信区间。

开源与方法依据：原生[CPOP/JSS2024](https://www.jstatsoft.org/article/view/v109i07)已有所需接口，继续复用锁定本地版本；[Hampel官方文档](https://search.r-project.org/CRAN/refmans/pracma/html/hampel.html)及[MIT实现候选](https://github.com/rnd-student-lab/hampel-filter)支持局部中位/MAD做法，本次短小适配自主实现，无额外依赖；[R-FPOP作者实现](https://github.com/guillemr/robust-fpop)及[原论文](https://arxiv.org/abs/1609.07363)提醒极端异常稳健性需要特别损失，常均值方法不能无说明充当连续变坡CPOP。没有安装新库，也未声称本筛查获得其理论保证。

## 同条件新模拟比较

复用未改的独立一/二阶动态生成器，用新种子和用户生成数据；增加真实单格响应、真实单格间断两个保护组，防止把真实短动作当噪声抹掉。参考为明确给定的模拟未调用功率，不训练预测、不把指令当反事实。

80基础验证任务×常规高斯/加两尖峰=160配对输入，3个κ内部验证配置及原CP/LABS共800输出；验证选κ5后冻结，才生成6新种子×40基础任务=240基础任务、480配对输入，三法1440输出全可用。不能把480变体当480独立任务。任务/参考/量测/指令/σ/采样/判据一致；候选不接触truth、机制标签或注入点索引。

主结果是**累计有效时长与最长连续有效时长两项绝对误差的平均**，越小越好，仍用既有.1q阈值；不是响应延迟：

| 方法 | 常规高斯噪声/s | 同高斯＋两尖峰/s | 两条件平均/s |
|---|---:|---:|---:|
| 原版CPOP | **22.250** | **55.625** | **38.938** |
| 本次改进版κ5 | 23.000 | 56.125 | 39.563 |
| 原作者LABS | 68.250 | 147.500 | 107.875 |

**本版没有实际时长收益，不采用为默认。** 尖峰条件曲线RMSE虽从.125423降到.122623kW，但时长55.625→56.125s，没有达到预定≥10%改善门槛。更重要的是，常规噪声下真实单格响应24条，原CP整次漏0，本版漏3，超过最多多1条的预定安全门。

所有真实短动作、间断、未达与失败状态均保留，不借提高物理阈值、删困难样本或仅统计检出者制造收益。LABS对单格/短间断也有明显失败，不能只看其null无误检称整体更好。原始η在每个480输入、三方法间精确相同；曲线变好不冒充计量电量改善。

这批任务包含新增短动作压力组及人工尖峰，与上轮192任务不同；不跨批直接比较分数。当前仍限已知参照、1分钟/30分钟/q1.5kW模拟；不支持未知参照/现场/能量债务或真实需求期限结论，未声明整任务5%认证。

## 真实记录辅助有局部收益，但不能替代安全门

复用已冻结KIT144事件/18套记录，不声称新真实留出。秒/安培变化归一进度与分钟/kW主模拟分开；进度1对应`事前实测电流+指令变化幅度`，不一定等于新绝对电流指令。用新固定噪声seed，原记录/加高斯/同高斯再加两尖峰共432输入、三法1296输出全可用；κ5不在真实记录上重选。

同方法、同一高斯噪声和σ下，额外两尖峰造成的变化：

| 方法 | 累计达90%时长变化/s | 最长连续时长变化/s | 达90%状态翻转/144 |
|---|---:|---:|---:|
| 原CP | .2271 | 1.8549 | 21 |
| 本版κ5 | .1431 | .7646 | 7 |
| LABS | .2431 | .3868 | 5 |

本版在这项人工扰动下较原CP稳定，LABS的最长时长更稳。但原记录没有独立干净曲线或未调用真值，不能称实测时长准确率提升；该局部收益不能抵消新模拟中真实短响应被抹掉的失败。原记录相对原观测的差异与同方法扰动变化两种口径都保留。[真实协议](real_protocol.json)、[真实摘要](real_summary.json)、[配对稳定性](real_paired_stability.json)、[收据](real_receipt.json)。

## 四种方法简要介绍

子agent已按源码和原论文核实：老师包名是**RIDE**，本次“RED”按此理解，未找到另一个独立RED方法。

| 方法 | 核心思路 |
|---|---|
| CPOP | 全局寻找斜率改变点，把曲线拟合成连续折线，同时惩罚过多折点。 |
| LABS | 递归找斜率变化，利用子区间结果回头复查父区间，校正位置。 |
| 老师RIDE过程模块 | 先规定延迟、爬坡、保持、释放/回补等阶段形状，再拟合参数。RIDE整包还含因素估计，本轮只谈过程模块。 |
| 最早F0 | 直接按阈值和连续驻留条件识别响应，并积分算电量。后续F1才加常均值分段平滑，不能把它写成PELT或CPOP。 |

详见[子agent简要介绍](method_introduction.md)、[来源与本地源码SHA](sources.json)。
