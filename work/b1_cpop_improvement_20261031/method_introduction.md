# 四种特征提取方法简要介绍

“RED”这里按项目收到的 **RIDE** 代码解释；尚无依据认定另有一个RED算法。以下只讲第一部分。四者都不能凭曲线重建，自动证明变化由调控造成。

| 方法 | 通俗解释、输出及限制 |
|---|---|
| **CPOP：全局折线分段** | 输入一条实测曲线，或已给定参照与实测的差值。用首尾相接的直线逼近曲线，通过动态规划平衡“拟合误差”和“折点数量”，再按统一规则提取起变、幅度、持续和恢复。形状较自由，但尖峰可能引入多余折点；最优只针对其数学目标。[原文](https://www.jstatsoft.org/article/view/v109i07) |
| **LABS：递归找变化，再回头检查** | 输入同类时间序列。先把曲线递归拆开，利用子区间找到的变化重新检查父区间位置，再选出一组斜率变点并重建折线。之后同样计算特征。通常计算较快，但连续折线假设对跳变有限制；它是2026年预印本方法，不能预设优于CPOP。[原文](https://arxiv.org/abs/2608.21122)、[作者实现](https://github.com/pfryz/LABS) |
| **老师的RIDE：按响应阶段拟合模板** | 输入参考差值、任务和采样信息，预设延迟、爬坡、保持、释放及回补形状，也允许中途掉落。用区间平均模型和有界最小二乘找参数，再选择无响应、单平台或双平台结构。阶段含义直观；真实过程偏离模板或求解停在较差解时，会影响结果。它是老师提供的项目实现。 |
| **最早F0：阈值、驻留和积分规则** | 输入参考与实际功率，先求差值；达到规定幅度并连续保持若干格，就标记开始或达标，再算时长、恢复和电量。简单、可解释，但近阈值噪声易把持续响应切碎。后来F1增加常均值分段平滑，再套相同规则，属于后续版本。 |

CPOP和LABS负责重建曲线，仍需共同的特征定义；RIDE提供阶段形状假设；F0直接按观察规则计算。净减载特征都需要可信未调控参照，指令跟踪特征可直接使用指令与实测。
