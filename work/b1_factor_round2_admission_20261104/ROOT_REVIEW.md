# 第2点 R1-A 总管审查与下一轮决定

2026-11-04。**通过数据准入。下一轮做一轮限额记录与实测跟随的观察分析，物理限流模型比较继续暂缓。** 当前交付的研究进展是新增了可用的真实证据来源，并确定了它能回答的问题。模型效果与跨阶段迁移尚待验证。

## 审查结论

1. 原表与角色冻结可追溯。主审重算了四份原件和三项冻结关联的 SHA-256，从交易表重放了角色计数。27,346,192 条计量记录、71,264 个有效交易键来自本轮原表审计。最初误显示的无表头首行所属交易已在角色冻结前隔离，主审本次复核未读取确认响应。
2. 新证据可以区分**后台计算限额和桩端记录不一致**、**桩端记录降限后的实测变化**。开发实例同一条分钟记录的后台值由 32 A 降到 27.918 A 时，桩端仍记 32 A。下一条记录的后台、桩端与实测分别为 24.426、28.160、27.140 A。该例可证明这种记录现象可查，整体频率、送达时刻及响应时延仍待独立依据。[官方字典](https://commercial.nationalgrid.co.uk/downloads-view/81670) · [开发实例](development_fields.json)
3. 确认侧 2,840 笔交易、41 台桩、22 个交易起始周只是六个连续时间点的上限。它们尚未检查实际降限、两组共同支持及后点可测。训练无 Trial 2/3，确认有 1,884 笔 Trial 2、825 笔 Trial 3。同属训练主要阶段 Trial 1 的确认侧，仅交易表就最多 238 笔、28 台桩。主审用交易全窗重算，涉及的 UTC 周也只有 6 周。原拟 30 台/12 周在同阶段已不可达。当前留出同时改变了日期、设备、试验阶段及控制环境，合并分数无法拆清各自的影响。因此保留现有确认区，暂不放行跨阶段评分，也不为达到样本门改动分割。[角色凭证](role_freeze.json)
4. `MaxAmpsUsed` 的统计区间、相别和计量精度仍未查明。官方字典还说明控制器升级后，连接但未充电时由每分钟改为每半小时上报。只分析后一分钟仍有值的交易，可能漏掉转为停充的记录，偏差方向不能预定。现有15笔开发样例只用于核字段，不能用样例行比例估全库。原协议暂留空的采用门处理合理。[官方字典](https://commercial.nationalgrid.co.uk/downloads-view/81670)
5. 修订后 C1 的额外项还存在解释问题。在 `I_pre ≤ L_old` 的常见候选条件下，`H = I_pre − P0`，因此 `a + b P0 + c H = a + (b−c) P0 + c I_pre`。即使赢过只含 P0 的校准，也可能只是重新加入事前电流，而非提供独立交互信息。此处是公式恒等关系，发生比例还未知。若将来恢复候选比较，须先报该条件比例，并纳入以事前电流、P0 做普通校准的等信息对照，再判断还有什么可检验的增量。[修订协议](protocol_revised.json)

## 下一轮 R1-B 可交办范围

**要回答的问题**是后台与桩端的记录偏差在哪些条件下出现，以及在相近的前态和降限幅度下，桩端降限后实际电流怎样变化。真正需要新增的是分母、条件及未响应证据，避免把这一轮做成单纯整理数据。

- 只使用现有冻结的开发训练、开发验证角色。先固定索引、计量对齐、分层和聚合规则，再打开超出15笔样例的开发响应值。以 Trial 1 为主要开发证据，阶段未知单列，Trial 2 验证记录只作范围诊断。确认响应继续保留封存。
- 分别以**后台计算降限**和**桩端记录降限**为入口，各用本身符合条件的交易作分母。第一张表报告同刻和下一原生记录两列是否一致、差多少、有多少没有后续记录。第二张表按事前电流、降限幅度和试验阶段，在有共同支持的范围比较下一原生样点实测电流及带符号变化。分别列出桩、周、组、交易数，报告同场未降限伪事件作自然波动参照。
- 逐级公开样本减少的原因。尤其报告下一分钟可测、原生间隔变长、已见停充、交易结束、字段缺测的分母。有后点的变化量只代表可测子集。后点缺失、停充记录和后续新降限分开记录，禁止按实际下降方向重选样本。无法分辨设备或组规则时限制解释范围。
- 做一次有边界的官方资料追查，限定查采样区间、相别和精度，核不到就结束本轮物理模型路线。交付可复查事件台账、两张结果表、共同支持与缺测报告，以及更新的关系证据表。模型拟合和确认计分另议。

总管审查后按结果分流。两层记录的差别及执行关系有足够支持时，作为 R1 的实测观察证据保留。覆盖不足或只有不可比条件时，给出适用边界并结束这条资料的深入比较。仅在同口径计量、明确增量及独立确认范围都落实后，才重议物理模型比较。

R1-B 完成后，第2点资源优先转回**报价怎样影响参与和用电**。先找有完整分配与全体结果的真实设计，参与机制再查邀请和接受记录。已有 iFlex 已消费组日可帮助设计，连续补偿估计按五点框架归第4点。解除与恢复仍列为独立证据缺口，待合格恢复记录后再做。
