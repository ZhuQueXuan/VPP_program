# R1-A · Electric Nation 原表准入与协议修订

2026-11-04。**原表通过来源、连接键和角色隔离核查，可用来研究分钟记录中的限额不一致。物理限流比较暂缓放行。** 当前缺 `MaxAmpsUsed` 的采样区间、相别和计量精度，原角色也存在明显的试验阶段错位。总管需审查这两项，再决定是否推进开发比较。当前已停在 R1-A。

## 原件和角色

从发布方取得 CrowdCharge 计量 ZIP、交易表、组定义表和计量字典，均保存在本目录 `original/`。计量 ZIP 为 188,915,502 字节，与发布方响应长度相同。单个 CSV 压缩成员读至末尾通过 CRC32，两个工作簿的 ZIP 成员也通过 CRC。SHA-256 为本地取得版本的指纹。发布方把本数据集标为 Open。本轮用作本地研究。 [下载凭证](source_access.json) · [原件散列与审计](metadata.json) · [发布方数据入口](https://commercial.nationalgrid.co.uk/electric-nation-data) · [发布方共享评估](https://connecteddata.nationalgrid.co.uk/dataset/a33247f4-e48e-49f1-ae4e-75e8448bb31c/resource/7175c8ae-1741-46b1-ae7e-7f064c092772/download/dsa011-electric-nation.pdf)

开发切片中 16,849 行的两条限额均可读，其中 8,928 行记录值不等，289 行差值绝对值至少 1 A。同一可读子集有 304 行的实测字段超过同条桩端记录限额。样本含 14,701 条未充电状态行，长交易会贡献很多重复行。上述是字段核查计数，不能视为事件效应、准确率或全库不一致比例。电流实例 `30.710` 等显示原文件小数存储格式，多条记录有两位有效小数。官方字典未说明是瞬时值或区间汇总、区间起止、逐相或合计，也无计量误差规格。字段名称、显示精度和超限行均不足以推断具体计量定义。 [官方计量字典](https://commercial.nationalgrid.co.uk/downloads-view/81670) · [开发字段台账](development_fields.json)

## 修订和放行条件

- 主目标固定为索引后第一条合格原生记录中的**绝对电流**。参考窗到后点的带符号变化另用于关系分析。早窗和近窗仍相关，稳定性筛选会压小自然波动。新增同场未降限伪索引、分层前态残差、稳定筛选和后点缺失分母。没有按分数切换目标的步骤。
- 加入无需拟合的 `min(I_pre, L_new)` 及其截距和斜率校准版。后一版本是候选的主要对照。候选仅额外使用已知限流关系给出的 `H`，先查它是否与既有特征近似重复。它的增益和同条件观测关系分开评价。旧分组加性对照只用于衔接。
- 暂不批准绝对或相对改善门。先取得计量字段的区间、相别及精度定义，或限定一个能核实同口径的设备子集。再在任何拟合前冻结与使用场景相符的误差门。若关键字段定义无法取得，保留原表记录级关系与不一致分析，停止物理候选比较。
- 请总管决定是否接受明确标注的跨阶段外推目标，或另找满足同阶段条件的元数据分割。在现有角色及协议下，没有足够资料承诺同阶段确认。独立确认的结果列继续封存。 [修订协议](protocol_revised.json)

开始时将无表头 CSV 的第一条记录误当表头查看，暴露了一行的响应和限额。该行所属整笔交易从所有角色隔离。之后只按键、时间和行存在核预留确认区，开发响应仅从冻结的 15 个交易读取。组定义首次解析因字母数字桩号中止，修正发生在计量扫描和角色冻结之前。本轮未拟合、未做模型效果比较或确认计分，旧草案与正式方法保留。 [过程凭证](source_access.json)
