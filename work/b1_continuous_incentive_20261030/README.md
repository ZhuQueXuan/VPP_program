# B1连续激励输入与曲线预测

用户澄清并授权：激励值可以连续调节，对任意有数据支持的金额估计平均响应；曲线允许弯曲，同一条曲线内固定任务时长和请求功率。报告及其他资源继续后置。

## 已改的算法功能

运行代码位于根 `B1算法/`。新增 `estimate_event_curve`、`estimate_metered_curve`、`fit_continuous_effects`、`ContinuousEffectConfig`、`export_incentive_curve`，调用示例见 [源码说明](../../B1算法/README.md)。实际训练金额保持连续，查询0.73、0.85、1.17不需要匹配原七档；每个金额按模型直接计算，查询值不依赖绘图网格插值。

融合采用原RIDE连续分支与成熟Kennedy连续DR的伪结果＋局部线性架构，补声明金额范围、同用户交叉拟合、同模型密度边缘化、连续样条结果模型、局部支持拒答和单位换算。整条曲线允许非线性、平台或下降；原固定离散AIPW及原过程CPOP对照保留。公式、作者开源方案/许可评估及取舍见 [方法依据](method_basis.md)。这项适配不构成新的DR估计器。

任务时长同时放开为按输入的起止时间计算正时长，仍要求完整、对齐电表区间。本轮补测20/37/45/75/120分钟，以及10秒计量的5.5分钟任务。已训练参考模型仍保持原相对[-120,+90]分钟范围，长任务可用有合法来源的外部参考；本轮没有静默外推旧预测模型或重训模型。

## 验证与比较

- [44项功能核验](verification.json)：任意金额、查询网格不变性、元↔分、精确DR四象限、局部线性矩条件、同用户分折、纯连续/七档/零点混合/支持空洞、自由时长、400事件公开两入口、旧任务曲线数值。
- [32项独立技术核验](technical_review/independent_receipt.json)：另核非恒定边缘密度下DR四象限、估计密度的单位换算、WLS/Jacobian、公开接口和异常边界。前三个DR象限精确误差≤2.22e-16；两模型均错保留明显偏差。属于公式与功能核验。
- [8项兼容与图示检查](compatibility_receipt.json)：480事件离散AIPW的逐项得分、曲线、区间与修改前相同；通用ratio结果的纵轴不误标为净交付。
- [新模拟比较](study_receipt.json)：12个新独立种子块，每块600用户×4事件×5配对机制，共144000事实变体，对应28800基础事件条件。不是60次独立重复。每次只把事实条件、金额和结果交给估计器，真曲线仅用于事后评价。原始事实在项目 `data/B1_continuous_incentive_v1_20261030/`，60份完整数据及哈希保留。

下面为12次重复的平均曲线误差，单位**百分点**，越小越好；每种机制使用同一份输入和同一查询网格，没有根据结果调模型：

|---|---:|---:|---:|---:|
| 随机分配、先增长后趋缓 | 1.373 | 1.523 | 1.383 | 14.555 |
| 非随机分配、先增长后趋缓 | 1.948 | 3.404 | 5.258 | 14.978 |
| 零作用 | 0.439 | 0.513 | 0.776 | 0.193 |
| 非单调压力测试 | 1.154 | 0.765 | 1.181 | 27.934 |

## 当前明确保留的限制

1. 首版针对纯连续激励分配；若有一大批精确零奖励和正值连续奖励，需混合设计方法，本版拒答。零端点查询是单侧光滑极限。固定少量档位仍用离散接口，不能仅凭画图声称连续识别。
2. 未知分配密度采用有界logit-normal模型，是待数据支持的模型假设。已知密度首版只接受已声明随机均匀设计；支持诊断不是无遗漏混杂的证明。
3. 曲线是共同任务下的人群平均响应及增量，不是单车执行保证；不同任务时长/功率不静默混算。参与/结果比较仍需完整因果假设，未确认只返回关联。
4. 阴影只表示条件抽样波动，尚未包括平滑偏差及模型/参考/过程的全部不确定性；没有现场验证、完整连续置信带覆盖或算法全面优越的结论。

最初一轮功能检查误用了原空调查询样例来核EV的37分钟预测，输入被正确拒绝；已保留 `verify_initial_failure.log` 并改为显式EV样例，未放宽空调范围。独立审查另发现通用ratio纵轴误标，已修标签并回归，数值估计未改。历史研究及保护目录保持，最终身份见 `adoption_receipt.json`、`after_manifest.json`。
