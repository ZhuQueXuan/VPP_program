# 正式过程模块运行验收

实现位于[正式process包](../../../b1_algorithm/process)，单例与批量入口均已提供。此处保存协议、开发准入和新留出验证，不是汇报报告；原稳定b123入口未改。

默认策略已在6个开发种子上按预冻结规则准入：以原生CPOP起步，只在观测块验证支持时采用任务模板；4格粗计量保留原格值。开发总平均RMSE相对保守版改善4.299%，6/6块非劣。策略在新留出运行前固定。

核验：16项单例输入/真实R/运行故障回退检查，批量顺序与单次R调用检查通过；新留出7680方法输出、7360有效RMSE独立重算通过，全部正式冻结文件SHA保持。主R批4160个完整和CV拟合case，一次进程约323.5秒；Python模板/比较约633.2秒。有效独立单位为20个种子块，不能称960个独立实验。
