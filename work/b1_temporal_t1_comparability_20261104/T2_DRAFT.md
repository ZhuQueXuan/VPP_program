# T2 单用途开发比较拟定冻结

状态为 T1 形成的待审方案。当前匹配及分户结构未过门，未形成可执行的评估样本清单，尚未放行拟合。T1 的4对保留作开发例证，独立确认另立新数据协议。

## 任务与比较输入

热泵停止后的事后形态检索。在同背景且6小时电量相近的三元组中，给一条查询曲线，判断哪条更接近它的高功率段先后、维持和反复。参考来自两名互相隔离的原点审阅者，见 [T1规则](T1_RULES.md)。图保留停止后真实时间、共同纵轴和缺口。审阅者先记区间和可见理由，再作相似选择；早晚阈值、匹配变量、手工特征和任何模型分数均不参与生成答案。相近、不可判、分歧分别保留。

所有方法以相同的停止后0至6小时功率作为唯一形态输入。用同一覆盖判据和同一分段线性功率，将每5分钟功率面积除以300秒得72个均值，保留单位W和固定时长；只按记录停止对齐。端点延伸、无效记录及共有分母同 T1。每条共有输入的72格面积和原始积分须相等到1e-9 kWh。前状态、控制、总电量和覆盖仅用于共享匹配及诊断。禁止把户ID、原日期、停止原因、通知、采样密度输入形态距离。固定保留只按总电量的排序对照，检验匹配后仍剩多少总量差异。

每折从训练户合格事件按户等量取样。每户取前 m 条，m 为训练户合格事件数的最小值，按 SHA256(t2-fit-v1|事件键) 固定排序。PCA、AE 和 FPCA 共用这批训练原格的逐格均值向量和全格标准差这一标量，手工特征在原量纲计算。评价户的全部事件从拟合隔离。记录每户入选/未入选及版本散列。若公共尺度为零或训练秩不足以得到六维，记拟合失败。共同比较分母为所有冻结后通过复核的三元组，单方法未能编码或预测并列计该法未答对，另报其覆盖及全方法共同输出子集。

## 四种六维表示

对每种表示分别使用训练事件各分量的标准差缩放，低于 1e-12 的分量固定为零，固定欧氏距离。设 72 格为 x，t 是格中点小时。

| 表示 | 拟定做法 |
| --- | --- |
| 手工统计6 | 末3小时均值减前3小时均值；非负功率加权时间重心（权重为零时填0并记诊断）；相邻格绝对差和；高位连续段数；最长高位段分钟；最后1小时对 t 的普通最小二乘斜率。高位门用单条格功率的第10百分位+200 W，至少连续两格。该门只定义手工对照。 |
| PCA6 | 同72格训练均值中心化、完整 SVD 前6方向，训练均值用于验证。 |
| 小型AE6 | 复用既有 tanh 72→24→6→24→72，Adam、alpha=.001、初始步长.003、批量 min(128,训练事件数)、恰60轮、无早停，种子20261104。瓶颈为6维。复用既有优化设定，按新输入宽度重新拟合。 |
| 平滑 FPCA6 | 一个候选。对72格用固定高斯权重局部均值，标准差10分钟、截断在三倍尺度、边界按实有权重重新归一。用训练平滑曲线的均值中心化，以5分钟积分内积求协方差前6个特征函数。以同样平滑及内积投影新曲线。此固定等宽网格是平滑后主成分，记录边界及短峰损失。 |

曾查过作者 [fdapace 实现](https://github.com/functionaldata/tPACE)和[0.6.0 手册](https://functionaldata.r-universe.dev/fdapace/doc/manual.html)，支持密集和稀疏网格，BSD 三条款。这里采用已有本地数值库的固定网格平滑及 SVD，便于锁定输入和带宽，省去 R 接入及自动平滑选择。AE 的实现依据为[现有历史编码器](../../B1算法/b1_algorithm/history.py)。两条线都使用成熟方法，不将其本身当作创新。

## 评价与停手

1. 只有 T1 的结构和双人原点参照门都过，且总管明确放行，才可在同一冻结开发清单上执行一次。主分数为三元组最近邻选对率，先同查询事件平均，再同查询户平均，再对查询户等权。报每折、每户、可判/可编码分母及方向一致性。训练户以外的两条比较事件也必须与查询来自同一三户留出折。
2. 诊断对照为绝对6小时电量差、按72格欧氏距离。报告审阅者区分“反复”“维持”“先后”的预先记项分层结果。可重建的方法另报原点误差和面积误差。固定保护检查用原曲线格上超过该曲线第10百分位+200 W且至少连续2格、经原点核实的高位段。重建值用同一功率门，以至少连续2格且覆盖原段至少一半计保留。窗口尾仍在高位的按窗内可见范围计。保护门为 FPCA 相比排序最强的可重建基线（PCA、AE）高位段保留率降幅≤2个百分点，户等权6小时绝对面积误差不额外增加超过0.10 kWh。面积门约等于六小时平均17 W，作为工程诊断约定。
3. 开发层仅当 FPCA 对本批最强六维基线高至少5个百分点、所有达标分折的差值非负、覆盖不降且保护门通过，才提议找新家庭/日期做一次独立确认。开发同分优先手工、PCA、AE。可计分结构不足、简单统计已够、FPCA无新增益或保护门失守，则保留开发中有效的简单版本及原点参照，结束这轮候选。全程记录失败。少量家庭的配对不能提供可信的独立区间，T3 另按新对象规模执行总体方案的区间门。
