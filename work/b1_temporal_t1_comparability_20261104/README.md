## 热泵

先冻结[匹配与判读规则](T1_RULES.md)，再按停止后6小时原始功率积分、事前温度和功率、实际干预时长及同类控制背景配对。形态判读只在配对编号、原点、图和文件散列全部固定后进行。温度和控制字段按其可用时点使用，停止原因和后窗电量用于事后匹配。功率积分保留原始秒间隔，边缘最多同侧延伸300秒，间隔超过450秒、功率缺失、重复时点及后窗叠加控制均按冻结条件处理。

同场次 **M02** 的两段干预均有事前通知，源代码均为热水温度阈值停止。实际干预长15.71和18.68小时，后6小时用电为2.667和2.605 kWh，差0.062 kWh。A在停止后2.83小时前一直约21–28 W，随后集中升高再回到低位。B在0.67–1.17小时已出现连续的主峰，后段反复升降，例如4.75、4.92、5.00小时的原值分别约598、33、568 W。两户事前平均功率也相差约232 W，接近250 W容差，保留在配对证据中。[M02原曲线](blind_pairs/M02.png)

**M03** 两边都在早段上升且出现两个早峰。后6小时用电为6.822和6.466 kWh。A在3.67–3.92小时又出现约2.62–3.32 kW高段，之后回到低位；B在1.50–4.50小时维持约1.06–1.19 kW。仅按早晚分类会漏掉这个差别。M04的一条曲线复用了M02的事件，独立事件分母按7个计。[M03原曲线](blind_pairs/M03.png) · [4对逐条首审](review_first.psv)

相近用电量确实对应过不同过程。总管隔离判读的4对类别均与首审一致，仍属于同一开发小包，缺独立人工参照。差异是否由控制造成需要另外识别。配对和分户结构均未过门，双人三元组参照尚无可计分对象。相近和失配留在台账中。[总管盲判](ROOT_BLIND_READ.md)
