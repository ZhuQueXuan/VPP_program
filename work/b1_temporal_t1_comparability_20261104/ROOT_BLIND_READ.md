# 主审盲看配对

先只打开冻结的四张匿名配对图，未查看执行方判读或事件身份。以下时间为记录停止后的真实小时。

| 盲号 | 主审判断 | 原点所见 |
| --- | --- | --- |
| M01 | 整体相近，有局部峰谷差 | 两条均在前约1小时进入主要高位，之后较长的阶梯式衰减。A约0.5小时后重新爬至3.1 kW，B较早达峰。差异主要在前段细节，整体类型相近。 |
| M02 | 明显不同 | A前约2.8小时低位，3–4.3小时集中冲高后回落。B主要高位在约0.7–1.2小时，此后多次低幅起落。 |
| M03 | 明显不同 | A在0–1小时多峰，约3.7–4小时另一次高峰，之后约4.8小时跌至近零。B前约1.3小时两峰，随后较长约1 kW平台。 |
| M04 | 明显不同 | A主高位约3–4.3小时。B很早冲高，约1–5.3小时长低位，最后半小时又进入高位。 |

盲看用于验证所见形态和规则边界。它与执行方逐图判读属于两个隔离视角的开发证据，既不构成独立人工真值，也不增加家庭数量。此记录是配对是否明显不同的初判，不能取代三元组的排序参照。
