# 算法报告格式修订

按用户指定原位修改现用Word及同名PDF：各级标题黑体；正文中文宋体、英文Times New Roman，五号10.5pt、1.25倍行距、首行两字符，段前后0。表格单元格及公式保持独立对齐，不加正文首行缩进；图注表注中文宋体/英文Times New Roman、10pt居中不加粗，取消10处章节强制分页并避免表头单独留页底。

现为10页。PDF由同一份Word原生导出，经render_docx.py逐页检查。全部文字、12条原生公式、全部媒体与排版前一致，只更改word/document.xml和word/styles.xml，其他包部分字节保持。before_format.docx/pdf保留上轮11页原件；qa_receipt.json为现用排版核查。

此脚本针对本次排版前底稿，不应在后续内容更新后直接重跑覆盖新内容；未来修订应以现用文件为底稿并沿用本格式。未改变研究代码、数据或实验结论。
