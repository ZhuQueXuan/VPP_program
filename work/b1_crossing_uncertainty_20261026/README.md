# B1交点不确定性实验 v1

2026-10-26。接续D109，实际运行新实验；只留复现说明，不另写整体规划。

## 结果与取舍

研究对象是净交付相对零激励**首次达到或超过10个百分点**的七档网格位置，辅报5个百分点；不是连续精确价格阈值或硬拐点。按用户整体重采样形成增量曲线的近似95%同时带，再返回首次达标的候选区间集合，同时保留“在支持内未达到”的可能。没有强制单调或选择新曲线模型。

下表只列总体、主10pp，分母均为100组新模拟重复：

| 声明机制 | 原严格规则 | 直接取首次交点 | 用户重采样带的实际输出 |
| --- | --- | --- | --- |
| 平台后上升 | 4次位置正确，1次位置错，95次非单调拒答 | 54次位置正确，46次位置错 | 100次确认存在但保留多个首次候选，均包含真位置；0次唯一定位 |
| 真非单调 | 100次拒答 | 100次首次位置正确 | 100次唯一首次位置正确，100次支持下降且支持全部3个上穿边 |
| 零作用 | 100次未达到 | 100次未达到 | 100次支持未达到 |
| 接近目标但总体未达 | 26次误报达到，10次拒答，64次未达 | 36次误报达到，64次未达 | 99次达到/未达仍不确定，1次支持未达；0次错误确认达到 |

这里的集合包含真值与单区间定位是不同指标。平台后上升的总体候选平均2个网格区间，包络宽度0.8元/kWh；新方法改善了结果的可信表达，尚未解决精确定位。近未达机制总体真实最大增量9.633pp，高组实际11.2385pp会达标、低组8.0275pp未达，不能全场景统称未达。

12条场景/组曲线的六档增量同时覆盖频率为90—99/100，总体四场景99/98/97/97；最低为真非单调低组90/100，exact Monte Carlo区间[82.38%,95.10%]。这是近似bootstrap带的经验覆盖，不能声称每组均达到95%或全部12条联合95%。两档目标的候选集合都100/100包含真首次位置或未达状态，原因包括保留多个候选/未达可能；不是100%准确率。某一单元观察到0/100错误，错误概率的95%二项区间仍为[0,3.62%]。

弱信号仍有限：近未达机制高组真实达10pp，但96/100次仍无法确认；5pp目标下零作用高组32/100次仍不确定。所有未知、拒答和不可用都保留100分母，不按能输出的次数重新计算成功率。未见bootstrap空分母或不足50条的原始组/档位。

## 方法、数据与运行

- 计算前冻结`protocol.json`及6份科学源码SHA。新种子261026101—261026200，每次600用户×14事件×4机制，共840000基础事件、3360000相关事实变体、60000次用户抽样；原件在[data新版本](../../data/驱动因素解耦模拟数据集_B1_crossing_uncertainty_v1_20261026/README.md)。四机制共享外生条件/剂量/噪声，不能当独立样本。原D109不回写。
- 固定估计器使用全600用户，没有模型选择或训练/测试划分；100组新种子用来独立重复评价方法。结果Y来自带噪公共请求功率积分，分母固定、有符号不截断，保留拒绝；接受A独立记录，不作结果调整变量。事前组由事件x划分。
- 每次999个multinomial用户整簇抽样，保留该用户全部事件、组别、剂量及四机制配对；组/档均值以抽样总和除抽样计数重算。六个非零档`gain_boot-gain_hat`的最大绝对值取95%高分位；基线增量固定0。任一draw空分母，整格不可用，不丢draw或重新抽样。单候选且仍可能未达不能叫唯一定位。
- 先保存`bands.npz`及SHA收据，再由评价器计算总体真值；解析与独立多项式积分差小于1e−15。仅七个节点，不识别档间隐藏反转或连续根。后窗只有解析可恢复余量检查，没有新增完整恢复波形或真实需求证据。

`inference.py`提供`aggregate / estimate / invert`可调用函数，比较函数为`old_strict / naive_first`；输入为观测值和用户抽样权重，不接收机制真值。`invert`返回首次候选、未达可能、唯一与否、可能/支持上穿及支持下降。

从项目根目录复核：`python work/b1_crossing_uncertainty_20261026/verify.py`。主实验已依次执行`run.py --freeze`、`run.py --generate`、`run.py`、`evaluate.py`、`plot_results.py`；前三步拒绝覆盖既存结果，复核不需要重新生成。生成实测9.36秒，推断15.82秒，CPU，无新增依赖。

132项主微型检查通过。另实现的验证器不导入主推断/评价/生成代码，独立复算全部999次用户bootstrap、7200条交点输出/1200条覆盖、72条汇总、总体真值及84条公共请求曲线；186450项通过、0失败。bootstrap结果完全一致，显式逐事件加权均值最大差2.22e−16，独立真值差5.55e−17。设计审查另有2503项逻辑检查，不能与大表字段核对数量一起当研究样本量。验证器两次CSV空值/Windows编码错误已修，记录`verification_notes.json`；冻结科学代码和结果未改。

主要证据：`evaluation.json`、`crossings.csv`、`coverage.csv`、`bands.npz`、`source_freeze.json`、`independent_verification.json`。图为`gain_bands.png`（预先固定第1次，非挑选）、`crossing_comparison.png`（全部100次）。

开源复用已安装[NumPy](https://github.com/numpy/numpy)与[SciPy BSD3](https://github.com/scipy/scipy/blob/main/LICENSE.txt)，成熟官方项目，适合小型数组统计；[SciPy bootstrap文档](https://docs.scipy.org/doc/scipy-1.15.3/reference/generated/scipy.stats.bootstrap.html)的通用接口不直接提供本研究的用户整簇/最大误差带/有限网格反演，故透明实现而不另装复杂因果库。置信带反演的研究背景见[Inverse set estimation and inversion of simultaneous confidence intervals](https://arxiv.org/abs/2210.03933)；本轮是有限网格自定义反演，不是该连续方法的复现或理论保证。
