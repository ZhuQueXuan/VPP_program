# 第3点执行方案：时序特征学习与演化规律

2026-11-04｜总管审定研究路线；尚未训练或通过效果验收

对应[五点框架](../../B1算法/RESEARCH_FRAMEWORK.md)的**新第3点**。旧记录中的“第三点补偿曲线”现属第4点，本次不重训。本文统一本目录两份专项建议中有差异的观察范围和比较口径。

## 用通俗的话说明

**要回答：持续时间、总电量差不多的两次过程，是否仍有平稳、反复中断、先强后弱、缓慢回升等重要差别？这些差别在什么状态和控制条件下稳定出现？**

| 输入 | 输出 | 用途 |
|---|---|---|
| 实际功率随时间的记录、收到的限额或干预记录、开始前状态；原始缺测也保留 | 可回查原曲线的过程形态、变化顺序与阶段规律，以及少量可供后续研究使用的时间特征 | 找到只看时长、电量等汇总数会漏掉的响应差别 |

先描述已经发生的完整观察过程。证明时间特征有用后，才考虑用调用前已经结束的历史解释下一次响应；本次完整曲线不能当本次调用前的信息。

## 1. 研究路线与旧结果的关系

分三步形成结论：**确认摘要遗漏了什么 → 学会保留这些时间信息 → 核对规律能否在不同对象和时间成立。** 形态检索只是第一项用途检验，不用一个排序分数代替整个“时序演化规律”研究。

10月30日已做过合法历史统计、PCA和小型自编码器的B1用途比较，新表示未胜。原数据、负结果和简单方案保留。本轮新增理由是“真实过程中先后次序和回升形态的信息遗漏”，不重复旧模拟面板追分，亦不以未来用电预测代替研究目标。

## 2. 真实数据与固定的首轮观察对象

**主资料：ACN已有训练与开发验证记录。** 1,169训练会话、129用户；254验证会话、27用户。均已被探索，统一按开发使用。原主测试及Office外站本轮不打开。

- 按控制记录选每会话第一个具备前60秒记录、收到限额下降至少2 A的候选。保留前60秒和之后30分钟内的完整控制—功率序列；期间明确解除限额时，额外检查解除后5分钟，最晚不超过锚点后35分钟。这些是观察窗，不是任务书规定的调节时长。
- 每会话只设一个主对象，同用户重复记录共同分组。没有明确解除、提前结束、缺测、多次控制均进台账，不能按“是否响应成功”选样。
- 主研究包含多次控制下的执行顺序。解除后回升另设子集：须有明确解除且后窗无新控制；后窗充分但未见回升与后窗不完整分开。当前小样本核查不足以证明有足够独立完整恢复片段。
- 控制记录只代表桩端可见限额，不能改名为独立发令、送达或物理生效时刻。功率形态随指令变化时，不称用户自主中断。

**补充资料：已有热泵公开试验。** 9户、287次干预，其中253次正时长；全是已探索开发资料。用干预前1小时、真实干预全段、结束后6小时，保留真实时间和缺测。零时长单列，重复时点先查来源，不能自动合并。热泵独立拟合、独立计分，不能用EV的30分钟或电流阈值套用。9户只支持有限跨机制探索。

实际可用数须经全开发台账核实；本方案不把已知总会话数当作合格形态样本数。详见[数据核查](data_feasibility.md)。

## 3. 采用什么方法，与谁比较

**唯一新增候选：函数主成分表示FPCA，固定6维。** 它从多条随时间变化的曲线中学习少量常见变化方式。优先评估复用作者的fdapace实现；成熟方法本身不作为创新。平滑可能漏掉短中断，必须实际检验。

比较四种增量表示，均共享既有可信摘要、控制背景、事前水平和覆盖状态：

1. 强手工时间摘要6维：前后段差、变化时间重心、变化总量、可见中断、解除后早晚差、末段趋势。原时间公式及不可计算条件在盲核可行性结束后、模型拟合前锁定。
2. 已有PCA形式6维：重新用同批真实开发资料学习。
3. 已有小型自编码器形式6维：保留既有小架构与60轮预算，重新适配；不拿旧模拟权重直接比较。
4. 新FPCA6：只评估预定参考平滑尺度的0.5、1、2倍，不扩大候选族。

**同条件比较分两层。** 主要方法比较先让四法使用相同时间单元、相同原点汇总和同一共同可编码对象；原时刻FPCA作为额外适用性诊断，不能把保留了更多原点的收益全部称为表示算法优势。时间单元只按原采样分布与覆盖条件确定，拟合前冻结；不补零、不跨缺口拉直。PCA/AE不能处理的缺格记录明确记不适用，不能静默删掉。若共同对象过少，此比较不可验收，不能靠放宽覆盖条件追分。

阶段对齐只使用控制开始或解除，不按响应峰值、回升点对齐；不用时间扭曲消掉早晚差异。采用训练集统一尺度，保留实际幅度与时长。四法相同6维和相同评价方法不等于严格同容量，真实成本分别记录。

## 4. 如何证明有用

**先建立盲于模型输出的原曲线参照。** 在摘要和控制背景相近的记录中，固定三个判读维度：平稳与多次中断、强弱变化的先后顺序、有明确解除时的回升形态。允许“相近”“无法判断”，不强行给每条记录贴类别。

首个可行性包最多24条ACN记录、12条热泵记录，按原角色、控制次数及时间覆盖分层后固定哈希抽取，限制同对象重复；数量不足如实记录。此包用于检查定义是否可判，不作为效果确认。参照需保存原点依据及复核差异；只有助手首审时只能标暂定，不能称独立人工真值。

之后固定可比记录组：给定一个查询过程，在两条比较记录中判断哪条时间形态更相近。主指标为排序正确率，先对象内、再对象间等权；分别报告可判率、可编码率、独立对象数。各配对不能当作独立用户数。比较组必须跨用户/家庭，不能只靠身份或采样密度检索。

补充检查三个维度各自误差、短中断是否丢失、原时刻留点误差、可见功率差面积，以及固定遮挡诊断。重建误差和漂亮聚类不能单独决定采用。加入相同控制背景的匹配及仅控制信息对照，核对是否只是学会识别指令。

**演化规律须另外交付：** 对可核的形态给出真实时间上的阶段变化和对象间差异；在事先选定的控制背景与事前状态下比较阶段轨迹、变化次序及回升分布。每条规律必须有原始例证、对象级分母、相反例与较晚日期或新对象的复核。这里是观测规律；因素因果作用由第2、4点承担，不能由形态分组自动推导。

## 5. 哪些结果决定保留

确认前固定开发选出的最强简单基线。新表示的拟定采用门为：主排序正确率提高至少5个百分点，对象聚类的配对95%区间下界大于0；三个可评价维度均不得退步超过2个百分点；同一总台账上的可编码率不下降。关键短变化、面积或时间次序出现系统性丢失时，不因平均分上涨而采用。

这些是本轮研究选择标准，不是任务书90%指标。可行性阶段要确定参照一致性、最小可识别时间变化、面积误差容限以及确认样本量；它们须在任何模型效果比较前冻结。若数据或参照质量不足，记录为不足，不把未知当作失败或通过。热泵9户探索不单独作跨资源通过结论。

新方法无益时保留最有效的现有或简单方法；仍须交付经核的规律与适用范围。仅有一次方法失败或一个可运行接口，不能宣布本点完成。

## 7. 论文与开源依据

截至2026-11-04完成定向核查：

- [fdapace作者库](https://github.com/functionaldata/tPACE)与[文档](https://functionaldata.r-universe.dev/fdapace/doc/manual.html)支持稀疏/密集函数数据及新曲线编码。作者DESCRIPTION为0.6.0、2024-07-02、BSD-3-Clause；2026构建时间不算新算法发表。实际复用前固定提交与许可文件，核自动分箱和噪声设定；本轮未安装。改造重点是阶段、缺测和评价接口。
- [2025年电力曲线FPCA研究的作者机构记录](https://pure.psu.edu/en/publications/clustering-electricity-consumption-patterns-using-functional-data/)支持水平/形状分解思路；目前只据摘要，不冒称完整复现或DR效果已证。
- [TimeDRL主源](https://arxiv.org/abs/2312.04142)及[MIT作者库](https://github.com/blacksnail789521/TimeDRL)提醒裁剪、遮挡不变性可能丢失有用信息。本轮借鉴这一问题，不再新增网络。
- [2026年10月TS2Vec-FM预印本](https://arxiv.org/abs/2610.28602)提供同时保留幅度和形状的启发；分类成绩不直接证明本任务有效，对应实现/权重许可未核实，本轮不采用。

更详细的方法讨论见[方法建议](method_design.md)。两份建议是审查依据；本文件对观察窗、比较层次和当前推进权限的裁定优先。
