# EV主问题、结果与因素口径（步骤1）

2026-10-30。用户已授权按定稿先完成步骤1，再推进步骤2、3。本轮只做单向交流充电资源，不展开连续阈值、时序新网络、其他资源或报告。

**主问题：**同样时长和请求功率的任务中，事先告知的连续补偿怎样改变目标人群的平均累计减载时长；需求紧迫和期限余量造成的原有差异怎样与激励作用分开？原始净交付比例η并行保留。

| 字段/对象 | 含义和单位 | 形成时点与角色 |
|---|---|---|
| task/user/meter ID | 任务、用户与单车电表的对应关系 | 任务前确定；重复任务按原用户分折与聚类 |
| start/end/request | 任务起止（统一绝对分钟）、请求减载kW | 激励作用研究前固定，同一曲线不混W/q |
| offered_incentive | 事先告知的补偿标准，明确元/千瓦时等单位 | 不晚于通知；主要处理D，非事后结算金额 |
| deadline_slack | 事前期限余量；模拟标准化为[-1,1] | 不晚于通知；事前条件L，非事后实际离站 |
| demand_urgency | 事前需求紧迫度；模拟标准化为[-1,1] | 不晚于通知；事前条件U，非最终充入电量反推 |
| participation | 实际参加/拒绝记录 | 激励后中介A；保留拒绝事件，不作为总作用调整条件 |
| interval power | 电表区间平均功率kW | 任务中/后观测，只用于事后过程与结果 |
| reference | 未调用功率或其预测，kW，与任务网格绑定 | 预测只使用通知前可得历史/环境；真实反事实不因预测而已知 |
| cumulative_response_seconds | 任务窗中减载超过0.1×请求的区间总时长 | 事后结果；累计与最长连续分开，不推断粗格内动作时点 |
| eta_raw | 原始功率差的有符号积分/事前请求电量 | 并行电量结果；过程拟合不替代积分 |

过程主结果显式指定 `selected_curve` 或 `raw_observed`；两者是在同一计量尺度、阈值下对同一目标的测量方案。比较测量误差后，再比较作用误差。实际未知参考下的曲线解释为对所声明测量结果的作用，不自动升级为无误差潜在响应效应。

初始结构为声明的EV研究假设：L/U影响D、参加及响应；D影响参加和执行结果，参加影响结果。随机设计删除L/U→D边。未观测用户特征可以影响参加/执行，但在模拟中不影响D；真实数据若存在该路径，当前无遗漏混杂假设不成立。

识别按声明图的后门条件核验。方向来自时序/机制，数据筛选仅辅助；不能因筛掉L→D就取消对L的必要调整。辅助图研究本轮限于连续激励的事前父集：对logit域转换后的D，训练用户内比较高斯线性条件BIC，不宣称已识别完整EV因果图。

本轮对比均以同一目标人群、同W/q、同计量/判据为准；不参加者以实际记录的无减载/测量结果保留。因素字段逐项绑定可得时间，晚于通知、对象错配、处理后变量、重复物理窗口或不可算事件不静默删除。因果假设未确认时仅关联，诊断不能证明真实无混杂。

模拟真值仅由评价器使用；参考模型/过程识别/效应估计只读事实及合法历史。测量与效应分评，不承诺新方法普遍胜出或全链CI覆盖。原基线修正失败结果保持，不在旧留出上追分。
