# 第二点响应因素漏检复盘与同条件比较

回放上一轮 48 个响应因素漏检，29 个在无条件检验就被筛掉，13 个在条件里加入报价后被筛掉，6 个在加入其他因素后被筛掉。原记录中的响应有大量零值，部分效应较弱。分阶段回放能定位筛除步骤，尚无法把 29 个逐一归因为零值或噪声。每条边的条件集与原检验值保存在 `results.json` 的 `diagnostics`。

## 比较方法

两版共用现有 `ResourceFactorStudy` 和 `analyze_resource_factors` 的输入校验、每组取样和时间约束 KCI 报价筛查。候选只换响应侧，先控制报价和其他事前因素，再用一个二次加性条件均值回归联合检验每个因素的一次项和二次项，使用 HC3 方差。保留所有零响应和负值，不做两部筛样。两个模拟案例的六个检验值已用 statsmodels HC3 独立核对。PCM 的论文与 `comets` 实现提供了聚焦条件均值的思路，完整 PCM 还包含样本拆分和投影，本轮验证的是更简单的低维回归候选。也查看了近期 KCI 性能研究与 GKCM，未将其纳入本轮候选。[PCM 论文](https://arxiv.org/abs/2211.02039) · [comets](https://github.com/LucasKook/comets) · [KCI 实证研究](https://arxiv.org/abs/2512.14000) · [GKCM](https://arxiv.org/abs/2604.03721)

## 有已知答案的比较

| 数据 | 共同因素找回，现有版 → 候选 | 共同因素误报，现有版 → 候选 |
| --- | ---: | ---: |
| 新充电桩模拟 | 14/48 → 17/48 | 1 → 2 |
| 新热泵模拟 | 9/48 → 11/48 | 0 → 0 |
| 新模拟合计 | 23/96 → 28/96 | 1 → 2 |
| 使用真实事前变量分布的半模拟 | 15/32 → 19/32 | 1 → 0 |

新模拟包含 72 个资源、机制、种子组合，每组 120 个模拟独立个体。四个随机种子在不同机制和资源间配对。响应因素单独看从 54/120 到 67/120，误报均为 8 个。纯交互机制下，两版响应侧都找回 0 个。候选新增的共同因素误报出现在随机报价机制，真实共同因素为零。固定的报价筛查在主试验最多给响应侧留下 56/96 个可找回的共同因素。

预定采用条件为共同因素找回率至少增加 10 个百分点、共同因素误报不增加、两类资源均不退步。实际增加 5.21 个百分点并新增 1 个误报，保留现有版。候选在研究脚本，第三点没有调用它。

## 现场数据的用途

- 充电站公开记录含 6,672 个站点小时。用间隔四个日历日的固定 13:00 UTC 样本做探索比较，实际折扣四档，61 个可用站点小时。同一个通用接口下，两版都筛出前 48 小时对应小时用电量与响应有关，都没有筛出共同因素。公开表缺逐条报价时间，按项目披露的约提前 24 小时通知构造时间口径；站点小时存在时间依赖，结果为描述性，不能计算现场找回率或误报率。[作者数据](https://github.com/INESCTEC/ev-dml) · [项目通知说明](https://www.inesctec.pt/en/news/inesc-tec-behind-the-wheel-of-a-solution-that-allows-charging-electric-cars-and-getting-discounts)
- 热泵现场数据有 9 户实测温度和功率，发布表记录控制干预，没有逐事件补偿报价。取 2,013 条非干预的清晨温度记录构建事前变量分布。充电站半模拟用 234 条记录的市场价及历史用电分布。两类半模拟均对实测变量对做秩变换后成对重采样，报价和响应依照已知机制生成，因此可计分。模拟个体数和现场户数分别记录。[热泵作者数据](https://github.com/RigauxBaptiste/The_Proof_of_the_Pudding_is_in_the_Heating)

`benchmark.py` 记录生成和评分方法。`protocol.json` 保留首轮日期类型转换失败前的配置，`protocol_replay.json` 对应有效结果。日期修复发生在任何新机制计分前，两份配置的算法、种子和采用条件一致。逐组结果见 `results.json`。
