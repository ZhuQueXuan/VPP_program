# 第一部分：泛化风险核对与后续研究规划

2026-11-02。本轮只核对和制定规划，没有训练、调参、生成新测试或修改算法。当前有效入口仍为`effective_response_refined`；上一轮候选未采用。

## 核实的事实

- 最近一轮`b1_residual_false_20261102/train.py`明确把既往验证/测试转为开发数据；`source_data.py`集中复用既往来源。新7801验证、7802测试、7803确认没有用于该轮拟合，不能据此指称该轮直接把当前测试标签用于训练。
- 但`data.py`始终调用同一`b1_duration_release_20261101/generation.py`及其旧模拟器，主要变化是随机种子、幅度分层与固定类型干扰。换种子验证了同一模拟机制的新样本表现，未验证新物理机制、新设备或新干扰分布的泛化。
- 已采用模型经历多次基于旧测试诊断后的设计调整；即便随后更换随机种子，整个研究流程仍可能适应模拟器和固定场景。旧测试转开发并如实记录，不会让这些旧数据重新成为盲测。
- 从旧426维增加到上一轮527维，再叠加任务资格判断，增加了复杂度；未做完整模块去除实验与跨机制测试，不能证明每层有独立、稳定、可迁移的收益，也不能仅凭维数判断已过拟合。
- 上一轮首次测试收益不达预设门后追加了一次提前留件的独立确认，最后因新增真实任务误拒未采用。流程透明且未改模型，但研究者在看到首次结果后决定追加数据，属于需要限制的适应性研究决策；今后样本量、确认次数和停止规则应在首次最终测试前规定。
- 上轮被误拒任务旧版恰好输出正确总时长，但响应位置已错。这说明只盯总时长或任务准确率会掩盖片段提取问题。

## 下一步先做评测设计，再启动候选

1. **现版冻结、已见数据统一作开发。** 当前有益版、原CPOP和LABS保留；历史结果只支持其原实验范围。把历史所有看过的样本视作已见，不再用它们作最终成绩。
2. **按基础来源和机制隔离。** 同一物理任务的高斯/尖峰/成段干扰变体必须在同一分区；有真实数据时同一车辆、充电会话不得跨训练与测试。开发阶段按完整响应机制/干扰机制留组轮换，不只随机打散行或更换seed。独立生成器评测应事先明确其动力学、量测积分和干扰模型，不能只是复制旧生成器改函数名。
3. **保留真正未见的终测场景。** 留出整类未用于训练或选择的响应形状、不同相关噪声和干扰机制，以及由另一套合理物理模型产生的轨迹。未确认实际数据来源与真值前不宣称已建立真实响应终测。现有普通真实充电记录可单列检查自然波动误报；没有DR响应真值的记录不能给响应准确率。最终配置、样本规模、主指标、允许的取舍和最多试验次数在揭盲前锁定；本阶段最多比较三个预先说明的候选方向，用开发验证选择一个进入一次终测。终测失败如实收口，不针对暴露案例追分或追加抽到过关。
4. **优化片段提取与结构简化。** 候选研究重点是响应发生的位置、功率水平和边界，让有效资格与时长有可核对的局部依据。分别去掉时长校正、补检、整任务资格等层，检查它们在哪些未见机制中真正有用；在外部开发验证性能相近时优先更简单的方案。尚未预先指定某个新模型必胜，也不把论文新颖度作为采用理由。

## 固定评价原则

保持同输入、同参考、同阈值和同对照。主评分及短响应、误报、时长、位置的约束和允许取舍应在新实验前明确，不能只看一个综合准确率。按基础任务/设备或机制分组计算不确定性，不能把同一轨迹的干扰变体当成独立车辆。逐类“零新增误拒”是已见样本上的观测，不是未来零漏检保证；是否采用应同时看跨机制稳定性、配对差异及预先约定的实际收益与风险，不围绕少数样本临时改门。

阶段顺序：先完成数据分区、跨机制评测和停止规则；再做模块贡献核对；最后选择局部片段提取候选并一次终测。暂不继续加特征、扩保护规则或调分数。仍仅第一部分，参考预测、报告与第二部分后置。

## 原始方法依据

[Dwork等，Generalization in Adaptive Data Analysis and Holdout Reuse，NeurIPS 2015](https://proceedings.neurips.cc/paper/2015/hash/bad5f33780c42f2588878a9d07405083-Abstract.html)研究了适应性分析与测试数据复用的有效性问题。本文仅据此说明需要管理研究流程的适应性，没有实现其可复用留出机制，也不借用其理论保证。本项目额外的同一模拟器泛化风险来自上述本地源码核对。
