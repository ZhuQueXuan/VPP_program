# 算法立项说明（草案）

## 1. 算法名称

基于混合效应模型与结构因果学习的虚拟电厂资源调节行为关键驱动因素解耦算法。

## 2. 对应的会议任务与可研依据

- 会议要求：将“市场机制—资源特性—调节行为”的定性相关性矩阵转化为可计算、可解释的定量结果；数据到位前先开展算法设计，不等待数据。
- 可研对应：课题一“差异化市场环境下虚拟电厂多元资源行为影响因素分析与关键调节时序特征研究”；当前阶段要求开展混合效应建模、结构因果模型/因果图学习、非线性响应区间与敏感性识别。

## 3. 要解决的问题

在不同市场和任务条件下，资源的实际调节表现为什么会不同？市场激励、任务要求和资源自身状态分别与调节表现有多大关系，关系在什么条件下会变化？

第一版不同时解决所有问题，而是选定一个资源类型和一个行为结果。例如：

> 在同一类调节任务中，市场激励、任务持续时间和资源初始状态与“实际响应完成比例”之间的定量关系是什么？

## 4. 最小输入与输出

### 最小输入

只选择回答上述问题的必要数据，不要求使用《数据需求_课题一》中的全部字段：

1. 任务信息：资源/资源组标识、任务时间、调节方向、目标、持续时间；
2. 行为结果：实际调节结果或完成比例；
3. 一个重点因素：例如补偿水平或通知提前时间；
4. 必要控制条件：资源类型/额定能力、任务前状态、时间或场景等。

### 输出

1. 因素—行为关联强度表：影响方向、估计强度、置信区间和适用条件；
2. 关键影响路径图：说明哪些关系是业务假设、哪些由数据支持；
3. 阈值或敏感区间：例如任务持续时间超过某区间后，完成比例是否明显下降；
4. 可更新的资源—市场—因素关联矩阵，供后续能力刻画和分类使用。

## 5. 实施方法

### 第一步：建立事件样本

以“一个资源（或资源组）参与一次调节任务”为一个样本，而不是把每条功率记录都当作独立样本。每个样本保留任务前、任务中和任务后的必要信息。

### 第二步：混合效应模型

同一资源可能被多次调用，不同资源也存在先天差异。模型将市场和任务因素作为总体影响，同时把资源个体差异作为随机效应，从而避免把“某个资源天生表现较好”误判为市场因素的作用。

### 第三步：因果关系约束与效应识别

先基于资源物理规律、控制流程和时间先后关系绘制初始因果图；再用数据对可能的关系进行辅助校核。重点区分：

- 需要控制的共同影响条件；
- 市场激励通过用户接受等中间环节发挥作用的路径；
- 不应仅凭相关性写成因果结论的关系。

### 第四步：阈值和稳定性检查

通过分段/阈值分析观察关系是否在不同任务时长、资源状态或场景下发生改变；并按时间段、资源组或市场场景重复估计，检查结论是否稳定。

## 6. 数据到位前的工作

- 从可研、市场规则和已有报告中梳理候选影响关系，形成可由专业人员审查的初始关系图；
- 确定第一版的资源类型、行为结果、重点因素和最小控制条件；
- 设计结果表、矩阵和阈值图的展示样式；
- 必要时可用文本/规则材料提供初始证据，但不把文本挖掘结果直接当作真实定量结论。

## 7. 验证与边界

- 预测准确度与机制解释分别评价：前者可采用 MAE、RMSE、F1 等；后者关注方向、置信区间、安慰剂检验、敏感性检验和跨时段稳定性。
- 可研“模型精度不低于 90%”是后续可调容量与响应能力模型的验收目标；在真实数据和评价口径明确前，不声称本算法已达到该指标。
- 因果图学习仅为辅助；最终关系必须接受业务专家与资源物理约束的校核。
