# 组会算法说明（第二版）

## 算法名称

**基于广义加性混合效应模型（GAMM）的虚拟电厂资源调节行为关键驱动因素解耦算法**

> 核心套用算法为**广义加性混合效应模型**（Generalized Additive Mixed Model，GAMM）。本项目在该成熟模型的基础上，针对“同一资源多次参与调节任务”的事件数据加入资源个体随机效应，并以因果图约束变量选择和结果解释。为便于项目内称呼，可将该项目化实现简称为“因果约束 GAMM”。

## 1. 算法定位

课题一的研究主线为“**特征解耦—能力量化—智能分级**”。本算法对应第一步“特征解耦”：将“市场机制—资源特性—调节行为”的定性描述，转化为可解释、可随真实数据更新的定量关联结果。

可研当前阶段提出开展混合效应建模、结构因果模型/因果图学习，以及非线性响应区间和敏感性识别。GAMM同时具备“混合效应”和“非线性函数拟合”两项能力；因果图用于落实结构因果要求。本算法据此服务于后续的可调容量与响应能力建模、资源智能分级分类和市场适配分析，而不替代这些后续模型。

## 2. 要解决的具体问题

资源能否完成一次调节任务，通常同时受到市场激励、任务难度、资源自身能力、任务前状态和时间场景等因素影响。若直接比较“激励高时完成得是否更好”，容易把资源本来能力强或任务本来简单的影响误认为激励作用。

因此，第一版聚焦一个可验证的问题：

> 在相近的任务和资源条件下，市场激励、任务调节量和持续时间与资源**实际响应完成比例**之间有什么关系？这种关系是否会随资源状态或场景而改变？

其中，实际响应完成比例可暂按“实际完成调节量 / 任务要求调节量”理解，真实数据到位后，再依据实际市场规则、调节方向和异常任务处理规则确认最终计算口径。

## 3. 样本、输入与输出

### 3.1 样本定义

以“**一个资源（或资源组）参与一次调节任务**”作为一个样本，而不是将每一条功率记录作为独立样本。每个样本将任务前、任务中和任务后的必要信息关联起来，从而形成“任务—资源—执行结果”的闭环。

### 3.2 最小输入

| 信息类别 | 第一版最小字段与作用 |
| --- | --- |
| 任务信息 | 任务标识、时间、调节方向、目标调节量、持续时间；用于描述任务要求与难度。 |
| 结果信息 | 实际响应结果或完成比例；作为第一版核心结果。 |
| 市场信息 | 至少一个市场激励字段，例如补偿水平、激励方式或通知提前时间。 |
| 资源与状态信息 | 资源标识、资源类型/额定能力、任务前状态或可用能力。 |
| 场景信息 | 时间段、市场类型或运行场景等必要条件。 |

### 3.3 输出结果

1. **因素—行为影响表**：给出重点因素与完成比例的影响方向、估计强度、置信区间和适用条件；
2. **关键关系图**：区分业务假设、需要控制的共同影响条件和由数据支持的关系；
3. **阈值/敏感区间**：识别任务持续时间、资源状态等因素在哪些区间可能发生明显变化；
4. **资源—市场—因素定量关联矩阵**：呈现关系方向、强度、条件和可信度，为后续工作提供输入。

## 4. 核心算法与技术路线

```text
原始调节记录 → 事件样本构建 → 调节效果计算 → 因果约束变量筛选
             → GAMM 驱动因素估计 → 候选阈值识别 → 可信度评价
             → 定量关联矩阵、关键关系图与后续模型输入
```

算法由六个顺序衔接的模块组成：

| 模块 | 要解决的问题 | 主要产出 |
| --- | --- | --- |
| 1. 事件样本构建 | 原始指令、运行记录和响应结果如何对应为一次任务？ | “一资源—一任务—一结果”的事件样本表 |
| 2. 调节效果计算 | 一次任务完成得怎样？ | 完成比例及可扩展的时延、持续达标等指标 |
| 3. 因果约束变量筛选 | 哪些变量应控制，哪些不能作为输入？ | 变量角色表与初始因果图 |
| 4. GAMM 驱动因素估计 | 各因素在排除资源差异后如何影响结果？ | 影响曲线、资源随机效应和置信区间 |
| 5. 候选阈值识别 | 影响关系在哪些区间发生明显变化？ | 候选敏感区间及其复核结果 |
| 6. 可信度评价 | 哪些关系足够稳定、可用于后续工作？ | 数据、统计与业务三方面的可信度等级 |

### 4.1 任务样本构建与结果计算

先按照资源标识、任务标识和时间窗口关联调节指令、运行数据和实际响应结果。对每个任务样本计算完成比例，并核查调节方向、单位、时间对齐和异常任务处理规则。若任务、资源、结果无法闭环对应，则不进入第一版建模。

第一版可按以下规则执行：

1. 以 `resource_id + event_id` 作为优先关联键；若缺少 `event_id`，仅在业务人员确认后，以资源标识、指令下发时间和任务窗口进行辅助匹配；
2. 将任务开始前的必要状态、任务执行期间的响应记录和任务结束后的结果汇总为一条事件样本；
3. 统一调节方向、功率单位和时间粒度，记录缺失、冲突和异常标记；
4. 依据最终确认的业务规则计算完成比例，保留原始任务值与实际响应值以便复核；
5. 不满足“任务—资源—结果”闭环、时间明显错位或关键结果缺失的记录，只保留在数据质量清单中，不用于第一版效应估计。

**单条事件样本示例**：

| 信息 | 示例 |
| --- | --- |
| 资源 | 某储能设备 |
| 任务时间 | 2026-08-12 10:00 |
| 任务要求 | 下调 100 千瓦，持续 15 分钟 |
| 市场激励 | 某补偿标准 |
| 初始状态 | 任务开始前 SOC、初始功率等 |
| 结果 | 实际完成 80 千瓦 |
| 结果指标 | 暂按完成比例 80% 计算 |

上表仅用于说明事件样本的组织方式；真实数据到位后，资源名称、时间、任务目标、补偿字段和完成比例计算口径均以实际业务记录与确认规则为准。

将许多这样的事件样本汇总后，GAMM 可同时估计：

```text
完成比例 =
    激励曲线
  + 调节量曲线
  + 持续时间曲线
  + 初始状态曲线
  + 时段/场景影响
  + 资源个体差异
```

因此，模型最终得到的不是一个抽象分数，而是一组可解释、可用于后续工作的结果：

- 市场激励与完成比例的关系曲线；
- 任务持续时间与完成比例的关系曲线；
- 不同资源自身的稳定差异；
- 资源响应表现可能明显变化的候选区间；
- 不同资源类型、市场场景下的差异。

### 4.2 核心算法：广义加性混合效应模型（GAMM）

GAMM是可直接套用的成熟统计学习模型，适合同时处理“资源之间存在重复观测”和“因素影响可能不是直线关系”两类问题。第一版模型可写为：

```text
完成比例 = 总体水平
        + 市场激励的非线性影响 s(市场激励)
        + 任务调节量的非线性影响 s(任务调节量)
        + 持续时间的非线性影响 s(持续时间)
        + 资源状态、时间场景等必要条件
        + 资源个体随机效应
        + 随机误差
```

其中 `s(·)` 表示由数据学习得到的平滑曲线，而不是预先假定“激励每增加一个单位，效果永远增加同样多”。曲线斜率明显改变的区间，可作为后续重点核验的候选阈值。

同一资源可能被多次调用，不同资源也存在先天能力、运行习惯和未观测条件差异。模型将市场激励、任务要求和场景条件作为总体影响，同时将资源或资源组的个体差异作为随机效应处理。

本项目对标准GAMM的适配包括：以“一次资源参与一次任务”为样本；以资源编号/资源组设置随机效应；对市场激励、任务持续时间和资源状态拟合非线性曲线；在需要时加入“资源类型×市场激励”等交互项比较不同资源的差异。其目的不是追求复杂模型，而是避免将“某资源本来表现较好”误判为“某项市场因素带来的效果”。真实数据到位后，将根据完成比例的实际分布选择合适的比例型模型；如采用成功/失败口径，则相应使用二分类模型。

### 4.3 因果图约束：明确GAMM中应纳入和不应纳入的变量

因果图不是与GAMM并列的第二个“黑箱模型”，而是建模前的变量选择规则。先依据资源物理规律、调度控制流程和时间先后关系绘制初始因果图，再用数据对候选关系进行辅助校核。重点区分：

- 需要控制的共同影响条件，例如任务难度、资源类型、任务前状态和时间场景；
- 可能的中间路径，例如市场激励可能先影响用户接受或资源可用性，再影响最终响应；
- 不应作为输入的事后变量，例如任务完成后的失败原因不能用于解释任务发生前的决策。

因果图学习仅用于辅助发现和校核关系，不能脱离业务机理自动产生最终结论；最终解释仍需接受专业人员和资源物理约束的审查。

### 4.4 阈值与稳定性分析：识别关系何时发生变化

市场激励或任务持续时间对完成比例的影响可能不是线性的。例如，任务持续时间较短时影响有限，但超过某个区间后完成比例可能明显下降。算法将采用分段或阈值分析识别可能的变化区间。

同时按不同时间段、资源组或市场场景重复估计，并以替代完成比例口径和业务校核检验结果是否稳定，避免一次拟合得出偶然结论。

候选阈值不由人工预先指定，而按以下规则识别：先从 GAMM 平滑曲线中定位斜率或曲率明显改变的区间；再使用分段模型比较该位置前后的关系是否存在显著差异；最后在不同资源组、时间段和替代结果口径下复核。只有统计表现稳定且不违背资源物理规律、市场规则的区间，才作为“候选阈值”输出；它不是设备安全边界或已确认的业务规则。

### 4.5 可信度评价：决定哪些结果可进入关联矩阵

每个“资源/场景—因素—结果”的关系，除方向和强度外，还应给出可信度等级。可信度不以单一模型分数决定，而由以下四方面共同判断：

| 评价维度 | 核查内容 |
| --- | --- |
| 数据闭环与质量 | 任务、资源、结果是否完整对应；关键字段缺失率、异常率和时间对齐情况。 |
| 样本充分性 | 可用事件数、资源数，以及同一资源重复任务次数是否足以支持估计。 |
| 统计稳定性 | 置信区间、替代口径、分时段和分资源组估计下，影响方向是否一致。 |
| 业务合理性 | 结果是否符合资源物理边界、调度控制逻辑与市场规则，并经业务人员校核。 |

第一版可先用“高/中/低/待评价”表示可信度，避免在数据量不足时伪造精确评分。只有可信度达到预先约定要求的关系，才作为后续能力量化和资源分类的有效输入。

## 5. 数据到位后的实际执行顺序

1. 选定首批资源类型、市场场景、结果指标和一个重点因素；
2. 执行事件样本构建，输出数据闭环与质量检查清单；
3. 由业务人员复核初始因果图，确定 GAMM 的最小变量集；
4. 拟合基础 GAMM，检查资源随机效应、非线性曲线和模型诊断结果；
5. 对稳定的曲线开展候选阈值识别与分组/分时段复核；
6. 形成带可信度的关联矩阵和关键关系图，作为后续可调容量分析和资源分级分类的输入。

## 6. 验证方式与当前边界

验证分为两类：一类检查预测或拟合表现，另一类检查机制解释是否可信。后者将结合影响方向、置信区间、替代口径、分组/分时段稳定性、安慰剂检验和业务校核综合判断。

- 当前仅形成算法框架和验证方案，尚未获得真实影响系数、阈值或因果结论；
- “模型精度不低于 90%”是课题后续可调容量与响应能力模型的验收目标，须在真实数据和评价口径明确后单独评价；
