# 模型计算说明（第一版）

## 1. 先把每次调节任务变成一条记录

例如，某储能在 10:00 收到一次下调 100 千瓦、持续 15 分钟的任务。系统记录了它实际完成 80 千瓦、补偿标准、任务前状态等信息。这样的“一次资源参与一次任务”就是一条样本。

表中不需要放所有可获得数据，只放第一版研究问题所需内容：

| 一条样本包含什么 | 用途 |
| --- | --- |
| 资源或资源组标识 | 判断是否为同一资源的重复任务 |
| 实际响应完成比例 | 模型要解释的结果 |
| 市场激励 | 重点研究因素 |
| 要求调节量、持续时间 | 任务本身的难度 |
| 资源能力、任务前状态 | 保证不同资源间比较公平 |
| 时间或市场场景 | 排除时间、场景造成的共同影响 |

## 2. 基础模型在算什么

可以先把模型理解为下面这句话：

> 在资源能力、资源状态和任务难度相近时，市场激励提高一个单位，实际响应完成比例平均会变化多少。

其简化表达为：

```text
完成比例 = 总体水平
        + 市场激励的影响
        + 任务调节量的影响
        + 任务持续时间的影响
        + 资源状态的影响
        + 资源自身的固定差异
        + 未能解释的随机变化
```

模型估计出来的每一项“影响”都包含方向和大小。例如：

- 市场激励系数为正：其他条件相近时，激励更高通常对应更高完成比例；
- 任务持续时间系数为负：任务越长，完成难度可能越高；
- 资源状态系数为正或负：说明资源处于不同状态时的响应表现不同。

这些都是**真实数据到位后才可得出的结果**；当前只是在定义计算方法。

## 3. 为什么要用混合效应模型

不同资源有“天生差异”：有的储能控制性能更好，有的设备可用性较差。若不处理这种差异，模型可能把“某个资源一直表现好”误认为“它所在的高补偿市场造成了表现好”。

混合效应模型将影响分为两类：

| 类型 | 在本项目中的含义 |
| --- | --- |
| 总体影响（固定效应） | 市场激励、任务调节量、持续时间等在所有资源上的平均作用 |
| 个体差异（随机效应） | 每个资源、资源组或运营单位长期偏高/偏低的自身特点 |

因此，它特别适合“同一资源被多次调用”的项目数据。

## 4. 因果图在这里做什么

因果图不是自动生成结论的工具，而是一张“比较规则图”。它帮助我们回答：比较激励高低时，哪些条件必须同时考虑，哪些条件不能误当成独立影响因素。

```text
市场激励 ────────────────> 实际响应完成比例
任务要求 ────────────────> 实际响应完成比例
资源初始状态 ────────────> 实际响应完成比例
资源能力 ────────────────> 实际响应完成比例
时间/市场场景 ──> 市场激励、任务要求、实际响应完成比例
```

例如，某些高激励任务可能恰好出现在更紧张的时段；时间/市场场景同时影响激励和任务难度，因此应作为比较时的共同条件。模型不会因为有因果图就“自动证明因果”，还必须做稳健性检查。

## 5. 阈值分析做什么

平均影响有时会掩盖实际规律。第一版只检查两个容易解释的阈值：

1. 任务持续时间达到多长后，完成比例是否明显下降；
2. 资源初始状态处于什么区间时，完成比例是否明显改变。

实现上可以将样本按区间比较，或在模型中增加分段关系。得到的是“可能的关键区间”，后续需结合业务规则确认，不应直接当作设备安全边界。

## 6. 最终关联矩阵长什么样

矩阵不是简单的相关系数表，而是对模型结果的可读化汇总。

| 资源类型/场景 | 市场激励 | 要求调节量 | 持续时间 | 初始状态 | 结论可信度 |
| --- | --- | --- | --- | --- | --- |
| 储能—需求响应 | 正向、强度待估计 | 负向、强度待估计 | 负向、强度待估计 | 待估计 | 由样本量和稳健性检验确定 |
| 光伏—限发调节 | 待估计 | 待估计 | 待估计 | 待估计 | 待估计 |
| 充电站—需求响应 | 待估计 | 待估计 | 待估计 | 待估计 | 待估计 |

在没有真实数据时，表中只能写“待估计”，不能填入真假不明的数值。

## 7. 数据到位后的实际操作顺序

1. 先检查任务、资源和结果能否正确对应；
2. 计算或核对完成比例；
3. 先画最简单的分组对比图，检查是否存在明显异常；
4. 运行基础混合效应模型；
5. 检查模型结果是否符合物理与业务常识；
6. 再做阈值、稳健性和异质性分析；
7. 输出关联矩阵和解释，而非只给出一个模型分数。
