# 数据到位后的建模准入清单

## 1. 用途

拿到数据后，不应立刻运行模型。先用本清单判断第一版问题能否开展：

> 市场激励与资源实际响应完成比例之间有什么定量关系？

清单只检查第一版需要的最小信息，不要求数据需求表中的所有内容都齐全。

## 2. 四项必过检查

| 检查项 | 至少需要看到什么 | 不满足时怎么办 |
| --- | --- | --- |
| 任务可闭环 | 资源/资源组标识、任务标识、任务时间、目标要求、实际执行结果能对应 | 先与数据提供方补充对应关系；无法闭环时不建模 |
| 结果可计算 | 有系统完成比例，或有目标、基线和实际功率，可计算实际响应完成比例 | 先确认系统考核口径；没有结果指标时调整问题 |
| 重点因素可用 | 有补偿/价格/奖励等市场激励记录，且不同任务之间存在变化 | 没有激励字段时，第一版改研究任务要求或资源状态 |
| 基本可比 | 有资源能力或任务前关键状态，以及任务时段/场景信息 | 只能做描述性比较，不做强因果解释 |

## 3. 推荐但非必需的检查

- 资源个体被重复调用：有助于使用混合效应模型识别资源固有差异；
- 数据质量标记、通信状态和失败原因：有助于解释异常样本；
- 用户授权信息：后续研究参与意愿时再使用；
- 天气信息：选定光伏等环境敏感资源时再使用；
- 市场规则版本：市场机制发生变化时，用于分阶段分析。

## 4. 首次数据检查的实际顺序

1. 列出收到的数据表和字段含义，不急于清洗；
2. 检查资源标识、任务标识和时间字段是否存在、是否能关联；
3. 随机抽取少量任务，人工核对“指令—实际结果—完成比例”是否说得通；
4. 统计不同资源、场景和月份的任务数量，检查是否只集中在少数资源或少数日期；
5. 检查市场激励是否存在大量缺失或始终不变；
6. 形成一页“可否建模”的数据准备结论。

## 5. 数据准备结论的三种情形

| 结论 | 含义 | 下一步 |
| --- | --- | --- |
| 可以建模 | 四项必过检查都满足，数据质量基本可用 | 建立完成比例样本表，运行基础模型 |
| 可调整后建模 | 个别字段缺失，但可用系统口径或替代字段解决 | 记录替代口径，缩小问题后建模 |
| 暂不能建模 | 任务和结果无法对应，或没有可计算结果 | 暂停算法估计，优先解决数据对应或调整研究问题 |

## 6. 第一版不预设固定样本数量

是否“样本足够”不能现在写成一个固定数字。应同时看：

- 不同资源和场景是否都有一定覆盖；
- 重点因素是否存在变化；
- 单个资源是否被重复调用；
- 是否有足够任务用于训练与独立检查。

真实数据到位后，再根据数据规模、缺失情况和资源分布确定样本划分与评价口径。
