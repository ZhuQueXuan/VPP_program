# 空调研究成果 v1.1：首轮基础包有限收口

日期：2026-10-16；现用D063，预测代码/参数保持D062 v1.0。输入上一次和当前室温、当前室外温度、当前该房间空调用电、当前另一个试验房间温度，计算下一次5分钟采样的室温预测值。**参数只对原试验的两个房间核验过。**本轮基础研究按既定六项标准在上述范围内收口；完整空调调节能力、可调容量及真实控制未验证。

## 本轮完成范围与曲线

[六项有限验收](results/basic_research_acceptance_v1_1.json)确认对象/输入输出、曲线公式参数、按用途参照、正向简单组件、公平失败/覆盖及固定复现均有证据。验收覆盖原双区试验的发布值特征和条件室温预测，控制时延、舒适授权和可用容量仍是后续专项，没有从正式研究任务删除。此处“完成”不表示任意空调设备或全部功能可用。

[完整曲线PNG](results/test_temperature_curves_v1_1.png)与[可编辑SVG](results/test_temperature_curves_v1_1.svg)展示全部4评价日×2房间。蓝线为原室温，黑虚线为固定模型预测（按目标时刻对齐），灰色为该房间原发布W；原2304房间温度/功率标签及2288预测全部核对，没有挑最好片段、平滑或拟合新模型。图是回顾展示，不构成新增独立验证；SVG保留矢量和文字，PNG已目检，SVG未另行浏览器渲染。

[特征摘要](results/characteristic_summary_v1_1.json)包含8天×2房间共4608标签及4592组原相邻5分钟温差。发布正功率931、零功率3677；相邻零→正480、正→零480、正→正451、零→零3181。它们是原读数模式，不能当作480次真实启动/停止或控制成功；温差除以5分钟是观察变化率，不是控制后的因果冷却速度。未按不明计量区间积分电量或推物理开机时长。

v1.1只新增上述特征/图和六项验收，预测公式、10系数、输入范围、原2288评价成绩及失败不改。现用发布收据为[release_validation_v1_1.json](results/release_validation_v1_1.json)；v1.0发布收据和D062的evidence_summary.json保留为历史时点，后者“整体未宣告验收”由本次限定验收替代，其他未验能力不变。

双击`运行示例.cmd`，或用Python3运行`run_example.py`。程序仅需标准库，不需要原始数据、work目录或训练环境。示例输入明确为构造值，用来展示调用方式；数值核验及目录外启动已做，未通过桌面自动化验证双击窗口。

| 输入字段 | 含义与单位 |
|---|---|
| T_prev_C | 当前标签前5分钟的原相邻采样室温，℃ |
| T_now_C | 当前采样室温，℃ |
| Tout_C | 当前记录室外温度，℃ |
| P_now_W | 当前记录的该房间空调用电功率，W |
| T_other_C | 当前记录的另一个原试验房间温度，℃ |

调用[最终代码](code/room_temperature.py)的`predict_temperature(inputs, room)`，room只能是原试验房间1或2。返回下一标签温度、温度保持和温差延续两种参照，以及是否超出训练输入范围。缺字段、非数值及非有限输入会拒绝；超训练范围只标记，不剪裁预测，也不承诺域外可靠。没有另一个房间的温度时不能自行补值使用；新设备需要重新验证，不能把room编号理解成通用空调型号。

模型为`T_next = T_now + β·[1, T_now−T_prev, T_out−T_now, P_W/1000, T_other−T_now]`。两个房间各5个系数，[参数](parameters/dual_zone_temperature_v1.json)来自前四天等整日权重线性拟合。它受热平衡和温度记忆启发；系数是统计映射，不能解释成已辨识热阻、热容、COP或功率调节的因果效果。没有使用下一记录功率、天气、另一个房间温度或未来控制作为输入。

八个原CSV共2304时点、两个房间；每文件288行、相邻300秒。候选4608房间行中32个首末边界无法构成前/当前/后三点窗口，准入4576；排除标志可重叠。前四天2025-08-08—11训练2288点，后四天08-12/13/19/20评价2288点，同一试验台的时间留出。缺日期不补齐、不跨文件拼窗口、不随机拆相邻行；原日边界两侧均不入样本。所有数据/校验和与协议见[来源清单](source_manifest.json)。

总体、两个房间、四个评价日及当前发布功率>0的425点，模型均比两个参照双指标改善，达到事前相对标准。原零功率1863点MAE却从0.179659升至0.201626℃，RMSE从0.402177降至0.384128℃；不能声称每种状态都更好。零/正功率是发布读数分组，不能据此认定真实关机/开机。154点超出训练输入范围，仍全部保留。模型总体最差3.566680℃；08-20最差3.564588℃大于温度保持3.3℃。[全部聚合评价](results/validation_metrics.json)和[范围摘要](results/evidence_summary.json)包含失败，未事后改路由或门槛。

原CSV由独立解析器重建4608候选及23040准入标志，显式SVD独立复算训练系数/2288预测/204数值指标，五科研产物复跑相同。原最终代码对所有2288点回放及目录外构造例见[v1.0回放](results/release_validation_v1_0.json)；代码/参数指纹不变与新增证据以[现用v1.1发布核验](results/release_validation_v1_1.json)为准。回放和算术复算不能替代独立场站、传感器标定或现场验证。
