# 分布式光伏研究成果 v1.2.0

日期：2026-10-16。光伏基础研究、固定模型比较与复现归集阶段完成，见[六项限定验收](results/basic_research_acceptance.json)。保留两个计算组件：**组件直流功率重建**和**晴空辐照比例持续预测基线**。前者用同期G/T重建单组件DC；后者用当前屋顶电站功率及已知太阳几何预测下一15分钟发布标签。两者来自不同对象；在线真实提前量、完整电站AC物理模型及调节容量尚未验证。本版仅补充固定模型的九个月检验与范围裁决，计算代码和参数未变。

## 使用

Python3.12已核验。组件DC仅需标准库，运行`python run_example.py`打印三个构造样例。预测例先执行`python -m pip install -r requirements_forecast.txt`安装固定依赖，再运行`python run_forecast_example.py`。两种入口都不读取原始数据或work目录；预测需要pvlib自带的历史晴空气候参数，不调用在线天气接口。

- 最终计算代码：[dc_power.py](code/dc_power.py)。输入POA（W/m²）、背温（℃）、模块P0（W）和温度系数（1/℃）；输出辐照比例对照及温度修正功率（W）、片温代理值与超出实验室矩阵范围提示。
- [必要参数](parameters/iea_supsi_mono_si.json)来自IEA/SUPSI匿名单晶硅组件实验室表，P0=285.68591743441357W、γ约−0.00405/℃，**不是PVDAQ1239的Sharp组件参数**。换组件须另提供相应参数，不能直接乘到其他电站当验证结果。
- [样例](examples/constructed_inputs.json)是人工构造的调用示例，不是新实测结果。输入缺失、非有限值、负辐照或非正温度因子会报错，不静默补值/裁零。

## 组件DC实际验证与限制

[结果摘要](results/validation_summary.json)及[逐月指标](results/monthly_metrics.csv)保留12个月、34,751条主样本。参数由独立实验室表固定，未用室外功率拟合；MAE由15.447978降至7.575081W，RMSE由23.551939降至17.047254W。9个月两指标同时改善，2018年11月RMSE稍差，2018年12月/2019年1月两项均稍差，不能称全年逐月稳定优于基线。

主样本排除12条违反同曲线Pmax≤Voc×Isc等基本条件的记录，并保留全部34,763条有限记录的敏感性结果：MAE15.475940→7.604390W，RMSE23.774093→17.346479W。1,686条缺核心量单列，原记录不裁剪。主样本最差185.843349W且6,465点处于实验室G/T矩阵范围之外，未按误差删点。完整年度文件只覆盖356个有观测日期，未把夜间/缺标签填零或计算完整年发电量。

背温近似片温、总POA近似有效辐照；没有独立光谱、入射角、热梯度或物理时钟校验。默认ΔT=0是近似；ΔT=3仅固定敏感性对照，未据结果选最优。低出力失配的原因未知，未判限发或传感器故障。

PVDAQ1239同期AC重建中，固定温度候选劣于辐照比例，失败保持；没有把DC结果替换为该站AC成绩。代码未识别最大可用AC功率、上调余量、控制时延、真实未来天气或跨站迁移，也不代表103正式90%精度。

## 新增预测基线：当前记录可得假设下的下一标签

[clear_sky_forecast.py](code/clear_sky_forecast.py)输入当前功率W、起点时间及[站点几何](parameters/pvdaq1239_smart_geometry_v1.json)，输出持续法与晴空比例法功率W、目标时刻/比率/回退状态。接口支持批量；当前行必须完整可用。它使用未来已知天文位置和历史晴空气候参数，**没有未来实测辐照/温度、没有功率训练或天气预报接口**。

采用pvlib0.16.1的SPA、Ineichen/Linke历史气候值及各向同性阵面转换。当前理论晴空POA≥20W/m²时，预测=当前功率×下一时刻晴空POA/当前晴空POA，否则维持当前功率。20是固定分母保护阈值，未根据留出误差调节；不裁负值/名牌上限，输出不是可行调度指令。12℃标准温度、反照率0.25等是固定模型近似，元数据几何未独立确认对应2019安装。

在预先选定的2019年8月，2931条三方法共同样本上，持续法→晴空比例法的MAE **980.014330→892.473513W**，RMSE **2442.151493→2392.911893W**，分别改善8.9326%/2.0162%。31天的两指标均改善；最差绝对误差却由17720升至17760.523101W。固定6月AR2在同8月RMSE更低（2204.969122W），但MAE更高（1153.408996W）；不称此法所有指标最优或已可靠预测剧烈天气变化。

[预测摘要](results/smart_forecast_summary.json)及[逐日指标](results/smart_forecast_daily_metrics.csv)保留全部结果。原2976目标标签中2931有目标/起点/上一记录共同功率，公平比较多要求的上一记录只供固定AR2使用；持续/晴空法本身只需当前和目标参照，样本可得数另报2946。原48负功率、缺口和37偏移记录留原处，不插值或补夜间0；缩放1569点/回退1362点。源平均窗口起止及上传延迟未知，故**离线下一发布标签间隔15分钟**不证明实际在线提前15分钟可用。跨站/其他季节/业务绝对精度仍待独立验证。

v1.1代码曾在全部2931共同比较行及低分母/非法输入/目录外构造例上核对，见[历史v1.1发布核验](results/release_validation_v1_1.json)。当前核验为[release_validation_v1_2.json](results/release_validation_v1_2.json)；v1.0/v1.1收据保留历史，其README旧指纹不用于检查现用版本；DC核心、参数及原成绩保持。

## 固定模型九个月检验与阶段裁决（D055）

模型、20W/m²保护阈值、几何和6月AR2系数全部固定，在取得新数值/误差前预选2019-09至2020-05连续九个月。实际取得251日CSV及8月31日边界历史，252文件哈希/ETag核验；10月9—31日无源文件，未补零。26,304个预期目标中23,286个三方法共同样本（88.5265%），目标/起点对样本23,503另报。DST重复或不存在的本地标签及跨UTC非900秒区间按预定规则排除。回拨日两种发布格式有4条歧义功率不一致，均处于事先排除范围，没有据此改值。

总体MAE/RMSE相对改善11.5366%/2.6573%，满足预定“总体及三个季节观察组双改善”的比较标准；**仅5/9个月、91/251个有样本日期双改善**。2020年1、2、4、5月的有限功率只出现0或20W，这四个月晴空法两指标反而略差；设备/计量状态及原因未知。因此不能把低误差解释为正常健康电站全年预测精度，不能把季节合并改善写成每月稳定改善。未删除这些月份或按结果调整模型。

当前功率≥1000W的预定分组仅1779点，MAE1109.124227→967.083873W、RMSE2136.294657→2081.016378W。全部样本最差误差16620→16357.747715W（9月16日13:00）；冬季最差却3180→3415.504331W恶化。AR2在全部观察组MAE386.312171W、RMSE615.830457W，但在秋季和较高出力组RMSE仍低于晴空法；没有一种方法全面最优。
