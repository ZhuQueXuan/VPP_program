# 电动汽车充电设施研究成果 v1.1.0

日期：2026-10-16；现用D058。充电设施首轮基础研究在限定范围内收口，保留两个独立组件：**共同功率指令到同期网侧功率的静态映射**，以及**记录中的指令阶跃与分相电流响应特征提取**。两套数据来自不同实验对象，分别调用，不拼成同一车辆。六项基础检查见[范围与验收记录](results/basic_research_acceptance_v1_1.json)；现场调度端到端时延、可用容量及完整充电资源功能仍未验证。

## 新增：记录级分相电流响应特征

Python仅需标准库；运行`python run_step_example.py`可查看明确标注的构造阶跃样例。原静态例仍用`python run_example.py`。两例可从目录外通过脚本完整路径启动，不读取work或原始数据。

[最终计算代码](code/recorded_step_response.py)的`analyze_recorded_step`接收单次变化后完整15秒的相对时间（整数微秒表示）、某一相电流（A）、事前5秒实测电流中位数、变化前后电流指令（A），输出10%/90%指定变化幅度的首次持续越限时间、采样区间、10%到90%过渡时间，以及末5秒电流偏差。未观测到越限返回空值，不能填成0秒或10秒。整数微秒只是源文件时间的表示方式，不代表仪器有微秒精度。

上游须事先核对：原序时间严格递增；整个[-5,15)秒窗口无超过50毫秒的间隔，窗口两端观测覆盖误差不超过50毫秒；前5秒旧指令与后15秒新指令分别保持不变；两指令均≥6A、变化幅度≥2A、该相事前实测电流中位数≥1A。最后一项只是事前有负荷的条件，不能证明接口状态。完整后窗是回顾分析条件，不能用于实时预测可用性。上述过滤条件为预先固定的研究定义，未作为IEC合规阈值。

计算以`sign(新−旧指令)×(实测电流−事前中位数)/abs(新−旧指令)`衡量进度，分母使用**指令变化幅度**，不使用未来实测终值归一化。首次持续≥100毫秒达到10%或90%时，记最初观测采样时间；越限起点须≤10秒、确认观察最多延至10.1秒，不插值。返回的相邻采样区间并非经过仪器标定的物理时延置信区间。[固定定义](parameters/recorded_step_definition_v1.json)用于说明，修改此文件不会改变已核验代码。

数据取自KIT原始发布v1.0.0的LF Parquet，完整核验24,474,687行、18套记录、16个品牌车型组合、12个品牌。原有9,547次相邻指令变化形成28,641个分相候选，按特征计算前冻结的规则保留1,875次变化、4,928条分相观察（上调2,446，下调2,482）。相别和同一记录内的多次变化存在关联，不是4,928辆独立汽车；18套记录也不是18次单独充电会话。全部排除原因和覆盖见[覆盖统计](results/recorded_step_coverage.json)。

## 原静态组件：使用与输入输出

Python3.12已核验，仅标准库。在本目录运行`python run_example.py`，打印三个人工构造的调用例，不读取work或原始数据。

[最终计算代码](code/common_command_mapping.py)接收同一完整记录的ID2、ID3、ID4三项功率指令（kW）及明确适用对象的[标定参数](parameters/evtec_common_command_v1.json)。三指令必须有限、非负且完全相等，否则报错，不猜哪个接口正在工作。返回直接设定值基线、`min(共同指令,训练拟合截顶点)`估计值及超出训练指令范围标志。超范围仍返回公式值并提示，未验证其精度。

参数按车辆型号、AC/DC与插头组合分别给出15组，不能用于任意同型号车辆或其他充电站。截顶点是训练轨迹的统计参数，**不是实测最大接受功率、可承诺量或保守保证**。例如Fiat DC截顶点约0.973kW，只反映本轮训练曲线的拟合，不能据此认定该车型只能充约1kW。没有SOC、需求、截止/授权或动态状态输入，也没有将拟合值包装成完整物理模型。

上游仍需核对原时间顺序、严格递增及连续性、完整当前行可得。研究中保留原顺序，不排序插值；每行须晚于此前全部epoch，邻接步长0<Δt≤2秒，断点后积累5秒连续历史才评价。2秒与5秒是误差前固定的研究质量条件，不是设备时延或市场要求。代码只实现静态公式，不负责清洗或认定数据合格。

## 实际比较与限制

来源为TU Dortmund实验室EVTEC单向动态试验，8种车型、48实验（25AC/23DC）。同一车型/模式/插头内，按原epoch先后将最早floor(n/2)实验作训练，其余完整实验留出；20训练、28评价，训练103151点、评价159003点。15个分组均保留，训练与评价试验时间不重叠。每个训练实验等权拟合1个截顶点，共15个参数；不随机打散相邻点，不用旧EPFL比例或原德国实验成绩定参数。

263283原行中262154点符合共同指令与时钟规则，1129点排除；原因可重叠，包括639暖机历史不足、513指令不同、42邻接时步不连续、20未超过历史时间高水位。原数据未修改。三个接口指令相等使本轮无需选择活动接口，但不证明某一接口已连接、充电或可用。48组、相关时间点数量与独立车辆/控制事件数分别理解。

|---|---:|---:|---:|
| 全部 | 159003 | 1.518949→0.789190 | 3.016654→1.687642 |

满足预定总体及AC/DC两项误差同时下降的相对标准，整体改善48.0437%/44.0558%。按每实验等权平均MAE为1.193322→0.809652kW、RMSE为2.332540→1.659987kW；不能将点数合并增益当成每实验都有同样增益。

**仅8/15分组、14/28留出实验双指标改善。**Honda AC两项退步；另6组MAE未改善而RMSE改善。全部组均报告，不据成绩切换基线或删组。共同指令>0的108893点，MAE2.159287→1.093708kW、RMSE3.612412→1.980001kW；指令0的50110点两方法完全相同，没有靠修改该组降低误差。

截顶映射最差仍11.524kW：一条Tesla AC记录共同指令0、网侧发布功率11.524kW。静态映射不解释该切换记录的物理原因，不能将差值当实际响应时延、故障或控制不合格真值；指令更新、量测同步及动态状态均需更多证据。基线最差11.980kW也保留。

原包是历史已使用数据，本轮只做新冻结模型的受限留出比较，不称新盲测、跨站或独立车辆确认。对所有相关状态作发布值映射，非状态已确认的稳态能力识别，参数不是调度指令。平均误差改善不证明103正式90%精度或绝对业务精度通过。
