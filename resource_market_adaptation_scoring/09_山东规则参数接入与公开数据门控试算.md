# 山东规则参数接入与公开数据门控试算

> 核验日期：2026-09-10  
> 规则基准：《山东电力市场规则（试行）》（2026年4月修订版）  
> 试算程序：`code/run_official_rule_gate_trial.py`  
> 结果目录：`results/official_rule_gate_trial/`

## 1. 直接结论

山东已有规则足以补上大部分“准入门槛”和“调频技术基准”，相关值已进入可更新配置表并用于公开数据门控试算。山东尚未给出可直接用于本项目自动评分的备用市场正式交易阈值，因此备用仍保持“未开市、不可正式评分”；山西规则只作为外省参考场景。

需要区分两类数值：

- **规则要求值**：例如聚合容量不低于1 MW、持续时间不低于1 h或2 h、调频预留功率为额定功率的10%。这些已从正式规则取得。
- **某次任务指令值**：例如某日14:00要求某资源上调0.5 MW、60秒内到位并保持15分钟。它由出清或调度逐次产生，不存在一个可永久写死的统一数值。

现在已经可以计算“是否满足固定准入门槛”；没有逐次指令记录时，仍不能计算真实任务完成率、响应偏差和正式市场适配分。

## 2. 已接入的山东关键规则

| 对象 | 可直接采用的要求 | 用途 |
|---|---:|---|
| 分布式发电类虚拟电厂聚合单元 | 资源总容量不低于1 MW | 现货/绿电供给侧准入门控 |
| 储能类虚拟电厂聚合单元 | 资源总容量不低于1 MW | 现货/调频准入门控 |
| 储能类聚合单元参与电能量市场 | 持续充放电不低于2 h | 现货持续能力门控 |
| 储能类聚合单元参与调频等辅助服务 | 持续充放电不低于15 min | 辅助服务持续能力门控 |
| 调节量负荷类聚合单元 | 可调节能力不低于1 MW，连续调节不低于1 h | 负荷类现货门控 |
| 火电AGC机组 | 响应时间小于60 s | 调频响应门控 |
| 水电AGC机组 | 响应时间小于20 s | 调频响应门控 |
| AGC稳态偏差 | 不超过额定有功功率的1% | 指令跟踪精度评价 |
| 发电类资源调频预留 | 上、下方向各为额定容量的10% | 调频可用容量约束 |
| 储能类资源调频预留 | 上、下方向各为额定功率的10%，荷电量各预留最大荷电量的5% | 调频功率与SOC约束 |

以上阈值均写入 `config/market_rule_parameters.csv`，并保留适用对象、条款和复核日期。规则允许调度机构动态调整的10%与5%已标注为需定期复核，不当作永久常数。

## 3. 公开数据试算结果

本次只做规则门控，不生成0—100正式市场分。

| 数据对象 | 门控结果 | 解释 |
|---|---|---|
| Manchester 240 kW / 180 kWh储能，作为单个储能聚合单元候选 | 容量不通过；电能量持续时长不通过；辅助服务持续时长通过 | 0.24 MW低于1 MW；额定0.75 h低于2 h，但高于15 min。它可作为聚合资源的一部分，不能作为单体证明整个聚合单元准入。 |
| Manchester储能用于调频预留能力检查 | 只有支持性证据 | 规则要求单方向预留0.024 MW；实测功率绝对值95分位约0.236 MW，但没有证明同一运行点上下双向均可用，也没有山东AGC指令。 |
| EPFL充电站 | 不可判定1 MW可调负荷门槛 | 最大充电功率不是经山东测试认定的“可调节能力”，两者不能等同。 |
| 澳大利亚SGSC聚合负荷 | 容量仅部分事件达到；持续时间证据通过 | 13次事件逐次比较1 MW门槛；持续时间中位数4 h。国外记录只能验证算法和证据链，不能替代山东入市认定。 |

机器可读的逐项比较保存在 `rule_gate_comparison.csv`，程序同时记录命中的山东规则参数编号，便于后续替换为项目真实资源数据。

## 4. 备用市场处理

山东规则目前表述为探索开展备用辅助服务市场，没有给出可用于本项目自动评分的本地响应时间、持续时间、最小申报容量和价格上限。因此：

1. 山东备用市场输出仍为 `reserve_readiness`，不输出正式适配分和收益；
2. 山西正式细则中的“15分钟内响应、持续不少于2小时”登记为 `external_reference_only`；
3. 山西数值只用于算法演示或压力测试，不覆盖山东配置，不写成山东准入要求。

## 5. 下一步真正需要的数据

若要计算“完成率或正式适配分”，需要一张逐次任务表，至少包含：任务编号、主体/聚合单元、指令下发时间、目标功率或调节量、方向、要求响应时间、要求持续时间、允许偏差，以及同时间轴的实际功率。规则给出了比较方法和部分阈值，但不能替市场产生每次指令。
